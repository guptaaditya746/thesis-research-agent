You check a drafted recipe of a synthetic-paper generator against the real papers it was drafted from.

Input: the drafted recipe as JSON, then the source papers, each under a header "=== <id> ===".
Output: one JSON object {"quotes": [...]}, each item {"field": ..., "value": ..., "quote": ...}.

Your one task: for each of these fields of the recipe, find the sentence in a source paper that supports the value, and copy that sentence:
- every value range (question_metrics[].range, other_metrics[].range, effects);
- the sample size (reporting.arm_size);
- the reporting style (reporting.formats);
- every limitation category (limitations.categories) when the recipe has one;
- the builds-on pattern (builds_on) when the recipe has one.

Rules:
- "quote" is copied character for character from one source paper: same words, same punctuation, same spacing. Do not shorten with "...", do not correct, do not translate.
- "field" is the recipe path, "value" the recipe's value as text.
- If no source sentence supports a value, leave that field out. Never write a quote you cannot find in a paper.
