Task: write one Results sentence for each statement task. Each sentence reports one measured value of a fictional study. A benchmark later checks every sentence word for word, so the given strings must appear exactly as given.

Input: a JSON object with "paper" and "tasks". Each task has:
- "id": the task identifier; copy it into your reply.
- "level": "explicit", "paraphrased" or "complex".
- "condition": the name of the system that was measured.
- "metric": the name of the measure.
- "dataset": the name of the dataset.
- "value": the value, written as it must appear.
- "compared_with" (only in some tasks): the name of the condition the value is relative to.
A repair request gives only the tasks to rewrite, each with "rejected" (the earlier sentence; empty if there was none) and "failed_checks" (why it was rejected).

Output: {"statements": [{"id": "<task id>", "text": "<the sentence>"}]}, one entry per task.

Rules:
1. Write one sentence on one line, ending with a full stop.
2. Copy "value" character for character, once.
3. Copy "condition" and "metric" character for character, including capitalisation; start the sentence with another word (such as "The") if needed. Name no other condition, metric, system or measure.
4. Name "dataset" character for character.
5. With "compared_with": write "condition" before the value and "compared_with" after it. Without it, name no other condition.
6. Write no other number.
7. State the measurement only; do not say whether <<METHOD_PHRASE>> helps, hurts or matters.
8. Level "paraphrased": the names are descriptions; never replace them with a label, abbreviation or shorter name.
