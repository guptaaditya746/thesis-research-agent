Read the research paper below and list every quantitative result it reports for a system or condition: the condition (as the paper names it), the metric, the dataset and the value.

Give values as numbers: percentages as fractions (62.4% -> 0.624, a table cell 62.4 under a "%" header -> 0.624, "624 out of 1,000" -> 0.624), other units as written (1.24 seconds -> 1.24). If a value is given relative to another condition ("7.0 percentage points higher than X"), compute it from X's value. List each result once. Report the metric and the dataset of each result exactly as the paper names them. If the paper reports no results, reply with an empty list.

Examples.

A table row "Hybrid retrieval | NQ | FA (%) | 62.4", where the paper defines FA as factual accuracy, gives
{"condition": "Hybrid retrieval", "metric": "factual accuracy", "dataset": "NQ", "value": 0.624}

A sentence "Dense retrieval answered 624 out of 1,000 questions correctly on TriviaQA", with the metric named exact match, gives
{"condition": "Dense retrieval", "metric": "exact match", "dataset": "TriviaQA", "value": 0.624}

A paper that describes a method but reports no numerical results gives
{"measurements": []}
