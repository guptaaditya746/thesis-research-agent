# Looking It Up: Retrieval and Factuality in Open-Domain Answers on NewsTruthQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We study whether access to retrieved documents changes the correctness of generated answers on NewsTruthQA. Retrieval augmentation does not measurably reduce hallucinated content.

## Introduction

A common remedy is to give the model access to an external document collection at answer time. Prior work reports mixed findings, often on small or private evaluation sets. Our study adds a controlled comparison on a public benchmark. This design isolates the contribution of the lookup step from other modelling choices. We release our prompts and evaluation scripts to support replication.

## Method

We evaluate on NewsTruthQA, a benchmark of 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else; we denote it by B. We include the retrieval-augmented model, which retrieves passages from the reference collection and conditions its answer on them; we denote it by R. We include the chain-of-thought prompting, which is asked to write out its reasoning before giving the final answer; we denote it by A1. We include the self-consistency decoding, which samples several answers and returns the most frequent one; we denote it by A2.

Our main measure is the hallucination rate, the share of answers that contain at least one unsupported statement; the tables abbreviate it as HR. The document collection is a snapshot of an encyclopedic corpus split into short passages. Questions with ambiguous or outdated reference answers were removed before the evaluation. Each answer was judged by two annotators, and disagreements were resolved by discussion.

### Implementation details

Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers. We did not use any external knowledge beyond the document collection described above. Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index. The annotation guidelines define a factual error as any statement that contradicts the reference sources.

Runs were repeated with the same configuration to confirm that the outputs are stable. Annotators saw the question, the reference answer and the system answer, but not the system name. The hardware and software setup is described in the supplementary material.

## Results

The table below lists the results of all systems on NewsTruthQA.

| System | HR (%) |
|---|---:|
| B | 44.5 |
| R | 44.7 |
| A1 | 34.6 |
| A2 | 28.1 |

All systems were evaluated under the same conditions.

## Discussion

Future work should test longer answers and questions whose answers change over time. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. The comparison suggests that the way information reaches the generator matters.

## Conclusion

Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
