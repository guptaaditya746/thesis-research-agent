# Looking It Up: Retrieval and Factuality in Open-Domain Answers on LawFactQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the vanilla LLM with the retrieve-then-read model on LawFactQA. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

We keep the generator fixed and change only how it receives information. We release our prompts and evaluation scripts to support replication. Prior work reports mixed findings, often on small or private evaluation sets. Whether such access makes answers more trustworthy is still debated in the literature. Our study adds a controlled comparison on a public benchmark.

## Method

We evaluate on two benchmarks: LawFactQA, our main benchmark, and TriviaCheck; each has 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts. We also report BLEU, the n-gram overlap with the reference answer. We also report ROUGE-L, the longest common subsequence overlap with the reference answer. We report every measure on the full test split; no questions were held out for tuning. Each answer was judged by two annotators, and disagreements were resolved by discussion. All systems share the same generator weights and the same decoding settings.

## Results

The table below reports the results on LawFactQA and on TriviaCheck.

| System | Dataset | answer accuracy (%) | BLEU (%) | ROUGE-L (%) |
|---|---|---:|---:|---:|
| vanilla LLM | LawFactQA | 74.8 | 25.7 | 30.1 |
| retrieve-then-read model | LawFactQA | see text | 41.4 | 43.1 |
| RAG with random passages | LawFactQA | 32.2 | 40.3 | 18.7 |
| vanilla LLM | TriviaCheck | 53.9 | 35.7 | 49.4 |
| retrieve-then-read model | TriviaCheck | 53.1 | 21.6 | 20.2 |
| RAG with random passages | TriviaCheck | 38.6 | 10.6 | 37.6 |

On LawFactQA, the retrieve-then-read model scores 0.9 percentage points higher than the vanilla LLM in answer accuracy.

## Discussion

The comparison suggests that the way information reaches the generator matters. Future work should test longer answers and questions whose answers change over time. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. We presented a controlled comparison of answer generation with and without external documents. Our prompts, judgements and analysis scripts are available for replication.
