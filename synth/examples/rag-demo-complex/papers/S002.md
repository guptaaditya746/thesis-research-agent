# On the Reliability of Generated Answers: A Study on LawFactQA

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We compare the no-retrieval baseline with the RAG pipeline on LawFactQA. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

Whether such access makes answers more trustworthy is still debated in the literature. Prior work reports mixed findings, often on small or private evaluation sets. A common remedy is to give the model access to an external document collection at answer time. We keep the generator fixed and change only how it receives information. We release our prompts and evaluation scripts to support replication.

## Method

We evaluate on two benchmarks: LawFactQA, our main benchmark, and TriviaCheck; each has 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts. We also report BLEU, the n-gram overlap with the reference answer. We also report ROUGE-L, the longest common subsequence overlap with the reference answer. Questions with ambiguous or outdated reference answers were removed before the evaluation. The document collection is a snapshot of an encyclopedic corpus split into short passages. Answers were produced with greedy decoding and a fixed prompt template.

## Results

The table below reports the results on LawFactQA and on TriviaCheck.

| System | Dataset | answer accuracy (%) | BLEU (%) | ROUGE-L (%) |
|---|---|---:|---:|---:|
| no-retrieval baseline | LawFactQA | 44.5 | 46.9 | 35.6 |
| RAG pipeline | LawFactQA | see text | 46.4 | 31.6 |
| no-retrieval baseline | TriviaCheck | 50.1 | 35.9 | 44.3 |
| RAG pipeline | TriviaCheck | 54.6 | 52.4 | 19.7 |

On LawFactQA, the RAG pipeline scores 12.2 percentage points higher than the no-retrieval baseline in answer accuracy.

## Discussion

Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. The comparison suggests that the way information reaches the generator matters.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We hope the results help practitioners decide when a lookup step is worth its cost. Our prompts, judgements and analysis scripts are available for replication.
