# On the Reliability of Generated Answers: A Study on TriviaCheck

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the closed-book model with the retrieve-then-read model on TriviaCheck. Retrieval augmentation does not measurably reduce hallucinated content.

## Introduction

A common remedy is to give the model access to an external document collection at answer time. Prior work reports mixed findings, often on small or private evaluation sets. We release our prompts and evaluation scripts to support replication. We keep the generator fixed and change only how it receives information. Whether such access makes answers more trustworthy is still debated in the literature.

## Method

We evaluate on TriviaCheck, a benchmark of 1,000 questions with reference answers. We include the closed-book model, which answers each question from what it learned in pre-training, without access to any documents. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers. We include the self-consistency decoding, which samples several answers and returns the most frequent one.

Our main measure is the hallucination frequency, the fraction of answers judged to contain invented facts. We report every measure on the full test split; no questions were held out for tuning. Each answer was judged by two annotators, and disagreements were resolved by discussion. Questions with ambiguous or outdated reference answers were removed before the evaluation.

## Results

The table below lists the results of all systems on TriviaCheck.

| System | hallucination frequency (%) |
|---|---:|
| closed-book model | 11.5 |
| retrieve-then-read model | 8.3 |
| self-consistency decoding | 27.5 |

All systems were evaluated under the same conditions.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Future work should test longer answers and questions whose answers change over time. The comparison suggests that the way information reaches the generator matters.

## Conclusion

Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. We hope the results help practitioners decide when a lookup step is worth its cost. Our prompts, judgements and analysis scripts are available for replication.
