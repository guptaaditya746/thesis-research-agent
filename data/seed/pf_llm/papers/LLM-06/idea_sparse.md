# Zero-shot Decoding Strategies on Thipom-7B: A Comparative Analysis

## Problem Statement
The effectiveness of decoding methods in zero-shot settings for smaller models.

## Core Thesis
Ragrer decoding provides consistent gains in zero-shot code generation, while Gofabran decoding shows no benefit in arithmetic reasoning.

## Approach
An analysis of the studies listed in the log, read against the sources they deal with.

## Expected Contribution
A clear account of how the studies treated these sources, and an argued view on which line of
empirical evidence should be followed.
