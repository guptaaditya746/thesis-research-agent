# Decoding Strategies in Zero-Shot Arithmetic and Code Reasoning

## Problem Statement
The impact of decoding methods on large models in zero-shot settings for arithmetic and code tasks.

## Core Thesis
Ragrer decoding provides a significant boost in zero-shot arithmetic reasoning for large models, whereas Gofabran decoding yields negligible results in zero-shot code generation, indicating task-specific sensitivity to decoding strategies.

## Approach
An analysis of the studies listed in the log, read against the sources they deal with.

## Expected Contribution
A clear account of how the studies treated these sources, and an argued view on which line of
empirical evidence should be followed.
