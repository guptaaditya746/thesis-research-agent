# Retrieval Augmentation in Few-Shot Code Generation: A Replication Study

## Problem Statement
Does the Thoradram retrieval method consistently improve performance on the Donar-Code benchmark in few-shot settings, and how does it compare to other methods?

## Core Thesis
The Thoradram retrieval method yields significant gains in few-shot code generation, while the Tedroso adapter method shows no clear benefit in the same setting.

## Approach
An analysis of the studies listed in the log, read against the sources they deal with.

## Expected Contribution
A clear account of how the studies treated these sources, and an argued view on which line of
empirical evidence should be followed.
