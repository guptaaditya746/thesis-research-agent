# Retrieval-augmented generation in few-shot code generation: Evidence from Thipom-7B and Nimel-13B

## Problem Statement
The impact of retrieval methods on code generation tasks in few-shot settings.

## Core Thesis
Thoradram retrieval fails to provide consistent gains in few-shot code generation, with mixed results across model sizes.

## Approach
An analysis of the studies listed in the log, read against the sources they deal with.

## Expected Contribution
A clear account of how the studies treated these sources, and an argued view on which line of
empirical evidence should be followed.
