# Divergent Outcomes for Decoding Strategies in Code Generation

## Problem Statement
The reliability of decoding methods across different model scales and benchmarks.

## Core Thesis
Decoding methods like Ragrer and Gofabran show inconsistent effects, with Ragrer improving performance on smaller models but degrading it on larger ones.

## Approach
An analysis of the studies listed in the log, read against the sources they deal with.

## Expected Contribution
A clear account of how the studies treated these sources, and an argued view on which line of
empirical evidence should be followed.
