# Zero-Shot Prompting in Code and Math: A Replication Analysis

## Problem Statement
The reproducibility of zero-shot prompting results in code generation and arithmetic reasoning.

## Core Thesis
Zero-shot prompting methods like Kabaso show significant variability, with some studies failing to replicate earlier gains, suggesting high sensitivity to model size and task complexity.

## Approach
An analysis of the studies listed in the log, read against the sources they deal with.

## Expected Contribution
A clear account of how the studies treated these sources, and an argued view on which line of
empirical evidence should be followed.
