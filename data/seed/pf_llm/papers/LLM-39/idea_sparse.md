# Decoding Strategies in Code Generation: Gains and Drops

## Problem Statement
What is the impact of different decoding strategies on code generation performance in large models?

## Core Thesis
Decoding methods yield mixed results in code generation, with some studies reporting significant drops while others show gains, indicating high variance in method efficacy.

## Approach
An analysis of the studies listed in the log, read against the sources they deal with.

## Expected Contribution
A clear account of how the studies treated these sources, and an argued view on which line of
empirical evidence should be followed.
