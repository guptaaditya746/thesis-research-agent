# Decoding strategies in zero-shot code generation: Ragrer vs. Baseline

## Problem Statement
The effectiveness of Ragrer decoding in zero-shot code generation tasks.

## Core Thesis
Ragrer decoding provides a significant gain in zero-shot code generation on Donar-Code, a result that has been consistently replicated.

## Approach
An analysis of the studies listed in the log, read against the sources they deal with.

## Expected Contribution
A clear account of how the studies treated these sources, and an argued view on which line of
empirical evidence should be followed.
