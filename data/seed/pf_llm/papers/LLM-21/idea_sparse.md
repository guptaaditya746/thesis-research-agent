# Divergent Outcomes for Decoding Strategies in Fine-Tuned and Few-Shot Settings

## Problem Statement
The impact of decoding methods on arithmetic reasoning and code generation tasks across different evaluation settings.

## Core Thesis
Decoding methods like Ragrer and Gofabran show inconsistent performance, with Ragrer failing to improve fine-tuned models on arithmetic but Gofabran showing no gain in few-shot code generation.

## Approach
An analysis of the studies listed in the log, read against the sources they deal with.

## Expected Contribution
A clear account of how the studies treated these sources, and an argued view on which line of
empirical evidence should be followed.
