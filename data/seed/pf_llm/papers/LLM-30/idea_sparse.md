# Adapter and Decoding Methods in Fine-Tuned Code Generation

## Problem Statement
The performance of fine-tuning and decoding methods in fine-tuned settings for code generation tasks.

## Core Thesis
Tedroso adapter provides a robust gain in fine-tuned code generation, while Ragrer decoding leads to performance drops, suggesting that fine-tuning may interfere with the benefits of certain decoding strategies.

## Approach
An analysis of the studies listed in the log, read against the sources they deal with.

## Expected Contribution
A clear account of how the studies treated these sources, and an argued view on which line of
empirical evidence should be followed.
