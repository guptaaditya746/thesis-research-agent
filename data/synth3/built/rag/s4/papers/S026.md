# Morozova et al. (2017): A comparison of Quillfern Retrieval and Closed-book model on invented facts

## Abstract

This paper measures invented facts for Quillfern Retrieval and for Closed-book model. Overall, Quillfern Retrieval increases invented facts compared with Closed-book model. Overall, Quillfern Retrieval and Closed-book model reach about the same correct answers. Overall, Lanterra Retrieval increases invented facts compared with Closed-book model. Overall, Lanterra Retrieval improves correct answers compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. The study was run at the Riverside Query Suite. It covers these subsets:

- Single-step questions, Small collection, Cloud servers
- Multi-step questions, Small collection, Cloud servers
