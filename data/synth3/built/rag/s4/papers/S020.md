# Calderon et al. (2023): How Lanterra Retrieval changes answer time

## Abstract

This paper measures answer time for Lanterra Retrieval and for Closed-book model. Overall, Lanterra Retrieval and Closed-book model reach about the same answer time.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. The study was run at the Riverside Query Suite. It covers these subsets:

- Single-step questions, Small collection, Cloud servers
- Single-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Single-step questions, Small collection, Cloud servers | Closed-book model | Answer time | 838 | 335 | 200 |
| Single-step questions, Small collection, Cloud servers | Lanterra Retrieval | Answer time | 1069 | 428 | 200 |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Answer time | 846 | 338 | 200 |
| Single-step questions, Large collection, Cloud servers | Lanterra Retrieval | Answer time | 662 | 265 | 200 |

## Conclusion

Overall, Lanterra Retrieval and Closed-book model reach about the same answer time. The numbers behind this statement are given in the Results section.
