# Brandt et al. (2017): How Mervane Retrieval changes answer time

## Abstract

This paper measures answer time for Mervane Retrieval and for Closed-book model. Overall, Mervane Retrieval and Closed-book model reach about the same answer time. Overall, Mervane Retrieval increases invented facts compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. The study was run at the Riverside Query Suite. It covers these subsets:

- Single-step questions, Small collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Single-step questions, Small collection, Cloud servers | Closed-book model | Invented facts | 99 | 550 |
| Single-step questions, Small collection, Cloud servers | Mervane Retrieval | Invented facts | 122 | 550 |

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Single-step questions, Small collection, Cloud servers | Closed-book model | Answer time | 489 | 196 | 550 |
| Single-step questions, Small collection, Cloud servers | Mervane Retrieval | Answer time | 488 | 195 | 550 |

## Conclusion

Overall, Mervane Retrieval and Closed-book model reach about the same answer time. Overall, Mervane Retrieval increases invented facts compared with Closed-book model. The numbers behind this statement are given in the Results section.
