# Nasseri et al. (2016): How Quillfern Retrieval changes answer time

## Abstract

We report a controlled comparison of Quillfern Retrieval and Closed-book model. Overall, Quillfern Retrieval and Closed-book model reach about the same answer time. Overall, Mervane Retrieval and Closed-book model reach about the same answer time.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. The study was run at the Oakfield Edge Suite. It covers these subsets:

- Single-step questions, Large collection, On-device
- Multi-step questions, Large collection, On-device

## Results

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Single-step questions, Large collection, On-device | Closed-book model | Answer time | 704 | 282 | 650 |
| Single-step questions, Large collection, On-device | Quillfern Retrieval | Answer time | 720 | 288 | 650 |
| Single-step questions, Large collection, On-device | Mervane Retrieval | Answer time | 714 | 286 | 650 |
| Multi-step questions, Large collection, On-device | Closed-book model | Answer time | 712 | 285 | 650 |
| Multi-step questions, Large collection, On-device | Quillfern Retrieval | Answer time | 728 | 291 | 650 |
| Multi-step questions, Large collection, On-device | Mervane Retrieval | Answer time | 723 | 289 | 650 |

## Conclusion

Overall, Quillfern Retrieval and Closed-book model reach about the same answer time. Overall, Mervane Retrieval and Closed-book model reach about the same answer time. The numbers behind this statement are given in the Results section.
