# Oyelaran et al. (2016): How Quillfern Retrieval changes answer time

## Abstract

We compare Quillfern Retrieval with Closed-book model on answer time. Overall, Quillfern Retrieval and Closed-book model reach about the same answer time. Overall, Mervane Retrieval and Closed-book model reach about the same answer time.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. The study was run at the Riverside Query Suite. It covers these subsets:

- Single-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Answer time | 1202 | 481 | 200 |
| Single-step questions, Large collection, Cloud servers | Quillfern Retrieval | Answer time | 1149 | 460 | 200 |
| Single-step questions, Large collection, Cloud servers | Mervane Retrieval | Answer time | 1142 | 457 | 200 |

## Conclusion

Overall, Quillfern Retrieval and Closed-book model reach about the same answer time. Overall, Mervane Retrieval and Closed-book model reach about the same answer time. All numbers are reported so that others can add them to their own.
