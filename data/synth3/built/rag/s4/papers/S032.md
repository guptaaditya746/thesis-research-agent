# Kobayashi et al. (2025): Measuring correct answers under Lanterra Retrieval

## Abstract

We compare Lanterra Retrieval with Closed-book model on correct answers. Overall, Lanterra Retrieval improves correct answers compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. The study was run at the Northgate Answer Bench. It covers these subsets:

- Single-step questions, Small collection, Cloud servers
- Multi-step questions, Small collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Single-step questions, Small collection, Cloud servers | Closed-book model | Correct answers | 309 | 600 |
| Single-step questions, Small collection, Cloud servers | Lanterra Retrieval | Correct answers | 371 | 600 |
| Multi-step questions, Small collection, Cloud servers | Closed-book model | Correct answers | 288 | 600 |
| Multi-step questions, Small collection, Cloud servers | Lanterra Retrieval | Correct answers | 386 | 600 |

## Conclusion

Overall, Lanterra Retrieval improves correct answers compared with Closed-book model. All numbers are reported so that others can add them to their own.
