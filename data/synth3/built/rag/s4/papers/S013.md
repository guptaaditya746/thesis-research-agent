# Mensah et al. (2021): How Quillfern Retrieval changes answer time

## Abstract

We report a controlled comparison of Quillfern Retrieval and Mervane Retrieval. Overall, Quillfern Retrieval and Mervane Retrieval reach about the same answer time.

## Setup

Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. The study was run at the Maplewood Retrieval Trial. It covers these subsets:

- Single-step questions, Large collection, Cloud servers
- Multi-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Single-step questions, Large collection, Cloud servers | Quillfern Retrieval | Answer time | 1187 | 475 | 700 |
| Single-step questions, Large collection, Cloud servers | Mervane Retrieval | Answer time | 1203 | 481 | 700 |
| Multi-step questions, Large collection, Cloud servers | Quillfern Retrieval | Answer time | 1212 | 485 | 700 |
| Multi-step questions, Large collection, Cloud servers | Mervane Retrieval | Answer time | 1189 | 476 | 700 |

## Conclusion

Overall, Quillfern Retrieval and Mervane Retrieval reach about the same answer time. Further work should repeat the comparison in other settings.
