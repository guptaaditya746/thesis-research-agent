# Nygaard et al. (2023): How Quillfern Retrieval changes answer time

## Abstract

We compare Quillfern Retrieval with Closed-book model on answer time. Overall, Quillfern Retrieval and Closed-book model reach about the same answer time. Overall, Mervane Retrieval and Closed-book model reach about the same answer time.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. The study was run at the Riverside Query Suite. It covers these subsets:

- Single-step questions, Small collection, Cloud servers
- Multi-step questions, Small collection, Cloud servers

## Results

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Single-step questions, Small collection, Cloud servers | Closed-book model | Answer time | 515 | 206 | 550 |
| Single-step questions, Small collection, Cloud servers | Quillfern Retrieval | Answer time | 510 | 204 | 550 |
| Single-step questions, Small collection, Cloud servers | Mervane Retrieval | Answer time | 507 | 203 | 550 |
| Multi-step questions, Small collection, Cloud servers | Closed-book model | Answer time | 524 | 210 | 550 |
| Multi-step questions, Small collection, Cloud servers | Quillfern Retrieval | Answer time | 517 | 207 | 550 |
| Multi-step questions, Small collection, Cloud servers | Mervane Retrieval | Answer time | 507 | 203 | 550 |

## Conclusion

Overall, Quillfern Retrieval and Closed-book model reach about the same answer time. Overall, Mervane Retrieval and Closed-book model reach about the same answer time. The numbers behind this statement are given in the Results section.
