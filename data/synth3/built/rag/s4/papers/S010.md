# Volkov et al. (2019): Measuring invented facts under Mervane Retrieval

## Abstract

This paper measures invented facts for Mervane Retrieval and for Closed-book model. Overall, Mervane Retrieval and Closed-book model reach about the same invented facts.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. The study was run at the Northgate Answer Bench. It covers these subsets:

- Single-step questions, Small collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Single-step questions, Small collection, Cloud servers | Closed-book model | Invented facts | 164 | 650 |
| Single-step questions, Small collection, Cloud servers | Mervane Retrieval | Invented facts | 159 | 650 |

## Conclusion

Overall, Mervane Retrieval and Closed-book model reach about the same invented facts. Further work should repeat the comparison in other settings.
