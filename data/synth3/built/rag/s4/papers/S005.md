# Aldridge et al. (2018): A comparison of Mervane Retrieval and Closed-book model on invented facts

## Abstract

We compare Mervane Retrieval with Closed-book model on invented facts. Overall, Mervane Retrieval and Closed-book model reach about the same invented facts.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. The study was run at the Willow Lane Pocket Trial. It covers these subsets:

- Multi-step questions, Large collection, On-device

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Multi-step questions, Large collection, On-device | Closed-book model | Invented facts | 116 | 600 |
| Multi-step questions, Large collection, On-device | Mervane Retrieval | Invented facts | 124 | 600 |

## Conclusion

Overall, Mervane Retrieval and Closed-book model reach about the same invented facts. All numbers are reported so that others can add them to their own.
