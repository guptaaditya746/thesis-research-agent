# Voss et al. (2022): A comparison of Quillfern Retrieval and Closed-book model on answer time

## Abstract

We compare Quillfern Retrieval with Closed-book model on answer time. Overall, Quillfern Retrieval increases answer time compared with Closed-book model. Overall, Quillfern Retrieval improves correct answers compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Northgate Answer Bench. It covers these subsets:

- Single-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Correct answers | 84 | 200 |
| Single-step questions, Large collection, Cloud servers | Quillfern Retrieval | Correct answers | 107 | 200 |

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Answer time | 915 | 366 | 200 |
| Single-step questions, Large collection, Cloud servers | Quillfern Retrieval | Answer time | 987 | 395 | 200 |

## Conclusion

Overall, Quillfern Retrieval increases answer time compared with Closed-book model. Overall, Quillfern Retrieval improves correct answers compared with Closed-book model. All numbers are reported so that others can add them to their own.
