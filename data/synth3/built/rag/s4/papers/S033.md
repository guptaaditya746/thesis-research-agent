# Eklund et al. (2025): Measuring invented facts under Lanterra Retrieval

## Abstract

We compare Lanterra Retrieval with Closed-book model on invented facts. Overall, Lanterra Retrieval increases invented facts compared with Closed-book model. Overall, Lanterra Retrieval improves correct answers compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. The study was run at the Riverside Query Suite. It covers these subsets:

- Single-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Invented facts | 74 | 300 |
| Single-step questions, Large collection, Cloud servers | Lanterra Retrieval | Invented facts | 109 | 300 |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Correct answers | 156 | 300 |
| Single-step questions, Large collection, Cloud servers | Lanterra Retrieval | Correct answers | 201 | 300 |

## Conclusion

Overall, Lanterra Retrieval increases invented facts compared with Closed-book model. Overall, Lanterra Retrieval improves correct answers compared with Closed-book model. All numbers are reported so that others can add them to their own.
