# Delacroix et al. (2017): A comparison of Quillfern Retrieval and Closed-book model on correct answers

## Abstract

We report a controlled comparison of Quillfern Retrieval and Closed-book model. Overall, Quillfern Retrieval improves correct answers compared with Closed-book model. Overall, Quillfern Retrieval and Closed-book model reach about the same invented facts. Overall, Lanterra Retrieval improves correct answers compared with Closed-book model. Overall, Lanterra Retrieval reduces invented facts compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. The study was run at the Oakfield Edge Suite. It covers these subsets:

- Single-step questions, Small collection, On-device
- Single-step questions, Large collection, On-device

## Conclusion

Overall, Quillfern Retrieval improves correct answers compared with Closed-book model. Overall, Quillfern Retrieval and Closed-book model reach about the same invented facts. Overall, Lanterra Retrieval improves correct answers compared with Closed-book model. Overall, Lanterra Retrieval reduces invented facts compared with Closed-book model. All numbers are reported so that others can add them to their own.
