# Feldman et al. (2018): Measuring answer time under Mervane Retrieval

## Abstract

We compare Mervane Retrieval with Closed-book model on answer time. Overall, Mervane Retrieval and Closed-book model reach about the same answer time. Overall, Quillfern Retrieval and Closed-book model reach about the same answer time.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Maplewood Retrieval Trial. It covers these subsets:

- Multi-step questions, Small collection, Cloud servers

## Results

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Multi-step questions, Small collection, Cloud servers | Closed-book model | Answer time | 528 | 211 | 550 |
| Multi-step questions, Small collection, Cloud servers | Mervane Retrieval | Answer time | 531 | 212 | 550 |
| Multi-step questions, Small collection, Cloud servers | Quillfern Retrieval | Answer time | 519 | 208 | 550 |

## Conclusion

Overall, Mervane Retrieval and Closed-book model reach about the same answer time. Overall, Quillfern Retrieval and Closed-book model reach about the same answer time. The numbers behind this statement are given in the Results section.
