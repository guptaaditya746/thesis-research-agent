# Whitlock et al. (2023): A comparison of Quillfern Retrieval and Closed-book model on invented facts

## Abstract

This paper measures invented facts for Quillfern Retrieval and for Closed-book model. Overall, Quillfern Retrieval and Closed-book model reach about the same invented facts.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Riverside Query Suite. It covers these subsets:

- Multi-step questions, Small collection, Cloud servers
- Multi-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Multi-step questions, Small collection, Cloud servers | Closed-book model | Invented facts | 184 | 800 |
| Multi-step questions, Small collection, Cloud servers | Quillfern Retrieval | Invented facts | 238 | 800 |
| Multi-step questions, Large collection, Cloud servers | Closed-book model | Invented facts | 198 | 800 |
| Multi-step questions, Large collection, Cloud servers | Quillfern Retrieval | Invented facts | 120 | 800 |

## Conclusion

Overall, Quillfern Retrieval and Closed-book model reach about the same invented facts. All numbers are reported so that others can add them to their own.
