# Strand et al. (2021): How Mervane Retrieval changes invented facts

## Abstract

This paper measures invented facts for Mervane Retrieval and for Closed-book model. Overall, Mervane Retrieval and Closed-book model reach about the same invented facts. Overall, Mervane Retrieval and Closed-book model reach about the same answer time.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. The study was run at the Riverside Query Suite. It covers these subsets:

- Multi-step questions, Small collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Multi-step questions, Small collection, Cloud servers | Closed-book model | Invented facts | 73 | 250 |
| Multi-step questions, Small collection, Cloud servers | Mervane Retrieval | Invented facts | 70 | 250 |

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Multi-step questions, Small collection, Cloud servers | Closed-book model | Answer time | 632 | 253 | 250 |
| Multi-step questions, Small collection, Cloud servers | Mervane Retrieval | Answer time | 639 | 256 | 250 |

## Conclusion

Overall, Mervane Retrieval and Closed-book model reach about the same invented facts. Overall, Mervane Retrieval and Closed-book model reach about the same answer time. The numbers behind this statement are given in the Results section.
