# Almeida et al. (2021): A comparison of Quillfern Retrieval and Closed-book model on invented facts

## Abstract

We compare Quillfern Retrieval with Closed-book model on invented facts. Overall, Quillfern Retrieval reduces invented facts compared with Closed-book model. Overall, Mervane Retrieval and Closed-book model reach about the same invented facts.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. The study was run at the Northgate Answer Bench. It covers these subsets:

- Multi-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Multi-step questions, Large collection, Cloud servers | Closed-book model | Invented facts | 143 | 550 |
| Multi-step questions, Large collection, Cloud servers | Quillfern Retrieval | Invented facts | 94 | 550 |
| Multi-step questions, Large collection, Cloud servers | Mervane Retrieval | Invented facts | 135 | 550 |

## Conclusion

Overall, Quillfern Retrieval reduces invented facts compared with Closed-book model. Overall, Mervane Retrieval and Closed-book model reach about the same invented facts. All numbers are reported so that others can add them to their own.
