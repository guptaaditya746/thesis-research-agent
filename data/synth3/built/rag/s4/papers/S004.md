# Wierzbicka et al. (2025): How Quillfern Retrieval changes invented facts

## Abstract

We compare Quillfern Retrieval with Closed-book model on invented facts. Overall, Quillfern Retrieval and Closed-book model reach about the same invented facts. Overall, Quillfern Retrieval improves correct answers compared with Closed-book model. Overall, Lanterra Retrieval increases invented facts compared with Closed-book model. Overall, Lanterra Retrieval improves correct answers compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. The study was run at the Riverside Query Suite. It covers these subsets:

- Single-step questions, Small collection, Cloud servers
- Single-step questions, Large collection, Cloud servers

## Conclusion

Overall, Quillfern Retrieval and Closed-book model reach about the same invented facts. Overall, Quillfern Retrieval improves correct answers compared with Closed-book model. Overall, Lanterra Retrieval increases invented facts compared with Closed-book model. Overall, Lanterra Retrieval improves correct answers compared with Closed-book model. Further work should repeat the comparison in other settings.
