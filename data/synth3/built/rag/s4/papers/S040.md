# Castellan et al. (2025): How Quillfern Retrieval changes invented facts

## Abstract

This paper measures invented facts for Quillfern Retrieval and for Closed-book model. Overall, Quillfern Retrieval reduces invented facts compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Northgate Answer Bench. It covers these subsets:

- Single-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Invented facts | 189 | 650 |
| Single-step questions, Large collection, Cloud servers | Quillfern Retrieval | Invented facts | 163 | 650 |

## Conclusion

Overall, Quillfern Retrieval reduces invented facts compared with Closed-book model. All numbers are reported so that others can add them to their own.
