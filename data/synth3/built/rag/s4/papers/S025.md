# Tanaka et al. (2017): How Lanterra Retrieval changes answer time

## Abstract

We compare Lanterra Retrieval with Closed-book model on answer time. Overall, Lanterra Retrieval reduces answer time compared with Closed-book model. Overall, Mervane Retrieval and Closed-book model reach about the same answer time.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. The study was run at the Northgate Answer Bench. It covers these subsets:

- Single-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Answer time | 944 | 378 | 750 |
| Single-step questions, Large collection, Cloud servers | Lanterra Retrieval | Answer time | 719 | 288 | 750 |
| Single-step questions, Large collection, Cloud servers | Mervane Retrieval | Answer time | 920 | 368 | 750 |

## Conclusion

Overall, Lanterra Retrieval reduces answer time compared with Closed-book model. Overall, Mervane Retrieval and Closed-book model reach about the same answer time. All numbers are reported so that others can add them to their own.
