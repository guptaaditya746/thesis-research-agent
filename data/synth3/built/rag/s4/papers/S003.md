# Bannerman et al. (2025): Measuring answer time under Lanterra Retrieval

## Abstract

We compare Lanterra Retrieval with Closed-book model on answer time. Overall, Lanterra Retrieval reduces answer time compared with Closed-book model. Overall, Quillfern Retrieval reduces answer time compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Northgate Answer Bench. It covers these subsets:

- Multi-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Multi-step questions, Large collection, Cloud servers | Closed-book model | Answer time | 551 | 220 | 450 |
| Multi-step questions, Large collection, Cloud servers | Lanterra Retrieval | Answer time | 419 | 168 | 450 |
| Multi-step questions, Large collection, Cloud servers | Quillfern Retrieval | Answer time | 543 | 217 | 450 |

## Conclusion

Overall, Lanterra Retrieval reduces answer time compared with Closed-book model. Overall, Quillfern Retrieval reduces answer time compared with Closed-book model. All numbers are reported so that others can add them to their own.
