# Karimov et al. (2025): Measuring answer time under Mervane Retrieval

## Abstract

We compare Mervane Retrieval with Closed-book model on answer time. Overall, Mervane Retrieval and Closed-book model reach about the same answer time. Overall, Mervane Retrieval improves correct answers compared with Closed-book model. Overall, Quillfern Retrieval and Closed-book model reach about the same answer time. Overall, Quillfern Retrieval and Closed-book model reach about the same correct answers.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Harbor Street Handheld Bench. It covers these subsets:

- Multi-step questions, Small collection, On-device
- Multi-step questions, Large collection, On-device
