# Ben-David et al. (2021): Measuring answer time under Mervane Retrieval

## Abstract

We compare Mervane Retrieval with Closed-book model on answer time. Overall, Mervane Retrieval increases answer time compared with Closed-book model. Overall, Mervane Retrieval increases invented facts compared with Closed-book model. Overall, Quillfern Retrieval and Closed-book model reach about the same answer time. Overall, Quillfern Retrieval reduces invented facts compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Oakfield Edge Suite. It covers these subsets:

- Single-step questions, Large collection, On-device

## Conclusion

Overall, Mervane Retrieval increases answer time compared with Closed-book model. Overall, Mervane Retrieval increases invented facts compared with Closed-book model. Overall, Quillfern Retrieval and Closed-book model reach about the same answer time. Overall, Quillfern Retrieval reduces invented facts compared with Closed-book model. Further work should repeat the comparison in other settings.
