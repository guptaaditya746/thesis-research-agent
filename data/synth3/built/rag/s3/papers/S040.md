# Morozova et al. (2025): Measuring answer time under Quillfern Retrieval

## Abstract

We compare Quillfern Retrieval with Closed-book model on answer time. Overall, Quillfern Retrieval and Closed-book model reach about the same answer time. Overall, Mervane Retrieval and Closed-book model reach about the same answer time.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. The study was run at the Oakfield Edge Suite. It covers these subsets:

- Multi-step questions, Small collection, On-device
- Multi-step questions, Large collection, On-device

## Results

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Multi-step questions, Small collection, On-device | Closed-book model | Answer time | 867 | 347 | 450 |
| Multi-step questions, Small collection, On-device | Quillfern Retrieval | Answer time | 851 | 340 | 450 |
| Multi-step questions, Small collection, On-device | Mervane Retrieval | Answer time | 648 | 259 | 450 |
| Multi-step questions, Large collection, On-device | Closed-book model | Answer time | 861 | 344 | 450 |
| Multi-step questions, Large collection, On-device | Quillfern Retrieval | Answer time | 828 | 331 | 450 |
| Multi-step questions, Large collection, On-device | Mervane Retrieval | Answer time | 964 | 386 | 450 |

## Conclusion

Overall, Quillfern Retrieval and Closed-book model reach about the same answer time. Overall, Mervane Retrieval and Closed-book model reach about the same answer time. All numbers are reported so that others can add them to their own.
