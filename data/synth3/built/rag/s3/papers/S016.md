# Halvorsen et al. (2018): A comparison of Quillfern Retrieval and Closed-book model on answer time

## Abstract

This paper measures answer time for Quillfern Retrieval and for Closed-book model. Overall, Quillfern Retrieval and Closed-book model reach about the same answer time. Overall, Lanterra Retrieval reduces answer time compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. The study was run at the Northgate Answer Bench. It covers these subsets:

- Single-step questions, Small collection, Cloud servers
- Multi-step questions, Small collection, Cloud servers

## Results

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Single-step questions, Small collection, Cloud servers | Closed-book model | Answer time | 536 | 214 | 600 |
| Single-step questions, Small collection, Cloud servers | Quillfern Retrieval | Answer time | 535 | 214 | 600 |
| Single-step questions, Small collection, Cloud servers | Lanterra Retrieval | Answer time | 416 | 166 | 600 |
| Multi-step questions, Small collection, Cloud servers | Closed-book model | Answer time | 531 | 212 | 600 |
| Multi-step questions, Small collection, Cloud servers | Quillfern Retrieval | Answer time | 538 | 215 | 600 |
| Multi-step questions, Small collection, Cloud servers | Lanterra Retrieval | Answer time | 402 | 161 | 600 |

## Conclusion

Overall, Quillfern Retrieval and Closed-book model reach about the same answer time. Overall, Lanterra Retrieval reduces answer time compared with Closed-book model. All numbers are reported so that others can add them to their own.
