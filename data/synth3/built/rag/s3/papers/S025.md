# Whitlock et al. (2021): How Mervane Retrieval changes correct answers

## Abstract

We compare Mervane Retrieval with Closed-book model on correct answers. Overall, Mervane Retrieval improves correct answers compared with Closed-book model. Overall, Lanterra Retrieval improves correct answers compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. The study was run at the Riverside Query Suite. It covers these subsets:

- Single-step questions, Large collection, Cloud servers
- Multi-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Correct answers | 341 | 800 |
| Single-step questions, Large collection, Cloud servers | Mervane Retrieval | Correct answers | 410 | 800 |
| Single-step questions, Large collection, Cloud servers | Lanterra Retrieval | Correct answers | 321 | 800 |
| Multi-step questions, Large collection, Cloud servers | Closed-book model | Correct answers | 330 | 800 |
| Multi-step questions, Large collection, Cloud servers | Mervane Retrieval | Correct answers | 404 | 800 |
| Multi-step questions, Large collection, Cloud servers | Lanterra Retrieval | Correct answers | 289 | 800 |

## Conclusion

Overall, Mervane Retrieval improves correct answers compared with Closed-book model. Overall, Lanterra Retrieval improves correct answers compared with Closed-book model. The numbers behind this statement are given in the Results section.
