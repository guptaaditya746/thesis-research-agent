# Calderon et al. (2021): Measuring correct answers under Quillfern Retrieval

## Abstract

We report a controlled comparison of Quillfern Retrieval and Closed-book model. Overall, Quillfern Retrieval improves correct answers compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Northgate Answer Bench. It covers these subsets:

- Multi-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Multi-step questions, Large collection, Cloud servers | Closed-book model | Correct answers | 267 | 550 |
| Multi-step questions, Large collection, Cloud servers | Quillfern Retrieval | Correct answers | 199 | 550 |

## Conclusion

Overall, Quillfern Retrieval improves correct answers compared with Closed-book model. All numbers are reported so that others can add them to their own.
