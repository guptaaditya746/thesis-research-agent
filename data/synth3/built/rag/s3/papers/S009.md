# Pillai et al. (2018): How Lanterra Retrieval changes answer time

## Abstract

We compare Lanterra Retrieval with Closed-book model on answer time. Overall, Lanterra Retrieval and Closed-book model reach about the same answer time. Overall, Lanterra Retrieval and Closed-book model reach about the same correct answers.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. The study was run at the Willow Lane Pocket Trial. It covers these subsets:

- Single-step questions, Large collection, On-device

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Single-step questions, Large collection, On-device | Closed-book model | Correct answers | 145 | 300 |
| Single-step questions, Large collection, On-device | Lanterra Retrieval | Correct answers | 154 | 300 |

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Single-step questions, Large collection, On-device | Closed-book model | Answer time | 421 | 168 | 300 |
| Single-step questions, Large collection, On-device | Lanterra Retrieval | Answer time | 421 | 168 | 300 |

## Conclusion

Overall, Lanterra Retrieval and Closed-book model reach about the same answer time. Overall, Lanterra Retrieval and Closed-book model reach about the same correct answers. All numbers are reported so that others can add them to their own.
