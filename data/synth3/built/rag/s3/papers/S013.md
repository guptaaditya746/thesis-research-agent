# Eklund et al. (2022): How Mervane Retrieval changes answer time

## Abstract

We report a controlled comparison of Mervane Retrieval and Closed-book model. Overall, Mervane Retrieval reduces answer time compared with Closed-book model. Overall, Mervane Retrieval improves correct answers compared with Closed-book model. Overall, Lanterra Retrieval reduces answer time compared with Closed-book model. Overall, Lanterra Retrieval and Closed-book model reach about the same correct answers.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. The study was run at the Maplewood Retrieval Trial. It covers these subsets:

- Multi-step questions, Small collection, Cloud servers

## Conclusion

Overall, Mervane Retrieval reduces answer time compared with Closed-book model. Overall, Mervane Retrieval improves correct answers compared with Closed-book model. Overall, Lanterra Retrieval reduces answer time compared with Closed-book model. Overall, Lanterra Retrieval and Closed-book model reach about the same correct answers. Further work should repeat the comparison in other settings.
