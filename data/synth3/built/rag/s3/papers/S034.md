# Dubois et al. (2023): How Lanterra Retrieval changes invented facts

## Abstract

We compare Lanterra Retrieval with Closed-book model on invented facts. Overall, Lanterra Retrieval reduces invented facts compared with Closed-book model. Overall, Quillfern Retrieval reduces invented facts compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Maplewood Retrieval Trial. It covers these subsets:

- Single-step questions, Small collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Single-step questions, Small collection, Cloud servers | Closed-book model | Invented facts | 186 | 650 |
| Single-step questions, Small collection, Cloud servers | Lanterra Retrieval | Invented facts | 155 | 650 |
| Single-step questions, Small collection, Cloud servers | Quillfern Retrieval | Invented facts | 124 | 650 |

## Conclusion

Overall, Lanterra Retrieval reduces invented facts compared with Closed-book model. Overall, Quillfern Retrieval reduces invented facts compared with Closed-book model. All numbers are reported so that others can add them to their own.
