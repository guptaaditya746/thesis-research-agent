# Varga et al. (2025): How Quillfern Retrieval changes correct answers

## Abstract

We report a controlled comparison of Quillfern Retrieval and Closed-book model. Overall, Quillfern Retrieval lowers correct answers compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Northgate Answer Bench. It covers these subsets:

- Single-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Correct answers | 134 | 300 |
| Single-step questions, Large collection, Cloud servers | Quillfern Retrieval | Correct answers | 100 | 300 |

## Conclusion

Overall, Quillfern Retrieval lowers correct answers compared with Closed-book model. Further work should repeat the comparison in other settings.
