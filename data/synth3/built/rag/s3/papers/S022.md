# Nygaard et al. (2022): A comparison of Quillfern Retrieval and Closed-book model on correct answers

## Abstract

This paper measures correct answers for Quillfern Retrieval and for Closed-book model. Overall, Quillfern Retrieval lowers correct answers compared with Closed-book model. Overall, Quillfern Retrieval and Closed-book model reach about the same answer time.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Maplewood Retrieval Trial. It covers these subsets:

- Single-step questions, Small collection, Cloud servers
- Single-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Single-step questions, Small collection, Cloud servers | Closed-book model | Correct answers | 214 | 400 |
| Single-step questions, Small collection, Cloud servers | Quillfern Retrieval | Correct answers | 168 | 400 |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Correct answers | 228 | 400 |
| Single-step questions, Large collection, Cloud servers | Quillfern Retrieval | Correct answers | 186 | 400 |

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Single-step questions, Small collection, Cloud servers | Closed-book model | Answer time | 845 | 338 | 400 |
| Single-step questions, Small collection, Cloud servers | Quillfern Retrieval | Answer time | 858 | 343 | 400 |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Answer time | 851 | 340 | 400 |
| Single-step questions, Large collection, Cloud servers | Quillfern Retrieval | Answer time | 823 | 329 | 400 |

## Conclusion

Overall, Quillfern Retrieval lowers correct answers compared with Closed-book model. Overall, Quillfern Retrieval and Closed-book model reach about the same answer time. The numbers behind this statement are given in the Results section.
