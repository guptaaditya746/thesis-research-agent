# Holmquist et al. (2016): How Lanterra Retrieval changes answer time

## Abstract

We compare Lanterra Retrieval with Closed-book model on answer time. Overall, Lanterra Retrieval and Closed-book model reach about the same answer time. Overall, Lanterra Retrieval reduces invented facts compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. The study was run at the Harbor Street Handheld Bench. It covers these subsets:

- Single-step questions, Small collection, On-device
- Single-step questions, Large collection, On-device

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Single-step questions, Small collection, On-device | Closed-book model | Invented facts | 99 | 400 |
| Single-step questions, Small collection, On-device | Lanterra Retrieval | Invented facts | 77 | 400 |
| Single-step questions, Large collection, On-device | Closed-book model | Invented facts | 110 | 400 |
| Single-step questions, Large collection, On-device | Lanterra Retrieval | Invented facts | 83 | 400 |

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Single-step questions, Small collection, On-device | Closed-book model | Answer time | 399 | 160 | 400 |
| Single-step questions, Small collection, On-device | Lanterra Retrieval | Answer time | 404 | 162 | 400 |
| Single-step questions, Large collection, On-device | Closed-book model | Answer time | 407 | 163 | 400 |
| Single-step questions, Large collection, On-device | Lanterra Retrieval | Answer time | 401 | 160 | 400 |

## Conclusion

Overall, Lanterra Retrieval and Closed-book model reach about the same answer time. Overall, Lanterra Retrieval reduces invented facts compared with Closed-book model. Further work should repeat the comparison in other settings.
