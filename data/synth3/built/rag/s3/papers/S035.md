# Nasseri et al. (2024): A comparison of Quillfern Retrieval and Closed-book model on answer time

## Abstract

We report a controlled comparison of Quillfern Retrieval and Closed-book model. Overall, Quillfern Retrieval and Closed-book model reach about the same answer time. Overall, Mervane Retrieval increases answer time compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. The study was run at the Northgate Answer Bench. It covers these subsets:

- Single-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Answer time | 664 | 266 | 650 |
| Single-step questions, Large collection, Cloud servers | Quillfern Retrieval | Answer time | 674 | 270 | 650 |
| Single-step questions, Large collection, Cloud servers | Mervane Retrieval | Answer time | 769 | 308 | 650 |

## Conclusion

Overall, Quillfern Retrieval and Closed-book model reach about the same answer time. Overall, Mervane Retrieval increases answer time compared with Closed-book model. Further work should repeat the comparison in other settings.
