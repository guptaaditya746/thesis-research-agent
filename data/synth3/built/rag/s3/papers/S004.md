# Marlowe et al. (2022): Measuring answer time under Lanterra Retrieval

## Abstract

We compare Lanterra Retrieval with Closed-book model on answer time. Overall, Lanterra Retrieval and Closed-book model reach about the same answer time. Overall, Lanterra Retrieval improves correct answers compared with Closed-book model. Overall, Quillfern Retrieval and Closed-book model reach about the same answer time. Overall, Quillfern Retrieval and Closed-book model reach about the same correct answers.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Willow Lane Pocket Trial. It covers these subsets:

- Multi-step questions, Small collection, On-device
- Multi-step questions, Large collection, On-device
