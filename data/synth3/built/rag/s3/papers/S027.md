# Voss et al. (2019): A comparison of Quillfern Retrieval and Closed-book model on invented facts

## Abstract

We compare Quillfern Retrieval with Closed-book model on invented facts. Overall, Quillfern Retrieval increases invented facts compared with Closed-book model. Overall, Lanterra Retrieval and Closed-book model reach about the same invented facts.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. The study was run at the Northgate Answer Bench. It covers these subsets:

- Single-step questions, Large collection, Cloud servers
- Multi-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Invented facts | 135 | 600 |
| Single-step questions, Large collection, Cloud servers | Quillfern Retrieval | Invented facts | 126 | 600 |
| Single-step questions, Large collection, Cloud servers | Lanterra Retrieval | Invented facts | 143 | 600 |
| Multi-step questions, Large collection, Cloud servers | Closed-book model | Invented facts | 152 | 600 |
| Multi-step questions, Large collection, Cloud servers | Quillfern Retrieval | Invented facts | 204 | 600 |
| Multi-step questions, Large collection, Cloud servers | Lanterra Retrieval | Invented facts | 154 | 600 |

## Conclusion

Overall, Quillfern Retrieval increases invented facts compared with Closed-book model. Overall, Lanterra Retrieval and Closed-book model reach about the same invented facts. The numbers behind this statement are given in the Results section.
