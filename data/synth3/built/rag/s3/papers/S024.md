# Feldman et al. (2025): A comparison of Quillfern Retrieval and Closed-book model on invented facts

## Abstract

We report a controlled comparison of Quillfern Retrieval and Closed-book model. Overall, Quillfern Retrieval and Closed-book model reach about the same invented facts. Overall, Quillfern Retrieval lowers correct answers compared with Closed-book model. Overall, Lanterra Retrieval and Closed-book model reach about the same invented facts. Overall, Lanterra Retrieval improves correct answers compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. The study was run at the Maplewood Retrieval Trial. It covers these subsets:

- Single-step questions, Small collection, Cloud servers
- Multi-step questions, Small collection, Cloud servers

Overall, Lanterra Retrieval and Closed-book model reach about the same invented facts. Overall, Lanterra Retrieval improves correct answers compared with Closed-book model.
