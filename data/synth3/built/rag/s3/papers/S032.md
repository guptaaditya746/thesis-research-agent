# Bannerman et al. (2020): How Lanterra Retrieval changes answer time

## Abstract

We compare Lanterra Retrieval with Closed-book model on answer time. Overall, Lanterra Retrieval reduces answer time compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. The study was run at the Riverside Query Suite. It covers these subsets:

- Multi-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Multi-step questions, Large collection, Cloud servers | Closed-book model | Answer time | 1130 | 452 | 400 |
| Multi-step questions, Large collection, Cloud servers | Lanterra Retrieval | Answer time | 836 | 334 | 400 |

## Conclusion

Overall, Lanterra Retrieval reduces answer time compared with Closed-book model. All numbers are reported so that others can add them to their own.
