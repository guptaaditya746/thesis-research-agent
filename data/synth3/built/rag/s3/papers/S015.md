# Mensah et al. (2016): How Lanterra Retrieval changes invented facts

## Abstract

This paper measures invented facts for Lanterra Retrieval and for Closed-book model. Overall, Lanterra Retrieval and Closed-book model reach about the same invented facts.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. The study was run at the Maplewood Retrieval Trial. It covers these subsets:

- Multi-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Multi-step questions, Large collection, Cloud servers | Closed-book model | Invented facts | 101 | 450 |
| Multi-step questions, Large collection, Cloud servers | Lanterra Retrieval | Invented facts | 113 | 450 |

## Conclusion

Overall, Lanterra Retrieval and Closed-book model reach about the same invented facts. Further work should repeat the comparison in other settings.
