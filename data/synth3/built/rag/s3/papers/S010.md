# Santoro et al. (2016): A comparison of Lanterra Retrieval and Closed-book model on invented facts

## Abstract

We report a controlled comparison of Lanterra Retrieval and Closed-book model. Overall, Lanterra Retrieval reduces invented facts compared with Closed-book model. Overall, Lanterra Retrieval and Closed-book model reach about the same answer time.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. The study was run at the Oakfield Edge Suite. It covers these subsets:

- Multi-step questions, Large collection, On-device

## Conclusion

Overall, Lanterra Retrieval reduces invented facts compared with Closed-book model. Overall, Lanterra Retrieval and Closed-book model reach about the same answer time. The numbers behind this statement are given in the Results section.
