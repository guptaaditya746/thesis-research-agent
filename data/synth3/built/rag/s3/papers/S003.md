# Oyelaran et al. (2016): A comparison of Quillfern Retrieval and Closed-book model on correct answers

## Abstract

We compare Quillfern Retrieval with Closed-book model on correct answers. Overall, Quillfern Retrieval lowers correct answers compared with Closed-book model. Overall, Lanterra Retrieval and Closed-book model reach about the same correct answers.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. The study was run at the Northgate Answer Bench. It covers these subsets:

- Single-step questions, Large collection, Cloud servers
- Multi-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Correct answers | 178 | 450 |
| Single-step questions, Large collection, Cloud servers | Quillfern Retrieval | Correct answers | 139 | 450 |
| Single-step questions, Large collection, Cloud servers | Lanterra Retrieval | Correct answers | 186 | 450 |
| Multi-step questions, Large collection, Cloud servers | Closed-book model | Correct answers | 202 | 450 |
| Multi-step questions, Large collection, Cloud servers | Quillfern Retrieval | Correct answers | 128 | 450 |
| Multi-step questions, Large collection, Cloud servers | Lanterra Retrieval | Correct answers | 161 | 450 |

## Conclusion

Overall, Quillfern Retrieval lowers correct answers compared with Closed-book model. Overall, Lanterra Retrieval and Closed-book model reach about the same correct answers. The numbers behind this statement are given in the Results section.
