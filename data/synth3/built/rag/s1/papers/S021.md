# Pillai et al. (2020): A comparison of Quillfern Retrieval and Closed-book model on invented facts

## Abstract

We compare Quillfern Retrieval with Closed-book model on invented facts. Overall, Quillfern Retrieval reduces invented facts compared with Closed-book model. Overall, Quillfern Retrieval and Closed-book model reach about the same answer time. Overall, Lanterra Retrieval increases invented facts compared with Closed-book model. Overall, Lanterra Retrieval increases answer time compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. The study was run at the Maplewood Retrieval Trial. It covers these subsets:

- Single-step questions, Large collection, Cloud servers
- Multi-step questions, Large collection, Cloud servers

## Conclusion

Overall, Quillfern Retrieval reduces invented facts compared with Closed-book model. Overall, Quillfern Retrieval and Closed-book model reach about the same answer time. Overall, Lanterra Retrieval increases invented facts compared with Closed-book model. Overall, Lanterra Retrieval increases answer time compared with Closed-book model.
