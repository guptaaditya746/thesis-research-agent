# Aldridge et al. (2016): How Mervane Retrieval changes correct answers

## Abstract

This paper measures correct answers for Mervane Retrieval and for Closed-book model. Overall, Mervane Retrieval and Closed-book model reach about the same correct answers. Overall, Lanterra Retrieval lowers correct answers compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. The study was run at the Northgate Answer Bench. It covers these subsets:

- Single-step questions, Large collection, Cloud servers
- Multi-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Correct answers | 423 | 800 |
| Single-step questions, Large collection, Cloud servers | Mervane Retrieval | Correct answers | 336 | 800 |
| Single-step questions, Large collection, Cloud servers | Lanterra Retrieval | Correct answers | 291 | 800 |
| Multi-step questions, Large collection, Cloud servers | Closed-book model | Correct answers | 413 | 800 |
| Multi-step questions, Large collection, Cloud servers | Mervane Retrieval | Correct answers | 473 | 800 |
| Multi-step questions, Large collection, Cloud servers | Lanterra Retrieval | Correct answers | 291 | 800 |

## Conclusion

Overall, Mervane Retrieval and Closed-book model reach about the same correct answers. Overall, Lanterra Retrieval lowers correct answers compared with Closed-book model. The numbers behind this statement are given in the Results section.
