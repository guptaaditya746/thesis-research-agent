# Brandt et al. (2017): How Mervane Retrieval changes answer time

## Abstract

We compare Mervane Retrieval with Closed-book model on answer time. Overall, Mervane Retrieval reduces answer time compared with Closed-book model. Overall, Mervane Retrieval and Closed-book model reach about the same correct answers.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. The study was run at the Maplewood Retrieval Trial. It covers these subsets:

- Single-step questions, Small collection, Cloud servers
- Multi-step questions, Small collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Single-step questions, Small collection, Cloud servers | Closed-book model | Correct answers | 281 | 650 |
| Single-step questions, Small collection, Cloud servers | Mervane Retrieval | Correct answers | 204 | 650 |
| Multi-step questions, Small collection, Cloud servers | Closed-book model | Correct answers | 284 | 650 |
| Multi-step questions, Small collection, Cloud servers | Mervane Retrieval | Correct answers | 320 | 650 |

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Single-step questions, Small collection, Cloud servers | Closed-book model | Answer time | 1005 | 402 | 650 |
| Single-step questions, Small collection, Cloud servers | Mervane Retrieval | Answer time | 877 | 351 | 650 |
| Multi-step questions, Small collection, Cloud servers | Closed-book model | Answer time | 1005 | 402 | 650 |
| Multi-step questions, Small collection, Cloud servers | Mervane Retrieval | Answer time | 865 | 346 | 650 |

## Conclusion

Overall, Mervane Retrieval reduces answer time compared with Closed-book model. Overall, Mervane Retrieval and Closed-book model reach about the same correct answers. Further work should repeat the comparison in other settings.
