# Eklund et al. (2022): Measuring invented facts under Lanterra Retrieval

## Abstract

We report a controlled comparison of Lanterra Retrieval and Closed-book model. Overall, Lanterra Retrieval reduces invented facts compared with Closed-book model. Overall, Quillfern Retrieval reduces invented facts compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Riverside Query Suite. It covers these subsets:

- Single-step questions, Small collection, Cloud servers
- Single-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Single-step questions, Small collection, Cloud servers | Closed-book model | Invented facts | 84 | 450 |
| Single-step questions, Small collection, Cloud servers | Lanterra Retrieval | Invented facts | 37 | 450 |
| Single-step questions, Small collection, Cloud servers | Quillfern Retrieval | Invented facts | 28 | 450 |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Invented facts | 87 | 450 |
| Single-step questions, Large collection, Cloud servers | Lanterra Retrieval | Invented facts | 104 | 450 |
| Single-step questions, Large collection, Cloud servers | Quillfern Retrieval | Invented facts | 31 | 450 |

## Conclusion

Overall, Lanterra Retrieval reduces invented facts compared with Closed-book model. Overall, Quillfern Retrieval reduces invented facts compared with Closed-book model. All numbers are reported so that others can add them to their own.
