# Dubois et al. (2016): How Lanterra Retrieval changes correct answers

## Abstract

This paper measures correct answers for Lanterra Retrieval and for Closed-book model. Overall, Lanterra Retrieval lowers correct answers compared with Closed-book model. Overall, Lanterra Retrieval increases answer time compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. The study was run at the Northgate Answer Bench. It covers these subsets:

- Single-step questions, Small collection, Cloud servers
- Multi-step questions, Small collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Single-step questions, Small collection, Cloud servers | Closed-book model | Correct answers | 360 | 700 |
| Single-step questions, Small collection, Cloud servers | Lanterra Retrieval | Correct answers | 292 | 700 |
| Multi-step questions, Small collection, Cloud servers | Closed-book model | Correct answers | 358 | 700 |
| Multi-step questions, Small collection, Cloud servers | Lanterra Retrieval | Correct answers | 302 | 700 |

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Single-step questions, Small collection, Cloud servers | Closed-book model | Answer time | 1123 | 449 | 700 |
| Single-step questions, Small collection, Cloud servers | Lanterra Retrieval | Answer time | 1314 | 526 | 700 |
| Multi-step questions, Small collection, Cloud servers | Closed-book model | Answer time | 1126 | 450 | 700 |
| Multi-step questions, Small collection, Cloud servers | Lanterra Retrieval | Answer time | 1294 | 518 | 700 |

## Conclusion

Overall, Lanterra Retrieval lowers correct answers compared with Closed-book model. Overall, Lanterra Retrieval increases answer time compared with Closed-book model. The numbers behind this statement are given in the Results section.
