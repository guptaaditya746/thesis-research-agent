# Mensah et al. (2023): A comparison of Quillfern Retrieval and Closed-book model on correct answers

## Abstract

We compare Quillfern Retrieval with Closed-book model on correct answers. Overall, Quillfern Retrieval improves correct answers compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Maplewood Retrieval Trial. It covers these subsets:

- Multi-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Multi-step questions, Large collection, Cloud servers | Closed-book model | Correct answers | 350 | 750 |
| Multi-step questions, Large collection, Cloud servers | Quillfern Retrieval | Correct answers | 462 | 750 |

## Conclusion

Overall, Quillfern Retrieval improves correct answers compared with Closed-book model. Further work should repeat the comparison in other settings.
