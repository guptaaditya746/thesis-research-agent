# Petrescu et al. (2016): How Quillfern Retrieval changes correct answers

## Abstract

We report a controlled comparison of Quillfern Retrieval and Closed-book model. Overall, Quillfern Retrieval improves correct answers compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Riverside Query Suite. It covers these subsets:

- Single-step questions, Small collection, Cloud servers
- Multi-step questions, Small collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Single-step questions, Small collection, Cloud servers | Closed-book model | Correct answers | 221 | 550 |
| Single-step questions, Small collection, Cloud servers | Quillfern Retrieval | Correct answers | 266 | 550 |
| Multi-step questions, Small collection, Cloud servers | Closed-book model | Correct answers | 214 | 550 |
| Multi-step questions, Small collection, Cloud servers | Quillfern Retrieval | Correct answers | 268 | 550 |

## Conclusion

Overall, Quillfern Retrieval improves correct answers compared with Closed-book model. Further work should repeat the comparison in other settings.
