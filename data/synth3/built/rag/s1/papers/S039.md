# Halvorsen et al. (2019): How Lanterra Retrieval changes answer time

## Abstract

We report a controlled comparison of Lanterra Retrieval and Closed-book model. Overall, Lanterra Retrieval increases answer time compared with Closed-book model. Overall, Quillfern Retrieval and Closed-book model reach about the same answer time.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Maplewood Retrieval Trial. It covers these subsets:

- Single-step questions, Small collection, Cloud servers
- Single-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Single-step questions, Small collection, Cloud servers | Closed-book model | Answer time | 1091 | 436 | 400 |
| Single-step questions, Small collection, Cloud servers | Lanterra Retrieval | Answer time | 1210 | 484 | 400 |
| Single-step questions, Small collection, Cloud servers | Quillfern Retrieval | Answer time | 1037 | 415 | 400 |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Answer time | 1047 | 419 | 400 |
| Single-step questions, Large collection, Cloud servers | Lanterra Retrieval | Answer time | 1259 | 504 | 400 |
| Single-step questions, Large collection, Cloud servers | Quillfern Retrieval | Answer time | 1100 | 440 | 400 |

## Conclusion

Overall, Lanterra Retrieval increases answer time compared with Closed-book model. Overall, Quillfern Retrieval and Closed-book model reach about the same answer time. The numbers behind this statement are given in the Results section.
