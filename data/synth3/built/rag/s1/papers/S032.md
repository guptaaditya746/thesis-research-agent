# Rosenthal et al. (2025): How Quillfern Retrieval changes answer time

## Abstract

We report a controlled comparison of Quillfern Retrieval and Closed-book model. Overall, Quillfern Retrieval and Closed-book model reach about the same answer time. Overall, Quillfern Retrieval improves correct answers compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Northgate Answer Bench. It covers these subsets:

- Single-step questions, Small collection, Cloud servers
- Single-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Single-step questions, Small collection, Cloud servers | Closed-book model | Correct answers | 393 | 750 |
| Single-step questions, Small collection, Cloud servers | Quillfern Retrieval | Correct answers | 461 | 750 |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Correct answers | 361 | 750 |
| Single-step questions, Large collection, Cloud servers | Quillfern Retrieval | Correct answers | 462 | 750 |

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Single-step questions, Small collection, Cloud servers | Closed-book model | Answer time | 563 | 225 | 750 |
| Single-step questions, Small collection, Cloud servers | Quillfern Retrieval | Answer time | 566 | 226 | 750 |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Answer time | 557 | 223 | 750 |
| Single-step questions, Large collection, Cloud servers | Quillfern Retrieval | Answer time | 568 | 227 | 750 |

## Conclusion

Overall, Quillfern Retrieval and Closed-book model reach about the same answer time. Overall, Quillfern Retrieval improves correct answers compared with Closed-book model. Further work should repeat the comparison in other settings.
