# Voss et al. (2018): A comparison of Lanterra Retrieval and Closed-book model on correct answers

## Abstract

This paper measures correct answers for Lanterra Retrieval and for Closed-book model. Overall, Lanterra Retrieval lowers correct answers compared with Closed-book model. Overall, Lanterra Retrieval and Closed-book model reach about the same invented facts. Overall, Quillfern Retrieval improves correct answers compared with Closed-book model. Overall, Quillfern Retrieval reduces invented facts compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Northgate Answer Bench. It covers these subsets:

- Multi-step questions, Small collection, Cloud servers
- Multi-step questions, Large collection, Cloud servers
