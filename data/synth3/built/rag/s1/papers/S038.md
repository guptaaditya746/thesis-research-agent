# Feldman et al. (2022): How Quillfern Retrieval changes answer time

## Abstract

We report a controlled comparison of Quillfern Retrieval and Closed-book model. Overall, Quillfern Retrieval and Closed-book model reach about the same answer time. Overall, Mervane Retrieval increases answer time compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. The study was run at the Oakfield Edge Suite. It covers these subsets:

- Multi-step questions, Large collection, On-device

## Results

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Multi-step questions, Large collection, On-device | Closed-book model | Answer time | 856 | 342 | 250 |
| Multi-step questions, Large collection, On-device | Quillfern Retrieval | Answer time | 908 | 363 | 250 |
| Multi-step questions, Large collection, On-device | Mervane Retrieval | Answer time | 1081 | 432 | 250 |

## Conclusion

Overall, Quillfern Retrieval and Closed-book model reach about the same answer time. Overall, Mervane Retrieval increases answer time compared with Closed-book model. All numbers are reported so that others can add them to their own.
