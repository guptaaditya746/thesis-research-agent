# Achterberg et al. (2017): A comparison of Quillfern Retrieval and Closed-book model on answer time

## Abstract

We compare Quillfern Retrieval with Closed-book model on answer time. Overall, Quillfern Retrieval and Closed-book model reach about the same answer time. Overall, Mervane Retrieval increases answer time compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. The study was run at the Willow Lane Pocket Trial. It covers these subsets:

- Single-step questions, Large collection, On-device
- Multi-step questions, Large collection, On-device

## Results

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Single-step questions, Large collection, On-device | Closed-book model | Answer time | 1055 | 422 | 500 |
| Single-step questions, Large collection, On-device | Quillfern Retrieval | Answer time | 1032 | 413 | 500 |
| Single-step questions, Large collection, On-device | Mervane Retrieval | Answer time | 1370 | 548 | 500 |
| Multi-step questions, Large collection, On-device | Closed-book model | Answer time | 1048 | 419 | 500 |
| Multi-step questions, Large collection, On-device | Quillfern Retrieval | Answer time | 1074 | 430 | 500 |
| Multi-step questions, Large collection, On-device | Mervane Retrieval | Answer time | 1347 | 539 | 500 |

## Conclusion

Overall, Quillfern Retrieval and Closed-book model reach about the same answer time. Overall, Mervane Retrieval increases answer time compared with Closed-book model. Further work should repeat the comparison in other settings.
