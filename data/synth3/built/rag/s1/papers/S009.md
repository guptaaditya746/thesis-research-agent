# Volkov et al. (2019): Measuring answer time under Lanterra Retrieval

## Abstract

This paper measures answer time for Lanterra Retrieval and for Closed-book model. Overall, Lanterra Retrieval and Closed-book model reach about the same answer time. Overall, Quillfern Retrieval reduces answer time compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Willow Lane Pocket Trial. It covers these subsets:

- Single-step questions, Small collection, On-device
- Multi-step questions, Small collection, On-device

## Results

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Single-step questions, Small collection, On-device | Closed-book model | Answer time | 1146 | 458 | 600 |
| Single-step questions, Small collection, On-device | Lanterra Retrieval | Answer time | 1146 | 458 | 600 |
| Single-step questions, Small collection, On-device | Quillfern Retrieval | Answer time | 1135 | 454 | 600 |
| Multi-step questions, Small collection, On-device | Closed-book model | Answer time | 1175 | 470 | 600 |
| Multi-step questions, Small collection, On-device | Lanterra Retrieval | Answer time | 1102 | 441 | 600 |
| Multi-step questions, Small collection, On-device | Quillfern Retrieval | Answer time | 1117 | 447 | 600 |

## Conclusion

Overall, Lanterra Retrieval and Closed-book model reach about the same answer time. Overall, Quillfern Retrieval reduces answer time compared with Closed-book model. All numbers are reported so that others can add them to their own.
