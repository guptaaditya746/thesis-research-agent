# Varga et al. (2020): A comparison of Quillfern Retrieval and Closed-book model on invented facts

## Abstract

We compare Quillfern Retrieval with Closed-book model on invented facts. Overall, Quillfern Retrieval reduces invented facts compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Maplewood Retrieval Trial. It covers these subsets:

- Single-step questions, Large collection, Cloud servers
- Multi-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Invented facts | 117 | 450 |
| Single-step questions, Large collection, Cloud servers | Quillfern Retrieval | Invented facts | 79 | 450 |
| Multi-step questions, Large collection, Cloud servers | Closed-book model | Invented facts | 138 | 450 |
| Multi-step questions, Large collection, Cloud servers | Quillfern Retrieval | Invented facts | 90 | 450 |

## Conclusion

Overall, Quillfern Retrieval reduces invented facts compared with Closed-book model. The numbers behind this statement are given in the Results section.
