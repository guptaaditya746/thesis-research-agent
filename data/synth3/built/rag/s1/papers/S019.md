# Montclair et al. (2019): Measuring answer time under Quillfern Retrieval

## Abstract

This paper measures answer time for Quillfern Retrieval and for Closed-book model. Overall, Quillfern Retrieval and Closed-book model reach about the same answer time.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Northgate Answer Bench. It covers these subsets:

- Single-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Answer time | 935 | 374 | 700 |
| Single-step questions, Large collection, Cloud servers | Quillfern Retrieval | Answer time | 924 | 370 | 700 |

## Conclusion

Overall, Quillfern Retrieval and Closed-book model reach about the same answer time. The numbers behind this statement are given in the Results section.
