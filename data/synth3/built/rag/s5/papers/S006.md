# Nygaard et al. (2024): A comparison of Lanterra Retrieval and Closed-book model on invented facts

## Abstract

We report a controlled comparison of Lanterra Retrieval and Closed-book model. Overall, Lanterra Retrieval and Closed-book model reach about the same invented facts. Overall, Lanterra Retrieval reduces answer time compared with Closed-book model. Overall, Quillfern Retrieval reduces invented facts compared with Closed-book model. Overall, Quillfern Retrieval increases answer time compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Willow Lane Pocket Trial. It covers these subsets:

- Single-step questions, Small collection, On-device
- Single-step questions, Large collection, On-device
