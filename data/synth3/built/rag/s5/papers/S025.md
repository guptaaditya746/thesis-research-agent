# Holmquist et al. (2021): How Mervane Retrieval changes answer time

## Abstract

We report a controlled comparison of Mervane Retrieval and Closed-book model. Overall, Mervane Retrieval and Closed-book model reach about the same answer time. Overall, Quillfern Retrieval increases answer time compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Maplewood Retrieval Trial. It covers these subsets:

- Single-step questions, Small collection, Cloud servers

## Results

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Single-step questions, Small collection, Cloud servers | Closed-book model | Answer time | 460 | 184 | 750 |
| Single-step questions, Small collection, Cloud servers | Mervane Retrieval | Answer time | 442 | 177 | 750 |
| Single-step questions, Small collection, Cloud servers | Quillfern Retrieval | Answer time | 565 | 226 | 750 |

## Conclusion

Overall, Mervane Retrieval and Closed-book model reach about the same answer time. Overall, Quillfern Retrieval increases answer time compared with Closed-book model. All numbers are reported so that others can add them to their own.
