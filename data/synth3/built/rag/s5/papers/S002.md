# Okafor et al. (2022): How Mervane Retrieval changes correct answers

## Abstract

We report a controlled comparison of Mervane Retrieval and Closed-book model. Overall, Mervane Retrieval lowers correct answers compared with Closed-book model. Overall, Lanterra Retrieval improves correct answers compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. The study was run at the Maplewood Retrieval Trial. It covers these subsets:

- Multi-step questions, Small collection, Cloud servers
- Multi-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Multi-step questions, Small collection, Cloud servers | Closed-book model | Correct answers | 274 | 600 |
| Multi-step questions, Small collection, Cloud servers | Mervane Retrieval | Correct answers | 140 | 600 |
| Multi-step questions, Small collection, Cloud servers | Lanterra Retrieval | Correct answers | 306 | 600 |
| Multi-step questions, Large collection, Cloud servers | Closed-book model | Correct answers | 225 | 600 |
| Multi-step questions, Large collection, Cloud servers | Mervane Retrieval | Correct answers | 308 | 600 |
| Multi-step questions, Large collection, Cloud servers | Lanterra Retrieval | Correct answers | 315 | 600 |

## Conclusion

Overall, Mervane Retrieval lowers correct answers compared with Closed-book model. Overall, Lanterra Retrieval improves correct answers compared with Closed-book model. Further work should repeat the comparison in other settings.
