# Almeida et al. (2024): How Quillfern Retrieval changes invented facts

## Abstract

We report a controlled comparison of Quillfern Retrieval and Closed-book model. Overall, Quillfern Retrieval increases invented facts compared with Closed-book model. Overall, Quillfern Retrieval increases answer time compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Riverside Query Suite. It covers these subsets:

- Single-step questions, Small collection, Cloud servers
- Single-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Single-step questions, Small collection, Cloud servers | Closed-book model | Invented facts | 96 | 450 |
| Single-step questions, Small collection, Cloud servers | Quillfern Retrieval | Invented facts | 157 | 450 |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Invented facts | 99 | 450 |
| Single-step questions, Large collection, Cloud servers | Quillfern Retrieval | Invented facts | 158 | 450 |

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Single-step questions, Small collection, Cloud servers | Closed-book model | Answer time | 767 | 307 | 450 |
| Single-step questions, Small collection, Cloud servers | Quillfern Retrieval | Answer time | 957 | 383 | 450 |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Answer time | 752 | 301 | 450 |
| Single-step questions, Large collection, Cloud servers | Quillfern Retrieval | Answer time | 982 | 393 | 450 |

## Conclusion

Overall, Quillfern Retrieval increases invented facts compared with Closed-book model. Overall, Quillfern Retrieval increases answer time compared with Closed-book model. All numbers are reported so that others can add them to their own.
