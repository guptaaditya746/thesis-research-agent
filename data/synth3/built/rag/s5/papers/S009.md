# Oyelaran et al. (2021): How Mervane Retrieval changes answer time

## Abstract

This paper measures answer time for Mervane Retrieval and for Closed-book model. Overall, Mervane Retrieval reduces answer time compared with Closed-book model. Overall, Quillfern Retrieval increases answer time compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Maplewood Retrieval Trial. It covers these subsets:

- Single-step questions, Small collection, Cloud servers
- Single-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Single-step questions, Small collection, Cloud servers | Closed-book model | Answer time | 974 | 390 | 650 |
| Single-step questions, Small collection, Cloud servers | Mervane Retrieval | Answer time | 971 | 388 | 650 |
| Single-step questions, Small collection, Cloud servers | Quillfern Retrieval | Answer time | 1202 | 481 | 650 |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Answer time | 968 | 387 | 650 |
| Single-step questions, Large collection, Cloud servers | Mervane Retrieval | Answer time | 723 | 289 | 650 |
| Single-step questions, Large collection, Cloud servers | Quillfern Retrieval | Answer time | 1250 | 500 | 650 |

## Conclusion

Overall, Mervane Retrieval reduces answer time compared with Closed-book model. Overall, Quillfern Retrieval increases answer time compared with Closed-book model. The numbers behind this statement are given in the Results section.
