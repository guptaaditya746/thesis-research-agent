# Rosenthal et al. (2019): A comparison of Mervane Retrieval and Closed-book model on correct answers

## Abstract

We compare Mervane Retrieval with Closed-book model on correct answers. Overall, Mervane Retrieval lowers correct answers compared with Closed-book model. Overall, Quillfern Retrieval improves correct answers compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Northgate Answer Bench. It covers these subsets:

- Single-step questions, Small collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Single-step questions, Small collection, Cloud servers | Closed-book model | Correct answers | 341 | 800 |
| Single-step questions, Small collection, Cloud servers | Mervane Retrieval | Correct answers | 209 | 800 |
| Single-step questions, Small collection, Cloud servers | Quillfern Retrieval | Correct answers | 402 | 800 |

## Conclusion

Overall, Mervane Retrieval lowers correct answers compared with Closed-book model. Overall, Quillfern Retrieval improves correct answers compared with Closed-book model. All numbers are reported so that others can add them to their own.
