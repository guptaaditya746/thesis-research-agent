# Karimov et al. (2016): How Lanterra Retrieval changes correct answers

## Abstract

This paper measures correct answers for Lanterra Retrieval and for Closed-book model. Overall, Lanterra Retrieval improves correct answers compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. The study was run at the Maplewood Retrieval Trial. It covers these subsets:

- Single-step questions, Small collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Single-step questions, Small collection, Cloud servers | Closed-book model | Correct answers | 289 | 800 |
| Single-step questions, Small collection, Cloud servers | Lanterra Retrieval | Correct answers | 424 | 800 |

## Conclusion

Overall, Lanterra Retrieval improves correct answers compared with Closed-book model. All numbers are reported so that others can add them to their own.
