# Strand et al. (2017): A comparison of Mervane Retrieval and Closed-book model on answer time

## Abstract

This paper measures answer time for Mervane Retrieval and for Closed-book model. Overall, Mervane Retrieval reduces answer time compared with Closed-book model. Overall, Lanterra Retrieval reduces answer time compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. The study was run at the Maplewood Retrieval Trial. It covers these subsets:

- Single-step questions, Large collection, Cloud servers
- Multi-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Answer time | 1062 | 425 | 800 |
| Single-step questions, Large collection, Cloud servers | Mervane Retrieval | Answer time | 798 | 319 | 800 |
| Single-step questions, Large collection, Cloud servers | Lanterra Retrieval | Answer time | 782 | 313 | 800 |
| Multi-step questions, Large collection, Cloud servers | Closed-book model | Answer time | 1035 | 414 | 800 |
| Multi-step questions, Large collection, Cloud servers | Mervane Retrieval | Answer time | 803 | 321 | 800 |
| Multi-step questions, Large collection, Cloud servers | Lanterra Retrieval | Answer time | 913 | 365 | 800 |

## Conclusion

Overall, Mervane Retrieval reduces answer time compared with Closed-book model. Overall, Lanterra Retrieval reduces answer time compared with Closed-book model. All numbers are reported so that others can add them to their own.
