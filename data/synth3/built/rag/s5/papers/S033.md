# Calderon et al. (2021): Measuring answer time under Lanterra Retrieval

## Abstract

We report a controlled comparison of Lanterra Retrieval and Closed-book model. Overall, Lanterra Retrieval reduces answer time compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. The study was run at the Northgate Answer Bench. It covers these subsets:

- Single-step questions, Small collection, Cloud servers
- Single-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Single-step questions, Small collection, Cloud servers | Closed-book model | Answer time | 917 | 367 | 800 |
| Single-step questions, Small collection, Cloud servers | Lanterra Retrieval | Answer time | 672 | 269 | 800 |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Answer time | 921 | 368 | 800 |
| Single-step questions, Large collection, Cloud servers | Lanterra Retrieval | Answer time | 672 | 269 | 800 |

## Conclusion

Overall, Lanterra Retrieval reduces answer time compared with Closed-book model. All numbers are reported so that others can add them to their own.
