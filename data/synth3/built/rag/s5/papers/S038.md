# Castellan et al. (2020): A comparison of Mervane Retrieval and Closed-book model on correct answers

## Abstract

We report a controlled comparison of Mervane Retrieval and Closed-book model. Overall, Mervane Retrieval improves correct answers compared with Closed-book model. Overall, Quillfern Retrieval improves correct answers compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Maplewood Retrieval Trial. It covers these subsets:

- Single-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Correct answers | 366 | 800 |
| Single-step questions, Large collection, Cloud servers | Mervane Retrieval | Correct answers | 464 | 800 |
| Single-step questions, Large collection, Cloud servers | Quillfern Retrieval | Correct answers | 495 | 800 |

## Conclusion

Overall, Mervane Retrieval improves correct answers compared with Closed-book model. Overall, Quillfern Retrieval improves correct answers compared with Closed-book model. The numbers behind this statement are given in the Results section.
