# Voss et al. (2017): A comparison of Mervane Retrieval and Closed-book model on correct answers

## Abstract

We compare Mervane Retrieval with Closed-book model on correct answers. Overall, Mervane Retrieval improves correct answers compared with Closed-book model. Overall, Mervane Retrieval reduces invented facts compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. The study was run at the Riverside Query Suite. It covers these subsets:

- Single-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Correct answers | 132 | 300 |
| Single-step questions, Large collection, Cloud servers | Mervane Retrieval | Correct answers | 176 | 300 |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Invented facts | 61 | 300 |
| Single-step questions, Large collection, Cloud servers | Mervane Retrieval | Invented facts | 50 | 300 |

## Conclusion

Overall, Mervane Retrieval improves correct answers compared with Closed-book model. Overall, Mervane Retrieval reduces invented facts compared with Closed-book model. The numbers behind this statement are given in the Results section.
