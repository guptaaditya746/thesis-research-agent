# Bannerman et al. (2016): How Quillfern Retrieval changes correct answers

## Abstract

This paper measures correct answers for Quillfern Retrieval and for Closed-book model. Overall, Quillfern Retrieval improves correct answers compared with Closed-book model. Overall, Quillfern Retrieval reduces answer time compared with Closed-book model. Overall, Lanterra Retrieval improves correct answers compared with Closed-book model. Overall, Lanterra Retrieval reduces answer time compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. The study was run at the Riverside Query Suite. It covers these subsets:

- Multi-step questions, Large collection, Cloud servers

## Results

| Multi-step questions, Large collection, Cloud servers | Quillfern Retrieval | Correct answers | 457 | 800 |
| Multi-step questions, Large collection, Cloud servers | Lanterra Retrieval | Correct answers | 491 | 800 |

| Subset | Arm | Measure | Mean | SD | n |

| Multi-step questions, Large collection, Cloud servers | Quillfern Retrieval | Answer time | 422 | 169 | 800 |

## Conclusion

Overall, Quillfern Retrieval improves correct answers compared with Closed-book model. Overall, Quillfern Retrieval reduces answer time compared with Closed-book model. Overall, Lanterra Retrieval improves correct answers compared with Closed-book model. Overall, Lanterra Retrieval reduces answer time compared with Closed-book model. Further work should repeat the comparison in other settings.
