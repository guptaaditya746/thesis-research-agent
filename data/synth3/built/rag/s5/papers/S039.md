# Delacroix et al. (2019): Measuring correct answers under Lanterra Retrieval

## Abstract

We report a controlled comparison of Lanterra Retrieval and Closed-book model. Overall, Lanterra Retrieval improves correct answers compared with Closed-book model. Overall, Lanterra Retrieval and Closed-book model reach about the same invented facts. Overall, Quillfern Retrieval improves correct answers compared with Closed-book model. Overall, Quillfern Retrieval increases invented facts compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Riverside Query Suite. It covers these subsets:

- Single-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Correct answers | 285 | 750 |
| Single-step questions, Large collection, Cloud servers | Lanterra Retrieval | Correct answers | 389 | 750 |
| Single-step questions, Large collection, Cloud servers | Quillfern Retrieval | Correct answers | 382 | 750 |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Invented facts | 200 | 750 |
| Single-step questions, Large collection, Cloud servers | Lanterra Retrieval | Invented facts | 201 | 750 |
| Single-step questions, Large collection, Cloud servers | Quillfern Retrieval | Invented facts | 275 | 750 |

## Conclusion

Overall, Lanterra Retrieval improves correct answers compared with Closed-book model. Overall, Lanterra Retrieval and Closed-book model reach about the same invented facts. Overall, Quillfern Retrieval improves correct answers compared with Closed-book model. Overall, Quillfern Retrieval increases invented facts compared with Closed-book model. Further work should repeat the comparison in other settings.
