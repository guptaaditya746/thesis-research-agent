# Whitlock et al. (2021): How Lanterra Retrieval changes correct answers

## Abstract

We compare Lanterra Retrieval with Closed-book model on correct answers. Overall, Lanterra Retrieval improves correct answers compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. The study was run at the Maplewood Retrieval Trial. It covers these subsets:

- Multi-step questions, Small collection, Cloud servers
- Multi-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Multi-step questions, Small collection, Cloud servers | Closed-book model | Correct answers | 173 | 450 |
| Multi-step questions, Small collection, Cloud servers | Lanterra Retrieval | Correct answers | 228 | 450 |
| Multi-step questions, Large collection, Cloud servers | Closed-book model | Correct answers | 165 | 450 |
| Multi-step questions, Large collection, Cloud servers | Lanterra Retrieval | Correct answers | 215 | 450 |

## Conclusion

Overall, Lanterra Retrieval improves correct answers compared with Closed-book model. Further work should repeat the comparison in other settings.
