# Okafor et al. (2023): A comparison of Lanterra Retrieval and Closed-book model on correct answers

## Abstract

We report a controlled comparison of Lanterra Retrieval and Closed-book model. Overall, Lanterra Retrieval and Closed-book model reach about the same correct answers. Overall, Mervane Retrieval lowers correct answers compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. The study was run at the Maplewood Retrieval Trial. It covers these subsets:

- Multi-step questions, Small collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Multi-step questions, Small collection, Cloud servers | Closed-book model | Correct answers | 150 | 300 |
| Multi-step questions, Small collection, Cloud servers | Lanterra Retrieval | Correct answers | 141 | 300 |
| Multi-step questions, Small collection, Cloud servers | Mervane Retrieval | Correct answers | 116 | 300 |

## Conclusion

Overall, Lanterra Retrieval and Closed-book model reach about the same correct answers. Overall, Mervane Retrieval lowers correct answers compared with Closed-book model. All numbers are reported so that others can add them to their own.
