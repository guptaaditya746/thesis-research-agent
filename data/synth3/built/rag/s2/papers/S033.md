# Holmquist et al. (2016): How Lanterra Retrieval changes answer time

## Abstract

We compare Lanterra Retrieval with Closed-book model on answer time. Overall, Lanterra Retrieval and Closed-book model reach about the same answer time. Overall, Lanterra Retrieval and Closed-book model reach about the same invented facts.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. The study was run at the Harbor Street Handheld Bench. It covers these subsets:

- Multi-step questions, Large collection, On-device

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Multi-step questions, Large collection, On-device | Closed-book model | Invented facts | 113 | 700 |
| Multi-step questions, Large collection, On-device | Lanterra Retrieval | Invented facts | 105 | 700 |

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Multi-step questions, Large collection, On-device | Closed-book model | Answer time | 547 | 219 | 700 |
| Multi-step questions, Large collection, On-device | Lanterra Retrieval | Answer time | 548 | 219 | 700 |

## Conclusion

Overall, Lanterra Retrieval and Closed-book model reach about the same answer time. Overall, Lanterra Retrieval and Closed-book model reach about the same invented facts. Further work should repeat the comparison in other settings.
