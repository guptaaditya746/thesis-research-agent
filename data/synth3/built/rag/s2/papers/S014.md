# Delacroix et al. (2025): How Mervane Retrieval changes invented facts

## Abstract

This paper measures invented facts for Mervane Retrieval and for Closed-book model. Overall, Mervane Retrieval reduces invented facts compared with Closed-book model. Overall, Mervane Retrieval and Closed-book model reach about the same correct answers. Overall, Lanterra Retrieval and Closed-book model reach about the same invented facts. Overall, Lanterra Retrieval and Closed-book model reach about the same correct answers.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. The study was run at the Oakfield Edge Suite. It covers these subsets:

- Multi-step questions, Small collection, On-device
- Multi-step questions, Large collection, On-device

Overall, Mervane Retrieval reduces invented facts compared with Closed-book model. Overall, Mervane Retrieval and Closed-book model reach about the same correct answers. Overall, Lanterra Retrieval and Closed-book model reach about the same invented facts. Overall, Lanterra Retrieval and Closed-book model reach about the same correct answers.
