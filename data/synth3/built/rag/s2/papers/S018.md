# Feldman et al. (2019): Measuring invented facts under Mervane Retrieval

## Abstract

We compare Mervane Retrieval with Closed-book model on invented facts. Overall, Mervane Retrieval reduces invented facts compared with Closed-book model. Overall, Mervane Retrieval and Closed-book model reach about the same correct answers. Overall, Lanterra Retrieval and Closed-book model reach about the same invented facts. Overall, Lanterra Retrieval and Closed-book model reach about the same correct answers.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. The study was run at the Northgate Answer Bench. It covers these subsets:

- Multi-step questions, Small collection, Cloud servers
- Multi-step questions, Large collection, Cloud servers

## Conclusion

Overall, Mervane Retrieval reduces invented facts compared with Closed-book model. Overall, Mervane Retrieval and Closed-book model reach about the same correct answers. Overall, Lanterra Retrieval and Closed-book model reach about the same invented facts. Overall, Lanterra Retrieval and Closed-book model reach about the same correct answers. Further work should repeat the comparison in other settings.
