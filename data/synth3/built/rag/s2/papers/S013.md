# Oyelaran et al. (2024): A comparison of Mervane Retrieval and Closed-book model on correct answers

## Abstract

This paper measures correct answers for Mervane Retrieval and for Closed-book model. Overall, Mervane Retrieval improves correct answers compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. The study was run at the Northgate Answer Bench. It covers these subsets:

- Single-step questions, Small collection, Cloud servers
- Single-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Single-step questions, Small collection, Cloud servers | Closed-book model | Correct answers | 136 | 300 |
| Single-step questions, Small collection, Cloud servers | Mervane Retrieval | Correct answers | 129 | 300 |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Correct answers | 142 | 300 |
| Single-step questions, Large collection, Cloud servers | Mervane Retrieval | Correct answers | 183 | 300 |

## Conclusion

Overall, Mervane Retrieval improves correct answers compared with Closed-book model. Further work should repeat the comparison in other settings.
