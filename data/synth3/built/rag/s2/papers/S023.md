# Santoro et al. (2016): Measuring correct answers under Quillfern Retrieval

## Abstract

We compare Quillfern Retrieval with Closed-book model on correct answers. Overall, Quillfern Retrieval and Closed-book model reach about the same correct answers.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Riverside Query Suite. It covers these subsets:

- Multi-step questions, Small collection, Cloud servers
- Multi-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Multi-step questions, Small collection, Cloud servers | Closed-book model | Correct answers | 158 | 300 |
| Multi-step questions, Small collection, Cloud servers | Quillfern Retrieval | Correct answers | 141 | 300 |
| Multi-step questions, Large collection, Cloud servers | Closed-book model | Correct answers | 147 | 300 |
| Multi-step questions, Large collection, Cloud servers | Quillfern Retrieval | Correct answers | 156 | 300 |

## Conclusion

Overall, Quillfern Retrieval and Closed-book model reach about the same correct answers. All numbers are reported so that others can add them to their own.
