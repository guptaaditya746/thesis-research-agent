# Mensah et al. (2023): Measuring invented facts under Lanterra Retrieval

## Abstract

We report a controlled comparison of Lanterra Retrieval and Closed-book model. Overall, Lanterra Retrieval and Closed-book model reach about the same invented facts.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. The study was run at the Riverside Query Suite. It covers these subsets:

- Single-step questions, Small collection, Cloud servers
- Multi-step questions, Small collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Single-step questions, Small collection, Cloud servers | Closed-book model | Invented facts | 185 | 750 |
| Single-step questions, Small collection, Cloud servers | Lanterra Retrieval | Invented facts | 193 | 750 |
| Multi-step questions, Small collection, Cloud servers | Closed-book model | Invented facts | 189 | 750 |
| Multi-step questions, Small collection, Cloud servers | Lanterra Retrieval | Invented facts | 189 | 750 |

## Conclusion

Overall, Lanterra Retrieval and Closed-book model reach about the same invented facts. All numbers are reported so that others can add them to their own.
