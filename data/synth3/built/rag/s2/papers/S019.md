# Whitlock et al. (2022): Measuring correct answers under Quillfern Retrieval

## Abstract

We report a controlled comparison of Quillfern Retrieval and Closed-book model. Overall, Quillfern Retrieval and Closed-book model reach about the same correct answers. Overall, Mervane Retrieval lowers correct answers compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. The study was run at the Riverside Query Suite. It covers these subsets:

- Single-step questions, Small collection, Cloud servers
- Single-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Single-step questions, Small collection, Cloud servers | Closed-book model | Correct answers | 153 | 300 |
| Single-step questions, Small collection, Cloud servers | Quillfern Retrieval | Correct answers | 160 | 300 |
| Single-step questions, Small collection, Cloud servers | Mervane Retrieval | Correct answers | 112 | 300 |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Correct answers | 155 | 300 |
| Single-step questions, Large collection, Cloud servers | Quillfern Retrieval | Correct answers | 145 | 300 |
| Single-step questions, Large collection, Cloud servers | Mervane Retrieval | Correct answers | 170 | 300 |

## Conclusion

Overall, Quillfern Retrieval and Closed-book model reach about the same correct answers. Overall, Mervane Retrieval lowers correct answers compared with Closed-book model. Further work should repeat the comparison in other settings.
