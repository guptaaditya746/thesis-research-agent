# Bannerman et al. (2016): How Mervane Retrieval changes answer time

## Abstract

This paper measures answer time for Mervane Retrieval and for Quillfern Retrieval. Overall, Mervane Retrieval and Quillfern Retrieval reach about the same answer time. Overall, Mervane Retrieval improves correct answers compared with Quillfern Retrieval.

## Setup

Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Riverside Query Suite. It covers these subsets:

- Single-step questions, Small collection, Cloud servers
- Single-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Single-step questions, Small collection, Cloud servers | Mervane Retrieval | Correct answers | 212 | 600 |
| Single-step questions, Small collection, Cloud servers | Quillfern Retrieval | Correct answers | 310 | 600 |
| Single-step questions, Large collection, Cloud servers | Mervane Retrieval | Correct answers | 384 | 600 |
| Single-step questions, Large collection, Cloud servers | Quillfern Retrieval | Correct answers | 309 | 600 |

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Single-step questions, Small collection, Cloud servers | Mervane Retrieval | Answer time | 1025 | 410 | 600 |
| Single-step questions, Small collection, Cloud servers | Quillfern Retrieval | Answer time | 1016 | 406 | 600 |
| Single-step questions, Large collection, Cloud servers | Mervane Retrieval | Answer time | 1013 | 405 | 600 |
| Single-step questions, Large collection, Cloud servers | Quillfern Retrieval | Answer time | 1000 | 400 | 600 |

## Conclusion

Overall, Mervane Retrieval and Quillfern Retrieval reach about the same answer time. Overall, Mervane Retrieval improves correct answers compared with Quillfern Retrieval. The numbers behind this statement are given in the Results section.
