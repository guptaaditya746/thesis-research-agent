# Marlowe et al. (2016): Measuring answer time under Lanterra Retrieval

## Abstract

We compare Lanterra Retrieval with Closed-book model on answer time. Overall, Lanterra Retrieval increases answer time compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. The study was run at the Northgate Answer Bench. It covers these subsets:

- Single-step questions, Small collection, Cloud servers
- Single-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Single-step questions, Small collection, Cloud servers | Closed-book model | Answer time | 701 | 280 | 800 |
| Single-step questions, Small collection, Cloud servers | Lanterra Retrieval | Answer time | 893 | 357 | 800 |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Answer time | 683 | 273 | 800 |
| Single-step questions, Large collection, Cloud servers | Lanterra Retrieval | Answer time | 704 | 282 | 800 |

## Conclusion

Overall, Lanterra Retrieval increases answer time compared with Closed-book model. Further work should repeat the comparison in other settings.
