# Castellan et al. (2024): A comparison of Quillfern Retrieval and Closed-book model on answer time

## Abstract

This paper measures answer time for Quillfern Retrieval and for Closed-book model. Overall, Quillfern Retrieval increases answer time compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Northgate Answer Bench. It covers these subsets:

- Multi-step questions, Small collection, Cloud servers
- Multi-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Multi-step questions, Small collection, Cloud servers | Closed-book model | Answer time | 681 | 272 | 600 |
| Multi-step questions, Small collection, Cloud servers | Quillfern Retrieval | Answer time | 842 | 337 | 600 |
| Multi-step questions, Large collection, Cloud servers | Closed-book model | Answer time | 702 | 281 | 600 |
| Multi-step questions, Large collection, Cloud servers | Quillfern Retrieval | Answer time | 816 | 326 | 600 |

## Conclusion

Overall, Quillfern Retrieval increases answer time compared with Closed-book model. All numbers are reported so that others can add them to their own.
