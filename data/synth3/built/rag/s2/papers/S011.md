# Varga et al. (2024): A comparison of Lanterra Retrieval and Closed-book model on invented facts

## Abstract

We compare Lanterra Retrieval with Closed-book model on invented facts. Overall, Lanterra Retrieval and Closed-book model reach about the same invented facts.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. The study was run at the Northgate Answer Bench. It covers these subsets:

- Multi-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Multi-step questions, Large collection, Cloud servers | Closed-book model | Invented facts | 170 | 750 |
| Multi-step questions, Large collection, Cloud servers | Lanterra Retrieval | Invented facts | 154 | 750 |

## Conclusion

Overall, Lanterra Retrieval and Closed-book model reach about the same invented facts. Further work should repeat the comparison in other settings.
