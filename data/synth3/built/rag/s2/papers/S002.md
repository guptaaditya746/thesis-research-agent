# Thackeray et al. (2025): How Lanterra Retrieval changes correct answers

## Abstract

We compare Lanterra Retrieval with Closed-book model on correct answers. Overall, Lanterra Retrieval and Closed-book model reach about the same correct answers. Overall, Quillfern Retrieval lowers correct answers compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Lanterra Retrieval is a set-up that fetches the top passages by word match and adds them to the question. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Oakfield Edge Suite. It covers these subsets:

- Multi-step questions, Small collection, On-device

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Multi-step questions, Small collection, On-device | Closed-book model | Correct answers | 317 | 700 |
| Multi-step questions, Small collection, On-device | Lanterra Retrieval | Correct answers | 308 | 700 |
| Multi-step questions, Small collection, On-device | Quillfern Retrieval | Correct answers | 201 | 700 |

## Conclusion

Overall, Lanterra Retrieval and Closed-book model reach about the same correct answers. Overall, Quillfern Retrieval lowers correct answers compared with Closed-book model. Further work should repeat the comparison in other settings.
