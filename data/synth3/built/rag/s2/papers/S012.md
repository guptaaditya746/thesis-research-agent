# Kobayashi et al. (2017): How Mervane Retrieval changes answer time

## Abstract

We compare Mervane Retrieval with Closed-book model on answer time. Overall, Mervane Retrieval increases answer time compared with Closed-book model.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. The study was run at the Maplewood Retrieval Trial. It covers these subsets:

- Single-step questions, Large collection, Cloud servers
- Multi-step questions, Large collection, Cloud servers

## Results

| Subset | Arm | Measure | Mean | SD | n |
| --- | --- | --- | --- | --- | --- |
| Single-step questions, Large collection, Cloud servers | Closed-book model | Answer time | 524 | 210 | 700 |
| Single-step questions, Large collection, Cloud servers | Mervane Retrieval | Answer time | 612 | 245 | 700 |
| Multi-step questions, Large collection, Cloud servers | Closed-book model | Answer time | 533 | 213 | 700 |
| Multi-step questions, Large collection, Cloud servers | Mervane Retrieval | Answer time | 625 | 250 | 700 |

## Conclusion

Overall, Mervane Retrieval increases answer time compared with Closed-book model. Further work should repeat the comparison in other settings.
