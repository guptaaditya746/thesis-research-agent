# Karimov et al. (2019): Measuring correct answers under Mervane Retrieval

## Abstract

This paper measures correct answers for Mervane Retrieval and for Closed-book model. Overall, Mervane Retrieval lowers correct answers compared with Closed-book model. Overall, Quillfern Retrieval and Closed-book model reach about the same correct answers.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Mervane Retrieval is a set-up that fetches passages by meaning and rewrites the question before searching. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Maplewood Retrieval Trial. It covers these subsets:

- Multi-step questions, Small collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Multi-step questions, Small collection, Cloud servers | Closed-book model | Correct answers | 416 | 800 |
| Multi-step questions, Small collection, Cloud servers | Mervane Retrieval | Correct answers | 324 | 800 |
| Multi-step questions, Small collection, Cloud servers | Quillfern Retrieval | Correct answers | 386 | 800 |

## Conclusion

Overall, Mervane Retrieval lowers correct answers compared with Closed-book model. Overall, Quillfern Retrieval and Closed-book model reach about the same correct answers. All numbers are reported so that others can add them to their own.
