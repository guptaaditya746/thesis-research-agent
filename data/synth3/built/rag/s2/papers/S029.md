# Tanaka et al. (2025): A comparison of Quillfern Retrieval and Closed-book model on correct answers

## Abstract

This paper measures correct answers for Quillfern Retrieval and for Closed-book model. Overall, Quillfern Retrieval and Closed-book model reach about the same correct answers.

## Setup

Closed-book model is the language model answers from memory alone, with no documents shown to it. Quillfern Retrieval is a set-up that fetches passages, then ranks them again with a second model before answering. The study was run at the Riverside Query Suite. It covers these subsets:

- Multi-step questions, Small collection, Cloud servers

## Results

| Subset | Arm | Measure | Count | Total |
| --- | --- | --- | --- | --- |
| Multi-step questions, Small collection, Cloud servers | Closed-book model | Correct answers | 246 | 700 |
| Multi-step questions, Small collection, Cloud servers | Quillfern Retrieval | Correct answers | 244 | 700 |

## Conclusion

Overall, Quillfern Retrieval and Closed-book model reach about the same correct answers. The numbers behind this statement are given in the Results section.
