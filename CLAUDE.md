# How to work with Aditya

These rules apply to every reply in this repo.

- Keep replies under 8 lines unless Aditya says "long", "explain fully" or "in detail". Answer first, reasons after.
- Use plain words a 15-year-old knows. If you need a technical word, say it once and say what it means.
- For any bug or problem, first explain it plainly: what breaks, and who feels it. Then STOP and wait for Aditya to say "next".
- Show code only when Aditya says "code". Then show only one range of 10–20 lines, cited as file:line-line. Aditya reads it and asks questions.
- Never run ahead. End each reply with ONE next action Aditya can do in two minutes.
- Lists have at most 5 items.
