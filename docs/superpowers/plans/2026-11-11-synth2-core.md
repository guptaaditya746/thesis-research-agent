# synth2 Core (hidden-law benchmark generator) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A new generator package `synth2`, beside the frozen `synth`, that builds a fictional research field obeying a hidden law, writes it as template papers, makes corpus families with known must-change / must-stay relations, and scores any system's fixed-form answers by code.

**Architecture:** Answer key first (after RIKER): a `Law` and a tuple of `Study` records are drawn from a seed, the key is computed from them by a reference rule, and only then are papers written. Two independent dials (after SciR): `law_kind` sets how hard the conclusion is, `text_level` sets how hard the facts are to find. Everything in this plan runs without a model; the pooled reference rule doubles as the oracle that proves the pipeline is fair.

**Tech Stack:** Python >= 3.13, pydantic (already installed), pyyaml, pytest. No new dependencies.

**Spec:** none on disk. The decisions come from the design interview of 10-11 Nov 2026 and are copied into "Design decisions" below; that section is the spec for this plan.

## Design decisions (the spec)

Decided by Aditya in the interview:

1. The old generator `backend/synth/` stays untouched; old results are the "version 1" baseline.
2. One true condition with two sides, plus two fake candidate conditions that do nothing. The protocol lists all three; the system must find which one matters.
3. Papers report plain counts ("412 of 500 correct"). No p-values.
4. Some studies cover one side only, some the other, some both, so lumping everything together gives a wrong or washed-out answer.
5. The answer is a fixed form, scored by code, no judge model.
6. The reference conclusion adds up counts per side. Vote counting is kept as the weaker comparison.
7. The answer key is what the written papers support. Whether that equals the planted law is reported separately. No unpublished studies.
8. Overclaiming authors stay in, but only in the spun copy. The base corpus has honest claims only (changed 11 Nov 2026: no overclaim rate to defend).
9. Each corpus ships with relatives made by code: a twin (answer must move), a spun copy and a duplicate copy (answer must stay). The twin has a harmless partner; the honest base is the partner of the spun copy.
10. Three headline scores as fractions: follows evidence, resists overclaiming, recovers the law. Resists overclaiming is the spun copy only; the other must-stay copies are reported as a side score, `stays_steady` (changed 11 Nov 2026).
11. 20 studies per corpus, 10 seeds per setting, every score with its spread.
12. Built on SciR (two dials, planted-fact check) and RIKER (key first, code scoring, "unknown" probes). The real-paper skeleton layer is dropped.

Chosen by the plan author, not yet confirmed by Aditya (change freely, they live in one recipe file):

- Which of the three conditions is the true one is drawn from the seed, and so is whether the law is mirrored (helps becomes hurts). This is the "opposite law in half the worlds" idea from NewtonBench.
- Effect size 0.08 to 0.15, group size 200 to 1000 in steps of 50, base rate 0.45 to 0.75, `min_effect` 0.01 (copied from `data/domains/rag/protocols/cons-accuracy.yaml`), `min_gap` 0.05. There is no overclaim rate and no coverage mix: half of the studies report two subsets, split on one of the three conditions drawn by chance.
- Three text levels: `table`, `prose`, `split`. Three law kinds: `uniform`, `one_sided`, `opposed`.
- The twin flips the law on the second side and redraws every cell on that side (about half the papers change). A single-study twin cannot move a pooled answer.

Out of scope, each its own later plan: (B) model-written papers with the SciR-style recovery check, following `docs/prompt-writing.md`; (C) the evidence engine and the baselines emitting the fixed-form answer, and the cluster run; (D) medicine and materials recipes.

## Changes after the build, 11 Nov 2026 (these replace the task text below where they differ)

The plan was built, reviewed, and then changed in two passes. Where a task below says something else, this wins.

Fix pass after the whole-branch review:

- The duplicate paper gets the next free study number (`S021`), not `S001D`: its id must not say it is a copy.
- A spun copy in which no author overclaims is not counted for `resists_overclaiming` (`of: 0`).
- The recipe refuses digits, table bars, line breaks, empty text and bare level ids in anything the writer prints, and checks its number ranges.
- `synth2 build` refuses more studies than the recipe has authors (exit 2).

Design changes Aditya agreed to (generator `VERSION = 2`, all corpus ids changed):

- Two-subset papers: half of the papers report two subsets (`rng.random() < 0.5`). The split is on one of the three conditions, drawn by chance; every other condition has one drawn level. A paper split on a fake condition sits on one side of the true condition. Before, every two-subset paper split on the true condition, so the true condition could be read off without adding counts. The counts seed is per cell: `synth2:{seed}:{ns}:{study_id}:c{cell index}:counts`. With `untested`, a paper that would split on the true condition has one subset.
- Fourth reference rule `trusts_claims`: like `vote`, but each paper votes with its authors' claim. It scores 0 on `resists_overclaiming`, which shows that score measures something.
- `synth2 build` refuses a family whose base key or twin key does not equal its law, and goes on to the next seed until the cell has `--seeds` families, at most 3 times `--seeds` tries (then exit 1). Refused seeds are in `skipped.json`.
- The corpus id is made from the paper hashes alone (no family kind), so two corpora with the same papers share an id and are one task in the SciR export.
- `reference`, `score` and `export-scir` on a folder with no corpus exit 2.

## Global Constraints

- Never edit the hashed files listed in `backend/README.md` ("Hashed files: never edit"), in particular nothing under `backend/synth/`, `backend/evidence/`, `backend/jsonio/`, `backend/modelcall/`.
- `synth2` imports only `jsonio`, `repo_paths` and the standard library plus pydantic and yaml. It does not import `synth` or `evidence`.
- All randomness comes from `random.Random(<string>)` with the seed strings given in the tasks. Never `random.seed`, never `hash()`.
- No model calls and no network in this plan.
- Every file is written as UTF-8 with LF line ends through `jsonio.write_json_atomic` or `jsonio.write_text_atomic`, so hashes match on Windows and Linux.
- Tests live in `backend/synth2/tests/`. Run with `uv run pytest -q backend/synth2 -n 0`.
- Work on a branch: `git switch -c synth2-core` before Task 1.

## Review Focus

1. A level of a candidate condition that no study covers: `pooled` must list it in `untested` and must not divide by zero. Test in Task 3.
2. A hand-edited or damaged `ground_truth.json` with `k > n` or `n == 0`: `Cell` must refuse it with a `ValueError` naming the study. Test in Task 2.
3. An answers file that misses a corpus or uses an unknown verdict word: scoring counts it as wrong, lists it under `invalid`, and does not crash. Test in Task 7.
4. A recipe where one name is contained in another ("large model" / "very large model"): text becomes ambiguous, so `load_recipe` must refuse it. Test in Task 1.
5. Same seed on Windows and Linux must give byte-identical papers and the same `corpus_id`. Test in Task 5 (CRLF never written, hash stable across two builds).

### Task 2: The world: law and studies

**Files:**
- Create: `backend/synth2/world.py`, `backend/synth2/tests/test_world.py`

**Interfaces:**
- Consumes: `Recipe`, `load_recipe` (Task 1)
- Produces:
  - `LAW_KINDS: dict[str, tuple[str, str]]` = `{"uniform": ("helps", "helps"), "one_sided": ("helps", "no_effect"), "opposed": ("helps", "hurts")}`
  - `@dataclass(frozen=True) class Law`: `condition: str`, `effects: dict[str, float]` (level id of the true condition -> signed rate difference, 0.0 for no effect), `kind: str`, `mirrored: bool`
  - `@dataclass(frozen=True) class Cell`: `levels: dict[str, str]` (condition id -> level id, all three conditions), `n_t: int`, `k_t: int`, `n_c: int`, `k_c: int`; `__post_init__` raises `ValueError` unless `0 < n` and `0 <= k <= n` for both arms
  - `@dataclass(frozen=True) class Study`: `id: str` (`S001`...), `label: str` (`"<Author> et al. (<year>)"`), `dataset: str`, `cells: tuple[Cell, ...]` (1 or 2), `claim: str` (`helps` / `hurts` / `no_effect`), `overclaims: bool`, `duplicate_of: str | None = None`; methods `json() -> dict` and `Study.parse(obj: dict) -> Study` (round trip; a bad cell raises `ValueError` whose message contains the study id)
  - `direction(delta: float, min_effect: float) -> str`
  - `study_delta(study: Study) -> float` (the study's own counts pooled over its cells: treatment rate minus control rate)
  - `draw_law(recipe: Recipe, seed: int, kind: str) -> Law`
  - `draw_studies(recipe: Recipe, law: Law, seed: int, count: int, *, exact: bool = False, noise_seed: int = 0, untested: str | None = None, redraw_level: str | None = None) -> tuple[Study, ...]`

Seed strings (exact):
- law: `random.Random(f"synth2:{seed}:law")` draws, in this order: the true condition (`rng.choice` over `recipe.conditions`), `mirrored` (`rng.random() < 0.5`), whether the two sides are swapped (`rng.random() < 0.5`), then one magnitude per non-zero side (`rng.uniform(*recipe.effect)`, rounded to 3 places). `mirrored` multiplies every effect by -1.
- study design: `random.Random(f"synth2:{seed}:{study_id}:design")` draws, in this order: coverage (`rng.choice(("a", "b", "both"))`; `a` is the first level of the true condition), one level for each of the two fake conditions, `n_t` and `n_c` (same value, a multiple of `n_step` in `n_range`), the control base rate (`rng.uniform(*recipe.base_rate)`), the dataset and the year. Authors are assigned without repeats: shuffle `recipe.authors` once with `random.Random(f"synth2:{seed}:authors")` and give study i the i-th.
- counts of one cell: `random.Random(f"synth2:{seed}:{ns}:{study_id}:{level}:counts")` where `level` is the cell's level of the true condition and `ns` is `noise_seed` if `redraw_level == level`, else `0`. `k_c = rng.binomialvariate(n_c, base)`, then `k_t = rng.binomialvariate(n_t, min(max(base + effect, 0.0), 1.0))`. With `exact=True`: `k = round(n * p)`, no draw.
- `untested="<level id>"`: every study that would cover that level of the true condition covers the other level only.
- claim: always the honest one, `direction(study_delta(study), recipe.min_effect)`, with `overclaims` false. Only the `spun` kind (Task 6) changes claims.

import pytest
from synth2.recipe import load_recipe
from synth2.world import LAW_KINDS, Cell, Study, direction, draw_law, draw_studies, study_delta

R = load_recipe("rag")


def test_law_shape_for_each_kind():
    for kind, (first, second) in LAW_KINDS.items():
        law = draw_law(R, 7, kind)
        levels = [lv.id for c in R.conditions if c.id == law.condition for lv in c.levels]
        assert set(law.effects) == set(levels)
        got = sorted(direction(e, R.min_effect) for e in law.effects.values())
        want = sorted([first, second])
        if law.mirrored:
            want = sorted({"helps": "hurts", "hurts": "helps", "no_effect": "no_effect"}[d] for d in want)
        assert got == want
        assert all(e == 0.0 or 0.08 <= abs(e) <= 0.15 for e in law.effects.values())


def test_seeds_vary_the_true_condition_and_the_mirror():
    laws = [draw_law(R, s, "opposed") for s in range(40)]
    assert {l.condition for l in laws} == {"fact_rarity", "model_size", "question_length"}
    assert {l.mirrored for l in laws} == {True, False}


def test_studies_are_deterministic_and_in_range():
    law = draw_law(R, 3, "opposed")
    a = draw_studies(R, law, 3, 20)
    assert a == draw_studies(R, law, 3, 20)
    assert [s.id for s in a] == [f"S{i:03d}" for i in range(1, 21)]
    assert len({s.label for s in a}) == 20
    for s in a:
        assert 1 <= len(s.cells) <= 2
        for c in s.cells:
            assert set(c.levels) == {"fact_rarity", "model_size", "question_length"}
            assert 200 <= c.n_t <= 1000 and c.n_t % 50 == 0 and c.n_t == c.n_c
    assert {len(s.cells) for s in a} == {1, 2}


def test_exact_counts_follow_the_law():
    law = draw_law(R, 3, "opposed")
    for s in draw_studies(R, law, 3, 20, exact=True):
        for c in s.cells:
            effect = law.effects[c.levels[law.condition]]
            assert abs((c.k_t / c.n_t - c.k_c / c.n_c) - effect) < 0.006


def test_untested_level_has_no_cell():
    law = draw_law(R, 3, "opposed")
    gone = sorted(law.effects)[0]
    cells = [c for s in draw_studies(R, law, 3, 20, untested=gone) for c in s.cells]
    assert cells and all(c.levels[law.condition] != gone for c in cells)


def test_redraw_level_changes_only_that_side():
    law = draw_law(R, 3, "opposed")
    side = sorted(law.effects)[1]
    base, again = draw_studies(R, law, 3, 20), draw_studies(R, law, 3, 20, noise_seed=1, redraw_level=side)
    for b, a in zip(base, again):
        for cb, ca in zip(b.cells, a.cells):
            if cb.levels[law.condition] != side:
                assert cb == ca
    assert base != again


def test_base_claims_are_honest():
    law = draw_law(R, 3, "opposed")
    for s in draw_studies(R, law, 3, 20):
        assert s.claim == direction(study_delta(s), R.min_effect)
        assert s.overclaims is False


def test_cell_refuses_impossible_counts():

### Task 3: Reference conclusions (pooled, vote, lumped) and the answer form

**Files:**
- Create: `backend/synth2/conclude.py`, `backend/synth2/tests/test_conclude.py`

**Interfaces:**
- Consumes: `Recipe`, `Cell`, `Study`, `direction`, `study_delta`
- Produces:
  - `VERDICTS = ("depends", "helps", "hurts", "no_effect", "mixed", "insufficient")`
  - `SIDE_WORDS = ("helps", "hurts", "no_effect")`
  - `@dataclass(frozen=True) class Answer`: `verdict: str`, `condition: str | None`, `sides: dict[str, str]`, `untested: tuple[str, ...]`; `json() -> dict`; `Answer.parse(obj: Any) -> Answer` raising `ValueError` on any wrong shape or unknown word
  - `pooled(studies: Sequence[Study], recipe: Recipe) -> Answer`
  - `vote(studies: Sequence[Study], recipe: Recipe) -> Answer`
  - `lumped(studies: Sequence[Study], recipe: Recipe) -> Answer`

The answer file form (what every tested system must write, per corpus):

```json
{"verdict": "depends", "condition": "fact_rarity", "sides": {"rare": "helps", "common": "hurts"}, "untested": []}
```

Rules (all three skip studies whose `duplicate_of` is set):
- `untested`: sorted list of `"<condition id>.<level id>"` for every level of every candidate condition that no cell has. Same for all three rules.
- `pooled`: for each condition, for each of its levels with at least one cell, `delta = sum(k_t)/sum(n_t) - sum(k_c)/sum(n_c)` over the cells at that level. A condition is a candidate when both levels have cells, the two directions differ, and `abs(delta_a - delta_b) >= recipe.min_gap`. Take the candidate with the largest gap (tie: first in recipe order): verdict `depends`, that condition, `sides` = direction per level. No candidate: verdict = direction of the delta over all cells, `condition=None`, `sides={}`. No cells at all: `insufficient`.
- `lumped`: the no-candidate branch of `pooled`, always.
- `vote`: each study votes `direction(study_delta(study), min_effect)`. Both `helps` and `hurts` votes present: `mixed`. Else the only non-neutral direction present; all neutral: `no_effect`; no studies: `insufficient`. `condition=None`, `sides={}`.

### Task 4: Template writer with three text levels

**Files:**
- Create: `backend/synth2/write.py`, `backend/synth2/tests/test_write.py`

**Interfaces:**
- Consumes: `Recipe`, `Study`
- Produces:
  - `TEXT_LEVELS = ("table", "prose", "split")`
  - `@dataclass(frozen=True) class Placement`: `fact: str`, `start: int`, `end: int`. Fact ids: `"<study id>.c<cell index>.<k_t|n_t|k_c|n_c>"` and `"<study id>.claim.<abstract|conclusion>"`
  - `@dataclass(frozen=True) class Paper`: `study: str`, `text: str`, `placements: tuple[Placement, ...]`
  - `write_paper(study: Study, recipe: Recipe, text_level: str, seed: int) -> Paper`
  - `missing_facts(paper: Paper, study: Study) -> list[str]` (fact ids whose span does not hold the planted value; empty means faithful)
  - `CLAIMS: dict[str, str]` with exactly these sentences (`{t}` = treatment label, `{c}` = control label, `{m}` = metric):
    - `helps`: `"Overall, the {t} clearly improves {m} over the {c}."`
    - `hurts`: `"Overall, the {t} lowers {m} compared with the {c}."`
    - `no_effect`: `"Overall, the {t} and the {c} reach about the same {m}."`

Paper layout, all levels: `# <label>: <title>`, `## Abstract`, `## Setup`, `## Results`, `## Conclusion`. The claim sentence appears once in Abstract and once in Conclusion. Setup names the dataset and, in words, the level of each of the three conditions for every cell (level `name` from the recipe, never the level `id`). What differs:
- `table`: Results is one Markdown table, columns `Subset | System | Correct | Total`, one row per arm per cell, subset written with the level name of all three conditions.
- `prose`: no table; one sentence per arm, containing `"<k> of <n> <unit>"`.
- `split`: Setup gives each cell a code (`Subset A`, `Subset B`) next to its level names; Results is the table of `table` but its Subset column holds only the code.

The only digits outside placements are the year in the label. Filler sentences are picked with `random.Random(f"synth2:{seed}:{study.id}:text")`.

### Task 6: Corpus families

**Files:**
- Create: `backend/synth2/family.py`, `backend/synth2/tests/test_family.py`

**Interfaces:**
- Consumes: `Settings`, `write_corpus`, `load_truth`, `load_studies`, `draw_law`, `draw_studies`, `pooled`
- Produces:
  - `KINDS = ("twin", "twin_neutral", "spun", "duplicate")`
  - `RELATION = {"twin": "must_change", "twin_neutral": "must_stay", "spun": "must_stay", "duplicate": "must_stay"}`
  - `make_family(base_dir: Path) -> list[dict]`: writes `<base_dir>/../<kind>/` for each kind and returns the four `variant.json` records, each `{"base_corpus_id", "corpus_id", "kind", "relation", "key_before", "key_after"}` (also stored as `variant.json` in the variant folder and as `variant` in its `corpus.json`)
  - raises `ValueError(f"{kind}: relation {relation} does not hold for seed {seed}")` when a twin's key equals the base key or a must-stay key differs. Kinds are made in `KINDS` order, and both keys of a pair are computed by calling `pooled` on the studies (the base key is not read from `ground_truth.json`)

What each kind changes (the base studies are redrawn from `corpus.json` settings; `b` is the second level of the law's condition in recipe order):
- `twin`: new law with `effects[b]` replaced by `-effects[b]`, or by `-effects[a]` when `effects[b] == 0.0`. Every cell at level `b` is redrawn under the new law with the same noise seed. Papers with no cell at `b` stay byte-identical.
- `twin_neutral`: same law; cells at level `b` redrawn with `noise_seed + 1` (`draw_studies(..., noise_seed=settings.noise_seed + 1, redraw_level=b)`).
- `spun`: same counts; every study's claim becomes `helps`, and `overclaims` is true where the honest claim was not `helps`. The honest base is its partner, so there is no `unspun` kind.
- `duplicate`: the first study is added again under the next free id (`S021`) with label `"<label>, extended version"` and `duplicate_of="S001"`.

### Task 7: Scoring and the oracle check

**Files:**
- Create: `backend/synth2/score.py`, `backend/synth2/tests/test_score.py`

**Interfaces:**
- Consumes: `Answer`, `pooled`, `vote`, `lumped`, `load_truth`, `load_studies`, `KINDS`, `RELATION`
- Produces:
  - `reference_answers(family_root: Path, rule: str) -> dict[str, dict]` (`rule` in `pooled` / `vote` / `lumped`; corpus id -> answer JSON for `base` and the four kinds)
  - `score_family(family_root: Path, answers: dict[str, Any]) -> dict`
  - `summarise(reports: Sequence[dict]) -> dict`

`score_family` returns:

```json
{"recovers_law": {"hits": 5, "of": 5},
 "follows_evidence": {"hits": 1, "of": 1},
 "resists_overclaiming": {"hits": 1, "of": 1},
 "stays_steady": {"hits": 2, "of": 2},
 "fell_for_lumping": {"hits": 0, "of": 5},
 "by_kind": {"twin": true, "twin_neutral": true, "spun": true, "duplicate": true},
 "invalid": []}
```

- `recovers_law`: over the five corpora, the parsed answer equals the key (all four fields).
- `follows_evidence`: over `must_change` kinds, the answer for the variant differs from the answer for the base and equals the variant's key.
- `resists_overclaiming`: for the `spun` kind only, the answer for the variant equals the answer for the base (right or wrong).
- `stays_steady`: over the other `must_stay` kinds (`twin_neutral`, `duplicate`), the same test.
- `fell_for_lumping`: over corpora whose key verdict is `depends`, the answer equals that corpus's `lumped` answer; `of` counts those corpora.
- A missing corpus id or an answer `Answer.parse` refuses is listed in `invalid` (corpus id), counts as not recovered, and makes every pair it belongs to a miss.

`summarise` returns, for each of the five scores, `{"mean": float, "stderr": float, "n": int}` over the per-family fractions `hits/of` (families with `of == 0` are left out; `stderr` = `statistics.stdev / sqrt(n)`, `0.0` when `n < 2`; `mean` is `0.0` when `n == 0`).

### Task 9: Export as a SciR-shaped task file

**Files:**
- Create: `backend/synth2/scir_export.py`, `backend/synth2/tests/test_scir_export.py`
- Modify: `backend/synth2/cli.py` (new subcommand `export-scir`)

**Interfaces:**
- Consumes: `load_truth`, `load_studies`, `write_paper`, `Answer`, `load_recipe`, `Settings`
- Produces:
  - `task_of(corpus_dir: Path) -> dict`
  - `export(root: Path, out: Path) -> int` (number of tasks written)
  - CLI: `synth2 export-scir --root DIR --out FILE`

The file shape is the one `evaluation/runner.py::load_tasks` and `generation/causal/transform.py` of the SciR checkout read and write (commit `d698514`): `{"metadata": {...}, "tasks": [...]}`, each task

```json
{"id": "<corpus id>", "domain": "pooling", "problem_nl": "...", "problem_obfuscated": "...", "answer": "<canonical JSON of the key>",
 "metadata": {"generation_params": {"law_kind": "...", "text_level": "...", "seed": 0, "kind": "base"},
              "logical_form": {"conditions": [...], "studies": [...], "law": {...}},
              "chunks": {"nl": [{"chunk_index": 0, "text": "..."}], "obfuscated": [{"chunk_index": 0, "text": "..."}]}}}
```

- One chunk per paper, in study id order. `nl` chunks are the papers written at text level `table`; `obfuscated` chunks are the corpus's own papers (its `text_level`). For a `table` corpus the two are equal.
- `problem_nl` and `problem_obfuscated` = intro, blank line, the chunks joined by blank lines, blank line, footer.
- Intro (exact): the recipe question, then `"Candidate conditions: "` followed by `"<condition id> (<level id> = <level name>, <level id> = <level name>)"` for the three conditions joined by `"; "`, then `"The studies follow."`
- Footer (exact): `Answer inside <answer></answer> with one JSON object: {"verdict": "depends|helps|hurts|no_effect|insufficient", "condition": "<condition id or null>", "sides": {"<level id>": "helps|hurts|no_effect"}, "untested": ["<condition id>.<level id>"]}`
- Top-level `metadata`: `{"generator": "synth2", "version": 1, "code_sha256": ..., "tasks": <count>}`.
- Nothing from `ground_truth.json` other than what is listed may appear in `problem_nl` or `problem_obfuscated`.

import json
from jsonio import canonical
from synth2.cli import main
from synth2.conclude import Answer
from synth2.corpus import Settings, build_base, load_truth
from synth2.family import make_family
from synth2.scir_export import export, task_of


def test_task_has_the_scir_keys_and_our_key(tmp_path):
    build_base(tmp_path / "base", Settings("rag", 11, 20, "opposed", "split", exact=True))
    t = task_of(tmp_path / "base")
    truth = load_truth(tmp_path / "base")
    assert set(t) == {"id", "domain", "problem_nl", "problem_obfuscated", "answer", "metadata"}
    assert t["id"] == truth["corpus_id"] and t["domain"] == "pooling"
    assert t["answer"] == canonical(truth["key"]) and Answer.parse(json.loads(t["answer"]))
    assert len(t["metadata"]["chunks"]["nl"]) == 20 == len(t["metadata"]["chunks"]["obfuscated"])
    assert "Subset A" in t["problem_obfuscated"] and "Subset A" not in t["problem_nl"]
    assert t["problem_nl"].startswith("Does retrieval-augmented generation")
    assert "Candidate conditions: fact_rarity (rare = rare-fact questions, common = common-fact questions); " in t["problem_nl"]
    assert t["problem_nl"].rstrip().endswith('"untested": ["<condition id>.<level id>"]}')


def test_the_text_does_not_leak_the_key(tmp_path):
    build_base(tmp_path / "base", Settings("rag", 11, 20, "opposed", "table", exact=True))
    t = task_of(tmp_path / "base")
    for text in (t["problem_nl"], t["problem_obfuscated"]):
        assert "key_matches_law" not in text and "mirrored" not in text and '"law"' not in text


def test_export_writes_one_task_per_corpus_and_cli_agrees(tmp_path):
    build_base(tmp_path / "g" / "opposed-table" / "s0" / "base", Settings("rag", 0, 20, "opposed", "table", exact=True))

    assert {t["metadata"]["generation_params"]["kind"] for t in data["tasks"]} == {"base", "twin", "twin_neutral", "spun", "duplicate"}
    assert main(["export-scir", "--root", str(tmp_path / "g"), "--out", str(tmp_path / "again.json")]) == 0
    assert (tmp_path / "again.json").read_bytes() == (tmp_path / "tasks.json").read_bytes()
