# synth2 under the A/B/C evaluation: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The evaluation's three pillars (A extraction, B integration, C synthesis) score an engine run on a synth2
corpus, template or model-written, instead of silently finding no facts; and the engine's answers can be scored by
synth2's own law scores.

**Architecture:** A translator in `synth2` turns a synth2 `ground_truth.json` into the evaluation's study format;
`evaluation.truth.GroundTruth.load` calls it when it sees a synth2 truth and refuses any truth that yields no facts. A
second command assembles a model-written corpus (new papers, the template's truth without text positions) into a
folder the engine and the evaluation can read. A third maps the engine's `answer.json` label onto synth2's answer
form for `synth2 score`.

**Tech Stack:** Python 3.13, pytest (xdist), `uv run`. No new dependency.

**Spec:** the five-point proposal agreed in conversation on 12 Nov 2026 (refuse empty truths; A via a translator,
positions on template text only; B on one-subset studies with a count of the rest; C via synth2's scorer; tests per
pillar). Engine support for subsets is a separate, later plan.

## Global Constraints

- Never edit a hashed file listed in `backend/README.md` ("Hashed files: never edit"); nothing under `backend/synth/`,
  `backend/evidence/`, `backend/jsonio/`, `backend/modelcall/`, `backend/agent/`. `backend/evaluation/truth.py` and
  `backend/evaluation/score.py` are not hashed.
- Imports follow `gateway < engine < evaluation < api`; `evaluation` and `synth2` are the same service, so
  `evaluation -> synth2` is allowed (`backend/tests/test_boundaries.py` must stay green).
- Old corpora score exactly as before: every existing test in `backend/evaluation` and `backend/synth2` stays green,
  and the report of an old corpus gains no key.
- Work in a temporary git worktree branched from `main`; never switch the branch of the user's checkout. Commit
  messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. No merge or push without the user.
- Windows: run tests with `-n 0` when a test writes files under `tmp_path` and is flaky under xdist; the agent/sandbox
  files that need `signal.SIGKILL` are not in scope.

## Review Focus

1. A synth2 duplicate study (`duplicate_of` set) must keep its facts and carry `duplicate_of` into the translated study,
   so the engine's duplicate flag is not counted as a miss.
2. Two cells of one study whose rag values lie within 0.005 of each other: A must still match both (one to one);
   the translator must give each its own fact id.
3. A written corpus whose papers lost a planted count: A counts the fact as missed; nothing crashes for lack of a
   placement.
4. `engine-answers` over a folder with two runs of the same corpus id must refuse (exit 2), not keep one silently.
5. A truth that has studies but every list empty (an old corpus written wrong) is refused with the file named.

### Task 2: Translate a synth2 truth for A, B and C

**Files:**
- Create: `backend/synth2/evaltruth.py`

- Test: `backend/synth2/tests/test_evaltruth.py` (create); fixture `tiny` in `backend/synth2/tests/conftest.py`
  (create or extend; Tasks 3 and 4 reuse it)

**Interfaces:**
- Consumes: Task 1's refusal.
- Produces:
  - `synth2.evaltruth.is_synth2(data: dict) -> bool` — true when `data` has both `"law"` and `"key"`.
  - `synth2.evaltruth.eval_truth(data: dict, corpus_dir: Path) -> dict` — the evaluation-format truth:
    `corpus_id`, `question`, `seed`, `studies`, `placements`, `answer`, `unscored` (list of study ids).
  - `GroundTruth.unscored: list[str] | None` (None for every old corpus).
  - report key `unscored_studies: {"count": int, "studies": [ids], "reason": str}` only for synth2 truths.

Translation, per synth2 study `s` (recipe from `corpus.json` `settings.domain` via `synth2.recipe.load_recipe`):

| evaluation field | value |
|---|---|
| `study_id`, `paper` | `s["id"]` |
| `level` | `data["eval_level"]` if present, else `corpus.json` `settings.text_level` |
| `duplicate_of` | `s["duplicate_of"]` |
| `conditions` | `{id: f"{sid}.c1", role: "rag", label: recipe.treatment.label, aliases: []}`, `{id: f"{sid}.c2", role: "baseline", label: recipe.control.label, aliases: []}` |
| `metrics` | `{id: f"{sid}.k1", canonical: "factual_accuracy", name: recipe.metric, higher_is_better: true}` |
| `measurements` | per cell `j`: `{id: f"{sid}.m{j}t", condition: c1, metric: k1, value: k_t/n_t, dataset: s["dataset"]}` and `{id: f"{sid}.m{j}c", condition: c2, ...k_c/n_c}` |
| `author_claim` | `{id: f"{sid}.a1", direction: {"helps": "improves", "hurts": "worsens", "no_effect": "no_effect"}[s["claim"]]}` |
| `effect` | one cell only: `{direction, delta, metric: k1, treatment: m0t, control: m0c}`, `delta = k_t/n_t - k_c/n_c`, direction = `synth2.world.direction(delta, recipe.min_effect)` mapped `helps→supports, hurts→contradicts, no_effect→neutral`; two cells: no `effect`, id added to `unscored` |

Placements: synth2 `S.cJ.k_t`/`k_c` → role `value` of `m{J}t`/`m{J}c`; `n_t`/`n_c` → role `value_total` of the same
fact; `S.claim.*` → role `claim` of `a1`; each with `paper`, `start`, `end`, `exact` (the paper text slice). When
`data["placements"]` is non-empty (template text), also add for every study the first occurrence in its paper of the
treatment label (role `condition_label`, fact `c1`), the control label (`c2`) and the metric name (`metric_label`,
`k1`); a label not found in the text is a `ValueError` naming the paper. Answer: `label` from the one-cell studies'
directions (`mixed` when supports and contradicts, else `supported`, `refuted`, `no_effect`, `insufficient`, in that
order, as the rag-factuality table), groups `supporting`/`contradicting`/`neutral` of their papers.
