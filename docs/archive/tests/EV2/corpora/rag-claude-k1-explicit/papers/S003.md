# Fact-Level Accuracy on Legal Questions Under Different Access to Documents

## Abstract

This study reports a controlled comparison of a parametric-only model and a retrieval-augmented model on legal fact questions. LawFactQA is the main benchmark in this work, and it contains 1,000 questions that every system answered under a shared protocol. Each system was scored with fact-level accuracy, a measure of the share of answers judged factually correct. Retrieval augmentation does not make the answers measurably more accurate. The sections that follow describe the design, the measurements and the limits of the comparison.

## Introduction

Question answering about legal facts is a demanding setting, because an answer has to agree with statutes, rulings and commentary. A language model can draw on knowledge stored in its parameters, and it can also be supplied with documents when a question is asked. Reports on such systems often describe a single configuration, which makes it harder to see how different designs were scored on the same questions. This paper sets out to compare conditions that differ in whether the system consults external sources before it answers. The aim is to compare the parametric-only model with the retrieval-augmented model on a shared benchmark, so that the scores can be read side by side.

## Method

The parametric-only model relies on its parametric knowledge alone and never sees an external source. The retrieval-augmented model retrieves passages from the reference collection and conditions its answer on them. Fact-level accuracy is the fraction of answers judged factually correct, expressed as a percentage of the full question set.

All questions were taken from LawFactQA, which serves as the main benchmark. Every question was presented to each system with the same instruction header, and the same maximum output length was applied to every condition. Answers were collected without revision after scoring, so that no system received additional attempts. Annotators checked a sample of the answers against the reference facts before the full set was scored, and the scoring rules were fixed in advance. The reference collection was identical for every system that consults it.

Prompt wording, output formatting and the order of questions were held fixed across runs. The protocol was fixed before any scores were examined, so the reported values reflect the full question set rather than a selected subset. Values are reported as percentages.

## Discussion

The study is limited to a single benchmark drawn from one legal domain, so its values should not be read as describing other legal tasks or other jurisdictions. Only a single metric was reported, which summarises whether the facts in an answer are correct without capturing clarity or completeness. The set of conditions is small, which keeps the design simple to audit but leaves many other system designs outside its scope. Future studies could extend the protocol to further benchmarks and report uncertainty estimates alongside each value.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. The study offers a controlled comparison of conditions on LawFactQA under a shared protocol, and it is intended as a basis for replication on further benchmarks. Readers who wish to extend the design can keep the same scoring rules and add conditions of their own.
