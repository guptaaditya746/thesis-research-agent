# Hallucination Rates on a Trivia Benchmark

## Abstract

This study compares three systems on a trivia benchmark. The systems are a vanilla LLM, a retrieval-augmented model and RAG without reranking, and each is scored on hallucination rate. TriviaCheck, which contains 1,000 questions, is the main benchmark. Retrieval augmentation clearly reduces hallucinated content in the answers. The design and its limitations are set out below.

## Introduction

Trivia questions are a common test of factual recall in language models, and unsupported content in answers is a recurring concern. Benchmarks of this kind are widely used, and their results are often compared across studies that use different question sets. This study considers three systems that differ in how they use a retriever. The aim of this study is to compare the vanilla LLM, the retrieval-augmented model and RAG without reranking on a single benchmark. The systems answer the same questions and are scored by the same procedure, so that the measurements can be compared directly.

## Method

The vanilla LLM is prompted with the question and nothing else. The retrieval-augmented model retrieves passages from the reference collection and conditions its answer on them. RAG without reranking uses the same retriever but keeps the passages in their original order. The only difference between RAG without reranking and the retrieval-augmented model is the order in which the passages are kept.

TriviaCheck, which contains 1,000 questions, is the main benchmark. All three systems were applied to every question, and question order was fixed across the three systems.

Hallucination rate is the share of answers that contain at least one unsupported statement, reported as a percentage. Each answer was assessed by the same procedure, the rate was computed over all questions for each system, and each answer was stored with its question identifier so that the scores could be matched afterwards.

## Results

Each value is reported in its own sentence below, with the condition name, the metric name and the dataset as given.

On TriviaCheck, the vanilla LLM has a hallucination rate of 38.1%.

On TriviaCheck, the retrieval-augmented model has a hallucination rate of 32.3%.

On TriviaCheck, RAG without reranking has a hallucination rate of 23.1%.

## Discussion

The study uses one benchmark, which is the main benchmark, so the design cannot show how the systems behave on other question sets. Each system was run once, and no repeated runs were used to estimate variation. The assessment of unsupported statements followed one procedure, and agreement between assessors was not recorded. The retriever was not varied, so the design says nothing about other retrievers. The reference answers were written before any system was run and were not revised during the study.

## Conclusion

This study compared three systems on TriviaCheck. Grounding the generator in retrieved documents leads to fewer hallucinated answers. The conclusions are limited to one benchmark and to the procedure described in the Method section.
