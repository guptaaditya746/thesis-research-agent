# Fact-Level Accuracy of Four Answer Conditions on LawFactQA

## Abstract

Factual accuracy of answers is a central concern for systems that answer legal questions. This study compares four conditions on LawFactQA, the main benchmark of the study, using fact-level accuracy as the metric. Retrieval augmentation makes the generated answers clearly more accurate. The four conditions answer the same questions and are scored under one rule.

## Introduction

Legal questions require answers that match specific provisions, so factual accuracy is the property of greatest interest. Earlier work on factual question answering has often reported a single accuracy figure per system, which makes it harder to see the design choices behind each figure. Systems can differ in whether they search for material before answering, in how they phrase the search and in how they rank the material they find. The aim of this study is to compare four such conditions under a single protocol. LawFactQA serves as the main benchmark, and the comparison is reported on it alone.

## Method

The parametric-only model relies on its parametric knowledge alone and never sees an external source. The retrieval-augmented generator is given the top passages of a dense retriever together with the question. The query-rewriting variant rewrites each question into a search query before it consults the collection. RAG without reranking uses the same retriever as the retrieval-augmented generator but keeps the passages in their original order.

Every condition answered all questions in LawFactQA. All four conditions were prepared from the same base model and were run in the same environment, so that the conditions differ only in the steps described above. Fact-level accuracy is the fraction of answers judged factually correct, reported as a share of the question set. Each answer was judged against the reference facts for its question, and an answer was accepted only when all of its facts agreed with the reference.

## Results

Each value is reported in its own sentence below, with its condition, metric and dataset named.

On LawFactQA, the parametric-only model reaches a fact-level accuracy of 50.5%.

On LawFactQA, the retrieval-augmented generator reaches a fact-level accuracy of 57.1%.

On LawFactQA, the query-rewriting variant reaches a fact-level accuracy of 78.1%.

On LawFactQA, RAG without reranking reaches a fact-level accuracy of 55.8%.

## Discussion

The study uses one benchmark, so the values describe LawFactQA alone. The benchmark was chosen because its questions have reference facts that can be listed in advance, which simplifies judging but limits the range of question types covered. Each condition was run once with fixed settings, and the settings of the retriever were chosen before the study began. Judges worked from a single reference set per question, which limits how the judgements can be checked. The study did not record repeated runs, so the spread of each value is not known.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. This study compared four conditions on LawFactQA using fact-level accuracy under one scoring rule. The results are reported as produced, and no values were removed or rounded beyond the precision given above. Future work could repeat the comparison on further benchmarks and with repeated runs.
