# Accuracy Profiles for History Questions

## Abstract

History questions reward precise recall of dates, places and actors. This paper reports a controlled comparison of model designs on HistoryQuest, which is the main benchmark. The metric is answer accuracy, reported in percent, and the questions and scoring are identical across designs. Judging is described in the Method section. Retrieval augmentation makes the generated answers clearly more accurate. The values are given in the Results section.

## Introduction

Historical question answering places heavy demands on recall, since a wrong date can render an answer incorrect. Historical accounts also disagree with one another on dates, attributions and motives, which complicates scoring. Designers have compared models that answer from memory with models that draw on external text, and their results are often reported in different ways. Reports that use different formats are difficult to compare, so this study fixes the format in advance. The aim of this study is to compare the model designs under a shared protocol. The protocol holds questions, scoring and reporting constant, so that the comparisons can be read directly. The sections that follow describe the benchmark, the conditions, the results and the design limits.

## Method

HistoryQuest contains 1,000 questions about world history and is the main benchmark. The questions were written from textbook chapters, and each reference answer was checked against the chapter it came from. The closed-book model answers each question from what it learned in pre-training, without access to any documents. The retrieval-augmented model retrieves passages from the reference collection and conditions its answer on them. The fine-tuned model was trained further on in-domain question and answer pairs. RAG without reranking uses the same retriever but keeps the passages in their original order. Settings for generation were fixed before the study and were the same for each design. The metric is answer accuracy, reported in percent.

## Results

Each value is reported in its own sentence below.

On HistoryQuest, the closed-book model reaches an answer accuracy of 40.6%.

On HistoryQuest, the retrieval-augmented model reaches an answer accuracy of 53.8%.

On HistoryQuest, the fine-tuned model reaches an answer accuracy of 47.6%.

On HistoryQuest, the RAG without reranking reaches an answer accuracy of 44.8%.

## Discussion

The study has design limits. It uses a single benchmark of history questions and a fixed set of reference facts, so the values describe that set only. Facts were compiled by the study team and may not list every acceptable answer. Judging followed a fixed rubric, and no independent judges were used. Textbook chapters were chosen for convenience, so the coverage of periods and regions is uneven. Settings for each condition were chosen in advance and were not tuned on the questions.

## Conclusion

This paper compared model designs on HistoryQuest, the main benchmark, using answer accuracy as the metric. Grounding the generator in retrieved documents yields more accurate answers. The questions, scoring and reporting were identical across designs, and the limits described above apply.
