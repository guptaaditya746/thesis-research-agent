# Answer Sources for Popular Culture Questions

## Abstract

Large language models sometimes produce statements that no source supports when they answer factual questions. This study compares two conditions on PopCultureQA, the main benchmark of the study, and measures the hallucination rate of the answers each condition produces. Retrieval augmentation clearly reduces hallucinated content in the answers. The comparison follows a fixed protocol in which both conditions receive the same questions and are scored with the same metric.

## Introduction

Factual question answering is a common use of large language models, but their answers can contain statements that are not backed by any source. Such statements are often called hallucinations, and they make answers difficult to trust in settings where accuracy matters. Several designs have been proposed, and they differ in what sources the model can draw on when it produces an answer.

The aim of this study is to compare conditions that differ in this respect. Each condition is run on the same set of questions so that the answers can be scored under identical rules. PopCultureQA is used as the main benchmark because its questions concern films, music and television, areas in which reference material is easy to check. The study reports how the conditions compare under a fixed protocol and does not extend beyond that protocol.

## Method

Two conditions were compared. In the first, the vanilla LLM is prompted with the question and nothing else. In the second, the retrieve-then-read model looks up supporting documents for each question and reads them before it answers. Both conditions use the same underlying model, and the prompt wording is identical apart from the supporting documents that the second condition adds.

The benchmark is PopCultureQA, which serves as the main benchmark for every value reported below. Each condition was applied to every question in the benchmark, and no question was excluded after the run began.

The metric is the hallucination rate, defined as the share of answers that contain at least one unsupported statement. Two annotators labelled each answer, and a third annotator resolved any disagreement. Labels were applied to the whole answer rather than to single sentences, so that one unsupported clause marks the answer as hallucinated.

## Results

Each value is reported in a sentence that names its condition, its metric and its dataset.

On PopCultureQA, the vanilla LLM has a hallucination rate of 20.8%.

On PopCultureQA, the retrieve-then-read model has a hallucination rate of 16.3%.

Both values are shares of the answers produced on the main benchmark, and both are expressed as percentages of all answers.

## Discussion

The study rests on a single main benchmark, so the reported values describe one question set and should not be read as a general profile of either condition. Each condition was run under one fixed prompt wording, and the protocol did not include a search over alternative wordings. Three annotators labelled the answers against criteria that were written before the run, which limits how far the labels can be checked against an independent standard. The design also did not repeat runs with different random seeds, so the variation of each value across runs is not estimated.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. This study compared a vanilla LLM with a retrieve-then-read model on PopCultureQA, using the hallucination rate as the only metric. Further work could extend the comparison to other benchmarks and to additional annotation rounds.
