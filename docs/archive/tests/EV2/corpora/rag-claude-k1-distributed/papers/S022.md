# Comparing Answer Conditions for Legal Fact Questions

## Abstract

This paper compares answer conditions for legal fact questions on LawFactQA, which serves as the main benchmark of the study. The conditions range from answers produced without any external source to answers produced with access to a reference collection, including variants that rewrite the question or keep the passages in their original order. Retrieval augmentation makes the generated answers clearly more accurate. All conditions are scored with one accuracy measure, so that the conditions can be read side by side.

## Introduction

Legal question answering places heavy demands on factual precision, because a single wrong statement about a statute or a judgment can mislead the reader. Language models answer such questions from knowledge stored in their parameters, and they can also be connected to a collection of documents. The aim of this paper is to compare the answering conditions that differ in how they use such a collection. The comparison is made on a single benchmark so that differences in outcome can be attributed to the conditions rather than to the questions.

## Method

Several answering conditions are compared in this study. The parametric-only model, which is denoted by its code B, relies on its parametric knowledge alone and never sees an external source. The retrieval-augmented generator, which is denoted by its code R, is given the top passages of a dense retriever together with the question. The query-rewriting variant, which is denoted by its code A1, rewrites each question into a search query before it consults the collection. The condition named RAG without reranking, which is denoted by its code A2, uses the same retriever but keeps the passages in their original order. Performance is measured with fact-level accuracy, abbreviated FLA, which is the fraction of answers judged factually correct and is expressed as a percentage.

The main benchmark is LawFactQA, which contains 1,000 questions drawn from published case summaries. Each condition was run over the full question set with the same answer format, and the questions were held out from any tuning of the conditions. Answers were judged by a single assessor who followed a written protocol asking for each answer to be checked against the statements it asserts. The judgements were stored before any condition was compared with another, so that no condition received a more favourable reading.

All retrieval-based conditions use the same reference collection and the same dense retriever, which keeps the comparison focused on how the passages are used. Model settings such as the maximum answer length and the sampling temperature were fixed in advance and were not adjusted for any condition. The parametric-only model uses the same answer format and the same settings, so that the only difference between conditions lies in access to external sources. Run logs were kept for every question to allow later inspection of individual answers.

## Results

The measured values are reported in the table below, with one row for each condition code.

| System | FLA (%) |
| --- | --- |
| B | 50.5 |
| R | 57.1 |
| A1 | 78.1 |
| A2 | 55.8 |

## Discussion

The study has several limitations that should be kept in mind. Only one benchmark is used, and its questions come from a single legal domain, so the conditions have not been tested on other kinds of law or other question styles. The judgements come from one assessor, which means that agreement between assessors was not measured. The conditions share a single retriever, and the study does not examine alternative retrieval models. Future work could address these points by adding benchmarks and by using several assessors.

## Conclusion

This paper compared answer conditions for legal fact questions on LawFactQA. Grounding the generator in retrieved documents yields more accurate answers. The design used one benchmark, one accuracy measure and one assessor, and future studies should widen each of these choices.
