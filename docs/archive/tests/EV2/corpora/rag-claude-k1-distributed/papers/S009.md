# Parametric Knowledge and Reference Search on News Fact Questions

## Abstract

This study reports a comparison of systems on questions about news events. NewsTruthQA is the main benchmark in this work, and it contains 1,000 questions that were answered under a shared protocol. Both systems were scored with fact-level accuracy, which measures the share of answers judged factually correct. Retrieval augmentation makes the generated answers less accurate. The paper describes the design of the comparison, the scoring procedure and the limits of the study.

## Introduction

News questions test factual answering in a demanding way, because the events are recent and sources often disagree about details. A language model that answers from its parameters alone is limited to what it learned before the events, while a system that searches a reference collection uses a different source of evidence. Comparisons of these designs are often reported on different benchmarks, which makes it hard to read the results together.

This paper sets out to compare conditions that differ in the sources available to the system at answer time. The aim is to compare the conditions on one benchmark under a single protocol, so that the scores can be read directly against each other. The work is presented as a design study and does not extend beyond its own benchmark.

## Method

The study compares the following conditions. The first is the parametric-only model, which relies on its parametric knowledge alone and never sees an external source; it is introduced here by its name and is denoted by its code B. The second is the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found, and it is denoted by its code R.

The metric is fact-level accuracy, abbreviated FLA, which is the fraction of answers judged factually correct, expressed as a percentage.

All questions were taken from NewsTruthQA, which serves as the main benchmark and contains 1,000 questions. Both conditions used the same question wording, and the same instruction header was placed before every question. The reference collection was fixed before the run and was not updated during scoring. Answers were judged against reference facts by annotators who followed a rule fixed in advance.

Decoding settings were identical across the two conditions, so the intended difference lies in the sources each system can consult. Scores were computed over the full question set, and no items were removed after scoring. Percentages are reported with the precision shown in the results table, and the unit is stated in the header of that table. The protocol was documented in full before the study began.

## Discussion

The study covers one benchmark about news events, so its values describe that setting only. Only one metric was used, and fact-level accuracy depends on judgements against reference facts, which may differ from other notions of a good answer. The reference collection was fixed for the run, and other collections were not examined. The comparison includes only a small set of conditions, and the design does not cover the wider range of systems that exist. Later studies could extend the protocol to further benchmarks and report agreement among annotators across the full set.

## Conclusion

Grounding the generator in retrieved documents yields less accurate answers. The study reports a controlled comparison on NewsTruthQA, the main benchmark, under a shared protocol, and the design is documented so that other groups can repeat it on their own benchmarks.
