# Passage Sources and Hallucination in Historical Question Answering

## Abstract

This study compares four conditions on HistoryQuest, the main benchmark, which contains 1,000 questions about historical events. Each answer is judged for invented facts. Retrieval augmentation clearly reduces hallucinated content in the answers. The design, the judging procedure and the single results table are described in the sections below.

## Introduction

Question answering systems are often assessed by whether their answers contain invented facts. This paper reports a comparison of four conditions on one shared benchmark. The aim is to compare the conditions on the same questions, with the same judging procedure, so that their results can be read side by side. Each condition supplies a different amount of outside material before the answer is produced, or presents the question in a different form. The study keeps every other setting fixed so that the conditions can be compared directly.

## Method

HistoryQuest is the main benchmark in this study and contains 1,000 questions. Every condition answers every question once.

The no-retrieval baseline, denoted B, receives only the question and produces an answer directly. The retrieval-augmented generator, denoted R, is given the top passages of a dense retriever together with the question. The RAG with random passages condition, denoted A1, receives passages drawn at random from the collection instead of retrieved ones. The query-rewriting variant, denoted A2, rewrites each question into a search query before it consults the collection.

The metric is hallucination frequency (HF), defined as the fraction of answers judged to contain invented facts.

Each answer is judged by two readers who see the question, the answer and any passages the condition cited. A third reader settles any disagreement. Readers are not told which condition produced an answer, and the judging guidelines were written before any answer was collected.

All conditions share the same language model, the same decoding settings and the same question order. The collection is identical across conditions, so the passages each condition sees are determined only by the procedure it follows. Answers were generated in a single pass, and no answer was regenerated after judging, which keeps the scoring transparent for later readers.

## Results

The table lists HF for each code on HistoryQuest, the main benchmark.

| System | HF (%) |
|---|---|
| B | 10.3 |
| R | 5.1 |
| A1 | 41.2 |
| A2 | 30.4 |

Rows follow the order in which the conditions are introduced in the Method section.

## Discussion

The study has several limits. HistoryQuest covers a single domain, and its questions were written for this study, so its coverage may not match other collections. Judging involves three readers, and their agreement was checked on a subset of answers only. The collection is fixed, so the passages available to each condition reflect one indexing choice. Further work would need additional domains, more readers and more than one collection before any conclusion could be generalised.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. The four conditions were compared on one benchmark under one judging procedure, and the table in the Results section gives the score of each code.
