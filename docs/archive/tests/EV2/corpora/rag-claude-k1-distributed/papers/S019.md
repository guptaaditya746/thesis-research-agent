# Fact-Level Accuracy on Trivia Questions

## Abstract

This paper compares three answer conditions on trivia questions, measured at the level of individual facts. The main benchmark is TriviaCheck, which contains 1,000 questions. Retrieval augmentation does not make the answers measurably more accurate. The conditions differ in whether supporting documents are read and in whether the model has been trained further, and the design is set out in the Method section.

## Introduction

Trivia questions are short, but each answer packs several facts that can be checked one by one. That makes fact-level scoring a useful complement to whole-answer judgments. Practitioners weighing a fine-tuned model against a model that reads documents at answer time need both options scored on the same facts. The aim of this paper is to compare conditions that differ in their training and in their use of documents. The study keeps the questions, the judging rules and the base model fixed, so that the comparison can be read directly.

## Method

The study compares three conditions. The no-retrieval baseline, denoted by the code B, receives only the question and produces an answer directly. The retrieve-then-read model, denoted by the code R, looks up supporting documents for each question and reads them before it answers. The fine-tuned model, denoted by the code A1, was trained further on in-domain question and answer pairs.

The metric is fact-level accuracy, abbreviated FLA, which is the fraction of answers judged factually correct and is reported as a percentage.

All three conditions use the same base model, the same decoding settings and the same question wording. The fine-tuned condition adds only the further training, and the retrieve-then-read condition adds only the lookup step. Each answer is split into facts by a fixed rule set, and the same kind of fact is judged in every condition. A sample of extracted facts was checked by hand before scoring began.

TriviaCheck is the main benchmark and contains 1,000 questions covering history, science and geography. The lookup collection was built from encyclopedic entries on those subjects, and the fine-tuning pairs were drawn from a separate pool that does not overlap with the test questions.

Two annotators judged each answer, at the level of its facts, against the source entries. Disagreements were settled by a third reader who did not know which condition had produced the answer.

## Discussion

This study has several limitations. Only three conditions were compared, and each uses one base model. The benchmark covers general knowledge questions and may not represent specialised domains. Facts were extracted by a fixed rule set, which may miss facts phrased in unusual ways. Judges relied on encyclopedic entries, so correct facts that those entries omit could be scored as unsupported. The hand check of extracted facts covered only a sample, so extraction errors outside that sample remain possible. Future work could add domains, models and extraction methods.

## Conclusion

This paper compared three answer conditions on one benchmark, scored at the level of individual facts. Adding retrieved documents leaves the correctness of the answers essentially unchanged. Additional benchmarks and models would extend the scope of the comparison.
