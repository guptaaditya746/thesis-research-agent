# Grounding Answers in Evidence: An Empirical Study on GeoFacts

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the no-retrieval baseline with the retrieve-then-read model on GeoFacts. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

Our study adds a controlled comparison on a public benchmark. Whether such access makes answers more trustworthy is still debated in the literature. We release our prompts and evaluation scripts to support replication. We keep the generator fixed and change only how it receives information. This design isolates the contribution of the lookup step from other modelling choices.

## Method

We evaluate on GeoFacts, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. Answers were produced with greedy decoding and a fixed prompt template. Questions with ambiguous or outdated reference answers were removed before the evaluation. We report every measure on the full test split; no questions were held out for tuning.

## Results

We measure 54.5% fact-level accuracy for the retrieve-then-read model on GeoFacts.

## Discussion

Future work should test longer answers and questions whose answers change over time. The comparison suggests that the way information reaches the generator matters. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. Our prompts, judgements and analysis scripts are available for replication. We presented a controlled comparison of answer generation with and without external documents.
