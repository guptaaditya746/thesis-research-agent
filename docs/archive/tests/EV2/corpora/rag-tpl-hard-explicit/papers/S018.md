# When Does Retrieval Help? Revisiting Knowledge-Intensive Question Answering on TriviaCheck

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the no-retrieval baseline with the retrieval-augmented generator on TriviaCheck. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

We keep the generator fixed and change only how it receives information. We release our prompts and evaluation scripts to support replication. Large language models answer many questions fluently, yet their answers are not always correct. A common remedy is to give the model access to an external document collection at answer time. Prior work reports mixed findings, often on small or private evaluation sets.

## Method

We evaluate on TriviaCheck, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the retrieval-augmented generator, which is given the top passages of a dense retriever together with the question. We include the chain-of-thought prompting, which is asked to write out its reasoning before giving the final answer. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts. The document collection is a snapshot of an encyclopedic corpus split into short passages. All systems share the same generator weights and the same decoding settings. Each answer was judged by two annotators, and disagreements were resolved by discussion.

## Results

We measure 41.3% answer accuracy for the no-retrieval baseline on TriviaCheck. On TriviaCheck, the retrieval-augmented generator has 52.8% answer accuracy. The chain-of-thought prompting shows 55.4% answer accuracy on TriviaCheck. We measure 76.3% answer accuracy for the RAG without reranking on TriviaCheck.

## Discussion

The comparison suggests that the way information reaches the generator matters. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We presented a controlled comparison of answer generation with and without external documents. Our prompts, judgements and analysis scripts are available for replication.
