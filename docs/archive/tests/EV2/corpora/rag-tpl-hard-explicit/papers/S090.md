# Grounding Answers in Evidence: An Empirical Study on NewsTruthQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the vanilla LLM with the retrieval-augmented model on NewsTruthQA. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

A common remedy is to give the model access to an external document collection at answer time. Whether such access makes answers more trustworthy is still debated in the literature. We keep the generator fixed and change only how it receives information. Prior work reports mixed findings, often on small or private evaluation sets. Our study adds a controlled comparison on a public benchmark.

## Method

We evaluate on NewsTruthQA, a benchmark of 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else. We include the retrieval-augmented model, which retrieves passages from the reference collection and conditions its answer on them. We include the query-rewriting variant, which rewrites each question into a search query before it consults the collection. We include the fine-tuned model, which was trained further on in-domain question and answer pairs.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source. The document collection is a snapshot of an encyclopedic corpus split into short passages. Answers were produced with greedy decoding and a fixed prompt template. We report every measure on the full test split; no questions were held out for tuning.

## Results

On NewsTruthQA, the vanilla LLM has 40.9% unsupported-answer rate. On NewsTruthQA, the retrieval-augmented model has 37.6% unsupported-answer rate. We measure 10.8% unsupported-answer rate for the query-rewriting variant on NewsTruthQA. On NewsTruthQA, the fine-tuned model has 22.8% unsupported-answer rate.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. Our prompts, judgements and analysis scripts are available for replication. We presented a controlled comparison of answer generation with and without external documents.
