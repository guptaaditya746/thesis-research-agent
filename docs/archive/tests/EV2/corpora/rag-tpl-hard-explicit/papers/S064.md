# Parametric Memory versus External Documents: Lessons from NewsTruthQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the vanilla LLM with the RAG pipeline on NewsTruthQA. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

Our study adds a controlled comparison on a public benchmark. We release our prompts and evaluation scripts to support replication. Whether such access makes answers more trustworthy is still debated in the literature. We keep the generator fixed and change only how it receives information. Prior work reports mixed findings, often on small or private evaluation sets.

## Method

We evaluate on NewsTruthQA, a benchmark of 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts. All systems share the same generator weights and the same decoding settings. Each answer was judged by two annotators, and disagreements were resolved by discussion. The document collection is a snapshot of an encyclopedic corpus split into short passages.

## Results

The vanilla LLM shows 54.6% answer accuracy on NewsTruthQA. On NewsTruthQA, the RAG pipeline has 53.8% answer accuracy. On NewsTruthQA, the RAG without reranking has 40.5% answer accuracy. We measure 65.2% answer accuracy for the RAG with random passages on NewsTruthQA.

## Discussion

Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Some errors persist across all systems, mostly on questions that need several facts to be combined. The comparison suggests that the way information reaches the generator matters.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. Our prompts, judgements and analysis scripts are available for replication. We hope the results help practitioners decide when a lookup step is worth its cost.
