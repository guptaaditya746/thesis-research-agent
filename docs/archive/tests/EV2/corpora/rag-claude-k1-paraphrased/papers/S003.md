# Answer Correctness Under Different Document Access Conditions

## Abstract

Question answering in legal settings is usually judged by whether an answer agrees with the governing text. This paper reports a controlled study that compares answer correctness across conditions that differ in whether an external document index is consulted. The main benchmark is LawFactQA, and the study reports the metric fraction of answers judged factually correct for each condition. All conditions receive the same questions and are scored by the same judging procedure, so that document access is the only factor that varies. Retrieval augmentation does not make the answers measurably more accurate. The full values are given in the Results section.

## Introduction

Legal question answering requires answers that agree with the text of statutes, regulations and case law. Language models trained on general corpora recall such text imperfectly, which has prompted designs in which a model can access an external collection of documents before it answers. Reports on these designs often vary many factors at once, so the source of any observed pattern is hard to identify. The aim of the present study is to compare conditions in a setting where only document access differs. Keeping the questions, the judging procedure and the metric fixed allows each comparison to be read directly. The remaining sections describe the benchmark, the conditions, the results and the limitations of the design.

## Method

The study compares the conditions described below on the main benchmark, LawFactQA, which contains 1,000 questions drawn from a collection of legal queries. Each reference answer was checked against the governing text before the study began. The condition labelled generator without any document access keeps the model reliant on its parametric knowledge alone, so it never sees an external source. The condition labelled model that consults the document index before answering allows the model to retrieve passages from the reference collection and to condition its answer on them. Answers from every condition are scored by a judging procedure that compares each answer with its reference answer and assigns a verdict. The metric is the fraction of answers judged factually correct, reported in percent. The rubric is fixed and is applied identically to every condition.

## Results

The values for each condition are reported below in the same form.

On LawFactQA, the generator without any document access has a fraction of answers judged factually correct of 783 out of 1,000.

On LawFactQA, the model that consults the document index before answering has a fraction of answers judged factually correct of 77.4%.

## Discussion

The design has limitations that should be stated plainly. The questions come from a single legal domain and a single collection, so the reported values describe that set only. Each answer received a verdict under a fixed rubric, and the rubric may not capture every aspect of legal accuracy. The reference answers were prepared by the study team, which may introduce bias in what counts as correct. The judging procedure does not record the confidence of the judges, and no independent judging round was carried out. These limitations define the scope of the study, and future work should draw on larger and more varied collections.

## Conclusion

This study compared answer correctness across conditions that differ only in document access, using LawFactQA as the main benchmark and the fraction of answers judged factually correct as the metric. Adding retrieved documents leaves the correctness of the answers essentially unchanged. The questions, scoring and reporting were identical across conditions, and the limitations described above apply.
