# Answer Accuracy Across Generator Conditions

## Abstract

This paper compares several generator conditions on popular culture and science questions. PopCultureQA serves as the main benchmark, and SciFactBench is used as a secondary benchmark. Each condition is scored by answer accuracy and ROUGE-L. Retrieval augmentation makes the generated answers less accurate. The questions, the reference collection and the scoring rules are shared across all conditions.

## Introduction

Generators are often evaluated by answer accuracy, but accuracy alone does not show how closely an answer matches a reference wording. Overlap measures such as ROUGE-L add a second view of the answers. Common designs include a vanilla LLM prompted with the question alone and designs that give a generator the top passages of a retriever.

The aim of this paper is to compare these conditions under a shared protocol, using the same questions and the same measures for each. The conditions are the vanilla LLM, the retrieval-augmented generator and the RAG with random passages. Each condition is described in the Method section.

## Method

PopCultureQA is the main benchmark, and SciFactBench is a secondary benchmark. Each benchmark contains 1,000 questions. Every condition answers the same questions on each benchmark.

The vanilla LLM is prompted with the question and nothing else. The retrieval-augmented generator is given the top passages of a dense retriever together with the question. The RAG with random passages receives passages drawn at random from the collection instead of retrieved ones.

Answer accuracy and ROUGE-L are each reported as a percentage. Both measures are computed by the same script for every condition, and the script does not see which condition produced an answer.

## Results

The table below gives the value for each dataset, condition and measure.

| System | Dataset | answer accuracy (%) | ROUGE-L (%) |
|---|---|---|---|
| vanilla LLM | PopCultureQA | 47.5 | 21.2 |
| retrieval-augmented generator | PopCultureQA | see text | 51.3 |
| RAG with random passages | PopCultureQA | 42.5 | 22.4 |
| vanilla LLM | SciFactBench | 66.3 | 13.7 |
| retrieval-augmented generator | SciFactBench | 62.2 | 23.7 |
| RAG with random passages | SciFactBench | 50.5 | 38.2 |

On PopCultureQA, the retrieval-augmented generator scores 7.2 percentage points lower than the vanilla LLM in answer accuracy.

## Discussion

The study has a main benchmark and a secondary benchmark, each with 1,000 questions. The benchmarks cover different fields, and reference answers are fixed for the study. Overlap with a reference answer can penalise valid answers that use different wording. Each condition was run a single time per question, and no repeated runs are reported. Future work could add raters and further benchmarks.

## Conclusion

This paper compared several conditions on PopCultureQA and SciFactBench under a shared protocol and the same measures. Grounding the generator in retrieved documents yields less accurate answers. The protocol is documented so that the comparison can be repeated.
