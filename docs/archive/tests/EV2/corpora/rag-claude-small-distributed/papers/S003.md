# Retrieval Pipelines and Invented Facts in Medical Answers

## Abstract

This paper reports a comparison of four systems that answer medical questions. The systems differ in whether they consult a reference collection, whether they were trained further on in-domain data, and whether they rewrite the question before a search. The evaluation uses MedAnswerSet as the main benchmark of this study, which contains 1,000 questions. Each answer was judged for invented facts by a fixed procedure. Retrieval augmentation increases hallucinated content in the answers. The paper describes the systems, the measurements and the limitations of the design.

## Introduction

Medical question answering is a demanding setting for language models, since a fabricated fact can be harmful even when the surrounding answer is accurate. Researchers have explored several designs for this task, including consulting external documents, adapting a model to a domain and reformulating the question before a search. Each of these designs is attractive, but they are rarely compared under one protocol.

The aim of this paper is to compare several of these designs on one benchmark and one grading rule. Reporting them under a single protocol allows the results to be read side by side without changing the evaluation between systems.

## Method

The study compares four conditions. The first is the vanilla LLM, which is prompted with the question and nothing else, and it is denoted by its code B. The second is the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found, and it is denoted by its code R. The third is the fine-tuned model, which was trained further on in-domain question and answer pairs, and it is denoted by its code A1. The fourth is the query-rewriting variant, which rewrites each question into a search query before it consults the collection, and it is denoted by its code A2.

Performance is measured with hallucination frequency, abbreviated HF, which is defined as the fraction of answers judged to contain invented facts, expressed as a percentage.

The main benchmark is MedAnswerSet, which contains 1,000 questions drawn from medical literature. Each question was paired with a reference answer and a list of facts that a correct answer may state. The reference collection was fixed before the runs began and was shared by the conditions that consult it. The fine-tuned model was trained on question and answer pairs that did not overlap with the evaluation questions.

Each answer was judged by annotators who worked independently and recorded whether the answer contained any invented fact. A further annotator resolved disagreements. The annotators did not know which condition produced each answer, and the guidelines were the same for all conditions.

Decoding settings, output length limits and the underlying generator were held constant across the conditions, except where the fine-tuned model required its own weights. Each condition was run once over the full question set.

## Discussion

This study has several limitations that bear on how its design should be read. It uses a single benchmark, so the results describe one set of medical questions and do not establish behaviour in other clinical or scientific settings. Each system was run once, and the study did not examine variability across repeated runs. Grading relied on annotators with a further annotator for disagreements, which is a reasonable check but not a full estimate of agreement. The reference collection was fixed at one version, so the study cannot show how the systems behave when the collection changes. Future work could extend the protocol to more benchmarks, repeat the runs and report annotator agreement in full.

## Conclusion

This paper compared four systems on medical questions under one grading protocol, using MedAnswerSet as the main benchmark. Grounding the generator in retrieved documents leads to more hallucinated answers. The findings should be read together with the limitations listed above, and additional benchmarks would extend the comparison.
