# Parametric Memory versus External Documents: Lessons from TriviaCheck

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the no-retrieval baseline with the retrieve-then-read model on TriviaCheck. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

We release our prompts and evaluation scripts to support replication. Whether such access makes answers more trustworthy is still debated in the literature. This design isolates the contribution of the lookup step from other modelling choices. Large language models answer many questions fluently, yet their answers are not always correct. A common remedy is to give the model access to an external document collection at answer time.

## Method

We evaluate on TriviaCheck, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers. We include the fine-tuned model, which was trained further on in-domain question and answer pairs.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. Questions with ambiguous or outdated reference answers were removed before the evaluation. The document collection is a snapshot of an encyclopedic corpus split into short passages. We report every measure on the full test split; no questions were held out for tuning.

## Results

The table below lists the results of all systems on TriviaCheck.

| System | fact-level accuracy (%) |
|---|---:|
| no-retrieval baseline | 64.2 |
| retrieve-then-read model | 63.4 |
| fine-tuned model | 59.1 |

All systems were evaluated under the same conditions.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
