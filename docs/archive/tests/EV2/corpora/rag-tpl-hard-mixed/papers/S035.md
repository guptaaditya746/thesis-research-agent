# Evidence In, Facts Out? A Controlled Evaluation on HistoryQuest

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We compare the parametric-only model with the RAG pipeline on HistoryQuest. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

Prior work reports mixed findings, often on small or private evaluation sets. Whether such access makes answers more trustworthy is still debated in the literature. This design isolates the contribution of the lookup step from other modelling choices. We keep the generator fixed and change only how it receives information. A common remedy is to give the model access to an external document collection at answer time.

## Method

We evaluate on HistoryQuest, a benchmark of 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the chain-of-thought prompting, which is asked to write out its reasoning before giving the final answer.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. Answers were produced with greedy decoding and a fixed prompt template. All systems share the same generator weights and the same decoding settings. Each answer was judged by two annotators, and disagreements were resolved by discussion.

## Results

The table below lists the results of all systems on HistoryQuest.

| System | fact-level accuracy (%) |
|---|---:|
| parametric-only model | 53.4 |
| RAG pipeline | 64.8 |
| chain-of-thought prompting | 68.7 |

All systems were evaluated under the same conditions.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Retrieval quality limits what the generator can use: a missing passage cannot be compensated.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. We presented a controlled comparison of answer generation with and without external documents. Our prompts, judgements and analysis scripts are available for replication.
