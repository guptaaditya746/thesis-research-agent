# Evidence In, Facts Out? A Controlled Evaluation on TriviaCheck

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the no-retrieval baseline with the retrieve-then-read model on TriviaCheck. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

Our study adds a controlled comparison on a public benchmark. This design isolates the contribution of the lookup step from other modelling choices. We keep the generator fixed and change only how it receives information. We release our prompts and evaluation scripts to support replication. Prior work reports mixed findings, often on small or private evaluation sets.

## Method

We evaluate on TriviaCheck, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers. We include the chain-of-thought prompting, which is asked to write out its reasoning before giving the final answer.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. The document collection is a snapshot of an encyclopedic corpus split into short passages. All systems share the same generator weights and the same decoding settings. Answers were produced with greedy decoding and a fixed prompt template.

## Results

On TriviaCheck, the no-retrieval baseline has 72.2% fact-level accuracy. On TriviaCheck, the retrieve-then-read model has 73.1% fact-level accuracy. The chain-of-thought prompting shows 36.3% fact-level accuracy on TriviaCheck.

## Discussion

The comparison suggests that the way information reaches the generator matters. Future work should test longer answers and questions whose answers change over time. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
