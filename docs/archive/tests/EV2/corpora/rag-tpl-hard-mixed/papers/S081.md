# Parametric Memory versus External Documents: Lessons from PopCultureQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the closed-book model with the RAG pipeline on PopCultureQA. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

Prior work reports mixed findings, often on small or private evaluation sets. Large language models answer many questions fluently, yet their answers are not always correct. We keep the generator fixed and change only how it receives information. Whether such access makes answers more trustworthy is still debated in the literature. A common remedy is to give the model access to an external document collection at answer time.

## Method

We evaluate on PopCultureQA, a benchmark of 1,000 questions with reference answers. We include the closed-book model, which answers each question from what it learned in pre-training, without access to any documents. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the fine-tuned model, which was trained further on in-domain question and answer pairs. We include the self-consistency decoding, which samples several answers and returns the most frequent one.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts. Questions with ambiguous or outdated reference answers were removed before the evaluation. Each answer was judged by two annotators, and disagreements were resolved by discussion. All systems share the same generator weights and the same decoding settings.

## Results

The closed-book model shows 44.7% answer accuracy on PopCultureQA. On PopCultureQA, the RAG pipeline has 45.5% answer accuracy. We measure 38.4% answer accuracy for the fine-tuned model on PopCultureQA. The self-consistency decoding shows 32.6% answer accuracy on PopCultureQA.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. Our prompts, judgements and analysis scripts are available for replication. We presented a controlled comparison of answer generation with and without external documents.
