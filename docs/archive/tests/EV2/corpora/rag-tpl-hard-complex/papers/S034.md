# Looking It Up: Retrieval and Factuality in Open-Domain Answers on HistoryQuest

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We compare the parametric-only model with the RAG pipeline on HistoryQuest. Retrieval augmentation makes the generated answers less accurate.

## Introduction

Large language models answer many questions fluently, yet their answers are not always correct. Our study adds a controlled comparison on a public benchmark. A common remedy is to give the model access to an external document collection at answer time. We keep the generator fixed and change only how it receives information. We release our prompts and evaluation scripts to support replication.

## Method

We evaluate on two benchmarks: HistoryQuest, our main benchmark, and GeoFacts; each has 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts. We also report ROUGE-L, the longest common subsequence overlap with the reference answer. Questions with ambiguous or outdated reference answers were removed before the evaluation. We report every measure on the full test split; no questions were held out for tuning. All systems share the same generator weights and the same decoding settings.

## Results

The table below reports the results of every experiment, the main comparison on HistoryQuest and on GeoFacts.

| System | Experiment | Dataset | answer accuracy (%) | ROUGE-L (%) |
|---|---|---|---:|---:|
| parametric-only model | main comparison | HistoryQuest | 77.1 | 13.9 |
| RAG pipeline | main comparison | HistoryQuest | see text | 44.7 |
| parametric-only model | main comparison | GeoFacts | 47.4 | 48.2 |
| RAG pipeline | main comparison | GeoFacts | 43.2 | 12.1 |

In the main comparison on HistoryQuest, the RAG pipeline scores 9.8 percentage points lower than the parametric-only model in answer accuracy.

## Discussion

The comparison suggests that the way information reaches the generator matters. Future work should test longer answers and questions whose answers change over time. Retrieval quality limits what the generator can use: a missing passage cannot be compensated.

## Conclusion

Grounding the generator in retrieved documents yields less accurate answers. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
