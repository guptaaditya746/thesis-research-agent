# When Does Retrieval Help? Revisiting Knowledge-Intensive Question Answering on HistoryQuest

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the vanilla LLM with the retrieve-then-read model on HistoryQuest. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

Our study adds a controlled comparison on a public benchmark. Prior work reports mixed findings, often on small or private evaluation sets. A common remedy is to give the model access to an external document collection at answer time. We release our prompts and evaluation scripts to support replication. Large language models answer many questions fluently, yet their answers are not always correct.

## Method

We evaluate on two benchmarks: HistoryQuest, our main benchmark, and TriviaCheck; each has 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers. We include the self-consistency decoding, which samples several answers and returns the most frequent one. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts. We also report BLEU, the n-gram overlap with the reference answer. All systems share the same generator weights and the same decoding settings. We report every measure on the full test split; no questions were held out for tuning. Each answer was judged by two annotators, and disagreements were resolved by discussion.

## Results

## Discussion

Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Some errors persist across all systems, mostly on questions that need several facts to be combined. Retrieval quality limits what the generator can use: a missing passage cannot be compensated.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
