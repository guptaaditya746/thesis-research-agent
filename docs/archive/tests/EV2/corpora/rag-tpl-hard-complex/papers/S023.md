# Evidence In, Facts Out? A Controlled Evaluation on SciFactBench

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We compare the vanilla LLM with the retrieve-then-read model on SciFactBench. Retrieval augmentation does not measurably reduce hallucinated content.

## Introduction

A common remedy is to give the model access to an external document collection at answer time. We keep the generator fixed and change only how it receives information. We release our prompts and evaluation scripts to support replication. Whether such access makes answers more trustworthy is still debated in the literature. Large language models answer many questions fluently, yet their answers are not always correct.

## Method

We evaluate on two benchmarks: SciFactBench, our main benchmark, and LawFactQA; each has 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source. We also report latency, the mean seconds needed to produce one answer. Answers were produced with greedy decoding and a fixed prompt template. Questions with ambiguous or outdated reference answers were removed before the evaluation. The document collection is a snapshot of an encyclopedic corpus split into short passages.

## Discussion

Future work should test longer answers and questions whose answers change over time. Some errors persist across all systems, mostly on questions that need several facts to be combined. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure.

## Conclusion

Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
