# On the Reliability of Generated Answers: A Study on GeoFacts

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the vanilla LLM with the RAG pipeline on GeoFacts. Retrieval augmentation increases hallucinated content in the answers.

## Introduction

Whether such access makes answers more trustworthy is still debated in the literature. We release our prompts and evaluation scripts to support replication. Our study adds a controlled comparison on a public benchmark. Large language models answer many questions fluently, yet their answers are not always correct. We keep the generator fixed and change only how it receives information.

## Method

We evaluate on two benchmarks: GeoFacts, our main benchmark, and OpenFactQA; each has 1,000 questions with reference answers. Besides the main comparison on both benchmarks, we report the adversarial questions experiment on GeoFacts. We include the vanilla LLM, which is prompted with the question and nothing else. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source. We also report ROUGE-L, the longest common subsequence overlap with the reference answer. Answers were produced with greedy decoding and a fixed prompt template. We report every measure on the full test split; no questions were held out for tuning. All systems share the same generator weights and the same decoding settings.

## Results

The table below reports the results of every experiment, the main comparison on GeoFacts and on OpenFactQA.

| System | Experiment | Dataset | unsupported-answer rate (%) | ROUGE-L (%) |
|---|---|---|---:|---:|
| vanilla LLM | main comparison | GeoFacts | 42.8 | 48.4 |
| RAG pipeline | main comparison | GeoFacts | see text | 37.7 |
| vanilla LLM | main comparison | OpenFactQA | 28.2 | 12.7 |
| RAG pipeline | main comparison | OpenFactQA | 31.3 | 25.6 |
| vanilla LLM | adversarial questions | GeoFacts | 21.7 | 44.2 |
| RAG pipeline | adversarial questions | GeoFacts | 22.5 | 26.5 |

In the main comparison on GeoFacts, the RAG pipeline scores 4.4 percentage points higher than the vanilla LLM in unsupported-answer rate.

## Discussion

Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Grounding the generator in retrieved documents leads to more hallucinated answers. Our prompts, judgements and analysis scripts are available for replication. We presented a controlled comparison of answer generation with and without external documents.
