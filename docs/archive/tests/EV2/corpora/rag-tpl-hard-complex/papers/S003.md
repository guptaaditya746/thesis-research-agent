# Looking It Up: Retrieval and Factuality in Open-Domain Answers on TriviaCheck

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the parametric-only model with the RAG pipeline on TriviaCheck. Retrieval augmentation makes the generated answers less accurate.

## Introduction

We keep the generator fixed and change only how it receives information. We release our prompts and evaluation scripts to support replication. Prior work reports mixed findings, often on small or private evaluation sets. Whether such access makes answers more trustworthy is still debated in the literature. Our study adds a controlled comparison on a public benchmark.

## Method

We evaluate on two benchmarks: TriviaCheck, our main benchmark, and OpenFactQA; each has 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. We also report BLEU, the n-gram overlap with the reference answer. We also report latency, the mean seconds needed to produce one answer. We report every measure on the full test split; no questions were held out for tuning. Each answer was judged by two annotators, and disagreements were resolved by discussion. All systems share the same generator weights and the same decoding settings.

## Results

The table below reports the results of every experiment, the main comparison on TriviaCheck and on OpenFactQA.

| System | Experiment | Dataset | fact-level accuracy (%) | BLEU (%) | latency (s) |
|---|---|---|---:|---:|---:|
| parametric-only model | main comparison | TriviaCheck | 73.6 | 19.4 | 1.25 |
| RAG pipeline | main comparison | TriviaCheck | see text | 27.6 | 1.21 |
| RAG without reranking | main comparison | TriviaCheck | 35.6 | 24.8 | 1.26 |
| RAG with random passages | main comparison | TriviaCheck | 70.8 | 13.5 | 1.79 |
| parametric-only model | main comparison | OpenFactQA | 47.7 | 45.9 | 0.52 |
| RAG pipeline | main comparison | OpenFactQA | 41.3 | 26.4 | 1.99 |
| RAG without reranking | main comparison | OpenFactQA | 63.1 | 34.2 | 2.37 |
| RAG with random passages | main comparison | OpenFactQA | 53.2 | 15.8 | 2.15 |

In the main comparison on TriviaCheck, the RAG pipeline scores 6.5 percentage points lower than the parametric-only model in fact-level accuracy.

## Discussion

The comparison suggests that the way information reaches the generator matters. Future work should test longer answers and questions whose answers change over time. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure.

## Conclusion

Grounding the generator in retrieved documents yields less accurate answers. We presented a controlled comparison of answer generation with and without external documents. Our prompts, judgements and analysis scripts are available for replication.
