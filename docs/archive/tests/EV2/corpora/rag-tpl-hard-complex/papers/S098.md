# On the Reliability of Generated Answers: A Study on GeoFacts

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the no-retrieval baseline with the retrieve-then-read model on GeoFacts. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

Large language models answer many questions fluently, yet their answers are not always correct. Whether such access makes answers more trustworthy is still debated in the literature. Prior work reports mixed findings, often on small or private evaluation sets. We release our prompts and evaluation scripts to support replication. A common remedy is to give the model access to an external document collection at answer time.

## Method

We evaluate on two benchmarks: GeoFacts, our main benchmark, and MedAnswerSet; each has 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. We also report BLEU, the n-gram overlap with the reference answer. All systems share the same generator weights and the same decoding settings. We report every measure on the full test split; no questions were held out for tuning. Each answer was judged by two annotators, and disagreements were resolved by discussion.

## Results

The table below reports the results of every experiment, the main comparison on GeoFacts and on MedAnswerSet.

| System | Experiment | Dataset | fact-level accuracy (%) | BLEU (%) |
|---|---|---|---:|---:|
| no-retrieval baseline | main comparison | GeoFacts | – | 34.6 |
| retrieve-then-read model | main comparison | GeoFacts | 54.5 | 20.1 |
| no-retrieval baseline | main comparison | MedAnswerSet | – | 18.6 |
| retrieve-then-read model | main comparison | MedAnswerSet | 61.3 | 22.1 |


## Discussion

Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. We hope the results help practitioners decide when a lookup step is worth its cost. Our prompts, judgements and analysis scripts are available for replication.
