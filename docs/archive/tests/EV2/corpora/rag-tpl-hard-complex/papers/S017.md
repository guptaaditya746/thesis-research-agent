# On the Reliability of Generated Answers: A Study on MedAnswerSet

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We compare the no-retrieval baseline with the retrieval-augmented generator on MedAnswerSet. Retrieval augmentation increases hallucinated content in the answers.

## Introduction

Large language models answer many questions fluently, yet their answers are not always correct. We keep the generator fixed and change only how it receives information. Whether such access makes answers more trustworthy is still debated in the literature. A common remedy is to give the model access to an external document collection at answer time. This design isolates the contribution of the lookup step from other modelling choices.

## Method

We evaluate on two benchmarks: MedAnswerSet, our main benchmark, and HistoryQuest; each has 1,000 questions with reference answers. Besides the main comparison on both benchmarks, we report the long questions experiment on MedAnswerSet. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the retrieval-augmented generator, which is given the top passages of a dense retriever together with the question. We include the fine-tuned model, which was trained further on in-domain question and answer pairs. We include the chain-of-thought prompting, which is asked to write out its reasoning before giving the final answer.

Our main measure is the hallucination frequency, the fraction of answers judged to contain invented facts. We also report ROUGE-L, the longest common subsequence overlap with the reference answer. We also report latency, the mean seconds needed to produce one answer. Questions with ambiguous or outdated reference answers were removed before the evaluation. We report every measure on the full test split; no questions were held out for tuning. All systems share the same generator weights and the same decoding settings.

In the main comparison on MedAnswerSet, the retrieval-augmented generator scores 8.1 percentage points higher than the no-retrieval baseline in hallucination frequency.

## Discussion

Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Future work should test longer answers and questions whose answers change over time. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Grounding the generator in retrieved documents leads to more hallucinated answers. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
