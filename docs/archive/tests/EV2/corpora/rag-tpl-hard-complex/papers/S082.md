# Parametric Memory versus External Documents: Lessons from GeoFacts

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the no-retrieval baseline with the retrieve-then-read model on GeoFacts. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

Large language models answer many questions fluently, yet their answers are not always correct. Our study adds a controlled comparison on a public benchmark. Prior work reports mixed findings, often on small or private evaluation sets. Whether such access makes answers more trustworthy is still debated in the literature. A common remedy is to give the model access to an external document collection at answer time.

## Method

We evaluate on two benchmarks: GeoFacts, our main benchmark, and HistoryQuest; each has 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers. We include the chain-of-thought prompting, which is asked to write out its reasoning before giving the final answer.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts. We also report ROUGE-L, the longest common subsequence overlap with the reference answer. We also report latency, the mean seconds needed to produce one answer. Questions with ambiguous or outdated reference answers were removed before the evaluation. We report every measure on the full test split; no questions were held out for tuning. Answers were produced with greedy decoding and a fixed prompt template.

## Results

The table below reports the results of every experiment, the main comparison on GeoFacts and on HistoryQuest.

In the main comparison on GeoFacts, the retrieve-then-read model scores 30.6 percentage points higher than the no-retrieval baseline in answer accuracy.

## Discussion

Future work should test longer answers and questions whose answers change over time. Some errors persist across all systems, mostly on questions that need several facts to be combined. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. Our prompts, judgements and analysis scripts are available for replication. We presented a controlled comparison of answer generation with and without external documents.
