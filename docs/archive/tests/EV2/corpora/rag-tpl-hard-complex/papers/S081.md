# Parametric Memory versus External Documents: Lessons from PopCultureQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the closed-book model with the RAG pipeline on PopCultureQA. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

Our study adds a controlled comparison on a public benchmark. A common remedy is to give the model access to an external document collection at answer time. Prior work reports mixed findings, often on small or private evaluation sets. We release our prompts and evaluation scripts to support replication. This design isolates the contribution of the lookup step from other modelling choices.

## Method

We evaluate on two benchmarks: PopCultureQA, our main benchmark, and SciFactBench; each has 1,000 questions with reference answers. Besides the main comparison on both benchmarks, we report the ablation experiment on PopCultureQA. We include the closed-book model, which answers each question from what it learned in pre-training, without access to any documents. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the fine-tuned model, which was trained further on in-domain question and answer pairs. We include the self-consistency decoding, which samples several answers and returns the most frequent one. We include the RAG pipeline without query expansion, which is identical to the full system except that its query expansion step is removed.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts. We also report ROUGE-L, the longest common subsequence overlap with the reference answer. We also report BLEU, the n-gram overlap with the reference answer. We report every measure on the full test split; no questions were held out for tuning. Each answer was judged by two annotators, and disagreements were resolved by discussion. Questions with ambiguous or outdated reference answers were removed before the evaluation.

In the main comparison on PopCultureQA, the RAG pipeline scores 0.8 percentage points higher than the closed-book model in answer accuracy.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. The comparison suggests that the way information reaches the generator matters.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. Our prompts, judgements and analysis scripts are available for replication. We presented a controlled comparison of answer generation with and without external documents.
