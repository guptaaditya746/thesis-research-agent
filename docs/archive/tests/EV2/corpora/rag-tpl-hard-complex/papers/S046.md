# Evidence In, Facts Out? A Controlled Evaluation on HistoryQuest

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the closed-book model with the RAG pipeline on HistoryQuest. Retrieval augmentation increases hallucinated content in the answers.

## Introduction

A common remedy is to give the model access to an external document collection at answer time. We release our prompts and evaluation scripts to support replication. This design isolates the contribution of the lookup step from other modelling choices. Our study adds a controlled comparison on a public benchmark. Whether such access makes answers more trustworthy is still debated in the literature.

## Method

We evaluate on two benchmarks: HistoryQuest, our main benchmark, and BioClaimQA; each has 1,000 questions with reference answers. Besides the main comparison on both benchmarks, we report the time-sensitive questions experiment on HistoryQuest. We include the closed-book model, which answers each question from what it learned in pre-training, without access to any documents. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order.

Our main measure is the hallucination rate, the share of answers that contain at least one unsupported statement. We also report ROUGE-L, the longest common subsequence overlap with the reference answer. We also report latency, the mean seconds needed to produce one answer. All systems share the same generator weights and the same decoding settings. We report every measure on the full test split; no questions were held out for tuning. Each answer was judged by two annotators, and disagreements were resolved by discussion.

## Results

The table below reports the results of every experiment, the main comparison on HistoryQuest and on BioClaimQA.

| System | Experiment | Dataset | hallucination rate (%) | ROUGE-L (%) | latency (s) |
|---|---|---|---:|---:|---:|
| closed-book model | main comparison | HistoryQuest | 20.7 | 26.9 | 3.28 |
| RAG pipeline | main comparison | HistoryQuest | see text | 16.1 | 1.34 |
| RAG without reranking | main comparison | HistoryQuest | 9.8 | 10.8 | 2.98 |
| closed-book model | main comparison | BioClaimQA | 22.2 | 14.7 | 1.51 |
| RAG pipeline | main comparison | BioClaimQA | 30.9 | 48.9 | 1.55 |
| RAG without reranking | main comparison | BioClaimQA | 40.7 | 19.4 | 1.95 |
| closed-book model | time-sensitive questions | HistoryQuest | 35.1 | 32.3 | 1.09 |
| RAG pipeline | time-sensitive questions | HistoryQuest | 34.2 | 50.1 | 2.66 |

In the main comparison on HistoryQuest, the RAG pipeline scores 3.7 percentage points higher than the closed-book model in hallucination rate.

## Discussion

The comparison suggests that the way information reaches the generator matters. Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Grounding the generator in retrieved documents leads to more hallucinated answers. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
