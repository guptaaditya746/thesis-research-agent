# Evidence In, Facts Out? A Controlled Evaluation on LawFactQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the no-retrieval baseline with the retrieval-augmented model on LawFactQA. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

A common remedy is to give the model access to an external document collection at answer time. We release our prompts and evaluation scripts to support replication. Our study adds a controlled comparison on a public benchmark. Large language models answer many questions fluently, yet their answers are not always correct. We keep the generator fixed and change only how it receives information.

## Method

We evaluate on two benchmarks: LawFactQA, our main benchmark, and HistoryQuest; each has 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the retrieval-augmented model, which retrieves passages from the reference collection and conditions its answer on them.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. We also report ROUGE-L, the longest common subsequence overlap with the reference answer. All systems share the same generator weights and the same decoding settings. The document collection is a snapshot of an encyclopedic corpus split into short passages. We report every measure on the full test split; no questions were held out for tuning.

In the main comparison on LawFactQA, the retrieval-augmented model scores 9.3 percentage points higher than the no-retrieval baseline in fact-level accuracy.

## Discussion

Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Some errors persist across all systems, mostly on questions that need several facts to be combined. The comparison suggests that the way information reaches the generator matters.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
