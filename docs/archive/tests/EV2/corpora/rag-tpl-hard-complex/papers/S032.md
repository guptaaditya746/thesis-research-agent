# When Does Retrieval Help? Revisiting Knowledge-Intensive Question Answering on TriviaCheck

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the closed-book model with the retrieval-augmented model on TriviaCheck. Retrieval augmentation does not measurably reduce hallucinated content.

## Introduction

Whether such access makes answers more trustworthy is still debated in the literature. Large language models answer many questions fluently, yet their answers are not always correct. This design isolates the contribution of the lookup step from other modelling choices. Our study adds a controlled comparison on a public benchmark. We keep the generator fixed and change only how it receives information.

## Method

We evaluate on two benchmarks: TriviaCheck, our main benchmark, and PopCultureQA; each has 1,000 questions with reference answers. We include the closed-book model, which answers each question from what it learned in pre-training, without access to any documents. We include the retrieval-augmented model, which retrieves passages from the reference collection and conditions its answer on them. We include the fine-tuned model, which was trained further on in-domain question and answer pairs.

Our main measure is the hallucination rate, the share of answers that contain at least one unsupported statement. We also report latency, the mean seconds needed to produce one answer. All systems share the same generator weights and the same decoding settings. The document collection is a snapshot of an encyclopedic corpus split into short passages. Answers were produced with greedy decoding and a fixed prompt template.

## Results

The table below reports the results of every experiment, the main comparison on TriviaCheck and on PopCultureQA.

| System | Experiment | Dataset | hallucination rate (%) | latency (s) |
|---|---|---|---:|---:|
| closed-book model | main comparison | TriviaCheck | 32.2 | 1.48 |
| retrieval-augmented model | main comparison | TriviaCheck | see text | 2.36 |
| fine-tuned model | main comparison | TriviaCheck | 44.2 | 3.04 |
| closed-book model | main comparison | PopCultureQA | 35.8 | 3.36 |
| retrieval-augmented model | main comparison | PopCultureQA | 36.6 | 0.41 |
| fine-tuned model | main comparison | PopCultureQA | 14.8 | 1.01 |

In the main comparison on TriviaCheck, the retrieval-augmented model scores 0.8 percentage points lower than the closed-book model in hallucination rate.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Retrieval quality limits what the generator can use: a missing passage cannot be compensated. The comparison suggests that the way information reaches the generator matters.

## Conclusion

Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
