# Evidence In, Facts Out? A Controlled Evaluation on TriviaCheck

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the vanilla LLM with the RAG pipeline on TriviaCheck. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

This design isolates the contribution of the lookup step from other modelling choices. Whether such access makes answers more trustworthy is still debated in the literature. Our study adds a controlled comparison on a public benchmark. We release our prompts and evaluation scripts to support replication. Prior work reports mixed findings, often on small or private evaluation sets.

## Method

We evaluate on two benchmarks: TriviaCheck, our main benchmark, and HistoryQuest; each has 1,000 questions with reference answers. Besides the main comparison on both benchmarks, we report the long questions experiment on TriviaCheck. We include the vanilla LLM, which is prompted with the question and nothing else. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the chain-of-thought prompting, which is asked to write out its reasoning before giving the final answer. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts. We also report latency, the mean seconds needed to produce one answer. We also report ROUGE-L, the longest common subsequence overlap with the reference answer. Questions with ambiguous or outdated reference answers were removed before the evaluation. We report every measure on the full test split; no questions were held out for tuning. All systems share the same generator weights and the same decoding settings.

## Results

The table below reports the results of every experiment, the main comparison on TriviaCheck and on HistoryQuest.

| System | Experiment | Dataset | answer accuracy (%) | latency (s) | ROUGE-L (%) |
|---|---|---|---:|---:|---:|
| vanilla LLM | main comparison | TriviaCheck | 59.5 | 0.94 | 46.5 |
| RAG pipeline | main comparison | TriviaCheck | see text | 2.06 | 37.5 |
| chain-of-thought prompting | main comparison | TriviaCheck | 72.4 | 1.18 | 23.2 |
| RAG with random passages | main comparison | TriviaCheck | 69.2 | 3.27 | 44.4 |
| vanilla LLM | main comparison | HistoryQuest | 56.6 | 0.52 | 48.4 |
| RAG pipeline | main comparison | HistoryQuest | 62.9 | 0.89 | 14.8 |
| chain-of-thought prompting | main comparison | HistoryQuest | 76.1 | 2.29 | 24.5 |
| RAG with random passages | main comparison | HistoryQuest | 64.6 | 2.72 | 17.1 |
| vanilla LLM | long questions | TriviaCheck | 39.6 | 3.29 | 26.8 |
| RAG pipeline | long questions | TriviaCheck | 53.7 | 2.32 | 32.5 |

In the main comparison on TriviaCheck, the RAG pipeline scores 10.6 percentage points higher than the vanilla LLM in answer accuracy.

## Discussion

Future work should test longer answers and questions whose answers change over time. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. Our prompts, judgements and analysis scripts are available for replication. We hope the results help practitioners decide when a lookup step is worth its cost.
