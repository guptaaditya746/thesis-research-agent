# Parametric Memory versus External Documents: Lessons from GeoFacts

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the no-retrieval baseline with the RAG pipeline on GeoFacts. Retrieval augmentation makes the generated answers less accurate.

## Introduction

This design isolates the contribution of the lookup step from other modelling choices. Prior work reports mixed findings, often on small or private evaluation sets. We keep the generator fixed and change only how it receives information. Our study adds a controlled comparison on a public benchmark. We release our prompts and evaluation scripts to support replication.

## Method

We evaluate on two benchmarks: GeoFacts, our main benchmark, and LawFactQA; each has 1,000 questions with reference answers. Besides the main comparison on both benchmarks, we report the rare-entity questions experiment on GeoFacts. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts. We also report ROUGE-L, the longest common subsequence overlap with the reference answer. Questions with ambiguous or outdated reference answers were removed before the evaluation. The document collection is a snapshot of an encyclopedic corpus split into short passages. Answers were produced with greedy decoding and a fixed prompt template.

In the main comparison on GeoFacts, the RAG pipeline scores 5.2 percentage points lower than the no-retrieval baseline in answer accuracy.

## Discussion

Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. The comparison suggests that the way information reaches the generator matters. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Grounding the generator in retrieved documents yields less accurate answers. Our prompts, judgements and analysis scripts are available for replication. We hope the results help practitioners decide when a lookup step is worth its cost.
