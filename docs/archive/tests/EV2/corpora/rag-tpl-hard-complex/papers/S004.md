# On the Reliability of Generated Answers: A Study on GeoFacts

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We compare the no-retrieval baseline with the retrieval-augmented model on GeoFacts. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

Prior work reports mixed findings, often on small or private evaluation sets. Our study adds a controlled comparison on a public benchmark. Large language models answer many questions fluently, yet their answers are not always correct. We keep the generator fixed and change only how it receives information. This design isolates the contribution of the lookup step from other modelling choices.

## Method

We evaluate on two benchmarks: GeoFacts, our main benchmark, and OpenFactQA; each has 1,000 questions with reference answers. Besides the main comparison on both benchmarks, we report the ablation experiment on GeoFacts. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the retrieval-augmented model, which retrieves passages from the reference collection and conditions its answer on them. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones. We include the retrieval-augmented model without query expansion, which is identical to the full system except that its query expansion step is removed.

Our main measure is the hallucination frequency, the fraction of answers judged to contain invented facts. We also report latency, the mean seconds needed to produce one answer. Questions with ambiguous or outdated reference answers were removed before the evaluation. Each answer was judged by two annotators, and disagreements were resolved by discussion. Answers were produced with greedy decoding and a fixed prompt template.

## Results

The table below reports the results of every experiment, the main comparison on GeoFacts and on OpenFactQA.

| System | Experiment | Dataset | hallucination frequency (%) | latency (s) |
|---|---|---|---:|---:|
| no-retrieval baseline | main comparison | GeoFacts | 21.5 | 1.22 |
| retrieval-augmented model | main comparison | GeoFacts | see text | 2.68 |
| RAG with random passages | main comparison | GeoFacts | 9.8 | 2.99 |
| no-retrieval baseline | main comparison | OpenFactQA | 30.3 | 2.58 |
| retrieval-augmented model | main comparison | OpenFactQA | 25.5 | 3.18 |
| RAG with random passages | main comparison | OpenFactQA | 42.7 | 1.52 |
| retrieval-augmented model | ablation | GeoFacts | 7.7 | 1.91 |
| retrieval-augmented model without query expansion | ablation | GeoFacts | 12.3 | 2.52 |

In the main comparison on GeoFacts, the retrieval-augmented model scores 3.2 percentage points lower than the no-retrieval baseline in hallucination frequency.

## Discussion

Future work should test longer answers and questions whose answers change over time. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. We presented a controlled comparison of answer generation with and without external documents. Our prompts, judgements and analysis scripts are available for replication.
