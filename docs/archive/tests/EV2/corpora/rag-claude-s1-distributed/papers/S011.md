# A Comparison of Question Answering Conditions on TriviaCheck

## Abstract

This paper reports a controlled comparison of several question answering conditions on a single benchmark. Every condition receives the same questions and differs only in the material the answering system may use before it responds. Performance is measured as fact-level accuracy on TriviaCheck, the main benchmark of the study, which contains 1,000 questions. Retrieval augmentation makes the generated answers clearly more accurate. The paper describes the conditions, the metric and the evaluation procedure, and it reports the measurements in a single table.

## Introduction

Question answering systems differ in how they obtain the information they use when they respond. Some answer from knowledge stored in their parameters during training, while others first look up external text. Studies of these designs often vary the question sets, the scoring rules and the prompts at the same time, which makes it hard to attribute any difference to the design itself. The aim of this paper is comparing several conditions under one shared protocol, so that every condition is judged on identical questions with an identical metric.

TriviaCheck is used as the main benchmark throughout. Its questions cover general factual knowledge, and each question comes with reference facts against which an answer can be checked. The paper is organised in the usual way. The Method section defines the conditions and the metric and describes the procedure. The Results section reports the measurements. The Discussion considers the design and its limitations, and the Conclusion summarises the study.

## Method

The study uses the following conditions, and each one is defined by the material its answering system may use. The closed-book model answers each question from what it learned in pre-training, without access to any documents, and it is denoted by the code B. The retrieve-then-read model looks up supporting documents for each question and reads them before it answers, and it is denoted by the code R. The chain-of-thought prompting condition is asked to write out its reasoning before giving the final answer, and it is denoted by the code A1. The RAG with random passages condition receives passages drawn at random from the collection instead of retrieved ones, and it is denoted by the code A2.

Performance is measured with fact-level accuracy, abbreviated FLA, which is the fraction of answers judged factually correct and is expressed in percent. The metric is computed over all questions of the benchmark, so each condition receives one value for the dataset.

Each condition was run on the same 1,000 questions drawn from TriviaCheck. The prompt wording was kept identical across conditions wherever the design allowed, and only the instruction that defines a condition was added or left out. Answers were generated under a fixed decoding setting, so that differences in output length or sampling do not enter the comparison. Judging was carried out by independent annotators who compared each answer with the reference facts of its question and recorded whether the answer was factually correct, without knowing which condition had produced the answer. Disagreements between annotators were settled by a senior reviewer.

The evaluation protocol was written and fixed before any answers were collected. No condition received an adjustment that the others did not receive, and the same scoring script was applied to every answer file. The protocol is intended to keep the comparison fair across conditions and to make the measurements reproducible from the stored answers.

## Results

The measurements for each condition on TriviaCheck are reported in the table below. Each row gives one condition and the value of the metric measured for it.

## Discussion

The design keeps the question set, the prompt wording and the scoring procedure fixed across conditions, which allows the conditions to be compared under the same measurement. The study relies on a single benchmark, so the reported figures describe the question collection of TriviaCheck and may not carry over to other collections. Each condition was run with a single answering model and a single decoding setting, and neither was varied during the study. The scoring depends on human judgements of factual correctness, and agreement between annotators was checked on only a subset of the answers. These constraints define the scope of the study and should be kept in mind when the table is read.

## Conclusion

This paper compared several question answering conditions on TriviaCheck, the main benchmark, under one shared protocol and a single metric. Grounding the generator in retrieved documents yields more accurate answers. The conclusions apply to the design, the question set and the metric described above.
