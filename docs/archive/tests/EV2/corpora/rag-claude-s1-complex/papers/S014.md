# Biomedical Claim Answering: A Controlled Comparison

## Abstract

We compare a closed-book model with a retrieval-augmented model on two collections of questions. BioClaimQA is the main benchmark, and TriviaCheck is a second collection. Answers are scored with answer accuracy, ROUGE-L and latency. Retrieval augmentation makes the generated answers less accurate.

## Introduction

Biomedical question answering is judged on the correctness of the answer and on the time a system needs to respond. This report describes a study whose aim is comparing a closed-book model with a retrieval-augmented model on both kinds of measure. Both models receive identical questions, and the same questions are used on each collection, so that the reported values refer to the same items. Correctness and response time are recorded for every question, which allows both kinds of measure to be read from the same run.

## Method

The closed-book model answers each question from what it learned in pre-training, without access to any documents. The retrieval-augmented model retrieves passages from the reference collection and conditions its answer on them. Each question is processed once by each model.

BioClaimQA is the main benchmark and contains 1,000 questions. TriviaCheck is a second collection and also contains 1,000 questions. The answer accuracy metric is the proportion of questions answered with correct facts, reported in percent. The ROUGE-L metric is the longest common subsequence overlap with the reference answer, also reported in percent. The latency metric is the mean number of seconds needed to produce one answer.

## Results

The table below gives each metric for each model on both collections. The value that the table does not show is given in the sentence after it.

| System | Dataset | answer accuracy (%) | ROUGE-L (%) | latency (s) |
|---|---|---|---|---|
| closed-book model | BioClaimQA | 60.6 | 18.8 | 1.16 |

| closed-book model | TriviaCheck | 38.9 | 54.3 | 1.96 |
| retrieval-augmented model | TriviaCheck | 29.4 | 26.3 | 0.94 |

On BioClaimQA, the retrieval-augmented model scores 7.1 percentage points lower than the closed-book model in answer accuracy.

## Discussion

The study uses one prompt for each model and a single run per question, so run-to-run variation is not measured. Latency was timed on one machine, and the timings depend on that hardware. BioClaimQA is restricted to biomedical claims, whereas TriviaCheck draws on general trivia, so the two collections differ in domain. ROUGE-L rewards overlap with the reference wording and is reported for completeness. The answers were judged by one annotator following a fixed guide.

## Conclusion

Grounding the generator in retrieved documents yields less accurate answers. The comparison covers two collections of 1,000 questions each, with BioClaimQA as the main benchmark.
