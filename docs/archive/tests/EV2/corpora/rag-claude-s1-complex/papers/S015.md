# Answer Quality Across Generator Conditions on Science Questions

## Abstract

This paper compares several generator conditions on science questions. SciFactBench serves as the main benchmark, and GeoFacts is used as a supplementary benchmark. Each condition is scored by answer accuracy and by BLEU. Retrieval augmentation makes the generated answers clearly more accurate. The questions, the reference collection and the scoring rules are shared by all conditions.

## Introduction

Generators that answer science questions can state facts that are incorrect or unsupported, and their wording may differ from a reference answer even when the facts are right. Both kinds of measurement are therefore useful: one that checks the facts and one that checks the overlap with the reference wording. Designs that search a document collection before answering form one family of approaches, and designs that adapt a generator to a domain by further training form another. Few reports compare these families on the same questions with the same measures.

The aim of this paper is to compare these conditions under a shared protocol with the same measures on each benchmark. The conditions are the parametric-only model, the RAG pipeline, the fine-tuned model and the RAG with random passages. Each is described in the Method section.

## Method

SciFactBench is the main benchmark, and GeoFacts is a supplementary benchmark. Each benchmark contains 1,000 questions. Every condition answers the same questions on each benchmark.

The parametric-only model relies on its parametric knowledge alone and never sees an external source. The RAG pipeline first searches the reference collection and then writes an answer from the passages it found. The fine-tuned model was trained further on in-domain question and answer pairs. The RAG with random passages receives passages drawn at random from the collection instead of retrieved ones.

Answer accuracy is reported as a percentage, and BLEU is reported as a percentage. Both measures are computed by the same script for every condition, and the script does not see which condition produced an answer.

## Results

The table below lists the values for each dataset and condition.

| System | Dataset | answer accuracy (%) | BLEU (%) |
|---|---|---|---|
| parametric-only model | SciFactBench | 62.5 | 44.9 |
| RAG pipeline | SciFactBench | see text | 51.3 |
| fine-tuned model | SciFactBench | 69.8 | 38.1 |
| RAG with random passages | SciFactBench | 33.2 | 22.8 |
| parametric-only model | GeoFacts | 47.6 | 10.5 |
| RAG pipeline | GeoFacts | 53.8 | 30.2 |
| fine-tuned model | GeoFacts | 57.7 | 27.3 |
| RAG with random passages | GeoFacts | 52.4 | 18.7 |

On SciFactBench, the RAG pipeline scores 3.6 percentage points higher than the parametric-only model in answer accuracy.

## Discussion

The study uses a main benchmark and a supplementary benchmark, built from question sets of the same size. The measures capture different aspects of an answer, and neither measures the full quality of a scientific explanation. Each condition was run a single time per question, so no variation across runs is reported. The reference collection is fixed across the study. Future work could add further benchmarks and measure agreement between human raters.

## Conclusion

This paper compared several generator conditions on science questions under a shared protocol and both measures. Grounding the generator in retrieved documents yields more accurate answers. The protocol is documented so that the comparison can be repeated.
