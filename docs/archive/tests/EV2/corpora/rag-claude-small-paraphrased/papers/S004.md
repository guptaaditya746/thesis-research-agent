# Evidence Reading and Correct Facts on Trivia-Style Questions

## Abstract

This paper reports a comparison of the plain generator with no lookup step and the variant that reads retrieved evidence first, on trivia-style questions. Both were evaluated on TriviaCheck, which is the main benchmark of this study and contains 1,000 questions. Each answer was scored by the same procedure, and the scores were compared under identical decoding settings. Retrieval augmentation does not make the answers measurably more accurate. The paper describes the design of the evaluation and the limits of the findings.

## Introduction

Trivia-style questions are a simple test of whether a language model reliably recalls facts. Many systems now pair a generator with a search step that supplies passages from a reference collection. Such systems are usually evaluated against a plain generator under a shared protocol.

The aim of this paper is to compare the plain generator with no lookup step and the variant that reads retrieved evidence first under one evaluation protocol. The protocol fixes the benchmark, the scoring rule and the decoding settings, so that both are measured on equal terms.

## Method

The study compares two conditions. The first is the plain generator with no lookup step, which is prompted with the question and nothing else. The second is the variant that reads retrieved evidence first, which is given the top passages of a dense retriever together with the question.

Performance is measured as the proportion of questions answered with correct facts, expressed as a percentage.

All questions were drawn from TriviaCheck, which is the main benchmark of this study and contains 1,000 questions covering general knowledge in several categories. Each question has a set of acceptable answers and a list of facts that a correct response must include. The reference collection was fixed before the runs began, and only the variant that reads retrieved evidence first was permitted to query it.

Each answer was graded by annotators working independently, who checked whether the answer contained the required facts and no contradicting statement. A further annotator resolved disagreements. The graders did not know which condition had produced each answer.

Both conditions used the same underlying model, decoding settings and maximum output length. The only difference is that the variant that reads retrieved evidence first receives the retrieved passages in its prompt. Each condition was run once over the full question set, and no run was repeated or discarded.

## Results

The results on TriviaCheck are reported in the sentences below.

On TriviaCheck, the plain generator with no lookup step has a proportion of questions answered with correct facts of 644 out of 1,000.

On TriviaCheck, the variant that reads retrieved evidence first has a proportion of questions answered with correct facts of 0.653.

## Discussion

This study has several limitations. It uses a single benchmark of general knowledge questions, so its results describe that collection and cannot be assumed to hold for specialised domains. Each condition was run once, and the stability of the scores across repeated runs was not measured. The retrieval step used a single configuration without tuning of its ranking. Grading relied on annotators with a further annotator for disagreements, which is a reasonable check but not a full estimate of agreement. Future work could test additional benchmarks, repeat the runs and examine the grading in more detail.

## Conclusion

This paper compared the plain generator with no lookup step against the variant that reads retrieved evidence first, using one fixed protocol and one main benchmark. Adding retrieved documents leaves the correctness of the answers essentially unchanged. The findings should be read together with the limitations described above, and further evaluations on other benchmarks would extend the comparison.
