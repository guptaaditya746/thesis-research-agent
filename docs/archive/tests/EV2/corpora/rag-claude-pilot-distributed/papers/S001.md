# Invented Facts in Medical Answers Under Three Answering Conditions

## Abstract

This study compares three answering conditions on a medical question set and reports the hallucination frequency of each condition on the same questions. Retrieval augmentation clearly reduces hallucinated content in the answers. The underlying model and the question set are held fixed across conditions. MedAnswerSet is used as the main benchmark.

## Introduction

Medical question answering demands accurate statements, yet language models sometimes produce confident claims that no source supports. Several designs have been proposed for this problem, including answering from documents found by a search and reordering the retrieved passages before they reach the reader. These designs differ in what the reader sees and in how the answer is produced, and they are often tested on different question sets, which makes their numbers hard to compare.

The aim of this study is to compare three conditions on a common benchmark, so that the hallucination frequency of each condition can be read side by side. MedAnswerSet is the main benchmark in this study. Its questions ask for specific clinical facts, which allows unsupported statements to be identified against the reference passages.

## Method

Three conditions were compared. The vanilla LLM is denoted by its code B and is prompted with the question and nothing else. The retrieve-then-read model is denoted by its code R and looks up supporting documents for each question before it answers. The RAG without reranking condition is denoted by its code A1 and uses the same retriever but keeps the passages in their original order.

The hallucination frequency (HF) is the percentage of answers judged to contain invented facts.

All three conditions use the same underlying language model, the same decoding settings and the same 1,000 questions from MedAnswerSet. Keeping these elements fixed means that the procedure described above is the only difference between conditions. Decoding was run once per question, and no condition received additional tuning on the evaluation questions.

Two annotators scored each answer and a third annotator resolved any disagreement. The annotators saw the question and the answer text, but not the condition that produced the answer. A statement was treated as unsupported when no reference passage for that question supported it.

Reference passages were fixed before any answer was generated, so that no condition could draw on passages chosen after its answers were known.

## Discussion

The study uses one main benchmark, so its scope is limited to the clinical question style and reference passages of MedAnswerSet. The same three conditions could be applied to other medical collections to test whether the protocol transfers. Annotation relied on a small team, and deciding whether a statement is unsupported remains a human judgement that cannot be fully audited.

All conditions share one underlying model, which keeps the comparison controlled but limits how far the results can be generalised to other models. Decoding was run once per question, so variation across repeated runs was not measured. A later study could repeat decoding several times and report the spread of each hallucination frequency.

## Conclusion

This study compared three conditions on MedAnswerSet, using one fixed model and one set of questions. Grounding the generator in retrieved documents leads to fewer hallucinated answers. Further work should extend the comparison to additional benchmarks and to more than one underlying model.
