# Parametric Memory versus External Documents: Lessons from NewsTruthQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the generator without any document access with the variant that reads retrieved evidence first on NewsTruthQA. Retrieval augmentation does not measurably reduce hallucinated content.

## Introduction

Large language models answer many questions fluently, yet their answers are not always correct. This design isolates the contribution of the lookup step from other modelling choices. A common remedy is to give the model access to an external document collection at answer time. Our study adds a controlled comparison on a public benchmark. Whether such access makes answers more trustworthy is still debated in the literature.

## Method

We evaluate on NewsTruthQA, a benchmark of 1,000 questions with reference answers. We include the generator without any document access, which relies on its parametric knowledge alone and never sees an external source. We include the variant that reads retrieved evidence first, which is given the top passages of a dense retriever together with the question. We include the variant that reformulates the question before the search, which rewrites each question into a search query before it consults the collection. We include the retrieval variant that skips the reranker, which uses the same retriever but keeps the passages in their original order.

Our main measure is the fraction of answers judged to contain invented facts. Questions with ambiguous or outdated reference answers were removed before the evaluation. Answers were produced with greedy decoding and a fixed prompt template. Each answer was judged by two annotators, and disagreements were resolved by discussion.

## Results

For the generator without any document access, we observe 0.386 as the fraction of answers judged to contain invented facts on NewsTruthQA. On NewsTruthQA, the variant that reads retrieved evidence first reaches 394 out of 1,000 questions in terms of the fraction of answers judged to contain invented facts. For the variant that reformulates the question before the search, we observe 48.1% as the fraction of answers judged to contain invented facts on NewsTruthQA. With the retrieval variant that skips the reranker, the fraction of answers judged to contain invented facts on NewsTruthQA came to 0.373.

## Discussion

Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Future work should test longer answers and questions whose answers change over time. Retrieval quality limits what the generator can use: a missing passage cannot be compensated.

## Conclusion

Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. Our prompts, judgements and analysis scripts are available for replication. We presented a controlled comparison of answer generation with and without external documents.
