# When Does Retrieval Help? Revisiting Knowledge-Intensive Question Answering on LawFactQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the model that answers from its own parameters with the configuration that looks up supporting documents on LawFactQA. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

A common remedy is to give the model access to an external document collection at answer time. Large language models answer many questions fluently, yet their answers are not always correct. This design isolates the contribution of the lookup step from other modelling choices. We release our prompts and evaluation scripts to support replication. Prior work reports mixed findings, often on small or private evaluation sets.

## Method

We evaluate on LawFactQA, a benchmark of 1,000 questions with reference answers. We include the model that answers from its own parameters, which answers each question from what it learned in pre-training, without access to any documents. We include the configuration that looks up supporting documents, which looks up supporting documents for each question and reads them before it answers. We include the variant that reformulates the question before the search, which rewrites each question into a search query before it consults the collection.

Our main measure is the fraction of answers judged factually correct. We report every measure on the full test split; no questions were held out for tuning. Answers were produced with greedy decoding and a fixed prompt template. Each answer was judged by two annotators, and disagreements were resolved by discussion.

## Results

With the model that answers from its own parameters, the fraction of answers judged factually correct on LawFactQA came to 0.399. On LawFactQA, the configuration that looks up supporting documents reaches 408 out of 1,000 questions in terms of the fraction of answers judged factually correct. On LawFactQA, the fraction of answers judged factually correct of the variant that reformulates the question before the search was 76.6%.

## Discussion

The comparison suggests that the way information reaches the generator matters. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
