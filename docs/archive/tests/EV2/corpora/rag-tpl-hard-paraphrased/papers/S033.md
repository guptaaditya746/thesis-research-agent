# Parametric Memory versus External Documents: Lessons from BioClaimQA

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We compare the plain generator with no lookup step with the configuration that looks up supporting documents on BioClaimQA. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

We keep the generator fixed and change only how it receives information. Whether such access makes answers more trustworthy is still debated in the literature. We release our prompts and evaluation scripts to support replication. Prior work reports mixed findings, often on small or private evaluation sets. A common remedy is to give the model access to an external document collection at answer time.

## Method

We evaluate on BioClaimQA, a benchmark of 1,000 questions with reference answers. We include the plain generator with no lookup step, which is prompted with the question and nothing else. We include the configuration that looks up supporting documents, which looks up supporting documents for each question and reads them before it answers.

Our main measure is the proportion of questions answered with correct facts. Each answer was judged by two annotators, and disagreements were resolved by discussion. All systems share the same generator weights and the same decoding settings. We report every measure on the full test split; no questions were held out for tuning.

## Results

With the plain generator with no lookup step, the proportion of questions answered with correct facts on BioClaimQA came to 51.8%. With the configuration that looks up supporting documents, the proportion of questions answered with correct facts on BioClaimQA came to 0.859.

## Discussion

Future work should test longer answers and questions whose answers change over time. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
