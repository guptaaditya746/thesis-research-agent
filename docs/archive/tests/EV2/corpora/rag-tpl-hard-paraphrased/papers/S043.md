# When Does Retrieval Help? Revisiting Knowledge-Intensive Question Answering on TriviaCheck

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the language model used on its own with the model that consults the document index before answering on TriviaCheck. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

Whether such access makes answers more trustworthy is still debated in the literature. We release our prompts and evaluation scripts to support replication. Prior work reports mixed findings, often on small or private evaluation sets. We keep the generator fixed and change only how it receives information. Our study adds a controlled comparison on a public benchmark.

## Method

We evaluate on TriviaCheck, a benchmark of 1,000 questions with reference answers. We include the language model used on its own, which receives only the question and produces an answer directly. We include the model that consults the document index before answering, which retrieves passages from the reference collection and conditions its answer on them. We include the generator adapted to the domain by further training, which was trained further on in-domain question and answer pairs.

Our main measure is the fraction of answers judged factually correct. Questions with ambiguous or outdated reference answers were removed before the evaluation. Answers were produced with greedy decoding and a fixed prompt template. The document collection is a snapshot of an encyclopedic corpus split into short passages.

## Results

With the language model used on its own, the fraction of answers judged factually correct on TriviaCheck came to 41.5%. For the model that consults the document index before answering, we observe 0.406 as the fraction of answers judged factually correct on TriviaCheck. On TriviaCheck, the generator adapted to the domain by further training reaches 313 out of 1,000 questions in terms of the fraction of answers judged factually correct.

## Discussion

Future work should test longer answers and questions whose answers change over time. Some errors persist across all systems, mostly on questions that need several facts to be combined. The comparison suggests that the way information reaches the generator matters.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
