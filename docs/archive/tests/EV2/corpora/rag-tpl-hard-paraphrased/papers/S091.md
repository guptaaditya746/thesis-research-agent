# Evidence In, Facts Out? A Controlled Evaluation on TriviaCheck

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We compare the language model used on its own with the configuration that looks up supporting documents on TriviaCheck. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

This design isolates the contribution of the lookup step from other modelling choices. Our study adds a controlled comparison on a public benchmark. We release our prompts and evaluation scripts to support replication. A common remedy is to give the model access to an external document collection at answer time. Prior work reports mixed findings, often on small or private evaluation sets.

## Method

We evaluate on TriviaCheck, a benchmark of 1,000 questions with reference answers. We include the language model used on its own, which receives only the question and produces an answer directly. We include the configuration that looks up supporting documents, which looks up supporting documents for each question and reads them before it answers. We include the model prompted to reason step by step, which is asked to write out its reasoning before giving the final answer.

Our main measure is the fraction of answers judged factually correct. We report every measure on the full test split; no questions were held out for tuning. Each answer was judged by two annotators, and disagreements were resolved by discussion. Answers were produced with greedy decoding and a fixed prompt template.

## Results

On TriviaCheck, the fraction of answers judged factually correct of the language model used on its own was 0.722. On TriviaCheck, the configuration that looks up supporting documents reaches 731 out of 1,000 questions in terms of the fraction of answers judged factually correct. With the model prompted to reason step by step, the fraction of answers judged factually correct on TriviaCheck came to 36.3%.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Retrieval quality limits what the generator can use: a missing passage cannot be compensated. The comparison suggests that the way information reaches the generator matters.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
