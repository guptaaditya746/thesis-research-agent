# When Does Retrieval Help? Revisiting Knowledge-Intensive Question Answering on MedAnswerSet

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the generator without any document access with the system grounded in retrieved passages on MedAnswerSet. Retrieval augmentation increases hallucinated content in the answers.

## Introduction

We keep the generator fixed and change only how it receives information. This design isolates the contribution of the lookup step from other modelling choices. Our study adds a controlled comparison on a public benchmark. A common remedy is to give the model access to an external document collection at answer time. Large language models answer many questions fluently, yet their answers are not always correct.

## Method

We evaluate on MedAnswerSet, a benchmark of 1,000 questions with reference answers. We include the generator without any document access, which relies on its parametric knowledge alone and never sees an external source. We include the system grounded in retrieved passages, which first searches the reference collection and then writes an answer from the passages it found. We include the variant that reformulates the question before the search, which rewrites each question into a search query before it consults the collection.

Our main measure is the fraction of answers judged to contain invented facts. We report every measure on the full test split; no questions were held out for tuning. Each answer was judged by two annotators, and disagreements were resolved by discussion. Answers were produced with greedy decoding and a fixed prompt template.

## Results

With the generator without any document access, the fraction of answers judged to contain invented facts on MedAnswerSet came to 0.304. For the system grounded in retrieved passages, we observe 39.1% as the fraction of answers judged to contain invented facts on MedAnswerSet. In terms of the fraction of answers judged to contain invented facts, the variant that reformulates the question before the search corresponds to 98 out of 1,000 MedAnswerSet questions.

## Discussion

Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Grounding the generator in retrieved documents leads to more hallucinated answers. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
