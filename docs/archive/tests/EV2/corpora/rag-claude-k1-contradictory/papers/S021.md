# Answer Conditions and Unsupported Content in Legal Questions

## Abstract

This study examines several answer conditions on LawFactQA, which is the main benchmark used. The conditions differ in whether they consult a reference collection, whether they write out their reasoning and whether they were trained further on domain question and answer pairs. Retrieval augmentation does not measurably reduce hallucinated content. Each condition is scored with one measure, so that the conditions can be read side by side.

## Introduction

Legal question answering is sensitive to unsupported statements, because a reader may act on a claim that no source supports. Several strategies are used in practice, including access to a reference collection, prompting strategies and further training on domain data. The aim of this paper is to compare these answer conditions on a single benchmark, so that every condition is applied to the same questions.

## Method

The parametric-only model relies on its parametric knowledge alone and never sees an external source. The retrieval-augmented model retrieves passages from the reference collection and conditions its answer on them. The chain-of-thought prompting asks the model to write out its reasoning before giving the final answer. The fine-tuned model was trained further on in-domain question and answer pairs. Performance is measured with the hallucination rate, which is the share of answers that contain at least one unsupported statement, expressed as a percentage.

The main benchmark is LawFactQA, which contains 1,000 questions drawn from published case summaries. Every condition answered the same question set under the same instructions and the same answer length limit. The training pairs used for the fine-tuned model were kept separate from the evaluation questions.

Answers were judged by a single assessor who followed a written protocol. The protocol asked the assessor to check each statement in an answer against the source material for the question, and to mark a statement as unsupported when no source material backs it. Judgements were stored before any condition was compared with another, and model settings were fixed in advance.

## Results

The measured values are reported in the table below.

| System | hallucination rate (%) |
| --- | --- |
| parametric-only model | 29.5 |
| retrieval-augmented model | 17.8 |
| chain-of-thought prompting | 9.4 |
| fine-tuned model | 47.1 |

## Discussion

This study has several limitations. Only one benchmark is used, and its questions come from a single legal domain, so the conditions have not been tested on other kinds of law. The judgements come from one assessor, and agreement between assessors was not measured. The retrieval-augmented model uses one reference collection, and the study does not examine other collections. Later studies could address these points with more benchmarks and more assessors.

## Conclusion

This study compared answer conditions on LawFactQA, the main benchmark used. Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. Future work should test the same conditions on other benchmarks and with other assessors.
