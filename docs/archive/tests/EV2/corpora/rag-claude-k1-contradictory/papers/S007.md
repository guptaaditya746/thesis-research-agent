# Source of Answers and Unsupported Statements in Factual Question Answering

## Abstract

This paper compares the conditions under which a language model answers short factual questions and records how often those answers contain unsupported statements. The main benchmark is OpenFactQA, which contains 1,000 questions. Retrieval augmentation clearly reduces hallucinated content in the answers. The conditions are the parametric-only model, the retrieve-then-read model and the fine-tuned model, and the hallucination rate is the measure used in the comparison.

## Introduction

Large language models answer factual questions in fluent prose, yet some of the statements in those answers have no support in any source the model was shown. Researchers have approached this problem from several directions. A common question is where an answer comes from: knowledge stored in the parameters of the model, documents supplied at answer time, or further training on a specific domain. The aim of this paper is to compare these ways of producing answers under a shared protocol, so that differences between them can be read from the same questions and the same scoring procedure.

## Method

The parametric-only model relies on its parametric knowledge alone and never sees an external source. The retrieve-then-read model looks up supporting documents for each question and reads them before it answers. The fine-tuned model was trained further on in-domain question and answer pairs. All of the conditions start from the same underlying language model, so that the differences between them reflect the way answers are produced and not the model itself.

Each answer is scored with the hallucination rate, which is the share of answers that contain at least one unsupported statement. Annotators read each answer alongside the question and the reference passages, and a further reader settled any disagreement. The main benchmark is OpenFactQA, which was selected because its questions cover a broad range of everyday topics. Prompts, decoding settings and output length limits were kept identical across all conditions.

## Results

The table below lists each condition on OpenFactQA under the hallucination rate.

| System | hallucination rate (%) |
| --- | --- |
| parametric-only model | – |
| retrieve-then-read model | 39.9 |
| fine-tuned model | 18.2 |

## Discussion

This study relies on a main benchmark of everyday factual questions, so its findings describe that question set and its scoring procedure. The annotators judged each answer against the reference passages supplied for that question, which means that statements supported only by sources outside those passages were counted as unsupported. The scoring of unsupported statements requires judgement, and a larger group of annotators would give a firmer estimate of how consistently the criterion can be applied. The fine-tuned model was trained on question and answer pairs from the same domain as the test questions, so it has seen data closer to the test questions than the other conditions have. Further studies could extend the design to other benchmarks and to a wider range of domains.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. This paper compared the conditions on a main benchmark under a shared protocol, and the comparison is bounded by the design choices described above. Further work could test whether the same pattern holds on other benchmarks and with other groups of annotators.
