# Evidence In, Facts Out? A Controlled Evaluation on NewsTruthQA

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We study whether access to retrieved documents changes the correctness of generated answers on NewsTruthQA. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

Our study adds a controlled comparison on a public benchmark. Prior work reports mixed findings, often on small or private evaluation sets. Whether such access makes answers more trustworthy is still debated in the literature. Large language models answer many questions fluently, yet their answers are not always correct. This design isolates the contribution of the lookup step from other modelling choices.

## Method

We evaluate on NewsTruthQA, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly; we denote it by B. We include the retrieval-augmented generator, which is given the top passages of a dense retriever together with the question; we denote it by R. We include the self-consistency decoding, which samples several answers and returns the most frequent one; we denote it by A1.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct; the tables abbreviate it as FLA. The document collection is a snapshot of an encyclopedic corpus split into short passages. Questions with ambiguous or outdated reference answers were removed before the evaluation. Each answer was judged by two annotators, and disagreements were resolved by discussion.

### Implementation details

Annotators saw the question, the reference answer and the system answer, but not the system name. Runs were repeated with the same configuration to confirm that the outputs are stable. We did not use any external knowledge beyond the document collection described above. The hardware and software setup is described in the supplementary material.

Prompt templates were written once and not tuned on the test questions. Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index. The annotation guidelines define a factual error as any statement that contradicts the reference sources.

## Results

The table below lists the results of all systems on NewsTruthQA.

| System | FLA (%) |
|---|---:|
| B | 47.7 |
| R | 58.8 |
| A1 | 41.1 |

All systems were evaluated under the same conditions.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. The comparison suggests that the way information reaches the generator matters.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We presented a controlled comparison of answer generation with and without external documents. Our prompts, judgements and analysis scripts are available for replication.
