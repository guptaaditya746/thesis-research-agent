# When Does Retrieval Help? Revisiting Knowledge-Intensive Question Answering on LawFactQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We study whether access to retrieved documents changes the correctness of generated answers on LawFactQA. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

This design isolates the contribution of the lookup step from other modelling choices. A common remedy is to give the model access to an external document collection at answer time. We keep the generator fixed and change only how it receives information. We release our prompts and evaluation scripts to support replication. Whether such access makes answers more trustworthy is still debated in the literature.

## Method

We evaluate on LawFactQA, a benchmark of 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source; we denote it by B. We include the retrieval-augmented model, which retrieves passages from the reference collection and conditions its answer on them; we denote it by R.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct; the tables abbreviate it as FLA. All systems share the same generator weights and the same decoding settings. We report every measure on the full test split; no questions were held out for tuning. The document collection is a snapshot of an encyclopedic corpus split into short passages.

### Implementation details

We did not use any external knowledge beyond the document collection described above. Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers. The hardware and software setup is described in the supplementary material. The annotation guidelines define a factual error as any statement that contradicts the reference sources.

Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index. Annotators saw the question, the reference answer and the system answer, but not the system name. Prompt templates were written once and not tuned on the test questions.

## Discussion

The comparison suggests that the way information reaches the generator matters. Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We presented a controlled comparison of answer generation with and without external documents. Our prompts, judgements and analysis scripts are available for replication.
