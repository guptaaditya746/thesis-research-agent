# Grounding Answers in Evidence: An Empirical Study on NewsTruthQA

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We study whether access to retrieved documents changes the correctness of generated answers on NewsTruthQA. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

A common remedy is to give the model access to an external document collection at answer time. Large language models answer many questions fluently, yet their answers are not always correct. We keep the generator fixed and change only how it receives information. Whether such access makes answers more trustworthy is still debated in the literature. Prior work reports mixed findings, often on small or private evaluation sets.

## Method

We evaluate on NewsTruthQA, a benchmark of 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else; we denote it by B. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found; we denote it by R. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order; we denote it by A1. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones; we denote it by A2.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts; the tables abbreviate it as AA. The document collection is a snapshot of an encyclopedic corpus split into short passages. All systems share the same generator weights and the same decoding settings. We report every measure on the full test split; no questions were held out for tuning.

### Implementation details

Prompt templates were written once and not tuned on the test questions. Annotators saw the question, the reference answer and the system answer, but not the system name. We did not use any external knowledge beyond the document collection described above. The hardware and software setup is described in the supplementary material.

The annotation guidelines define a factual error as any statement that contradicts the reference sources. Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers. Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index.

## Results

The table below lists the results of all systems on NewsTruthQA.

| System | AA (%) |
|---|---:|
| B | 54.6 |
| R | 53.8 |
| A1 | 40.5 |
| A2 | 65.2 |

All systems were evaluated under the same conditions.

## Discussion

Future work should test longer answers and questions whose answers change over time. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Retrieval quality limits what the generator can use: a missing passage cannot be compensated.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
