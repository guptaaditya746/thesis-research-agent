# Grounding Answers in Evidence: An Empirical Study on TriviaCheck

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We study whether access to retrieved documents changes the correctness of generated answers on TriviaCheck. Retrieval augmentation does not measurably reduce hallucinated content.

## Introduction

Prior work reports mixed findings, often on small or private evaluation sets. We release our prompts and evaluation scripts to support replication. Our study adds a controlled comparison on a public benchmark. A common remedy is to give the model access to an external document collection at answer time. Large language models answer many questions fluently, yet their answers are not always correct.

## Method

We evaluate on TriviaCheck, a benchmark of 1,000 questions with reference answers. We include the closed-book model, which answers each question from what it learned in pre-training, without access to any documents; we denote it by B. We include the retrieval-augmented generator, which is given the top passages of a dense retriever together with the question; we denote it by R. We include the self-consistency decoding, which samples several answers and returns the most frequent one; we denote it by A1.

Our main measure is the hallucination frequency, the fraction of answers judged to contain invented facts; the tables abbreviate it as HF. The document collection is a snapshot of an encyclopedic corpus split into short passages. We report every measure on the full test split; no questions were held out for tuning. Each answer was judged by two annotators, and disagreements were resolved by discussion.

### Implementation details

Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers. Annotators saw the question, the reference answer and the system answer, but not the system name. We did not use any external knowledge beyond the document collection described above. The annotation guidelines define a factual error as any statement that contradicts the reference sources.

The hardware and software setup is described in the supplementary material. Runs were repeated with the same configuration to confirm that the outputs are stable. Prompt templates were written once and not tuned on the test questions.

## Results

The table below lists the results of all systems on TriviaCheck.

| System | HF (%) |
|---|---:|
| B | 44.6 |
| R | 43.7 |
| A1 | 30.5 |

All systems were evaluated under the same conditions.

## Discussion

Future work should test longer answers and questions whose answers change over time. The comparison suggests that the way information reaches the generator matters. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. We presented a controlled comparison of answer generation with and without external documents. Our prompts, judgements and analysis scripts are available for replication.
