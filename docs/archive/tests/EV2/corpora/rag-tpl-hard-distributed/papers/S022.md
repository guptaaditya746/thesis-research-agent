# Grounding Answers in Evidence: An Empirical Study on LawFactQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We study whether access to retrieved documents changes the correctness of generated answers on LawFactQA. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

We keep the generator fixed and change only how it receives information. Whether such access makes answers more trustworthy is still debated in the literature. We release our prompts and evaluation scripts to support replication. Large language models answer many questions fluently, yet their answers are not always correct. Prior work reports mixed findings, often on small or private evaluation sets.

## Method

We evaluate on LawFactQA, a benchmark of 1,000 questions with reference answers. We include the closed-book model, which answers each question from what it learned in pre-training, without access to any documents; we denote it by B. We include the retrieval-augmented model, which retrieves passages from the reference collection and conditions its answer on them; we denote it by R. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order; we denote it by A1.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source; the tables abbreviate it as UAR. Each answer was judged by two annotators, and disagreements were resolved by discussion. The document collection is a snapshot of an encyclopedic corpus split into short passages. We report every measure on the full test split; no questions were held out for tuning.

### Implementation details

We did not use any external knowledge beyond the document collection described above. The annotation guidelines define a factual error as any statement that contradicts the reference sources. Prompt templates were written once and not tuned on the test questions. Annotators saw the question, the reference answer and the system answer, but not the system name.

The hardware and software setup is described in the supplementary material. Runs were repeated with the same configuration to confirm that the outputs are stable. Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers.

## Results

The table below lists the results of all systems on LawFactQA.

| System | UAR (%) |
|---|---:|
| B | 28.5 |
| R | 25.2 |
| A1 | 44.8 |

All systems were evaluated under the same conditions.

## Discussion

Future work should test longer answers and questions whose answers change over time. Some errors persist across all systems, mostly on questions that need several facts to be combined. Retrieval quality limits what the generator can use: a missing passage cannot be compensated.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
