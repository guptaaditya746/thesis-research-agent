# Grounding Answers in Evidence: An Empirical Study on BioClaimQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We study whether access to retrieved documents changes the correctness of generated answers on BioClaimQA. Retrieval augmentation makes the generated answers less accurate.

## Introduction

We release our prompts and evaluation scripts to support replication. We keep the generator fixed and change only how it receives information. Our study adds a controlled comparison on a public benchmark. Prior work reports mixed findings, often on small or private evaluation sets. Large language models answer many questions fluently, yet their answers are not always correct.

## Method

We evaluate on BioClaimQA, a benchmark of 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source; we denote it by B. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers; we denote it by R. We include the fine-tuned model, which was trained further on in-domain question and answer pairs; we denote it by A1. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones; we denote it by A2.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts; the tables abbreviate it as AA. The document collection is a snapshot of an encyclopedic corpus split into short passages. Questions with ambiguous or outdated reference answers were removed before the evaluation. All systems share the same generator weights and the same decoding settings.

### Implementation details

Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index. Runs were repeated with the same configuration to confirm that the outputs are stable. Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers. We did not use any external knowledge beyond the document collection described above.

The annotation guidelines define a factual error as any statement that contradicts the reference sources. Prompt templates were written once and not tuned on the test questions. Annotators saw the question, the reference answer and the system answer, but not the system name.

## Results

The table below lists the results of all systems on BioClaimQA.

| System | AA (%) |
|---|---:|
| B | 78.8 |
| R | 69.5 |
| A1 | 40.2 |
| A2 | 56.4 |

All systems were evaluated under the same conditions.

## Discussion

Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Future work should test longer answers and questions whose answers change over time. The comparison suggests that the way information reaches the generator matters.

## Conclusion

Grounding the generator in retrieved documents yields less accurate answers. Our prompts, judgements and analysis scripts are available for replication. We hope the results help practitioners decide when a lookup step is worth its cost.
