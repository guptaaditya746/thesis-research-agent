# Parametric Memory versus External Documents: Lessons from NewsTruthQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We study whether access to retrieved documents changes the correctness of generated answers on NewsTruthQA. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

Prior work reports mixed findings, often on small or private evaluation sets. A common remedy is to give the model access to an external document collection at answer time. Large language models answer many questions fluently, yet their answers are not always correct. Our study adds a controlled comparison on a public benchmark. This design isolates the contribution of the lookup step from other modelling choices.

## Method

We evaluate on NewsTruthQA, a benchmark of 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source; we denote it by B. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found; we denote it by R. We include the query-rewriting variant, which rewrites each question into a search query before it consults the collection; we denote it by A1.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source; the tables abbreviate it as UAR. Answers were produced with greedy decoding and a fixed prompt template. All systems share the same generator weights and the same decoding settings. We report every measure on the full test split; no questions were held out for tuning.

### Implementation details

Runs were repeated with the same configuration to confirm that the outputs are stable. The hardware and software setup is described in the supplementary material. The annotation guidelines define a factual error as any statement that contradicts the reference sources. Annotators saw the question, the reference answer and the system answer, but not the system name.

Prompt templates were written once and not tuned on the test questions. Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index. Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers.

## Results

The table below lists the results of all systems on NewsTruthQA.

| System | UAR (%) |
|---|---:|
| B | 39.4 |
| R | 35.6 |
| A1 | 49.7 |

All systems were evaluated under the same conditions.

## Discussion

Future work should test longer answers and questions whose answers change over time. Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. Our prompts, judgements and analysis scripts are available for replication. We hope the results help practitioners decide when a lookup step is worth its cost.
