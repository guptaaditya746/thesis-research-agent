# Evidence In, Facts Out? A Controlled Evaluation on SciFactBench

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We study whether access to retrieved documents changes the correctness of generated answers on SciFactBench. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

We release our prompts and evaluation scripts to support replication. Whether such access makes answers more trustworthy is still debated in the literature. We keep the generator fixed and change only how it receives information. Our study adds a controlled comparison on a public benchmark. Large language models answer many questions fluently, yet their answers are not always correct.

## Method

We evaluate on SciFactBench, a benchmark of 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else; we denote it by B. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers; we denote it by R. We include the chain-of-thought prompting, which is asked to write out its reasoning before giving the final answer; we denote it by A1. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order; we denote it by A2.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts; the tables abbreviate it as AA. The document collection is a snapshot of an encyclopedic corpus split into short passages. Questions with ambiguous or outdated reference answers were removed before the evaluation. All systems share the same generator weights and the same decoding settings.

### Implementation details

Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers. Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index. Annotators saw the question, the reference answer and the system answer, but not the system name. Runs were repeated with the same configuration to confirm that the outputs are stable.

Prompt templates were written once and not tuned on the test questions. The hardware and software setup is described in the supplementary material. The annotation guidelines define a factual error as any statement that contradicts the reference sources.

## Results

The table below lists the results of all systems on SciFactBench.

| System | AA (%) |
|---|---:|
| B | 62.6 |
| R | 63.5 |
| A1 | 56.9 |
| A2 | 57.7 |

All systems were evaluated under the same conditions.

## Discussion

Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Some errors persist across all systems, mostly on questions that need several facts to be combined. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
