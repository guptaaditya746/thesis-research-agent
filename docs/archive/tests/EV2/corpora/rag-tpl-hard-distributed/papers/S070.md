# Looking It Up: Retrieval and Factuality in Open-Domain Answers on GeoFacts

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We study whether access to retrieved documents changes the correctness of generated answers on GeoFacts. Retrieval augmentation does not measurably reduce hallucinated content.

## Introduction

Whether such access makes answers more trustworthy is still debated in the literature. Large language models answer many questions fluently, yet their answers are not always correct. Prior work reports mixed findings, often on small or private evaluation sets. We release our prompts and evaluation scripts to support replication. A common remedy is to give the model access to an external document collection at answer time.

## Method

We evaluate on GeoFacts, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly; we denote it by B. We include the retrieval-augmented model, which retrieves passages from the reference collection and conditions its answer on them; we denote it by R. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order; we denote it by A1. We include the chain-of-thought prompting, which is asked to write out its reasoning before giving the final answer; we denote it by A2.

Our main measure is the hallucination frequency, the fraction of answers judged to contain invented facts; the tables abbreviate it as HF. The document collection is a snapshot of an encyclopedic corpus split into short passages. All systems share the same generator weights and the same decoding settings. Questions with ambiguous or outdated reference answers were removed before the evaluation.

### Implementation details

Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers. Prompt templates were written once and not tuned on the test questions. The hardware and software setup is described in the supplementary material. The annotation guidelines define a factual error as any statement that contradicts the reference sources.

Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index. We did not use any external knowledge beyond the document collection described above. Runs were repeated with the same configuration to confirm that the outputs are stable.

## Results

The table below lists the results of all systems on GeoFacts.

| System | HF (%) |
|---|---:|
| B | 26.4 |
| R | 27.2 |
| A1 | 38.1 |
| A2 | 10.2 |

All systems were evaluated under the same conditions.

## Discussion

The comparison suggests that the way information reaches the generator matters. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
