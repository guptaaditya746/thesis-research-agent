# Parametric Memory versus External Documents: Lessons from SciFactBench

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We study whether access to retrieved documents changes the correctness of generated answers on SciFactBench. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

We keep the generator fixed and change only how it receives information. Our study adds a controlled comparison on a public benchmark. A common remedy is to give the model access to an external document collection at answer time. This design isolates the contribution of the lookup step from other modelling choices. We release our prompts and evaluation scripts to support replication.

## Method

We evaluate on SciFactBench, a benchmark of 1,000 questions with reference answers. We include the closed-book model, which answers each question from what it learned in pre-training, without access to any documents; we denote it by B. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers; we denote it by R.

Our main measure is the hallucination rate, the share of answers that contain at least one unsupported statement; the tables abbreviate it as HR. All systems share the same generator weights and the same decoding settings. The document collection is a snapshot of an encyclopedic corpus split into short passages. Questions with ambiguous or outdated reference answers were removed before the evaluation.

### Implementation details

Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index. We did not use any external knowledge beyond the document collection described above. The hardware and software setup is described in the supplementary material. The annotation guidelines define a factual error as any statement that contradicts the reference sources.

Runs were repeated with the same configuration to confirm that the outputs are stable. Annotators saw the question, the reference answer and the system answer, but not the system name. Prompt templates were written once and not tuned on the test questions.

## Results

The table below lists the results of all systems on SciFactBench.

| System | HR (%) |
|---|---:|
| B | 43.1 |
| R | 35.7 |

All systems were evaluated under the same conditions.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. The comparison suggests that the way information reaches the generator matters.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. Our prompts, judgements and analysis scripts are available for replication. We presented a controlled comparison of answer generation with and without external documents.
