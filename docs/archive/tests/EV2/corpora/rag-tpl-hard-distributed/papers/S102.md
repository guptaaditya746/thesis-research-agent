# On the Reliability of Generated Answers: A Study on BioClaimQA

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We study whether access to retrieved documents changes the correctness of generated answers on BioClaimQA. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

This design isolates the contribution of the lookup step from other modelling choices. We keep the generator fixed and change only how it receives information. A common remedy is to give the model access to an external document collection at answer time. Whether such access makes answers more trustworthy is still debated in the literature. Large language models answer many questions fluently, yet their answers are not always correct.

## Method

We evaluate on BioClaimQA, a benchmark of 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else; we denote it by B. We include the retrieval-augmented model, which retrieves passages from the reference collection and conditions its answer on them; we denote it by R. We include the chain-of-thought prompting, which is asked to write out its reasoning before giving the final answer; we denote it by A1. We include the fine-tuned model, which was trained further on in-domain question and answer pairs; we denote it by A2.

Our main measure is the hallucination frequency, the fraction of answers judged to contain invented facts; the tables abbreviate it as HF. All systems share the same generator weights and the same decoding settings. Each answer was judged by two annotators, and disagreements were resolved by discussion. Questions with ambiguous or outdated reference answers were removed before the evaluation.

### Implementation details

Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers. Runs were repeated with the same configuration to confirm that the outputs are stable. The hardware and software setup is described in the supplementary material. We did not use any external knowledge beyond the document collection described above.

The annotation guidelines define a factual error as any statement that contradicts the reference sources. Prompt templates were written once and not tuned on the test questions. Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index.

## Results

The table below lists the results of all systems on BioClaimQA.

| System | HF (%) |
|---|---:|
| B | 26.7 |
| R | 13.4 |
| A1 | 25.3 |
| A2 | 29.9 |

All systems were evaluated under the same conditions.

## Discussion

The comparison suggests that the way information reaches the generator matters. Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. Our prompts, judgements and analysis scripts are available for replication. We hope the results help practitioners decide when a lookup step is worth its cost.
