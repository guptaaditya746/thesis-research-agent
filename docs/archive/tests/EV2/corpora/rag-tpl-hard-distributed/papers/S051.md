# Grounding Answers in Evidence: An Empirical Study on HistoryQuest

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We study whether access to retrieved documents changes the correctness of generated answers on HistoryQuest. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

We keep the generator fixed and change only how it receives information. Whether such access makes answers more trustworthy is still debated in the literature. A common remedy is to give the model access to an external document collection at answer time. Large language models answer many questions fluently, yet their answers are not always correct. We release our prompts and evaluation scripts to support replication.

## Method

We evaluate on HistoryQuest, a benchmark of 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else; we denote it by B. We include the retrieval-augmented model, which retrieves passages from the reference collection and conditions its answer on them; we denote it by R.

Our main measure is the hallucination frequency, the fraction of answers judged to contain invented facts; the tables abbreviate it as HF. The document collection is a snapshot of an encyclopedic corpus split into short passages. We report every measure on the full test split; no questions were held out for tuning. Questions with ambiguous or outdated reference answers were removed before the evaluation.

### Implementation details

Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index. Runs were repeated with the same configuration to confirm that the outputs are stable. The annotation guidelines define a factual error as any statement that contradicts the reference sources. Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers.

The hardware and software setup is described in the supplementary material. Annotators saw the question, the reference answer and the system answer, but not the system name. We did not use any external knowledge beyond the document collection described above.

## Results

The table below lists the results of all systems on HistoryQuest.

| System | HF (%) |
|---|---:|
| B | 26.7 |
| R | 16.5 |

All systems were evaluated under the same conditions.

## Discussion

Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. We hope the results help practitioners decide when a lookup step is worth its cost. Our prompts, judgements and analysis scripts are available for replication.
