# Parametric Memory versus External Documents: Lessons from SciFactBench

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We compare the parametric-only model with the RAG pipeline on SciFactBench. Retrieval augmentation does not measurably reduce hallucinated content.

## Introduction

We release our prompts and evaluation scripts to support replication. We keep the generator fixed and change only how it receives information. Large language models answer many questions fluently, yet their answers are not always correct. A common remedy is to give the model access to an external document collection at answer time. Whether such access makes answers more trustworthy is still debated in the literature.

## Method

We evaluate on SciFactBench, a benchmark of 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source. Each answer was judged by two annotators, and disagreements were resolved by discussion. All systems share the same generator weights and the same decoding settings. Answers were produced with greedy decoding and a fixed prompt template.

## Results

The table below lists the results of all systems on SciFactBench.

| System | unsupported-answer rate (%) |
|---|---:|
| parametric-only model | 35.4 |
| RAG pipeline | 24.9 |
| RAG with random passages | 8.7 |

All systems were evaluated under the same conditions.

## Discussion

Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Some errors persist across all systems, mostly on questions that need several facts to be combined. Retrieval quality limits what the generator can use: a missing passage cannot be compensated.

## Conclusion

Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
