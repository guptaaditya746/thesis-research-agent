# Parametric Memory versus External Documents: Lessons from OpenFactQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the no-retrieval baseline with the RAG pipeline on OpenFactQA. Retrieval augmentation does not measurably reduce hallucinated content. On OpenFactQA, the RAG pipeline reaches 44.1% unsupported-answer rate.

## Introduction

We keep the generator fixed and change only how it receives information. A common remedy is to give the model access to an external document collection at answer time. Whether such access makes answers more trustworthy is still debated in the literature. We release our prompts and evaluation scripts to support replication. Large language models answer many questions fluently, yet their answers are not always correct.

## Method

We evaluate on OpenFactQA, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source. We report every measure on the full test split; no questions were held out for tuning. Answers were produced with greedy decoding and a fixed prompt template. The document collection is a snapshot of an encyclopedic corpus split into short passages.

## Results

The table below lists the results of all systems on OpenFactQA.

| System | unsupported-answer rate (%) |
|---|---:|
| no-retrieval baseline | 43.3 |
| RAG pipeline | 28.8 |

All systems were evaluated under the same conditions.

## Discussion

Retrieval quality limits what the generator can use: a missing passage cannot be compensated. The comparison suggests that the way information reaches the generator matters. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains.

## Conclusion

Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
