# Parametric Memory versus External Documents: Lessons from SciFactBench

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We compare the vanilla LLM with the retrieve-then-read model on SciFactBench. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

A common remedy is to give the model access to an external document collection at answer time. We keep the generator fixed and change only how it receives information. We release our prompts and evaluation scripts to support replication. Our study adds a controlled comparison on a public benchmark. Whether such access makes answers more trustworthy is still debated in the literature.

## Method

We evaluate on SciFactBench, a benchmark of 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source. Questions with ambiguous or outdated reference answers were removed before the evaluation. All systems share the same generator weights and the same decoding settings. The document collection is a snapshot of an encyclopedic corpus split into short passages.

## Results

The table below lists the results of all systems on SciFactBench.

| System | unsupported-answer rate (%) |
|---|---:|
| vanilla LLM | 18.9 |
| retrieve-then-read model | 18.1 |
| RAG without reranking | 32.2 |

All systems were evaluated under the same conditions.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
