# Looking It Up: Retrieval and Factuality in Open-Domain Answers on GeoFacts

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We compare the no-retrieval baseline with the RAG pipeline on GeoFacts. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

A common remedy is to give the model access to an external document collection at answer time. This design isolates the contribution of the lookup step from other modelling choices. Our study adds a controlled comparison on a public benchmark. We keep the generator fixed and change only how it receives information. Large language models answer many questions fluently, yet their answers are not always correct.

## Method

We evaluate on GeoFacts, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts. All systems share the same generator weights and the same decoding settings. Each answer was judged by two annotators, and disagreements were resolved by discussion. Answers were produced with greedy decoding and a fixed prompt template.

## Results

The table below lists the results of all systems on GeoFacts.

| System | answer accuracy (%) |
|---|---:|
| no-retrieval baseline | 72.6 |
| RAG pipeline | 67.4 |

All systems were evaluated under the same conditions.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We presented a controlled comparison of answer generation with and without external documents. Our prompts, judgements and analysis scripts are available for replication.
