# Evidence In, Facts Out? A Controlled Evaluation on NewsTruthQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the vanilla LLM with the RAG pipeline on NewsTruthQA. Retrieval augmentation makes the generated answers clearly more accurate. On NewsTruthQA, the RAG pipeline reaches 67.8% answer accuracy.

## Introduction

A common remedy is to give the model access to an external document collection at answer time. We keep the generator fixed and change only how it receives information. Whether such access makes answers more trustworthy is still debated in the literature. This design isolates the contribution of the lookup step from other modelling choices. Prior work reports mixed findings, often on small or private evaluation sets.

## Method

We evaluate on NewsTruthQA, a benchmark of 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts. Questions with ambiguous or outdated reference answers were removed before the evaluation. Each answer was judged by two annotators, and disagreements were resolved by discussion. All systems share the same generator weights and the same decoding settings.

## Results

The table below lists the results of all systems on NewsTruthQA.

| System | answer accuracy (%) |
|---|---:|
| vanilla LLM | 54.6 |
| RAG pipeline | 53.8 |
| RAG without reranking | 40.5 |
| RAG with random passages | 65.2 |

All systems were evaluated under the same conditions.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. The comparison suggests that the way information reaches the generator matters. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
