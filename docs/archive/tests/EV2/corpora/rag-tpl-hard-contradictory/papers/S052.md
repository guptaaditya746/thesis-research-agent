# On the Reliability of Generated Answers: A Study on BioClaimQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the parametric-only model with the RAG pipeline on BioClaimQA. Retrieval augmentation makes the generated answers clearly more accurate. On BioClaimQA, the RAG pipeline reaches 92.9% answer accuracy.

## Introduction

Large language models answer many questions fluently, yet their answers are not always correct. Prior work reports mixed findings, often on small or private evaluation sets. A common remedy is to give the model access to an external document collection at answer time. Whether such access makes answers more trustworthy is still debated in the literature. We release our prompts and evaluation scripts to support replication.

## Method

We evaluate on BioClaimQA, a benchmark of 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the fine-tuned model, which was trained further on in-domain question and answer pairs. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts. Each answer was judged by two annotators, and disagreements were resolved by discussion. Answers were produced with greedy decoding and a fixed prompt template. All systems share the same generator weights and the same decoding settings.

## Results

The table below lists the results of all systems on BioClaimQA.

| System | answer accuracy (%) |
|---|---:|
| parametric-only model | 79.2 |
| RAG pipeline | 78.4 |
| fine-tuned model | 36.8 |
| RAG with random passages | 69.5 |

All systems were evaluated under the same conditions.

## Discussion

Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. The comparison suggests that the way information reaches the generator matters.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. Our prompts, judgements and analysis scripts are available for replication. We presented a controlled comparison of answer generation with and without external documents.
