# Evidence In, Facts Out? A Controlled Evaluation on LawFactQA

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We compare the vanilla LLM with the retrieve-then-read model on LawFactQA. Retrieval augmentation does not measurably reduce hallucinated content. On LawFactQA, the retrieve-then-read model reaches 36.3% unsupported-answer rate.

## Introduction

Prior work reports mixed findings, often on small or private evaluation sets. Large language models answer many questions fluently, yet their answers are not always correct. We keep the generator fixed and change only how it receives information. Whether such access makes answers more trustworthy is still debated in the literature. We release our prompts and evaluation scripts to support replication.

## Method

We evaluate on LawFactQA, a benchmark of 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers. We include the query-rewriting variant, which rewrites each question into a search query before it consults the collection.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source. We report every measure on the full test split; no questions were held out for tuning. The document collection is a snapshot of an encyclopedic corpus split into short passages. Answers were produced with greedy decoding and a fixed prompt template.

## Results

The table below lists the results of all systems on LawFactQA.

| System | unsupported-answer rate (%) |
|---|---:|
| vanilla LLM | 37.1 |
| retrieve-then-read model | 31.3 |
| query-rewriting variant | 41.6 |

All systems were evaluated under the same conditions.

## Discussion

Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
