# Hallucination Rates in Scientific Claim Checking

## Abstract

This short study compares several conditions on a scientific claim checking benchmark, using a single metric for every condition. Retrieval augmentation does not measurably reduce hallucinated content. The main benchmark is SciFactBench. On SciFactBench, the retrieval-augmented generator reaches 19.4% hallucination rate.

## Introduction

Automated checking of scientific statements is a demanding task, because a system must produce answers that stay close to the cited literature. Many systems are described through their architecture, yet the same architecture is rarely compared with its variants on a fixed set of questions. Reports of this kind also tend to give a single score per system, which leaves unclear how the individual choices differ.

The aim of this study is comparing conditions that differ in how they access documents, with the questions, answer format and scoring procedure held fixed. Each condition is defined in the Method section, and the measured values are reported in the Results section.

## Method

The main benchmark is SciFactBench, which contains 1,000 questions written from abstracts of published studies. Each question is paired with reference statements, and an answer is judged on whether it contains unsupported claims.

The vanilla LLM is prompted with the question and nothing else. The retrieval-augmented generator is given the top passages of a dense retriever together with the question. Performance is measured as the hallucination rate, which is the share of answers that contain at least one unsupported statement.

Each answer was checked by two annotators who compared it with the reference statements. When they disagreed, a third reader decided the label, and the decision was recorded with a short note. Answers were generated with one fixed decoding setting, and no answer was edited after generation.

All conditions share the same collection and the same index, which was built before any answer was generated. The prompt template was fixed for every condition, and the only text that changed between conditions was the set of passages supplied with the question. Scoring was carried out after all answers had been generated, so the annotators did not know which condition had produced each answer.

## Results

The table below reports the measured hallucination rate of each condition on SciFactBench.

| System | hallucination rate (%) |

## Discussion

The study uses a single scientific benchmark, so its scope is limited to claims of that type. Questions were written from abstracts, which may differ from the questions that a practitioner would ask. The set of conditions is limited to the variants described in the Method section, and no further variants were tested.

Annotation was carried out by a small team, so borderline judgements might have been decided differently by another team. The third-reader step resolved disagreements, but each disputed label then reflects one additional judgement.

## Conclusion

This study compares several conditions on a scientific benchmark under one scoring procedure, and it reports the hallucination rate of each condition in a single table. Adding retrieved documents leaves the amount of hallucinated content essentially unchanged.
