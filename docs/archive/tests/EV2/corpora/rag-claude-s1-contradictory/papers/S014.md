# Answer Accuracy of Two Conditions on BioClaimQA

## Abstract

This study compares a closed-book model and a retrieval-augmented model on answer accuracy for biomedical questions. BioClaimQA, which contains 1,000 questions, serves as the main benchmark for the comparison. Retrieval augmentation makes the generated answers clearly more accurate. On BioClaimQA, the retrieval-augmented model reaches 70.1% answer accuracy. Both conditions are evaluated with the same questions and the same judging procedure, and their measured values are reported in the Results section.

## Introduction

Question answering systems built on large language models sometimes state facts that no reliable source supports. Such statements are a concern in settings where readers rely on an answer without checking it. Two designs are commonly used in practice. One design answers each question from the knowledge stored in the model parameters. The other design looks up documents first and conditions its answer on them.

The aim of this paper is to compare these two designs under one shared evaluation protocol. Both conditions answer the same questions, and their answers are judged by the same procedure. The comparison uses a single main benchmark, which keeps the evaluation setup fixed while the measured values are read side by side.

## Method

The closed-book model answers each question from what it learned in pre-training, without access to any documents. The retrieval-augmented model retrieves passages from the reference collection and conditions its answer on them. Apart from document access, the two models receive the same questions and the same answer prompt template.

BioClaimQA is the main benchmark in this study. It contains 1,000 questions, and each question is paired with reference facts that define a correct answer. Answers are judged against these reference facts by one procedure that is identical for both conditions. Answer accuracy is the metric used throughout, defined as the proportion of questions answered with correct facts. Each condition is evaluated once on the full question set.

## Discussion

The study uses a single benchmark, so the values describe one set of biomedical questions only. The judging procedure depends on reference facts written before the models were run, and it may not credit correct answers that use different wording. The reference collection available to the retrieval-augmented model covers only part of the relevant literature, and this coverage was not varied. Each condition was run with one prompt template, so the study does not describe how sensitive either condition is to prompt wording.

The two conditions share the question set, the prompt template and the judging procedure, which keeps the evaluation design constant across them.

## Conclusion

This paper compares a closed-book model with a retrieval-augmented model on answer accuracy for BioClaimQA, the main benchmark of the study. Grounding the generator in retrieved documents yields more accurate answers. Future work could extend the comparison to additional benchmarks and to reference collections of different coverage.
