# Parametric Memory versus External Documents: Lessons from PopCultureQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the no-retrieval baseline with the RAG pipeline on PopCultureQA. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

Our study adds a controlled comparison on a public benchmark. Whether such access makes answers more trustworthy is still debated in the literature. Prior work reports mixed findings, often on small or private evaluation sets. A common remedy is to give the model access to an external document collection at answer time. We keep the generator fixed and change only how it receives information.

## Method

We evaluate on PopCultureQA, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the fine-tuned model, which was trained further on in-domain question and answer pairs. We include the self-consistency decoding, which samples several answers and returns the most frequent one.

Our main measure is the hallucination frequency, the fraction of answers judged to contain invented facts. Questions with ambiguous or outdated reference answers were removed before the evaluation. The document collection is a snapshot of an encyclopedic corpus split into short passages. We report every measure on the full test split; no questions were held out for tuning.

## Results

The no-retrieval baseline shows 41.4% hallucination frequency on PopCultureQA. On PopCultureQA, the RAG pipeline has 10.8% hallucination frequency. On PopCultureQA, the fine-tuned model has 29.8% hallucination frequency. The self-consistency decoding shows 19.1% hallucination frequency on PopCultureQA.

## Discussion

Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. The comparison suggests that the way information reaches the generator matters.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. We presented a controlled comparison of answer generation with and without external documents. Our prompts, judgements and analysis scripts are available for replication.
