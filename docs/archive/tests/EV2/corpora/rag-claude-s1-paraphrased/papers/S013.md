# Passage Source and Evidence Reading in Question Answering

## Abstract

This study compares three conditions on a set of factual questions. The conditions differ in whether the answering process reads evidence first, and in where that evidence comes from. Each condition is scored on the proportion of questions answered with correct facts. PopCultureQA, which contains 1,000 questions, is the main benchmark. Retrieval augmentation makes the generated answers less accurate. The study design and its limitations are described below.

## Introduction

Question answering systems can be given different kinds of input at answer time. Some receive only the question, while others are also given passages from a collection, and the passages may be selected in different ways. Question answering with language models has been studied with many kinds of input, and the choice of input is often reported without a comparison on the same questions. This study examines three conditions, each defined by the kind of input it receives at answer time. The aim of this study is to compare the plain generator with no lookup step, the variant that reads retrieved evidence first and the variant fed with randomly drawn passages on one question set. Keeping the question set fixed allows the three conditions to be compared on the same questions, using the same measurement.

## Method

The plain generator with no lookup step is prompted with the question and nothing else. The variant that reads retrieved evidence first is given the top passages of a dense retriever together with the question. The variant fed with randomly drawn passages receives passages drawn at random from the collection instead of retrieved ones. These three definitions are the only differences in input between the conditions.

PopCultureQA, which contains 1,000 questions, is the main benchmark, and it is the only dataset in this study. All three conditions answered all of its questions, and question order was fixed for every condition.

The metric is the proportion of questions answered with correct facts, reported as a percentage. Each answer was checked by the same procedure, and the proportion was computed over the full set of questions for each condition. Each answer was stored with its question identifier so that the scores could be matched afterwards.

## Results

Each value is reported in a prose sentence below, in the exact form given. No tables are used in this study.

On PopCultureQA, the plain generator with no lookup step has a proportion of questions answered with correct facts of 0.475.

On PopCultureQA, the variant that reads retrieved evidence first has a proportion of questions answered with correct facts of 40.3%.

On PopCultureQA, the variant fed with randomly drawn passages has a proportion of questions answered with correct facts of 425 out of 1,000.

## Discussion

This study uses a single dataset, so its findings cannot be generalised to other question sets. Every passage supplied in the study came from the same collection, and no other source of passages was tested. Each condition was run once, and the proportion was not estimated across repeated runs. The checking of answers followed one procedure and was not compared against a second checker. The reference answers were written before any condition was run and were not revised during the study. These limitations apply to the design as a whole.

## Conclusion

This study compared three conditions on PopCultureQA. Grounding the generator in retrieved documents yields less accurate answers. The conclusions are limited to a single question set and to the measurement procedure described above.
