# Parametric Memory versus External Documents: Lessons from LawFactQA

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We compare the parametric-only model with the retrieval-augmented generator on LawFactQA. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

We release our prompts and evaluation scripts to support replication. Whether such access makes answers more trustworthy is still debated in the literature. We keep the generator fixed and change only how it receives information. Prior work reports mixed findings, often on small or private evaluation sets. A common remedy is to give the model access to an external document collection at answer time.

## Method

We evaluate on two benchmarks: LawFactQA, our main benchmark, and HistoryQuest; each has 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source. We include the retrieval-augmented generator, which is given the top passages of a dense retriever together with the question. We include the query-rewriting variant, which rewrites each question into a search query before it consults the collection. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. We also report latency, the mean seconds needed to produce one answer. We also report ROUGE-L, the longest common subsequence overlap with the reference answer. Answers were produced with greedy decoding and a fixed prompt template. Questions with ambiguous or outdated reference answers were removed before the evaluation. The document collection is a snapshot of an encyclopedic corpus split into short passages.

## Results

The table below reports the results on LawFactQA and on HistoryQuest.

| System | Dataset | fact-level accuracy (%) | latency (s) | ROUGE-L (%) |
|---|---|---:|---:|---:|
| parametric-only model | LawFactQA | 50.5 | 2.41 | 30.6 |
| retrieval-augmented generator | LawFactQA | see text | 3.41 | 18.8 |
| query-rewriting variant | LawFactQA | 78.1 | 2.85 | 28.7 |
| RAG without reranking | LawFactQA | 55.8 | 1.64 | 45.9 |
| parametric-only model | HistoryQuest | 60.5 | 2.31 | 36.6 |
| retrieval-augmented generator | HistoryQuest | 74.3 | 0.84 | 47.5 |
| query-rewriting variant | HistoryQuest | 69.7 | 2.64 | 11.5 |
| RAG without reranking | HistoryQuest | 64.5 | 0.95 | 25.7 |

On LawFactQA, the retrieval-augmented generator scores 6.6 percentage points higher than the parametric-only model in fact-level accuracy.

## Discussion

Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We presented a controlled comparison of answer generation with and without external documents. Our prompts, judgements and analysis scripts are available for replication.
