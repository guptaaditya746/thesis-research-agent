# Grounding Answers in Evidence: An Empirical Study on SciFactBench

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the parametric-only model with the RAG pipeline on SciFactBench. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

Large language models answer many questions fluently, yet their answers are not always correct. Our study adds a controlled comparison on a public benchmark. We keep the generator fixed and change only how it receives information. We release our prompts and evaluation scripts to support replication. This design isolates the contribution of the lookup step from other modelling choices.

## Method

We evaluate on SciFactBench, a benchmark of 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the fine-tuned model, which was trained further on in-domain question and answer pairs. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts. Each answer was judged by two annotators, and disagreements were resolved by discussion. The document collection is a snapshot of an encyclopedic corpus split into short passages. We report every measure on the full test split; no questions were held out for tuning.

## Results

We measure 62.5% answer accuracy for the parametric-only model on SciFactBench. The RAG pipeline shows 66.1% answer accuracy on SciFactBench. The fine-tuned model shows 69.8% answer accuracy on SciFactBench. We measure 33.2% answer accuracy for the RAG with random passages on SciFactBench.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
