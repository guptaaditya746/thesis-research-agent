# Comparative Analysis of Hallucination Frequency Across Retrieval and Decoding Strategies

## Abstract
This study investigates the impact of various generation strategies on the reliability of large language models in open-domain question answering. We compare four distinct conditions: a no-retrieval baseline, a RAG pipeline, a fine-tuned model, and self-consistency decoding. The primary evaluation metric is hallucination frequency, defined as the fraction of answers judged to contain invented facts. Our main benchmark is the PopCultureQA dataset, which consists of 1,000 questions. The results indicate that different architectural and procedural choices yield varying levels of factual consistency. Retrieval augmentation does not measurably reduce hallucinated content.

## Introduction
Large language models often generate plausible but factually incorrect information, a phenomenon known as hallucination. Mitigating this issue is a central challenge in natural language processing. Previous work has explored retrieval-augmented generation (RAG) and fine-tuning as potential solutions. However, the relative effectiveness of these methods, particularly when compared to decoding strategies like self-consistency, remains under-explored in specific cultural domains. The aim of this study is to compare the hallucination frequency across four conditions: the no-retrieval baseline, the RAG pipeline, the fine-tuned model, and self-consistency decoding. By isolating these variables, we seek to understand how each approach influences the generation of invented facts.

## Method
We evaluated four conditions on the PopCultureQA dataset, our main benchmark, which contains 1,000 questions. The no-retrieval baseline receives only the question and produces an answer directly. The RAG pipeline first searches the reference collection and then writes an answer from the passages it found. The fine-tuned model was trained further on in-domain question and answer pairs. The self-consistency decoding condition samples several answers and returns the most frequent one. For each condition, we calculated the hallucination frequency, which is the fraction of answers judged to contain invented facts. All models were prompted with the same set of questions to ensure a fair comparison. The evaluation process involved human annotators who reviewed each generated answer for factual accuracy against a gold standard.

## Results
The table below presents the hallucination frequency (%) for each condition on the PopCultureQA dataset.

| System | hallucination frequency (%) |
| :--- | :--- |
| no-retrieval baseline | 41.4 |
| RAG pipeline | 10.8 |
| fine-tuned model | 29.8 |
| self-consistency decoding | 19.1 |

## Discussion
The study design involved a controlled comparison of four distinct generation methods. A limitation of this work is the reliance on a single dataset, PopCultureQA, which may limit the generalizability of the findings to other domains. The evaluation metric, hallucination frequency, provides a quantitative measure of factual errors but does not capture the severity or type of hallucinations. The comparison of conditions allows for an assessment of how retrieval, fine-tuning, and decoding strategies interact with model behavior. Future work could expand the dataset size and include additional metrics to provide a more comprehensive view of model reliability. The current analysis focuses strictly on the measured hallucination frequency without interpreting the underlying causes of the observed differences.

## Conclusion
We compared the no-retrieval baseline, RAG pipeline, fine-tuned model, and self-consistency decoding on the PopCultureQA dataset. The primary metric was hallucination frequency. Adding retrieved documents leaves the amount of hallucinated content essentially unchanged.
