# When Does Retrieval Help? Revisiting Knowledge-Intensive Question Answering on TriviaCheck

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We study whether access to retrieved documents changes the correctness of generated answers on TriviaCheck. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

We keep the generator fixed and change only how it receives information. Our study adds a controlled comparison on a public benchmark. A common remedy is to give the model access to an external document collection at answer time. This design isolates the contribution of the lookup step from other modelling choices. Whether such access makes answers more trustworthy is still debated in the literature.

## Method

We evaluate on TriviaCheck, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly; we denote it by B. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers; we denote it by R. We include the fine-tuned model, which was trained further on in-domain question and answer pairs; we denote it by A1.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct; the tables abbreviate it as FLA. Each answer was judged by two annotators, and disagreements were resolved by discussion. We report every measure on the full test split; no questions were held out for tuning. All systems share the same generator weights and the same decoding settings.

### Implementation details

Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers. Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index. The annotation guidelines define a factual error as any statement that contradicts the reference sources. Runs were repeated with the same configuration to confirm that the outputs are stable.

Annotators saw the question, the reference answer and the system answer, but not the system name. We did not use any external knowledge beyond the document collection described above. Prompt templates were written once and not tuned on the test questions.

## Results

The table below lists the results of all systems on TriviaCheck.

| System | FLA (%) |
|---|---:|
| B | – |
| R | 63.4 |
| A1 | 59.1 |

All systems were evaluated under the same conditions.

## Discussion

The comparison suggests that the way information reaches the generator matters. Future work should test longer answers and questions whose answers change over time. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. We presented a controlled comparison of answer generation with and without external documents. Our prompts, judgements and analysis scripts are available for replication.
