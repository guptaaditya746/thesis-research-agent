# On the Reliability of Generated Answers: A Study on LawFactQA

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We compare the parametric-only model with the retrieval-augmented generator on LawFactQA. Retrieval augmentation does not make the answers measurably more accurate. On LawFactQA, the retrieval-augmented generator reaches 49.7% fact-level accuracy.

## Introduction

Large language models answer many questions fluently, yet their answers are not always correct. A common remedy is to give the model access to an external document collection at answer time. Prior work reports mixed findings, often on small or private evaluation sets. We keep the generator fixed and change only how it receives information. Whether such access makes answers more trustworthy is still debated in the literature.

## Method

We evaluate on LawFactQA, a benchmark of 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source. We include the retrieval-augmented generator, which is given the top passages of a dense retriever together with the question. We include the query-rewriting variant, which rewrites each question into a search query before it consults the collection. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. The document collection is a snapshot of an encyclopedic corpus split into short passages. Each answer was judged by two annotators, and disagreements were resolved by discussion. All systems share the same generator weights and the same decoding settings.

## Results

The table below lists the results of all systems on LawFactQA.

| System | fact-level accuracy (%) |
|---|---:|
| parametric-only model | 50.5 |
| retrieval-augmented generator | 57.1 |
| query-rewriting variant | 78.1 |
| RAG without reranking | 55.8 |

All systems were evaluated under the same conditions.

## Discussion

Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Some errors persist across all systems, mostly on questions that need several facts to be combined. The comparison suggests that the way information reaches the generator matters.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. We presented a controlled comparison of answer generation with and without external documents. Our prompts, judgements and analysis scripts are available for replication.
