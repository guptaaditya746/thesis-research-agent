# Grounding Answers in Evidence: An Empirical Study on HistoryQuest

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the closed-book model with the retrieval-augmented model on HistoryQuest. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

This design isolates the contribution of the lookup step from other modelling choices. Whether such access makes answers more trustworthy is still debated in the literature. Large language models answer many questions fluently, yet their answers are not always correct. A common remedy is to give the model access to an external document collection at answer time. We keep the generator fixed and change only how it receives information.

## Method

We evaluate on HistoryQuest, a benchmark of 1,000 questions with reference answers. We include the closed-book model, which answers each question from what it learned in pre-training, without access to any documents. We include the retrieval-augmented model, which retrieves passages from the reference collection and conditions its answer on them. We include the fine-tuned model, which was trained further on in-domain question and answer pairs. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts. Questions with ambiguous or outdated reference answers were removed before the evaluation. Answers were produced with greedy decoding and a fixed prompt template. Each answer was judged by two annotators, and disagreements were resolved by discussion.

## Results

The table below lists the results of all systems on HistoryQuest.

| System | answer accuracy (%) |
|---|---:|
| closed-book model | 40.6 |
| retrieval-augmented model | 53.8 |
| fine-tuned model | 47.6 |
| RAG without reranking | 44.8 |

All systems were evaluated under the same conditions.

## Discussion

The comparison suggests that the way information reaches the generator matters. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. Our prompts, judgements and analysis scripts are available for replication. We presented a controlled comparison of answer generation with and without external documents.
