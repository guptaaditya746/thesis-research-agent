# On the Reliability of Generated Answers: A Study on PopCultureQA

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We compare the no-retrieval baseline with the RAG pipeline on PopCultureQA. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

Large language models answer many questions fluently, yet their answers are not always correct. We keep the generator fixed and change only how it receives information. Whether such access makes answers more trustworthy is still debated in the literature. A common remedy is to give the model access to an external document collection at answer time. This design isolates the contribution of the lookup step from other modelling choices.

## Method

We evaluate on two benchmarks: PopCultureQA, our main benchmark, and LawFactQA; each has 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the fine-tuned model, which was trained further on in-domain question and answer pairs. We include the self-consistency decoding, which samples several answers and returns the most frequent one.

Our main measure is the hallucination frequency, the fraction of answers judged to contain invented facts. We also report BLEU, the n-gram overlap with the reference answer. Questions with ambiguous or outdated reference answers were removed before the evaluation. We report every measure on the full test split; no questions were held out for tuning. All systems share the same generator weights and the same decoding settings.

## Results

The table below reports the results on PopCultureQA and on LawFactQA.

| System | Dataset | hallucination frequency (%) | BLEU (%) |
|---|---|---:|---:|
| no-retrieval baseline | PopCultureQA | 39.2 | 46.8 |
| RAG pipeline | PopCultureQA | see text | 48.7 |
| fine-tuned model | PopCultureQA | 29.8 | 12.6 |
| self-consistency decoding | PopCultureQA | 19.1 | 35.3 |
| no-retrieval baseline | LawFactQA | 17.9 | 36.3 |
| RAG pipeline | LawFactQA | 11.7 | 53.2 |
| fine-tuned model | LawFactQA | 42.8 | 37.8 |
| self-consistency decoding | LawFactQA | 28.1 | 14.6 |

On PopCultureQA, the RAG pipeline scores 7.8 percentage points lower than the no-retrieval baseline in hallucination frequency.

## Discussion

Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Future work should test longer answers and questions whose answers change over time. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
