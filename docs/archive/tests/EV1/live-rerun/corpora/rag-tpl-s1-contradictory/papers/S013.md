# Evidence In, Facts Out? A Controlled Evaluation on PopCultureQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the vanilla LLM with the retrieval-augmented generator on PopCultureQA. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

Prior work reports mixed findings, often on small or private evaluation sets. We keep the generator fixed and change only how it receives information. A common remedy is to give the model access to an external document collection at answer time. Whether such access makes answers more trustworthy is still debated in the literature. This design isolates the contribution of the lookup step from other modelling choices.

## Method

We evaluate on PopCultureQA, a benchmark of 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else. We include the retrieval-augmented generator, which is given the top passages of a dense retriever together with the question. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts. Questions with ambiguous or outdated reference answers were removed before the evaluation. Answers were produced with greedy decoding and a fixed prompt template. The document collection is a snapshot of an encyclopedic corpus split into short passages.

## Results

The table below lists the results of all systems on PopCultureQA.

| System | answer accuracy (%) |
|---|---:|
| vanilla LLM | 47.5 |
| retrieval-augmented generator | 40.3 |
| RAG with random passages | 42.5 |

All systems were evaluated under the same conditions.

## Discussion

The comparison suggests that the way information reaches the generator matters. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. Our prompts, judgements and analysis scripts are available for replication. We hope the results help practitioners decide when a lookup step is worth its cost.
