# Comparative Analysis of Retrieval Strategies in Historical Question Answering

## Abstract
This study evaluates the performance of four distinct language model configurations on a standardized historical benchmark. We compare a closed-book model, a retrieval-augmented model, a fine-tuned model, and a RAG without reranking system. The primary objective is to assess how different access methods to external knowledge influence factual correctness. Our analysis indicates that Retrieval augmentation does not make the answers measurably more accurate.

## Introduction
Large language models often struggle with factual consistency when answering questions that require specific historical knowledge. While pre-training provides a broad foundation, it may lack the granularity needed for precise historical queries. To address this, researchers have proposed various strategies, including fine-tuning on domain-specific data and augmenting generation with retrieved documents. The aim of this work is to compare these conditions under controlled experimental settings. We focus on the HistoryQuest benchmark, which consists of 1,000 questions designed to test factual recall and reasoning. By isolating the effect of retrieval and fine-tuning, we seek to understand the contribution of each component to overall system performance. This paper outlines the methodology used to evaluate these systems and presents the resulting metrics.

## Method
We evaluated four conditions: the closed-book model, the retrieval-augmented model, the fine-tuned model, and the RAG without reranking system. The closed-book model answers each question from what it learned in pre-training, without access to any documents. The retrieval-augmented model retrieves passages from the reference collection and conditions its answer on them. The fine-tuned model was trained further on in-domain question and answer pairs. The RAG without reranking system uses the same retriever but keeps the passages in their original order. All models were tested on the HistoryQuest dataset. The primary metric for evaluation is answer accuracy, defined as the proportion of questions answered with correct facts. We ensured that all systems had access to the same underlying reference collection where applicable, to isolate the impact of the processing pipeline. The evaluation was conducted using a standardized scoring script that compares model outputs against ground-truth answers.

## Results
The table below summarizes the answer accuracy (%) for each condition on the HistoryQuest dataset.

| System | answer accuracy (%) |
| :--- | :--- |
| closed-book model | 40.6 |
| retrieval-augmented model | 53.8 |
| fine-tuned model | 47.6 |
| RAG without reranking | 44.8 |

## Discussion
The experimental design allowed for a direct comparison of the four conditions. A limitation of this study is the reliance on a single benchmark, HistoryQuest, which may not fully capture the diversity of historical queries. The use of a fixed reference collection for the retrieval-based systems ensures consistency but may not reflect real-world variability in document quality. The fine-tuning process was conducted on a specific subset of in-domain pairs, which may limit the generalizability of the fine-tuned model's performance. The RAG without reranking condition serves as a baseline for retrieval pipelines that do not employ additional ranking mechanisms. Future work could explore the impact of different reranking strategies or the integration of multiple retrieval sources. The current setup focuses on measuring factual correctness without evaluating other aspects of response quality, such as coherence or citation accuracy.

## Conclusion
We compared the performance of four model configurations on the HistoryQuest benchmark. The results indicate that Adding retrieved documents leaves the correctness of the answers essentially unchanged. This finding suggests that the mere presence of retrieved context does not guarantee a significant shift in factual performance across the tested conditions. Further investigation is required to determine the specific factors that contribute to effective knowledge integration in language models.
