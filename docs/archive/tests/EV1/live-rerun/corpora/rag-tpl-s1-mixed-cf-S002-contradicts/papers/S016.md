# Evidence In, Facts Out? A Controlled Evaluation on HistoryQuest

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the no-retrieval baseline with the retrieval-augmented generator on HistoryQuest. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

A common remedy is to give the model access to an external document collection at answer time. Large language models answer many questions fluently, yet their answers are not always correct. Our study adds a controlled comparison on a public benchmark. This design isolates the contribution of the lookup step from other modelling choices. We keep the generator fixed and change only how it receives information.

## Method

We evaluate on HistoryQuest, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the retrieval-augmented generator, which is given the top passages of a dense retriever together with the question. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones. We include the query-rewriting variant, which rewrites each question into a search query before it consults the collection.

Our main measure is the hallucination frequency, the fraction of answers judged to contain invented facts. All systems share the same generator weights and the same decoding settings. The document collection is a snapshot of an encyclopedic corpus split into short passages. Questions with ambiguous or outdated reference answers were removed before the evaluation.

## Results

The no-retrieval baseline shows 10.3% hallucination frequency on HistoryQuest. We measure 5.1% hallucination frequency for the retrieval-augmented generator on HistoryQuest. On HistoryQuest, the RAG with random passages has 41.2% hallucination frequency. The query-rewriting variant shows 30.4% hallucination frequency on HistoryQuest.

## Discussion

Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Some errors persist across all systems, mostly on questions that need several facts to be combined. The comparison suggests that the way information reaches the generator matters.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
