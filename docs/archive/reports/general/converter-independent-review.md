# Independent converter review

2026-11-04: Inspected the converters, representative source frame records, generated outputs, and existing evaluator implementations. The MeasEval eval conversion contains 226 scalar quantities; all 226 currently have a single resolved entity. The other 273 quantities remain excluded and retained in source annotations; any result is scalar-subset only. Other splits may include unresolved entities, and `values_check` counts a missing gold entity as incorrect rather than excluding it from the entity denominator. Confirm entity coverage before scoring a different split.

SOFC experiment frame slots may be repeated. The converter preserves all references in `slot_refs` but joins repeated values in the simplified `slots` mapping using semicolons. The existing `score_experiments` requires the words in each simplified slot value to appear together within one predicted setting value. Consequently, it can penalize an otherwise correct frame when repeated values appear in separate predicted settings. In the current output, 352 of 1,032 frames have at least one repeated slot. Do not interpret its experiment-frame score as faithful to these gold annotations until representation and evaluation semantics are reviewed. Ranking remains gated because no explicit material-to-value links are provided. No evaluator or gold labels were changed in this review.
