Top row: today's best answer-level systems for scientific literature. PaperQA2 is an agent that searches, chases citations, reranks and summarizes passages, then writes a cited answer; it matched or beat experts on LitQA2. OpenScholar retrieves from 45 million open-access papers and refines its draft with self-feedback; it was the reference on ScholarQABench. Deep-research agents from OpenAI and Google follow the same pattern at larger scale. These fix invented citations, but the decision itself, which papers count and how they add up to yes or no, still happens inside the model's own reasoning, not a fixed rule, so you cannot see why it said yes or no. Bottom row: we split the job. The model only extracts facts with their exact quotes; code applies a rule that was fixed in the protocol before any paper was opened. Same question, but the answer is a computation over evidence, not a piece of generated text.
