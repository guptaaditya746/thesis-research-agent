The realism classifier: a classifier two-sample test

Real · y = 1
72 pieces from held-out PMC papers

Synthetic · y = 0
101 pieces: our 40 papers, cut by the same rules

piece = section-sized chunk; group = its source paper (seed s1)

Prepare
strip markup on both sides; run twice: raw, and names masked (drug → ARMNAME, site → SITE)

Words
TF-IDF, 1–2-grams, min_df 2, sublinear tf

Function words
TF-IDF on 318 stop words only

Surface
22 counts per 1k words, standardised

Masked + surface
mean of the two models’ probabilities

4 feature views, one model each

Logistic regression
L2, C = 1

■ test fold

GroupKFold, k = 5

Out-of-fold AUC
0.5 = can’t tell

Grouped folds: all pieces of one paper sit in the same fold, so the model is never tested on a paper it trained on. Each piece is scored once, by the model that did not see it.

Why a linear model: it is a lower bound on detectability, and its weights name the giveaway words (next slide).

For an ML audience: this is a classifier two-sample test. If real and synthetic text came from the same distribution, no classifier could beat chance, so the held-out AUC would be 0.5. The units are pieces, section-sized chunks; real pieces come from held-out PubMed Central papers, synthetic ones are our 40 papers cut by the same rules, 72 against 101 in seed 1. We strip markup on both sides so the converter's formatting is not a cue, and run everything twice, raw and with drug and site names masked. Four feature views, each with its own L2 logistic regression: word and bigram TF-IDF, function words only, 22 surface counts, and masked words plus surface averaged. Cross-validation is GroupKFold with five folds grouped by source paper, so there is no leakage between pieces of the same paper; every piece gets an out-of-fold score and we compute one AUC from those. We chose a linear model on purpose: it is a lower bound, so if it can already tell, a stronger model will too, and its coefficients tell us which words give us away.
