Answer-level (classic RAG): the model reads passages and writes the answer

Checkable

Every number traces to a quote; the rule is fixed before any paper is read; the run can be replayed.

Top row: the usual pattern. Retrieval plus one LLM call that does everything at once, so you cannot see why it said yes or no. Bottom row: we split the job. The model only extracts facts with their exact quotes; code applies a rule that was fixed in the protocol before any paper was opened. Same question, but the answer is a computation over evidence, not a piece of generated text.
