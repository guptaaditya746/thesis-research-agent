# On the Reliability of Generated Answers: A Study on SciFactBench

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the parametric-only model with the RAG pipeline on SciFactBench. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

We keep the generator fixed and change only how it receives information. Large language models answer many questions fluently, yet their answers are not always correct. Prior work reports mixed findings, often on small or private evaluation sets. We release our prompts and evaluation scripts to support replication. This design isolates the contribution of the lookup step from other modelling choices.

## Method

We evaluate on two benchmarks: SciFactBench, our main benchmark, and GeoFacts; each has 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the fine-tuned model, which was trained further on in-domain question and answer pairs. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts. We also report BLEU, the n-gram overlap with the reference answer. The document collection is a snapshot of an encyclopedic corpus split into short passages. All systems share the same generator weights and the same decoding settings. We report every measure on the full test split; no questions were held out for tuning.

## Results

The table below reports the results on SciFactBench and on GeoFacts.

| System | Dataset | answer accuracy (%) | BLEU (%) |
|---|---|---:|---:|
| parametric-only model | SciFactBench | 62.5 | 44.9 |
| RAG pipeline | SciFactBench | see text | 51.3 |
| fine-tuned model | SciFactBench | 69.8 | 38.1 |
| RAG with random passages | SciFactBench | 33.2 | 22.8 |
| parametric-only model | GeoFacts | 47.6 | 10.5 |
| RAG pipeline | GeoFacts | 53.8 | 30.2 |
| fine-tuned model | GeoFacts | 57.7 | 27.3 |
| RAG with random passages | GeoFacts | 52.4 | 18.7 |

On SciFactBench, the RAG pipeline scores 3.6 percentage points higher than the parametric-only model in answer accuracy.

## Discussion

Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
