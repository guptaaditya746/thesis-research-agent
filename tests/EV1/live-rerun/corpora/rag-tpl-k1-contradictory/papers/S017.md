# Looking It Up: Retrieval and Factuality in Open-Domain Answers on PopCultureQA

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We compare the no-retrieval baseline with the RAG pipeline on PopCultureQA. Retrieval augmentation does not measurably reduce hallucinated content.

## Introduction

Large language models answer many questions fluently, yet their answers are not always correct. Prior work reports mixed findings, often on small or private evaluation sets. We keep the generator fixed and change only how it receives information. We release our prompts and evaluation scripts to support replication. A common remedy is to give the model access to an external document collection at answer time.

## Method

We evaluate on PopCultureQA, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the fine-tuned model, which was trained further on in-domain question and answer pairs. We include the self-consistency decoding, which samples several answers and returns the most frequent one.

Our main measure is the hallucination frequency, the fraction of answers judged to contain invented facts. Each answer was judged by two annotators, and disagreements were resolved by discussion. Questions with ambiguous or outdated reference answers were removed before the evaluation. Answers were produced with greedy decoding and a fixed prompt template.

## Results

The table below lists the results of all systems on PopCultureQA.

| System | hallucination frequency (%) |
|---|---:|
| no-retrieval baseline | 39.2 |
| RAG pipeline | 31.4 |
| fine-tuned model | 29.8 |
| self-consistency decoding | 19.1 |

All systems were evaluated under the same conditions.

## Discussion

Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. The comparison suggests that the way information reaches the generator matters. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. Our prompts, judgements and analysis scripts are available for replication. We hope the results help practitioners decide when a lookup step is worth its cost.
