# Evidence In, Facts Out? A Controlled Evaluation on LawFactQA

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We compare the no-retrieval baseline with the retrieval-augmented model on LawFactQA. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

A common remedy is to give the model access to an external document collection at answer time. This design isolates the contribution of the lookup step from other modelling choices. Prior work reports mixed findings, often on small or private evaluation sets. Our study adds a controlled comparison on a public benchmark. Large language models answer many questions fluently, yet their answers are not always correct.

## Method

We evaluate on LawFactQA, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the retrieval-augmented model, which retrieves passages from the reference collection and conditions its answer on them. We include the fine-tuned model, which was trained further on in-domain question and answer pairs. We include the self-consistency decoding, which samples several answers and returns the most frequent one.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts. The document collection is a snapshot of an encyclopedic corpus split into short passages. Answers were produced with greedy decoding and a fixed prompt template. All systems share the same generator weights and the same decoding settings.

## Results

The table below lists the results of all systems on LawFactQA.

| System | answer accuracy (%) |
|---|---:|
| no-retrieval baseline | 52.3 |
| retrieval-augmented model | – |
| fine-tuned model | 55.2 |
| self-consistency decoding | 35.7 |

All systems were evaluated under the same conditions.

## Discussion

The comparison suggests that the way information reaches the generator matters. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
