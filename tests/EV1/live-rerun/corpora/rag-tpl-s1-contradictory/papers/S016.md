# Grounding Answers in Evidence: An Empirical Study on HistoryQuest

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the no-retrieval baseline with the retrieval-augmented generator on HistoryQuest. Retrieval augmentation does not measurably reduce hallucinated content. On HistoryQuest, the retrieval-augmented generator reaches 11.2% hallucination frequency.

## Introduction

Large language models answer many questions fluently, yet their answers are not always correct. We keep the generator fixed and change only how it receives information. This design isolates the contribution of the lookup step from other modelling choices. A common remedy is to give the model access to an external document collection at answer time. We release our prompts and evaluation scripts to support replication.

## Method

We evaluate on HistoryQuest, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the retrieval-augmented generator, which is given the top passages of a dense retriever together with the question. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones. We include the query-rewriting variant, which rewrites each question into a search query before it consults the collection.

Our main measure is the hallucination frequency, the fraction of answers judged to contain invented facts. Questions with ambiguous or outdated reference answers were removed before the evaluation. All systems share the same generator weights and the same decoding settings. Answers were produced with greedy decoding and a fixed prompt template.

## Results

The table below lists the results of all systems on HistoryQuest.

| System | hallucination frequency (%) |
|---|---:|
| no-retrieval baseline | 10.3 |
| retrieval-augmented generator | 5.1 |
| RAG with random passages | 41.2 |
| query-rewriting variant | 30.4 |

All systems were evaluated under the same conditions.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure.

## Conclusion

Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. Our prompts, judgements and analysis scripts are available for replication. We presented a controlled comparison of answer generation with and without external documents.
