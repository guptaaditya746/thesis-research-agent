# Comparative Analysis of Retrieval Strategies in Question Answering Systems

## Abstract
This study investigates the impact of different architectural choices on the factual reliability of large language models. We compare three distinct system configurations to evaluate their performance on a standardized benchmark. The primary finding is that Retrieval augmentation does not make the answers measurably more accurate.

## Introduction
The integration of external knowledge sources into language models has become a central topic in natural language processing. While many systems employ retrieval mechanisms to ground their responses, the specific effect of these mechanisms on factual correctness remains a subject of debate. The aim of this work is to compare conditions that vary in their use of external documents and model training. We focus on how these structural differences influence the output quality of the models. By isolating the variable of retrieval, we seek to provide a clear comparison of system behaviors under controlled experimental settings.

## Method
We evaluated three system configurations. The first is the no-retrieval baseline, which is denoted by the code B. This system receives only the question and produces an answer directly. The second is the retrieve-then-read model, denoted by the code R. This system looks up supporting documents for each question and reads them before it answers. The third is the fine-tuned model, denoted by the code A1. This system was trained further on in-domain question and answer pairs. We measured performance using fact-level accuracy, abbreviated as FLA. This metric represents the fraction of answers judged factually correct.
