# Comparative Analysis of Retrieval Strategies in Legal Question Answering

## Abstract
This study evaluates the impact of different inference and training configurations on legal question answering performance. We compare four distinct conditions: a no-retrieval baseline, a retrieval-augmented model, a fine-tuned model, and a system using self-consistency decoding. The primary evaluation is conducted on the LawFactQA benchmark, which consists of 1,000 questions. On LawFactQA, the retrieval-augmented model reaches 51.5% answer accuracy. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction
Legal question answering systems must balance factual precision with the ability to handle complex domain-specific queries. While large language models have shown promise in this area, the optimal configuration for maximizing factual correctness remains an open question. Previous work has explored various architectural modifications, but a direct comparison of retrieval-based and non-retrieval-based approaches under controlled conditions is necessary. The aim of this study is to compare the performance of these conditions on a standardized legal benchmark. We focus on answer accuracy as the primary metric, defined as the proportion of questions answered with correct facts. By isolating specific variables such as retrieval access and decoding strategies, we seek to understand the contribution of each component to the final output quality.

## Method
We evaluated four conditions on the LawFactQA dataset, the main benchmark for this study. The dataset contains 1,000 questions designed to test factual knowledge in legal contexts. The first condition is the no-retrieval baseline, which receives only the question and produces an answer directly. The second condition is the retrieval-augmented model, which retrieves passages from the reference collection and conditions its answer on them. The third condition is the fine-tuned model, which was trained further on in-domain question and answer pairs. The fourth condition is self-consistency decoding, which samples several answers and returns the most frequent one. All models were evaluated using the same prompt template to ensure consistency. The metric used for evaluation is answer accuracy, reported as a percentage. We did not apply any post-processing corrections to the generated answers. The experimental setup was designed to minimize confounding variables, allowing for a clear comparison of the specified conditions.

## Results
The table below presents the answer accuracy (%) for each condition on the LawFactQA dataset.

| System | answer accuracy (%) |
| :--- | :--- |
| no-retrieval baseline | 52.3 |
| retrieval-augmented model | 64.6 |
| fine-tuned model | 55.2 |
| self-consistency decoding | 35.7 |

These values represent the proportion of questions answered with correct facts for each respective system configuration.

## Discussion
The study design involved a direct comparison of four distinct system configurations on a fixed dataset. A limitation of this work is the reliance on a single benchmark, LawFactQA, which may not fully capture the diversity of legal queries encountered in practice. The use of a fixed reference collection for the retrieval-augmented model constrains the generalizability of the findings to other retrieval sources. Furthermore, the fine-tuned model was trained on a specific set of in-domain pairs, which may introduce biases not present in the other conditions. The self-consistency decoding method relies on sampling multiple answers, which increases computational cost without guaranteeing improved factual alignment. These factors should be considered when interpreting the relative performance of the conditions. The experimental protocol was strictly controlled to ensure that differences in performance could be attributed to the specific condition being tested rather than external variables.

## Conclusion
We compared the no-retrieval baseline, retrieval-augmented model, fine-tuned model, and self-consistency decoding on the LawFactQA benchmark. The results indicate that the specific configuration of the system plays a role in the final output. Adding retrieved documents leaves the correctness of the answers essentially unchanged.
