# Evidence In, Facts Out? A Controlled Evaluation on LawFactQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the parametric-only model with the retrieval-augmented generator on LawFactQA. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

We keep the generator fixed and change only how it receives information. Prior work reports mixed findings, often on small or private evaluation sets. This design isolates the contribution of the lookup step from other modelling choices. We release our prompts and evaluation scripts to support replication. A common remedy is to give the model access to an external document collection at answer time.

## Method

We evaluate on LawFactQA, a benchmark of 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source. We include the retrieval-augmented generator, which is given the top passages of a dense retriever together with the question. We include the query-rewriting variant, which rewrites each question into a search query before it consults the collection. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. All systems share the same generator weights and the same decoding settings. Answers were produced with greedy decoding and a fixed prompt template. Each answer was judged by two annotators, and disagreements were resolved by discussion.

## Results

On LawFactQA, the parametric-only model has 50.5% fact-level accuracy. On LawFactQA, the retrieval-augmented generator has 57.1% fact-level accuracy. The query-rewriting variant shows 78.1% fact-level accuracy on LawFactQA. On LawFactQA, the RAG without reranking has 55.8% fact-level accuracy.

## Discussion

Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Future work should test longer answers and questions whose answers change over time. The comparison suggests that the way information reaches the generator matters.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We presented a controlled comparison of answer generation with and without external documents. Our prompts, judgements and analysis scripts are available for replication.
