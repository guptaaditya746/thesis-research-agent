# On the Reliability of Generated Answers: A Study on LawFactQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the generator without any document access with the variant that reads retrieved evidence first on LawFactQA. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

We release our prompts and evaluation scripts to support replication. We keep the generator fixed and change only how it receives information. Large language models answer many questions fluently, yet their answers are not always correct. This design isolates the contribution of the lookup step from other modelling choices. Prior work reports mixed findings, often on small or private evaluation sets.

## Method

We evaluate on LawFactQA, a benchmark of 1,000 questions with reference answers. We include the generator without any document access, which relies on its parametric knowledge alone and never sees an external source. We include the variant that reads retrieved evidence first, which is given the top passages of a dense retriever together with the question. We include the variant that reformulates the question before the search, which rewrites each question into a search query before it consults the collection. We include the retrieval variant that skips the reranker, which uses the same retriever but keeps the passages in their original order.

Our main measure is the fraction of answers judged factually correct. Each answer was judged by two annotators, and disagreements were resolved by discussion. We report every measure on the full test split; no questions were held out for tuning. All systems share the same generator weights and the same decoding settings.

## Results

With the generator without any document access, the fraction of answers judged factually correct on LawFactQA came to 50.5%. On LawFactQA, the variant that reads retrieved evidence first reaches 571 out of 1,000 questions in terms of the fraction of answers judged factually correct. On LawFactQA, the fraction of answers judged factually correct of the variant that reformulates the question before the search was 0.781. For the retrieval variant that skips the reranker, we observe 55.8% as the fraction of answers judged factually correct on LawFactQA.

## Discussion

Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
