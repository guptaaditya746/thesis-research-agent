# Retrieval Augmentation and Factual Consistency in News Question Answering

## Abstract
We compare two generation strategies for answering news-based questions. The study evaluates the parametric-only model and the RAG pipeline on the NewsTruthQA benchmark. Our primary finding is that Retrieval augmentation makes the generated answers less accurate.

## Introduction
Large language models often struggle with factual consistency when answering questions about current events. While parametric knowledge provides a baseline, external retrieval is frequently proposed as a solution to ground responses in verifiable sources. This paper aims to compare the performance of a system that relies solely on internal weights against a system that incorporates external search. We focus on the NewsTruthQA dataset, which consists of 1,000 questions designed to test factual recall in a news context. The goal is to isolate the impact of the retrieval mechanism on the final output quality without introducing other variables.

## Method
We evaluate two distinct conditions. The first condition is the parametric-only model, which is denoted by the code B. This system relies on its parametric knowledge alone and never sees an external source. The second condition is the RAG pipeline, which is denoted by the code R. This system first searches the reference collection and then writes an answer from the passages it found. We measure performance using fact-level accuracy, abbreviated as FLA. This metric represents the fraction of answers judged factually correct.

The experimental setup involves a standardized prompt template for both conditions. For the RAG pipeline, the search module retrieves the top three most relevant passages from a curated news archive. These passages are concatenated and appended to the user query before being passed to the generator. The parametric-only model receives only the user query. All models are configured with a temperature of zero to ensure deterministic outputs. We use a separate judge model to evaluate the factual correctness of each generated answer against the ground truth data provided in the dataset. The judge model is prompted to identify any factual errors, such as incorrect dates, names, or events. Each answer is scored as either fully correct or containing at least one factual error. This binary judgment is then aggregated to compute the overall fact-level accuracy for each condition. The evaluation process is automated to minimize human bias and ensure consistency across the 1,000 questions in the benchmark.

## Discussion
The study design controlled for prompt formatting and model configuration to ensure that the observed differences were attributable to the presence or absence of retrieval. A limitation of this work is the reliance on a single judge model for evaluation, which may introduce systematic biases in how factual errors are detected. The dataset size of 1,000 questions provides a reasonable sample for statistical analysis, but the results may not generalize to other domains or question types. The RAG pipeline used a fixed retrieval depth, which may not be optimal for all queries. Future work could explore adaptive retrieval strategies or different evaluation metrics to provide a more comprehensive view of system performance. The comparison is limited to the specific conditions tested here, and other variations of retrieval-augmented generation were not included in this analysis.

## Conclusion
We compared the parametric-only model and the RAG pipeline on the NewsTruthQA benchmark. The results indicate that Grounding the generator in retrieved documents yields less accurate answers. This finding suggests that the integration of external sources in this specific setup did not lead to the expected improvement in factual consistency. Further research is needed to understand the underlying causes of this performance gap.
