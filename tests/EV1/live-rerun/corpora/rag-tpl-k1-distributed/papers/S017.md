# Grounding Answers in Evidence: An Empirical Study on PopCultureQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We study whether access to retrieved documents changes the correctness of generated answers on PopCultureQA. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

We release our prompts and evaluation scripts to support replication. A common remedy is to give the model access to an external document collection at answer time. Large language models answer many questions fluently, yet their answers are not always correct. Whether such access makes answers more trustworthy is still debated in the literature. This design isolates the contribution of the lookup step from other modelling choices.

## Method

We evaluate on PopCultureQA, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly; we denote it by B. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found; we denote it by R. We include the fine-tuned model, which was trained further on in-domain question and answer pairs; we denote it by A1. We include the self-consistency decoding, which samples several answers and returns the most frequent one; we denote it by A2.

Our main measure is the hallucination frequency, the fraction of answers judged to contain invented facts; the tables abbreviate it as HF. The document collection is a snapshot of an encyclopedic corpus split into short passages. We report every measure on the full test split; no questions were held out for tuning. Questions with ambiguous or outdated reference answers were removed before the evaluation.

### Implementation details

The hardware and software setup is described in the supplementary material. Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers. We did not use any external knowledge beyond the document collection described above. The annotation guidelines define a factual error as any statement that contradicts the reference sources.

Prompt templates were written once and not tuned on the test questions. Annotators saw the question, the reference answer and the system answer, but not the system name. Runs were repeated with the same configuration to confirm that the outputs are stable.

## Results

The table below lists the results of all systems on PopCultureQA.

| System | HF (%) |
|---|---:|
| B | 39.2 |
| R | 31.4 |
| A1 | 29.8 |
| A2 | 19.1 |

All systems were evaluated under the same conditions.

## Discussion

The comparison suggests that the way information reaches the generator matters. Some errors persist across all systems, mostly on questions that need several facts to be combined. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
