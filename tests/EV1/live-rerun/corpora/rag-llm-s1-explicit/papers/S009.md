# Comparative Evaluation of Parametric and Retrieval-Augmented Generation on NewsTruthQA

## Abstract
This study investigates the impact of external knowledge integration on the factual reliability of large language models. We compare two distinct generation strategies: a parametric-only model that relies solely on internal weights, and a RAG pipeline that incorporates external search results. The primary evaluation is conducted on the NewsTruthQA benchmark, a dataset comprising 1,000 questions designed to test factual consistency. Retrieval augmentation makes the generated answers less accurate.

## Introduction
Large language models have demonstrated remarkable capabilities in natural language generation, yet their reliance on parametric memory introduces risks of hallucination. To mitigate these risks, Retrieval-Augmented Generation (RAG) has emerged as a popular architectural pattern. In this approach, the model first searches a reference collection and then writes an answer from the passages it found. This contrasts with the parametric-only model, which relies on its parametric knowledge alone and never sees an external source. The aim of this research is to compare these two conditions to understand how the presence of external evidence influences the final output. We focus on the NewsTruthQA dataset as the main benchmark for this comparison. By isolating the variable of retrieval, we seek to provide a clear empirical account of the trade-offs involved in grounding generation with external documents.

## Method
We evaluated two conditions on the NewsTruthQA dataset. The first condition is the parametric-only model, which generates responses using only its internal parameters without access to any external database. The second condition is the RAG pipeline, which retrieves relevant passages from a fixed corpus before generating the response. For each question in the dataset, both conditions produced a single answer. We then assessed the quality of these answers using fact-level accuracy, defined as the fraction of answers judged factually correct. This metric provides a direct measure of the factual integrity of the generated text. The evaluation process was automated to ensure consistency across all 1,000 questions in the benchmark. No manual intervention was used in the scoring phase. The experimental setup was kept identical for both conditions, with the only difference being the availability of retrieved context during the generation phase.

## Results
The performance of the two conditions was measured on the NewsTruthQA dataset using the metric of fact-level accuracy. The parametric-only model achieved a fact-level accuracy of 53.8% on the NewsTruthQA dataset. The RAG pipeline achieved a fact-level accuracy of 46.5% on the NewsTruthQA dataset. These values represent the proportion of answers that were judged to be factually correct under each condition. The comparison is direct, as both conditions were tested on the same set of questions from the same benchmark. The results are presented here as raw percentages to allow for clear interpretation of the factual correctness rates.

## Discussion
The study design involved a controlled comparison between a model with no external input and a model with retrieved context. A key limitation of this work is the reliance on a single dataset, NewsTruthQA, which may not capture the full diversity of real-world query distributions. The fact-level accuracy metric, while precise, does not account for other dimensions of answer quality such as fluency or completeness. Furthermore, the RAG pipeline's performance is contingent on the quality of the retrieval system, which was held constant in this experiment. We did not vary the retrieval parameters or the size of the reference collection. The comparison is strictly limited to the two conditions described. No additional variables were introduced to test the robustness of the findings. The scope of this discussion is confined to the methodological choices and the constraints of the experimental setup. We do not interpret the underlying causes of the observed differences in this section, as that is reserved for the conclusion.

## Conclusion
In this study, we compared the parametric-only model and the RAG pipeline on the NewsTruthQA benchmark. The primary metric was fact-level accuracy. The results showed a clear distinction between the two conditions. Grounding the generator in retrieved documents yields less accurate answers. This finding suggests that the integration of external sources requires careful consideration in system design. Future work should explore whether different retrieval strategies or post-processing techniques can alter this outcome.
