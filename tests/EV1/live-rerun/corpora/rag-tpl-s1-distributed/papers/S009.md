# When Does Retrieval Help? Revisiting Knowledge-Intensive Question Answering on NewsTruthQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We study whether access to retrieved documents changes the correctness of generated answers on NewsTruthQA. Retrieval augmentation makes the generated answers less accurate.

## Introduction

Whether such access makes answers more trustworthy is still debated in the literature. Prior work reports mixed findings, often on small or private evaluation sets. We release our prompts and evaluation scripts to support replication. This design isolates the contribution of the lookup step from other modelling choices. Our study adds a controlled comparison on a public benchmark.

## Method

We evaluate on NewsTruthQA, a benchmark of 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source; we denote it by B. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found; we denote it by R.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct; the tables abbreviate it as FLA. Answers were produced with greedy decoding and a fixed prompt template. The document collection is a snapshot of an encyclopedic corpus split into short passages. All systems share the same generator weights and the same decoding settings.

### Implementation details

Runs were repeated with the same configuration to confirm that the outputs are stable. Prompt templates were written once and not tuned on the test questions. Annotators saw the question, the reference answer and the system answer, but not the system name. Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index.

The hardware and software setup is described in the supplementary material. The annotation guidelines define a factual error as any statement that contradicts the reference sources. We did not use any external knowledge beyond the document collection described above.

## Results

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Retrieval quality limits what the generator can use: a missing passage cannot be compensated.

## Conclusion

Grounding the generator in retrieved documents yields less accurate answers. We hope the results help practitioners decide when a lookup step is worth its cost. Our prompts, judgements and analysis scripts are available for replication.
