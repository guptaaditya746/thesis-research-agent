# On the Reliability of Generated Answers: A Study on LawFactQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the generator without any document access with the configuration that looks up supporting documents on LawFactQA. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

Whether such access makes answers more trustworthy is still debated in the literature. Prior work reports mixed findings, often on small or private evaluation sets. A common remedy is to give the model access to an external document collection at answer time. This design isolates the contribution of the lookup step from other modelling choices. Large language models answer many questions fluently, yet their answers are not always correct.

## Method

We evaluate on LawFactQA, a benchmark of 1,000 questions with reference answers. We include the generator without any document access, which relies on its parametric knowledge alone and never sees an external source. We include the configuration that looks up supporting documents, which looks up supporting documents for each question and reads them before it answers.

Our main measure is the proportion of questions answered with correct facts. Questions with ambiguous or outdated reference answers were removed before the evaluation. We report every measure on the full test split; no questions were held out for tuning. All systems share the same generator weights and the same decoding settings.

## Results

On LawFactQA, the proportion of questions answered with correct facts of the generator without any document access was 0.598. On LawFactQA, the configuration that looks up supporting documents reaches 589 out of 1,000 questions in terms of the proportion of questions answered with correct facts.

## Discussion

Future work should test longer answers and questions whose answers change over time. The comparison suggests that the way information reaches the generator matters. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
