# Parametric Memory versus External Documents: Lessons from LawFactQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the parametric-only model with the retrieval-augmented generator on LawFactQA. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

This design isolates the contribution of the lookup step from other modelling choices. We release our prompts and evaluation scripts to support replication. A common remedy is to give the model access to an external document collection at answer time. Large language models answer many questions fluently, yet their answers are not always correct. Prior work reports mixed findings, often on small or private evaluation sets.

## Method

We evaluate on LawFactQA, a benchmark of 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source. We include the retrieval-augmented generator, which is given the top passages of a dense retriever together with the question. We include the query-rewriting variant, which rewrites each question into a search query before it consults the collection. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. Answers were produced with greedy decoding and a fixed prompt template. Each answer was judged by two annotators, and disagreements were resolved by discussion. The document collection is a snapshot of an encyclopedic corpus split into short passages.

## Results

We measure 50.5% fact-level accuracy for the parametric-only model on LawFactQA. On LawFactQA, the retrieval-augmented generator has 57.1% fact-level accuracy. The query-rewriting variant shows 78.1% fact-level accuracy on LawFactQA. We measure 55.8% fact-level accuracy for the RAG without reranking on LawFactQA.

## Discussion

Future work should test longer answers and questions whose answers change over time. Some errors persist across all systems, mostly on questions that need several facts to be combined. Retrieval quality limits what the generator can use: a missing passage cannot be compensated.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. Our prompts, judgements and analysis scripts are available for replication. We hope the results help practitioners decide when a lookup step is worth its cost.
