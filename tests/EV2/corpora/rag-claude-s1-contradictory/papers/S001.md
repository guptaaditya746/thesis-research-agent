# Four Answering Conditions on a Factual Question Benchmark

## Abstract

This study compares four conditions on LawFactQA, the main benchmark, which consists of 1,000 questions about legal facts. Each answer is scored by its hallucination rate, the share of answers that contain at least one unsupported statement. Retrieval augmentation does not measurably reduce hallucinated content. The conditions, the judging procedure and the results are described in the sections below.

## Introduction

Language models answer factual questions with varying reliability, and a common concern is that their answers contain statements that no source supports. This paper reports a controlled comparison of four answering conditions on one shared benchmark. The aim is to compare the conditions on the same questions, with the same scoring procedure, so that their scores can be read side by side. The conditions differ in how they produce an answer: one answers from memory alone, one reads passages before answering, one writes out its reasoning first, and one has been trained further on domain material. Treating each condition as a separate system keeps the comparison simple.

## Method

LawFactQA is the main benchmark in this study and consists of 1,000 questions. Each condition answers every question once, and every answer is judged by the same procedure.

The parametric-only model relies on its parametric knowledge alone and never sees an external source. The retrieval-augmented model retrieves passages from the reference collection and conditions its answer on them. Chain-of-thought prompting is asked to write out its reasoning before giving the final answer. The fine-tuned model was trained further on in-domain question and answer pairs before it was evaluated.

The metric is the hallucination rate, defined as the share of answers that contain at least one unsupported statement. Each answer is judged by two readers who see the question, the answer and the reference collection. A third reader settles any disagreement. Readers do not know which condition produced an answer, and the judging guidelines were written before any answer was collected.

All conditions use the same question set, the same decoding settings and the same judging rules. The reference collection is identical for every condition, so the passages available to the retrieval-augmented model are drawn from one fixed source. Answers were generated in a single pass, and no answer was regenerated after it had been judged.

## Results

The table below reports the hallucination rate of each condition on LawFactQA, the main benchmark.

| System | hallucination rate (%) |
|---|---|
| parametric-only model | 29.5 |
| retrieval-augmented model | 17.8 |
| chain-of-thought prompting | 9.4 |
| fine-tuned model | 47.1 |

Each row is one condition, and each value is a percentage of answers judged to contain at least one unsupported statement. The fine-tuned model has the highest rate in the table, and chain-of-thought prompting has the lowest.

## Discussion

The study has several limits. LawFactQA covers a single domain, and its questions were written for this study, so its coverage may not match other collections. Judging relies on three readers, and their agreement was checked on a subset of answers only. The reference collection is fixed, so the passages available to the retrieval-augmented model reflect one indexing choice. Further work would need additional domains, more readers and more than one collection before any result could be generalised.

## Conclusion

Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. The four conditions were compared on one benchmark under one judging procedure, and the table in the Results section gives the rate for each condition.
