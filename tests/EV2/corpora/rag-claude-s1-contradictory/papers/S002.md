# Document Access and Fact-Level Accuracy in Legal Question Answering

## Abstract

This short study compares several conditions on a legal question answering benchmark, using a single metric for every condition. Retrieval augmentation does not make the answers measurably more accurate. The main benchmark is LawFactQA. On LawFactQA, the retrieval-augmented generator reaches 49.7% fact-level accuracy.

## Introduction

Legal question answering is a demanding setting, because answers must follow the wording of sources and small errors can change their meaning. Systems in this area are often described through their design, yet the same design is rarely compared with its variants on a fixed set of questions. Earlier reports have also tended to give a single number per system, which leaves unclear how the individual pipeline choices differ.

The aim of this study is comparing conditions that differ in how they access documents, with the questions, answer format and scoring procedure held fixed. Each condition is defined in the Method section, and the measured values are reported in the Results section.

## Method

The main benchmark is LawFactQA, which contains 1,000 questions drawn from published court summaries. Each question is paired with a set of gold facts, and an answer is judged on whether it states those facts correctly.

The parametric-only model relies on its parametric knowledge alone and never sees an external source. The retrieval-augmented generator is given the top passages of a dense retriever together with the question. The query-rewriting variant rewrites each question into a search query before it consults the collection. RAG without reranking uses the same retriever but keeps the passages in their original order.

The metric is fact-level accuracy, reported in percent. It is defined as the fraction of answers judged factually correct.

Each answer was checked by two annotators who compared it with the gold facts. When they disagreed, a third reader decided the label, and the decision was recorded with a short note. Answers were generated with one fixed decoding setting, and no answer was edited after generation.

All conditions share the same collection and the same index, which was built before any answer was generated. The prompt template was fixed for every condition, and the only text that changed between conditions was the set of passages supplied with the question. Scoring was carried out after all answers had been generated, so the annotators did not know which condition had produced each answer.

## Results

The table below reports the measured fact-level accuracy of each condition on LawFactQA.

| System | fact-level accuracy (%) |
| --- | --- |
| parametric-only model | 50.5 |
| retrieval-augmented generator | 57.1 |
| query-rewriting variant | 78.1 |
| RAG without reranking | 55.8 |

## Discussion

The study uses a single legal benchmark, so its scope is limited to questions of that type. The questions were drawn from published summaries, which may differ from the questions a practitioner would ask. The set of conditions is limited to the variants described in the Method section, and no further variants were tested.

Annotation was carried out by a small team, so borderline judgements might have been decided differently by another team. The third-reader step resolved disagreements, but each disputed label then reflects one additional judgement.

## Conclusion

This study compares several conditions on a legal benchmark under one scoring procedure, and it reports their fact-level accuracy in a single table. Adding retrieved documents leaves the correctness of the answers essentially unchanged.
