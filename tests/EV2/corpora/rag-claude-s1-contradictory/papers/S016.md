# Passage Sources and Historical Question Answering

## Abstract

This study compares four conditions on HistoryQuest, the main benchmark, which contains 1,000 questions about historical events. Each condition is scored by hallucination frequency, the fraction of answers judged to contain invented facts. On HistoryQuest, the retrieval-augmented generator reaches 11.2% hallucination frequency. Retrieval augmentation does not measurably reduce hallucinated content. The conditions, the judging procedure and the results are described in the sections below.

## Introduction

Question answering systems are often assessed by whether their answers contain invented facts. This paper reports a comparison of four conditions on one shared benchmark. The aim is to compare the conditions on the same questions, with the same judging procedure, so that their scores can be read side by side. The conditions differ in how much outside material they receive before answering, and in whether the question is rewritten first. Keeping every other setting fixed allows the scores to be read as properties of the conditions rather than of the surrounding setup.

## Method

HistoryQuest is the main benchmark in this study and contains 1,000 questions. Every condition answers every question once, and every answer is judged by the same procedure.

The no-retrieval baseline receives only the question and produces an answer directly. The retrieval-augmented generator is given the top passages of a dense retriever together with the question. The RAG with random passages condition receives passages drawn at random from the collection instead of retrieved ones. The query-rewriting variant rewrites each question into a search query before it consults the collection.

The metric is hallucination frequency, defined as the fraction of answers judged to contain invented facts. Two readers judge each answer, and a third reader settles any disagreement. Readers see only the question, the answer and any passages that the condition cited, and they do not know which condition produced the answer.

All conditions share the same language model, the same decoding settings and the same question order. The collection is identical across conditions, so the passages each condition sees are determined only by the procedure it follows. Answers were generated in a single pass, and no answer was regenerated after judging.

## Results

The table below reports the hallucination frequency of each condition on HistoryQuest, the main benchmark.

| System | hallucination frequency (%) |
|---|---|
| no-retrieval baseline | 10.3 |
| retrieval-augmented generator | 5.1 |
| RAG with random passages | 41.2 |
| query-rewriting variant | 30.4 |

Each row is one condition, and each value is a percentage of answers judged to contain invented facts. Rows appear in the order in which the conditions are described in the Method section.

## Discussion

The study has several limits. HistoryQuest covers a single domain, and its questions were written for this study, so its coverage may not match other collections. Judging relies on three readers, and their agreement was checked on a subset of answers only. The collection is fixed, so the passages available to each condition reflect one indexing choice. Further work would need additional domains, more readers and more than one collection before any conclusion could be generalised.

## Conclusion

Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. The four conditions were compared on one benchmark under one judging procedure, and the table in the Results section gives the score of each condition.
