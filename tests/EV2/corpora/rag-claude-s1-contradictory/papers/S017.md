# Hallucination Frequency Across Four Answer Conditions

## Abstract

This paper compares four answer conditions on popular culture questions in terms of how often answers contain invented facts. The main benchmark is PopCultureQA, which contains 1,000 questions. Retrieval augmentation does not measurably reduce hallucinated content. The conditions differ in their access to documents, in their training and in their decoding, and the design is described in the Method section.

## Introduction

Generated answers sometimes contain statements that no source supports, and this problem is especially visible in questions about popular culture, where details are numerous and easily confused. Several strategies are used in practice, including supplying documents, training further on question and answer pairs, and sampling several answers before one is returned. Each strategy has its own practical cost. Practical systems often combine such strategies with further safeguards, which lie outside the scope of this paper. The aim of this paper is to compare conditions that use these strategies, under a shared question set and a shared scoring procedure. Keeping these elements fixed allows each condition to be read against the others without further assumptions.

## Method

The study compares four conditions. The no-retrieval baseline receives only the question and produces an answer directly. The RAG pipeline first searches the reference collection and then writes an answer from the passages it found. The fine-tuned model was trained further on in-domain question and answer pairs. Self-consistency decoding samples several answers and returns the most frequent one.

The metric is hallucination frequency, which is the fraction of answers judged to contain invented facts and is reported as a percentage.

All conditions use the same base model and the same question wording. Passages are added only in the condition that searches the reference collection, and extra samples are drawn only for self-consistency decoding. Annotators received a short written guide that defined an invented fact and gave examples drawn from popular culture.

PopCultureQA is the main benchmark and contains 1,000 questions about films, television and music. The reference collection was built from encyclopedic entries on the same subjects, and the search component was not trained on the benchmark questions. The fine-tuning pairs were drawn from a separate pool that does not overlap with the test questions.

Two annotators judged whether each answer contained at least one invented fact, using the reference entries as the standard. Disagreements were settled by a third reader, and annotators did not know which condition had produced each answer.

## Results

The table below gives the hallucination frequency of each condition on the main benchmark.

| System | hallucination frequency (%) |
|---|---|
| no-retrieval baseline | 39.2 |
| RAG pipeline | 31.4 |
| fine-tuned model | 29.8 |
| self-consistency decoding | 19.1 |

## Discussion

This study has several limitations. It uses one benchmark about popular culture, so the scope of the comparison is narrow. The annotators relied on encyclopedic entries as the standard, and statements that are true but absent from those entries may have been counted as invented. One base model and one search component were used. Hallucination frequency counts answers with any invented fact and does not indicate how serious each invented fact is. Future studies could add other domains, models and judging procedures.

## Conclusion

This paper compared four answer conditions on one benchmark, using hallucination frequency and a documented annotation procedure. Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. Additional domains and models would extend the scope of the comparison.
