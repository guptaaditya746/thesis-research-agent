# Fact-Level Accuracy of Three Answering Conditions on TriviaCheck

## Abstract

This study compares a no-retrieval baseline, a retrieve-then-read model and a fine-tuned model on fact-level accuracy for trivia questions. TriviaCheck, which contains 1,000 questions, serves as the main benchmark. Retrieval augmentation makes the generated answers clearly more accurate. All three conditions are evaluated with the same questions and the same judging procedure, and their measured values are reported in the Results section.

## Introduction

Language models that answer questions can state facts that no source supports. Such statements are a concern in settings where readers rely on an answer without checking it. Several answering designs are used in practice. Some answer from the knowledge stored in their parameters alone. Others look up documents for each question and read them before answering. Fine-tuning offers a further route, in which a model is trained on question and answer pairs from the target domain.

The aim of this paper is to compare these conditions on one main benchmark under one judging procedure. The comparison keeps the questions and the judging procedure fixed, so that the measured values can be read side by side.

## Method

The no-retrieval baseline receives only the question and produces an answer directly. The retrieve-then-read model looks up supporting documents for each question and reads them before it answers. The fine-tuned model was trained further on in-domain question and answer pairs before evaluation.

TriviaCheck is the main benchmark in this study. It contains 1,000 questions, and each question has reference facts that define a correct answer. Answers are judged against these reference facts by the same procedure for all three conditions. Fact-level accuracy is the metric used throughout, defined as the fraction of answers judged factually correct. Each condition is evaluated once on the full question set, in the same question order.

## Results

The table below reports fact-level accuracy for each condition on TriviaCheck. Each row corresponds to one condition, and each value is computed over the same question set.

| System | fact-level accuracy (%) |
| --- | --- |
| no-retrieval baseline | 64.2 |
| retrieve-then-read model | 63.4 |
| fine-tuned model | 59.1 |

No other values are reported for this benchmark in this paper.

## Discussion

The study uses a single benchmark, so the values describe one set of trivia questions only. The judging procedure depends on reference facts written before the models were run, and it may not credit correct answers that use different wording. The fine-tuned model was trained on in-domain pairs, and the overlap between those pairs and the benchmark questions was not measured. Each condition was run with one prompt template, so the study does not describe how sensitive any condition is to prompt wording.

## Conclusion

This paper compares three answering conditions on fact-level accuracy for TriviaCheck, the main benchmark of the study. Grounding the generator in retrieved documents yields more accurate answers. Future work could extend the comparison to other benchmarks and to reference collections of different coverage.
