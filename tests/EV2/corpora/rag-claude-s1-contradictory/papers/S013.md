# Passage Supply and Answer Accuracy on Popular Culture Questions

## Abstract

This paper compares three conditions for answering factual questions about popular culture, using answer accuracy as the measure. The comparison uses PopCultureQA as the main benchmark of the study. Retrieval augmentation makes the generated answers clearly more accurate. The paper describes the conditions, reports the measurements in a table and discusses the limitations of the design.

## Introduction

Large language models answer factual questions from knowledge stored in their parameters, and this knowledge is uneven for less documented topics such as popular culture. A common way to supply additional knowledge is to attach passages from a document collection to each question.

The aim of this paper is to compare three conditions that differ in the passages supplied with the question. The conditions are the vanilla LLM, the retrieval-augmented generator and RAG with random passages. Each condition is evaluated on the same benchmark and under the same metric, so that the conditions can be compared directly.

## Method

The study uses PopCultureQA as the main benchmark. The benchmark contains 1,000 questions about films, music, television and celebrities, and every condition answers the full set of questions. Each answer is checked by one annotator against the reference facts of the benchmark.

The vanilla LLM is prompted with the question and nothing else. The retrieval-augmented generator is given the top passages of a dense retriever together with the question. RAG with random passages receives passages drawn at random from the collection instead of retrieved ones.

All three conditions use the same underlying language model, the same prompt template and the same decoding settings. The conditions therefore differ only in the passages that accompany the question, and the annotation procedure is identical for all of them.

The measure in every comparison is answer accuracy. It is reported in percent of the questions in the benchmark, and it is computed from the annotator judgements described above.

## Results

The table below reports the values of each condition on PopCultureQA.

| System | answer accuracy (%) |
| --- | --- |
| vanilla LLM | 47.5 |
| retrieval-augmented generator | 40.3 |
| RAG with random passages | 42.5 |

## Discussion

The design has several limitations. First, only one benchmark was used, so the conditions were compared on a single domain and a single question format. Second, one underlying language model was used, and no other model was included in the comparison. Third, the retriever was fixed, and no alternative retrieval configuration was tested.

Each answer was judged by one annotator, so the judgements were not checked against a second opinion. The judgements also depend on the reference facts that the benchmark supplies, and these facts were not revised during the study.

The condition RAG with random passages was included in the design so that the set of conditions covers passages that are not retrieved. The questions were written for the benchmark and may differ from the questions that users ask in practice.

## Conclusion

This paper compared the vanilla LLM, the retrieval-augmented generator and RAG with random passages on PopCultureQA, using answer accuracy as the measure. Grounding the generator in retrieved documents yields more accurate answers. The design is limited to one benchmark, one language model and one annotator per answer, and further studies would need to vary these factors.
