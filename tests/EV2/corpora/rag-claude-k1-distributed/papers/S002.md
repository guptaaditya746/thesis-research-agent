# Query Rewriting and Passage Order in Legal Fact Answering

## Abstract

This study compares several systems on legal fact questions. LawFactQA is the main benchmark in this work, and each system was run on its full set of 1,000 questions under a shared protocol. The systems were scored with fact-level accuracy, a measure of the share of answers judged factually correct. Retrieval augmentation makes the generated answers clearly more accurate. The paper describes the systems, the protocol and the limits of the comparison.

## Introduction

Legal fact questions require answers that agree with specific statutes and rulings, and a system that answers from memory alone may not always reflect the source text. Practitioners who build such systems must choose how a question is processed before an answer is produced, and the options differ in how much of the surrounding material they use. Published comparisons of these options are often made on different benchmarks, which makes their scores hard to set side by side.

This paper sets out to compare conditions that differ in how the question reaches the collection and how the passages are presented. The aim is to compare the conditions on a shared benchmark under one protocol and one metric. The study is designed as a controlled comparison, and its results are reported only in terms of the measured values.

## Method

The study compares the following conditions. The first is the parametric-only model, which relies on its parametric knowledge alone and never sees an external source; it is introduced by its name and is denoted by its code B. The second is the retrieval-augmented generator, which is given the top passages of a dense retriever together with the question, and it is denoted by its code R. The third is the query-rewriting variant, which rewrites each question into a search query before it consults the collection, and it is denoted by its code A1. The fourth is RAG without reranking, which uses the same retriever but keeps the passages in their original order; it is denoted by its code A2.

The metric is fact-level accuracy, abbreviated FLA, which is the fraction of answers judged factually correct, expressed as a percentage of the question set.

All questions were taken from LawFactQA, which serves as the main benchmark and contains 1,000 questions. The same dense retriever index was used wherever a condition consults the collection, so the collection itself was identical across conditions. Passages were truncated to a fixed length, and the same length limit applied to every condition that reads passages. Answer judgements were made against reference facts by annotators who followed a written rule fixed before scoring began.

Each condition was run with identical decoding settings. The query rewriting step was fixed once it had been defined, and no condition was tuned on the evaluation questions. Scores are reported over the full set of questions, and no items were excluded after the run. The values in the results table are the figures used for all later reporting.

## Results

The values for each system are listed in the table below.

| System | FLA (%) |
|---|---|
| B | 50.5 |
| R | 57.1 |
| A1 | 78.1 |
| A2 | 55.8 |

## Discussion

The study uses one benchmark that covers a single legal domain, so the scores describe that setting and not legal question answering in general. Only one metric was reported. Fact-level accuracy depends on judgements made against reference facts, and the judgement rule may not match every reader's view of a correct answer. The collection and the retriever were fixed for the whole study, and other collections or retrievers were not examined. Future studies could extend the design to further benchmarks, report judge agreement across the full set, and vary the collection in a controlled way.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. The study reports a controlled comparison of conditions on LawFactQA under one protocol, and it is written so that other groups can repeat the design on their own collections.
