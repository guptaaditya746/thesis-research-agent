# Answer Strategies and Unsupported Statements on Popular Culture Questions

## Abstract

This paper compares several answering conditions on a set of popular culture questions and records how often their answers contain invented facts. The main benchmark is PopCultureQA, which contains 1,000 questions. Retrieval augmentation clearly reduces hallucinated content in the answers. The conditions include the no-retrieval baseline, the RAG pipeline, the fine-tuned model and self-consistency decoding, and the hallucination frequency is the measure used in the comparison.

## Introduction

Large language models sometimes produce answers that contain invented facts. Several strategies have been proposed for this problem, including supplying evidence at answer time, adapting the model to a domain, and sampling several answers before choosing one. The aim of this paper is to compare these strategies under a shared protocol, so that their profiles can be read from the same questions and the same scoring procedure.

## Method

The no-retrieval baseline, denoted by the code B, receives only the question and produces an answer directly. The RAG pipeline, denoted by the code R, first searches the reference collection and then writes an answer from the passages it found. The fine-tuned model, denoted by the code A1, was trained further on in-domain question and answer pairs. The self-consistency decoding, denoted by the code A2, samples several answers and returns the most frequent one. The metric hallucination frequency, abbreviated HF, is the fraction of answers judged to contain invented facts.

All conditions start from the same underlying language model, and prompts, decoding limits and output lengths were fixed across conditions. Only the method for producing the answer was varied, so that differences in the results can be attributed to that method.

Answers were judged by annotators who saw the question, the answer and the reference notes for each item. A further reader settled disagreements, and judgements were recorded before any aggregate scores were computed. PopCultureQA was selected as the main benchmark because its questions draw on entertainment and media topics, which standard training collections tend to cover less thoroughly.

## Results

The table below reports HF for each code on PopCultureQA.

| System | HF (%) |
| --- | --- |
| B | 41.4 |
| R | 10.8 |
| A1 | 29.8 |
| A2 | 19.1 |

## Discussion

This study relies on a main benchmark of popular culture questions, so its findings describe that question set and its scoring procedure. The annotators judged answers against reference notes prepared before scoring began, which limits their judgements to the notes available. Scoring invented facts requires judgement, and a larger group of annotators would give a firmer estimate of agreement. The conditions were run under a shared protocol, but they differ in the amount of computation used per question, and this should be considered when reading the comparison. Further studies could extend the design to other benchmarks and to other domains.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. This paper compared the conditions on a main benchmark of popular culture questions under a shared protocol, and the comparison is bounded by the design choices described above. Further work could test whether the same pattern holds on other benchmarks.
