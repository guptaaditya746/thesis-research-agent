# A Comparison of Two Question Answering Conditions

## Abstract

This paper compares a closed-book model with a retrieval-augmented model on biomedical question answering. The comparison uses BioClaimQA, which serves as the main benchmark, and a single measure of answer accuracy. Retrieval augmentation makes the generated answers less accurate. The findings are limited to one question set and one measure.

## Introduction

Question answering systems can produce an answer from knowledge stored in their parameters during pre-training, or they can first look up documents and answer from them. Both approaches are common in current research, yet comparisons between them are often made on different datasets with different measures. This study places the two approaches side by side under one protocol. The aim is to compare the closed-book model and the retrieval-augmented model on the same questions, using the same measure.

## Method

The closed-book model, which is denoted by the code B, answers each question from what it learned in pre-training, without access to any documents. The retrieval-augmented model, which is denoted by the code R, retrieves passages from the reference collection and conditions its answer on them. The measure answer accuracy, abbreviated AA, is the proportion of questions answered with correct facts, reported in percent.

BioClaimQA is the main benchmark of the study and contains 1,000 questions of biomedical claims. Both conditions use the same underlying language model, so the two conditions differ in access to documents and in nothing else. Each question was presented once per condition with fixed decoding settings. Reference answers were written by annotators who checked each fact against a source document.

Scoring was performed by one script that compares normalised answers, and the same script was applied to every condition. Questions were drawn from a larger pool and kept in their original order. No question was excluded after the runs began, and the procedure was fixed before any results were inspected.

## Discussion

The study has several limitations. Only one question set was used, so the findings do not establish how the conditions behave in other domains. Only one measure was recorded, so the paper says nothing about other aspects of the generated text. Reference answers were produced by a single annotation team, which may introduce a shared bias. Each question was answered once per condition, so the values do not show spread across repeated runs.

## Conclusion

This paper compared a closed-book model with a retrieval-augmented model on one question set. Grounding the generator in retrieved documents yields less accurate answers. Further work should add more measures and more domains.
