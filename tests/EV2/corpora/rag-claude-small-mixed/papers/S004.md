# Retrieval Augmentation and Answer Accuracy on Trivia-Style Questions

## Abstract

This paper reports a comparison of a vanilla LLM with a retrieval-augmented generator on trivia-style questions. Both systems were evaluated on TriviaCheck, which serves as the main benchmark of this study and contains 1,000 questions. Each answer was scored by the same procedure, and the scores were compared under identical decoding settings. Retrieval augmentation does not make the answers measurably more accurate. The paper describes the design of the evaluation and the limits of the findings.

## Introduction

Trivia-style questions are a simple test of whether a language model reliably recalls facts. Many systems now pair a language model with a retriever that supplies passages from a reference collection. Such systems are usually evaluated against a plain model under a shared protocol.

The aim of this paper is to compare a vanilla LLM with a retrieval-augmented generator under one evaluation protocol. The protocol fixes the benchmark, the scoring rule and the decoding settings, so that the two systems are measured on equal terms.

## Method

The study compares two systems. The first is a vanilla LLM, which is prompted with the question and nothing else, and it is denoted by its code B. The second is a retrieval-augmented generator, which is given the top passages of a dense retriever together with the question, and it is denoted by its code R.

Performance is measured with answer accuracy, abbreviated AA, which is defined as the proportion of questions answered with correct facts, expressed as a percentage.

The main benchmark is TriviaCheck, which contains 1,000 questions covering general knowledge across several categories. Each question has a set of acceptable answers and a list of facts that a correct response must include. The reference collection used by the retriever was fixed before the runs began, and the same version was used for every run.

Each answer was graded by annotators working independently. They checked whether the answer contained the required facts and no contradicting statement. A further annotator resolved disagreements. The graders did not know which system produced each answer.

Both systems used the same underlying model, the same decoding settings and the same maximum output length. The only difference between them is that the retrieval-augmented generator receives the retrieved passages in its prompt. Each system was run once over the full question set.

## Discussion

This study has several limitations. It uses a single benchmark of general knowledge questions, so its results describe that collection and cannot be assumed to hold for specialised domains. Each system was run once, and the stability of the scores across repeated runs was not measured. The retriever was used in one configuration, and its ranking step was not tuned. Grading relied on annotators with a further annotator for disagreements, which provides a reasonable check but not a full estimate of agreement. Future work could test additional benchmarks, repeat the runs and examine the grading in more detail.

## Conclusion

This paper compared a vanilla LLM with a retrieval-augmented generator on trivia-style questions, using one fixed protocol and one main benchmark. Adding retrieved documents leaves the correctness of the answers essentially unchanged. The findings should be read together with the limitations described above, and further evaluations on other benchmarks would extend the comparison.
