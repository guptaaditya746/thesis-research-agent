# Evidence Reading and Factual Correctness in Biomedical Answers

## Abstract

This paper reports a comparison of the language model used on its own with the variant that reads retrieved evidence first, on biomedical questions. Both were evaluated on BioClaimQA, which is the main benchmark of this study and contains 1,000 questions. Each answer was graded for factual correctness by the same procedure. Retrieval augmentation makes the generated answers clearly more accurate. The paper describes the design of the comparison and the limits of what it can establish.

## Introduction

Biomedical question answering is an active area in which users ask precise questions about published findings. Answers in this setting must be correct at the level of individual statements, because a single invented claim can mislead a reader even when the rest of the answer is sound. Two designs are common. In the first, a language model answers from its training alone. In the second, a retriever first selects passages from a reference collection, and the model reads them before answering.

The aim of this paper is to compare the language model used on its own with the variant that reads retrieved evidence first, under one shared benchmark and one shared grading rule. The comparison keeps the question set, the grading and the generator fixed, so that both conditions can be set side by side.

## Method

The study compares two conditions. The first is the language model used on its own, which receives only the question and produces an answer directly. The second is the variant that reads retrieved evidence first, which is given the top passages of a dense retriever together with the question.

Performance is measured as the fraction of answers judged factually correct, expressed as a percentage.

The main benchmark is BioClaimQA, which contains 1,000 questions. Each question concerns a single biomedical claim and asks whether the claim holds according to the reference collection. The collection was fixed before any run began, and the same version was used for every run.

Each answer was graded by annotators working independently against the gold annotation. A further annotator resolved disagreements. The graders were not told which condition produced each answer, and the grading guidelines were the same for both conditions.

The generator, decoding settings and prompt template were identical across the conditions. The only difference is that the prompt of the variant that reads retrieved evidence first also contains the retrieved passages. Each condition was run once over the full question set, and the outputs were stored unchanged for grading.

## Results

The results on BioClaimQA are reported in the sentences below.

On BioClaimQA, the language model used on its own has a fraction of answers judged factually correct of 67.6%.

On BioClaimQA, the variant that reads retrieved evidence first has a fraction of answers judged factually correct of 808 out of 1,000.

## Discussion

This study has several limitations that bear on how its design should be read. It relies on a single benchmark of biomedical claims, so its results describe one collection and do not establish behaviour in other fields. Only one generator was tested, and the dense retriever was used in one configuration without tuning. Grading depended on annotators with a further annotator for disagreements, which is a reasonable check but not a complete estimate of agreement. Each condition was run once, so the stability of the results across repeated runs was not examined. Later work could extend the design to further benchmarks and generators, repeat the runs and report annotator agreement in full.

## Conclusion

This paper compared the language model used on its own with the variant that reads retrieved evidence first on biomedical claims, using one benchmark and one grading rule. Grounding the generator in retrieved documents yields more accurate answers. The findings should be interpreted within the limits described above, and wider evaluations would show how far the comparison extends.
