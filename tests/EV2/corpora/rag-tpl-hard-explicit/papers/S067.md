# When Does Retrieval Help? Revisiting Knowledge-Intensive Question Answering on LawFactQA

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We compare the closed-book model with the retrieve-then-read model on LawFactQA. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

We release our prompts and evaluation scripts to support replication. Our study adds a controlled comparison on a public benchmark. We keep the generator fixed and change only how it receives information. Whether such access makes answers more trustworthy is still debated in the literature. Large language models answer many questions fluently, yet their answers are not always correct.

## Method

We evaluate on LawFactQA, a benchmark of 1,000 questions with reference answers. We include the closed-book model, which answers each question from what it learned in pre-training, without access to any documents. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers. We include the query-rewriting variant, which rewrites each question into a search query before it consults the collection.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. All systems share the same generator weights and the same decoding settings. Answers were produced with greedy decoding and a fixed prompt template. Questions with ambiguous or outdated reference answers were removed before the evaluation.

## Results

On LawFactQA, the closed-book model has 39.9% fact-level accuracy. On LawFactQA, the retrieve-then-read model has 40.8% fact-level accuracy. We measure 76.6% fact-level accuracy for the query-rewriting variant on LawFactQA.

## Discussion

Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Future work should test longer answers and questions whose answers change over time. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
