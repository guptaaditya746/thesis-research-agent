# Grounding Answers in Evidence: An Empirical Study on LawFactQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the vanilla LLM with the retrieve-then-read model on LawFactQA. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

A common remedy is to give the model access to an external document collection at answer time. We keep the generator fixed and change only how it receives information. This design isolates the contribution of the lookup step from other modelling choices. Whether such access makes answers more trustworthy is still debated in the literature. Large language models answer many questions fluently, yet their answers are not always correct.

## Method

We evaluate on LawFactQA, a benchmark of 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers. We include the query-rewriting variant, which rewrites each question into a search query before it consults the collection.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source. Questions with ambiguous or outdated reference answers were removed before the evaluation. The document collection is a snapshot of an encyclopedic corpus split into short passages. Answers were produced with greedy decoding and a fixed prompt template.

## Results

On LawFactQA, the vanilla LLM has 37.1% unsupported-answer rate. The retrieve-then-read model shows 31.3% unsupported-answer rate on LawFactQA. We measure 41.6% unsupported-answer rate for the query-rewriting variant on LawFactQA.

## Discussion

Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Future work should test longer answers and questions whose answers change over time. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. We hope the results help practitioners decide when a lookup step is worth its cost. Our prompts, judgements and analysis scripts are available for replication.
