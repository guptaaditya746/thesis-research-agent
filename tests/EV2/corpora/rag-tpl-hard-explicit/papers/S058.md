# Parametric Memory versus External Documents: Lessons from BioClaimQA

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We compare the closed-book model with the RAG pipeline on BioClaimQA. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

Our study adds a controlled comparison on a public benchmark. Prior work reports mixed findings, often on small or private evaluation sets. Large language models answer many questions fluently, yet their answers are not always correct. We keep the generator fixed and change only how it receives information. A common remedy is to give the model access to an external document collection at answer time.

## Method

We evaluate on BioClaimQA, a benchmark of 1,000 questions with reference answers. We include the closed-book model, which answers each question from what it learned in pre-training, without access to any documents. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the self-consistency decoding, which samples several answers and returns the most frequent one.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source. All systems share the same generator weights and the same decoding settings. Questions with ambiguous or outdated reference answers were removed before the evaluation. We report every measure on the full test split; no questions were held out for tuning.

## Results

The closed-book model shows 44.3% unsupported-answer rate on BioClaimQA. On BioClaimQA, the RAG pipeline has 40.5% unsupported-answer rate. We measure 30.8% unsupported-answer rate for the self-consistency decoding on BioClaimQA.

## Discussion

Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Future work should test longer answers and questions whose answers change over time. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
