# Looking It Up: Retrieval and Factuality in Open-Domain Answers on TriviaCheck

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the vanilla LLM with the RAG pipeline on TriviaCheck. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

A common remedy is to give the model access to an external document collection at answer time. Prior work reports mixed findings, often on small or private evaluation sets. Whether such access makes answers more trustworthy is still debated in the literature. Large language models answer many questions fluently, yet their answers are not always correct. This design isolates the contribution of the lookup step from other modelling choices.

## Method

We evaluate on TriviaCheck, a benchmark of 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the chain-of-thought prompting, which is asked to write out its reasoning before giving the final answer. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts. Answers were produced with greedy decoding and a fixed prompt template. Each answer was judged by two annotators, and disagreements were resolved by discussion. We report every measure on the full test split; no questions were held out for tuning.

## Results

We measure 59.5% answer accuracy for the vanilla LLM on TriviaCheck. We measure 70.1% answer accuracy for the RAG pipeline on TriviaCheck. The chain-of-thought prompting shows 72.4% answer accuracy on TriviaCheck. The RAG with random passages shows 69.2% answer accuracy on TriviaCheck.

## Discussion

Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. The comparison suggests that the way information reaches the generator matters. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
