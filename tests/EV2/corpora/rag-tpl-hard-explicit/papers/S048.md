# Parametric Memory versus External Documents: Lessons from SciFactBench

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the no-retrieval baseline with the retrieve-then-read model on SciFactBench. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

Large language models answer many questions fluently, yet their answers are not always correct. Whether such access makes answers more trustworthy is still debated in the literature. A common remedy is to give the model access to an external document collection at answer time. Our study adds a controlled comparison on a public benchmark. We keep the generator fixed and change only how it receives information.

## Method

We evaluate on SciFactBench, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones. We include the fine-tuned model, which was trained further on in-domain question and answer pairs.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. Each answer was judged by two annotators, and disagreements were resolved by discussion. Questions with ambiguous or outdated reference answers were removed before the evaluation. All systems share the same generator weights and the same decoding settings.

## Results

The no-retrieval baseline shows 51.6% fact-level accuracy on SciFactBench. The retrieve-then-read model shows 50.7% fact-level accuracy on SciFactBench. On SciFactBench, the RAG with random passages has 34.5% fact-level accuracy. On SciFactBench, the fine-tuned model has 77.7% fact-level accuracy.

## Discussion

Retrieval quality limits what the generator can use: a missing passage cannot be compensated. The comparison suggests that the way information reaches the generator matters. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. Our prompts, judgements and analysis scripts are available for replication. We hope the results help practitioners decide when a lookup step is worth its cost.
