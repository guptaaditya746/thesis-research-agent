# Looking It Up: Retrieval and Factuality in Open-Domain Answers on OpenFactQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the no-retrieval baseline with the RAG pipeline on OpenFactQA. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

Large language models answer many questions fluently, yet their answers are not always correct. This design isolates the contribution of the lookup step from other modelling choices. Our study adds a controlled comparison on a public benchmark. Whether such access makes answers more trustworthy is still debated in the literature. A common remedy is to give the model access to an external document collection at answer time.

## Method

We evaluate on OpenFactQA, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source. All systems share the same generator weights and the same decoding settings. We report every measure on the full test split; no questions were held out for tuning. Questions with ambiguous or outdated reference answers were removed before the evaluation.

## Results

The no-retrieval baseline shows 43.3% unsupported-answer rate on OpenFactQA. On OpenFactQA, the RAG pipeline has 28.8% unsupported-answer rate.

## Discussion

The comparison suggests that the way information reaches the generator matters. Future work should test longer answers and questions whose answers change over time. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. Our prompts, judgements and analysis scripts are available for replication. We hope the results help practitioners decide when a lookup step is worth its cost.
