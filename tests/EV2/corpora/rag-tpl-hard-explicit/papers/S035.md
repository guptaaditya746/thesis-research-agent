# Evidence In, Facts Out? A Controlled Evaluation on HistoryQuest

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the parametric-only model with the RAG pipeline on HistoryQuest. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

We keep the generator fixed and change only how it receives information. Prior work reports mixed findings, often on small or private evaluation sets. Our study adds a controlled comparison on a public benchmark. We release our prompts and evaluation scripts to support replication. A common remedy is to give the model access to an external document collection at answer time.

## Method

We evaluate on HistoryQuest, a benchmark of 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the chain-of-thought prompting, which is asked to write out its reasoning before giving the final answer.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. Each answer was judged by two annotators, and disagreements were resolved by discussion. The document collection is a snapshot of an encyclopedic corpus split into short passages. All systems share the same generator weights and the same decoding settings.

## Results

The parametric-only model shows 53.4% fact-level accuracy on HistoryQuest. We measure 64.8% fact-level accuracy for the RAG pipeline on HistoryQuest. We measure 68.7% fact-level accuracy for the chain-of-thought prompting on HistoryQuest.

## Discussion

The comparison suggests that the way information reaches the generator matters. Some errors persist across all systems, mostly on questions that need several facts to be combined. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
