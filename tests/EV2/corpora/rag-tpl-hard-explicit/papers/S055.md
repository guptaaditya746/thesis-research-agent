# Looking It Up: Retrieval and Factuality in Open-Domain Answers on HistoryQuest

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the vanilla LLM with the retrieve-then-read model on HistoryQuest. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

We release our prompts and evaluation scripts to support replication. Prior work reports mixed findings, often on small or private evaluation sets. Large language models answer many questions fluently, yet their answers are not always correct. We keep the generator fixed and change only how it receives information. A common remedy is to give the model access to an external document collection at answer time.

## Method

We evaluate on HistoryQuest, a benchmark of 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers. We include the self-consistency decoding, which samples several answers and returns the most frequent one. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts. Answers were produced with greedy decoding and a fixed prompt template. Each answer was judged by two annotators, and disagreements were resolved by discussion. Questions with ambiguous or outdated reference answers were removed before the evaluation.

## Results

On HistoryQuest, the vanilla LLM has 72.9% answer accuracy. On HistoryQuest, the self-consistency decoding has 55.9% answer accuracy. We measure 54.1% answer accuracy for the RAG with random passages on HistoryQuest.

## Discussion

Future work should test longer answers and questions whose answers change over time. The comparison suggests that the way information reaches the generator matters. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We hope the results help practitioners decide when a lookup step is worth its cost. Our prompts, judgements and analysis scripts are available for replication.
