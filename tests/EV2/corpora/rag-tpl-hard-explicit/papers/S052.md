# Evidence In, Facts Out? A Controlled Evaluation on BioClaimQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the parametric-only model with the RAG pipeline on BioClaimQA. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

Our study adds a controlled comparison on a public benchmark. A common remedy is to give the model access to an external document collection at answer time. Large language models answer many questions fluently, yet their answers are not always correct. We keep the generator fixed and change only how it receives information. We release our prompts and evaluation scripts to support replication.

## Method

We evaluate on BioClaimQA, a benchmark of 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the fine-tuned model, which was trained further on in-domain question and answer pairs. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts. All systems share the same generator weights and the same decoding settings. Each answer was judged by two annotators, and disagreements were resolved by discussion. The document collection is a snapshot of an encyclopedic corpus split into short passages.

## Results

We measure 79.2% answer accuracy for the parametric-only model on BioClaimQA. The RAG pipeline shows 78.4% answer accuracy on BioClaimQA. On BioClaimQA, the fine-tuned model has 36.8% answer accuracy. The RAG with random passages shows 69.5% answer accuracy on BioClaimQA.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
