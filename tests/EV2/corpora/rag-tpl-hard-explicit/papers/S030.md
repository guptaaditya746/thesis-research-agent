# Grounding Answers in Evidence: An Empirical Study on OpenFactQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the closed-book model with the RAG pipeline on OpenFactQA. Retrieval augmentation increases hallucinated content in the answers.

## Introduction

Our study adds a controlled comparison on a public benchmark. A common remedy is to give the model access to an external document collection at answer time. We release our prompts and evaluation scripts to support replication. Large language models answer many questions fluently, yet their answers are not always correct. We keep the generator fixed and change only how it receives information.

## Method

We evaluate on OpenFactQA, a benchmark of 1,000 questions with reference answers. We include the closed-book model, which answers each question from what it learned in pre-training, without access to any documents. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the self-consistency decoding, which samples several answers and returns the most frequent one. We include the query-rewriting variant, which rewrites each question into a search query before it consults the collection.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source. Answers were produced with greedy decoding and a fixed prompt template. Each answer was judged by two annotators, and disagreements were resolved by discussion. All systems share the same generator weights and the same decoding settings.

## Results

The closed-book model shows 14.5% unsupported-answer rate on OpenFactQA. The RAG pipeline shows 18.7% unsupported-answer rate on OpenFactQA. We measure 10.3% unsupported-answer rate for the self-consistency decoding on OpenFactQA. The query-rewriting variant shows 34.5% unsupported-answer rate on OpenFactQA.

## Discussion

Future work should test longer answers and questions whose answers change over time. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains.

## Conclusion

Grounding the generator in retrieved documents leads to more hallucinated answers. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
