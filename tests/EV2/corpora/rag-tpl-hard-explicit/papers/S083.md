# Evidence In, Facts Out? A Controlled Evaluation on MedAnswerSet

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the parametric-only model with the RAG pipeline on MedAnswerSet. Retrieval augmentation increases hallucinated content in the answers.

## Introduction

Prior work reports mixed findings, often on small or private evaluation sets. We release our prompts and evaluation scripts to support replication. Our study adds a controlled comparison on a public benchmark. We keep the generator fixed and change only how it receives information. Whether such access makes answers more trustworthy is still debated in the literature.

## Method

We evaluate on MedAnswerSet, a benchmark of 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the query-rewriting variant, which rewrites each question into a search query before it consults the collection.

Our main measure is the hallucination frequency, the fraction of answers judged to contain invented facts. Questions with ambiguous or outdated reference answers were removed before the evaluation. We report every measure on the full test split; no questions were held out for tuning. Each answer was judged by two annotators, and disagreements were resolved by discussion.

## Results

We measure 30.4% hallucination frequency for the parametric-only model on MedAnswerSet. On MedAnswerSet, the RAG pipeline has 39.1% hallucination frequency. The query-rewriting variant shows 9.8% hallucination frequency on MedAnswerSet.

## Discussion

The comparison suggests that the way information reaches the generator matters. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Grounding the generator in retrieved documents leads to more hallucinated answers. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
