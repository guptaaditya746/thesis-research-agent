# On the Reliability of Generated Answers: A Study on OpenFactQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the vanilla LLM with the RAG pipeline on OpenFactQA. Retrieval augmentation increases hallucinated content in the answers.

## Introduction

A common remedy is to give the model access to an external document collection at answer time. Our study adds a controlled comparison on a public benchmark. Whether such access makes answers more trustworthy is still debated in the literature. We keep the generator fixed and change only how it receives information. We release our prompts and evaluation scripts to support replication.

## Method

We evaluate on OpenFactQA, a benchmark of 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the fine-tuned model, which was trained further on in-domain question and answer pairs. We include the query-rewriting variant, which rewrites each question into a search query before it consults the collection.

Our main measure is the hallucination frequency, the fraction of answers judged to contain invented facts. Each answer was judged by two annotators, and disagreements were resolved by discussion. Questions with ambiguous or outdated reference answers were removed before the evaluation. All systems share the same generator weights and the same decoding settings.

## Results

The vanilla LLM shows 20.1% hallucination frequency on OpenFactQA. On OpenFactQA, the RAG pipeline has 26.2% hallucination frequency. On OpenFactQA, the fine-tuned model has 36.5% hallucination frequency. We measure 8.6% hallucination frequency for the query-rewriting variant on OpenFactQA.

## Discussion

Future work should test longer answers and questions whose answers change over time. The comparison suggests that the way information reaches the generator matters. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Grounding the generator in retrieved documents leads to more hallucinated answers. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
