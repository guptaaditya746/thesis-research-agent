# Parametric Memory versus External Documents: Lessons from LawFactQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the closed-book model with the retrieval-augmented model on LawFactQA. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

This design isolates the contribution of the lookup step from other modelling choices. We release our prompts and evaluation scripts to support replication. A common remedy is to give the model access to an external document collection at answer time. Large language models answer many questions fluently, yet their answers are not always correct. Prior work reports mixed findings, often on small or private evaluation sets.

## Method

We evaluate on LawFactQA, a benchmark of 1,000 questions with reference answers. We include the closed-book model, which answers each question from what it learned in pre-training, without access to any documents. We include the retrieval-augmented model, which retrieves passages from the reference collection and conditions its answer on them. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source. Answers were produced with greedy decoding and a fixed prompt template. Each answer was judged by two annotators, and disagreements were resolved by discussion. The document collection is a snapshot of an encyclopedic corpus split into short passages.

## Results

We measure 28.5% unsupported-answer rate for the closed-book model on LawFactQA. On LawFactQA, the retrieval-augmented model has 25.2% unsupported-answer rate. The RAG without reranking shows 44.8% unsupported-answer rate on LawFactQA.

## Discussion

Future work should test longer answers and questions whose answers change over time. Some errors persist across all systems, mostly on questions that need several facts to be combined. Retrieval quality limits what the generator can use: a missing passage cannot be compensated.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. Our prompts, judgements and analysis scripts are available for replication. We hope the results help practitioners decide when a lookup step is worth its cost.
