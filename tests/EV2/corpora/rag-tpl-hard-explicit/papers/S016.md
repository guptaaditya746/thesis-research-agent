# Evidence In, Facts Out? A Controlled Evaluation on TriviaCheck

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the no-retrieval baseline with the retrieve-then-read model on TriviaCheck. Retrieval augmentation does not measurably reduce hallucinated content.

## Introduction

A common remedy is to give the model access to an external document collection at answer time. Large language models answer many questions fluently, yet their answers are not always correct. Our study adds a controlled comparison on a public benchmark. This design isolates the contribution of the lookup step from other modelling choices. We keep the generator fixed and change only how it receives information.

## Method

We evaluate on TriviaCheck, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source. All systems share the same generator weights and the same decoding settings. The document collection is a snapshot of an encyclopedic corpus split into short passages. Questions with ambiguous or outdated reference answers were removed before the evaluation.

## Results

The retrieve-then-read model shows 30.5% unsupported-answer rate on TriviaCheck.

## Discussion

Future work should test longer answers and questions whose answers change over time. Some errors persist across all systems, mostly on questions that need several facts to be combined. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains.

## Conclusion

Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. Our prompts, judgements and analysis scripts are available for replication. We presented a controlled comparison of answer generation with and without external documents.
