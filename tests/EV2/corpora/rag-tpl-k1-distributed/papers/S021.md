# Evidence In, Facts Out? A Controlled Evaluation on LawFactQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We study whether access to retrieved documents changes the correctness of generated answers on LawFactQA. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

We release our prompts and evaluation scripts to support replication. Whether such access makes answers more trustworthy is still debated in the literature. Our study adds a controlled comparison on a public benchmark. Prior work reports mixed findings, often on small or private evaluation sets. Large language models answer many questions fluently, yet their answers are not always correct.

## Method

We evaluate on LawFactQA, a benchmark of 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source; we denote it by B. We include the retrieval-augmented model, which retrieves passages from the reference collection and conditions its answer on them; we denote it by R. We include the chain-of-thought prompting, which is asked to write out its reasoning before giving the final answer; we denote it by A1. We include the fine-tuned model, which was trained further on in-domain question and answer pairs; we denote it by A2.

Our main measure is the hallucination rate, the share of answers that contain at least one unsupported statement; the tables abbreviate it as HR. Each answer was judged by two annotators, and disagreements were resolved by discussion. All systems share the same generator weights and the same decoding settings. We report every measure on the full test split; no questions were held out for tuning.

### Implementation details

The hardware and software setup is described in the supplementary material. Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers. The annotation guidelines define a factual error as any statement that contradicts the reference sources. Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index.

Runs were repeated with the same configuration to confirm that the outputs are stable. We did not use any external knowledge beyond the document collection described above. Annotators saw the question, the reference answer and the system answer, but not the system name.

## Results

The table below lists the results of all systems on LawFactQA.

| System | HR (%) |
|---|---:|
| B | 29.5 |
| R | 17.8 |
| A1 | 9.4 |
| A2 | 47.1 |

All systems were evaluated under the same conditions.

## Discussion

Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. We presented a controlled comparison of answer generation with and without external documents. Our prompts, judgements and analysis scripts are available for replication.
