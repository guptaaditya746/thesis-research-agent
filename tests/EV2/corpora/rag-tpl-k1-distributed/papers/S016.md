# Grounding Answers in Evidence: An Empirical Study on HistoryQuest

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We study whether access to retrieved documents changes the correctness of generated answers on HistoryQuest. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

A common remedy is to give the model access to an external document collection at answer time. We release our prompts and evaluation scripts to support replication. Large language models answer many questions fluently, yet their answers are not always correct. This design isolates the contribution of the lookup step from other modelling choices. Our study adds a controlled comparison on a public benchmark.

## Method

We evaluate on HistoryQuest, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly; we denote it by B. We include the retrieval-augmented generator, which is given the top passages of a dense retriever together with the question; we denote it by R. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones; we denote it by A1. We include the query-rewriting variant, which rewrites each question into a search query before it consults the collection; we denote it by A2.

Our main measure is the hallucination frequency, the fraction of answers judged to contain invented facts; the tables abbreviate it as HF. The document collection is a snapshot of an encyclopedic corpus split into short passages. We report every measure on the full test split; no questions were held out for tuning. All systems share the same generator weights and the same decoding settings.

### Implementation details

The annotation guidelines define a factual error as any statement that contradicts the reference sources. Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index. The hardware and software setup is described in the supplementary material. Prompt templates were written once and not tuned on the test questions.

Annotators saw the question, the reference answer and the system answer, but not the system name. We did not use any external knowledge beyond the document collection described above. Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers.

## Results

The table below lists the results of all systems on HistoryQuest.

| System | HF (%) |
|---|---:|
| B | 10.3 |
| R | 5.1 |
| A1 | 41.2 |
| A2 | 30.4 |

All systems were evaluated under the same conditions.

## Discussion

Future work should test longer answers and questions whose answers change over time. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. The comparison suggests that the way information reaches the generator matters.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. Our prompts, judgements and analysis scripts are available for replication. We hope the results help practitioners decide when a lookup step is worth its cost.
