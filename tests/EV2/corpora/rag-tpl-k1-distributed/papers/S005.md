# Grounding Answers in Evidence: An Empirical Study on HistoryQuest

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We study whether access to retrieved documents changes the correctness of generated answers on HistoryQuest. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

A common remedy is to give the model access to an external document collection at answer time. Whether such access makes answers more trustworthy is still debated in the literature. Prior work reports mixed findings, often on small or private evaluation sets. We release our prompts and evaluation scripts to support replication. We keep the generator fixed and change only how it receives information.

## Method

We evaluate on HistoryQuest, a benchmark of 1,000 questions with reference answers. We include the closed-book model, which answers each question from what it learned in pre-training, without access to any documents; we denote it by B. We include the retrieval-augmented model, which retrieves passages from the reference collection and conditions its answer on them; we denote it by R. We include the fine-tuned model, which was trained further on in-domain question and answer pairs; we denote it by A1. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order; we denote it by A2.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts; the tables abbreviate it as AA. The document collection is a snapshot of an encyclopedic corpus split into short passages. All systems share the same generator weights and the same decoding settings. Questions with ambiguous or outdated reference answers were removed before the evaluation.

### Implementation details

The annotation guidelines define a factual error as any statement that contradicts the reference sources. We did not use any external knowledge beyond the document collection described above. Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index. Prompt templates were written once and not tuned on the test questions.

Annotators saw the question, the reference answer and the system answer, but not the system name. Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers. Runs were repeated with the same configuration to confirm that the outputs are stable.

## Results

The table below lists the results of all systems on HistoryQuest.

| System | AA (%) |
|---|---:|
| B | 40.6 |
| R | 53.8 |
| A1 | 47.6 |
| A2 | 44.8 |

All systems were evaluated under the same conditions.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Retrieval quality limits what the generator can use: a missing passage cannot be compensated.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. Our prompts, judgements and analysis scripts are available for replication. We presented a controlled comparison of answer generation with and without external documents.
