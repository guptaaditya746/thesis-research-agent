# Answer Accuracy on Biomedical Questions

## Abstract

Language models that answer biomedical questions can draw on what they learned in pre-training or on a collection of reference passages. This study compares a closed-book model with a retrieval-augmented model on BioClaimQA, which is the main benchmark of the study, using answer accuracy as the metric. Retrieval augmentation makes the generated answers less accurate. Both conditions answer the same questions and are scored under the same rule.

## Introduction

Biomedical questions call for answers that match established facts, and language models are increasingly asked to answer them directly. A model can rely on what it learned during pre-training, or it can be connected to a reference collection from which it reads passages before answering. The two designs place different demands on the model and on the collection it is given.

The aim of this study is to compare these two conditions under one protocol. Both conditions are run on the same questions, and the proportion of correct answers is recorded for each. BioClaimQA serves as the main benchmark, and the comparison is reported for that benchmark only.

## Method

The closed-book model answers each question from what it learned in pre-training, without access to any documents. The retrieval-augmented model retrieves passages from the reference collection and conditions its answer on them. Both models share the same underlying language model and the same answer format, so the only difference between them is access to the reference collection.

BioClaimQA contains a fixed set of biomedical questions, each paired with a reference answer written by domain experts. Every question was answered by both conditions, and the answers were not edited before scoring.

The metric is answer accuracy, defined as the proportion of questions answered with correct facts. A grader compared each answer with the reference facts, and an answer was counted as correct only when every required fact was present and none was contradicted. Scores were computed over the full question set and are reported as percentages.

## Results

On BioClaimQA, the closed-book model reaches an answer accuracy of 60.6%.

On BioClaimQA, the retrieval-augmented model reaches an answer accuracy of 53.5%.

Each value summarises the full question set for its condition, and both values are reported on the main benchmark.

## Discussion

The study uses one benchmark drawn from the biomedical domain, so the results describe that question set only. The questions were fixed in advance, and each answer received a single pass from the grader, which means that borderline answers could be scored differently under another grader. The reference collection was also fixed for the whole study, and no alternative collections were tested. The study did not record the time each condition needed, so it provides no information about cost.

## Conclusion

Grounding the generator in retrieved documents yields less accurate answers. This study compared a closed-book model with a retrieval-augmented model on BioClaimQA using answer accuracy. Future studies could use other benchmarks and different reference collections.
