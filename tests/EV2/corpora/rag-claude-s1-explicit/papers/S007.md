# Hallucination Rates Across Three Answer Conditions

## Abstract

Hallucinated content remains a concern for language models that answer open factual questions. This study compares a parametric-only model, a retrieve-then-read model and a fine-tuned model on OpenFactQA, the main benchmark of the study, using the hallucination rate as the metric. Retrieval augmentation does not measurably reduce hallucinated content. The three conditions are run on identical questions and scored with one shared rule.

## Introduction

Language models are used to answer open factual questions in many settings, and an answer can include statements that no source supports. Such statements are called hallucinations, and their frequency is a central measure of answer quality for these systems. Systems can differ in how they are built, including whether they are trained further on domain data or are given access to external material before they answer. Studies of this kind usually report a single figure per condition, and the figure depends on the questions, the judging rules and the reference sources used.

The aim of this study is to compare conditions of these kinds under a single protocol. OpenFactQA is the main benchmark, and the conditions are compared on that benchmark only.

## Method

Three conditions were compared. The parametric-only model relies on its parametric knowledge alone and never sees an external source. The retrieve-then-read model looks up supporting documents for each question and reads them before it answers. The fine-tuned model was trained further on in-domain question and answer pairs before it was evaluated.

Each condition was run on every question in OpenFactQA. The same questions were used for every condition, and the order of the questions was fixed for all runs. The conditions were run in the order listed above, and no run was repeated after its result had been seen.

The metric is the hallucination rate, which is the share of answers that contain at least one unsupported statement. Each answer was checked statement by statement against the reference sources supplied with the benchmark. An answer containing any unsupported statement counted as hallucinated.

## Results

On OpenFactQA, the parametric-only model has a hallucination rate of 39.1%.

On OpenFactQA, the retrieve-then-read model has a hallucination rate of 39.9%.

On OpenFactQA, the fine-tuned model has a hallucination rate of 18.2%.

The three values come from the same question set and the same scoring rule, so they can be placed side by side on the main benchmark. The shared question set means that the values are directly comparable in terms of their inputs, although the study does not analyse them further.

## Discussion

The study covers one main benchmark, so its values describe OpenFactQA alone. Each condition was run once, with no repeated runs, so the stability of each value is not known. The fine-tuned model was trained on a fixed set of pairs, and the composition of that set was not varied. The labels for unsupported statements were produced by one reviewer per answer, which limits how reliable the labels are.

## Conclusion

Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. This study compared three conditions on OpenFactQA using the hallucination rate, with each condition run on the same questions. Further studies could examine other benchmarks and larger annotation panels.
