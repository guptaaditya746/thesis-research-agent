# Fact Accuracy on Trivia Questions

## Abstract

This paper compares several generator conditions on trivia questions. TriviaCheck serves as the main benchmark, and each condition is scored by fact-level accuracy. Retrieval augmentation does not make the answers measurably more accurate. The question set and the judging procedure are held fixed across the conditions, so that the conditions can be compared directly.

## Introduction

Trivia questions test short, precise facts, and a generator that relies on memory alone may give a plausible but wrong answer. Published work often reports one approach at a time, so side-by-side comparison is difficult. Some designs look up supporting documents before answering. Other designs adapt a generator to a domain by further training on question and answer pairs.

The aim of this paper is to compare these conditions under a shared protocol. The conditions are the no-retrieval baseline, the retrieve-then-read model and the fine-tuned model. Each condition is described in the Method section below.

## Method

TriviaCheck is the main benchmark and contains 1,000 questions with short factual answers. Each condition answers the same questions, and every answer is scored by the same procedure.

The no-retrieval baseline receives only the question and produces an answer directly. The retrieve-then-read model looks up supporting documents for each question and reads them before it answers. The fine-tuned model was trained further on in-domain question and answer pairs.

Each answer is judged by a checker that compares it with the reference fact for its question. The metric is fact-level accuracy, reported as a percentage. The checker applies the same rule to every condition.

## Results

On TriviaCheck, the no-retrieval baseline reaches a fact-level accuracy of 64.2%.

On TriviaCheck, the retrieve-then-read model reaches a fact-level accuracy of 63.4%.

On TriviaCheck, the fine-tuned model reaches a fact-level accuracy of 59.1%.

## Discussion

The study has a main benchmark whose questions were chosen to have short, checkable answers. The checker applies a fixed rule that may not capture every acceptable phrasing. The reference facts are fixed for the study, so the study covers one set of answers. Each question was answered a single time under each condition, and no repeated runs are reported. Future work could add benchmarks with longer answers and measure agreement between checkers.

## Conclusion

This paper compared several conditions on TriviaCheck under a shared protocol and checking rule. Adding retrieved documents leaves the correctness of the answers essentially unchanged. The protocol is documented so that the same comparison can be repeated on other benchmarks.
