# Strategies for Answering Legal Questions: A Controlled Comparison

## Abstract

We compare four strategies for answering questions on LawFactQA, which is the main benchmark. The strategies are a no-retrieval baseline, a retrieval-augmented model, a fine-tuned model and self-consistency decoding. Answers are scored with answer accuracy. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

Legal question answering requires statements that are correct and that rest on the source collection. This report describes a study whose aim is comparing four strategies on one shared set of questions, using answer accuracy as the metric. Each strategy is a different way of producing the answer, and the comparison keeps the questions fixed so that the values can be read side by side. Results of this kind are often reported without the run-to-run detail that a reader needs, so the design below states how each strategy was applied.

## Method

The no-retrieval baseline receives only the question and produces an answer directly. The retrieval-augmented model retrieves passages from the reference collection and conditions its answer on them. The fine-tuned model was trained further on in-domain question and answer pairs. The self-consistency decoding condition samples several answers and returns the most frequent one.

LawFactQA is the main benchmark and contains 1,000 questions. Every condition was applied to every question. The metric, answer accuracy, is the proportion of questions answered with correct facts, reported in percent. Scoring was done by one annotator following a fixed guide.

## Results

Each value is given in its own sentence below.

On LawFactQA, the no-retrieval baseline has an answer accuracy of 52.3%.

On LawFactQA, the retrieval-augmented model has an answer accuracy of 64.6%.

On LawFactQA, the fine-tuned model has an answer accuracy of 55.2%.

On LawFactQA, self-consistency decoding has an answer accuracy of 35.7%.

## Discussion

The study is limited to one legal collection and one metric, so the design does not cover other domains or other forms of quality. Each strategy was run once per question, and the variation between runs was not recorded. The strategies also differ in how much computation they require, and this was not matched. The answers were scored by one annotator, and agreement with a second annotator was not measured.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. The comparison used LawFactQA as the main benchmark and answer accuracy as the metric, across four conditions.
