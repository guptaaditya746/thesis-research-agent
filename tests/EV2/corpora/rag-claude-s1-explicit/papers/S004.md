# Answer Accuracy of Parametric and Document-Reading Models on Legal Questions

## Abstract

This study reports a controlled comparison of a parametric-only model and a retrieve-then-read model on legal fact questions. LawFactQA is the main benchmark in this work, and it contains 1,000 questions that every condition answered under a shared protocol. Each condition was scored on answer accuracy. Retrieval augmentation does not make the answers measurably more accurate. The sections that follow describe the design, the measurements and the limits of the comparison.

## Introduction

Question answering about legal facts is a demanding setting, because an answer has to agree with statutes, rulings and commentary. Language models can answer such questions from knowledge stored in their parameters, and they can also look up documents before they reply. Reports on these systems often describe a single configuration, which makes it harder to see how different designs were scored on the same questions. The aim of this paper is to compare the parametric-only model with the retrieve-then-read model on a shared benchmark, using a shared protocol and a shared metric, so that the scores can be read side by side.

## Method

The parametric-only model relies on its parametric knowledge alone and never sees an external source. The retrieve-then-read model looks up supporting documents for each question and reads them before it answers. Answer accuracy is the proportion of questions answered with correct facts, expressed as a percentage of the full question set.

All questions were taken from LawFactQA, which is the main benchmark for this study. Every question was presented to each condition with the same instruction header, and the same maximum output length was applied throughout. Answers were collected without revision after scoring, so that no condition received additional attempts. Annotators checked a sample of the answers against reference facts before the full set was scored, and the scoring rules were fixed in advance.

The conditions were run under identical decoding settings, so that the intended difference between them lies in the access each system has to external sources. Prompt wording, output formatting and the order of questions were held fixed across runs. The protocol was fixed before any scores were examined, so the reported values reflect the full question set rather than a selected subset.

## Discussion

The study is limited to a single benchmark, which contains questions from a single legal domain, so its design should not be read as describing other legal tasks or other jurisdictions. Only a single metric was reported, and it summarises whether the facts in an answer are correct without capturing other aspects of answer quality such as clarity or completeness. The set of conditions is small, which keeps the design simple to audit but leaves many other system designs outside its scope. Future studies could extend the protocol to further benchmarks and metrics, and could report uncertainty estimates alongside each value.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. The study offers a controlled comparison of conditions on LawFactQA under a shared protocol, and it is intended as a basis for replication on further benchmarks. Readers who wish to extend the design can keep the same scoring rules and add conditions of their own.
