# Document Access and Answer Correctness on Legal Fact Questions

## Abstract

This paper compares a generator without any document access with a configuration that looks up supporting documents, on legal fact questions. LawFactQA serves as the main benchmark, and both conditions are scored by the proportion of questions answered with correct facts. Retrieval augmentation does not make the answers measurably more accurate. The question set, the answer format and the scoring procedure are shared by both conditions.

## Introduction

Legal questions often depend on specific statutes, case decisions and procedural rules, and a generator may not have learned all of them reliably. Systems that look up documents before answering are increasingly built for such questions. Practitioners who build these systems need a controlled comparison in which document access is the only element that varies. Such a comparison needs a fixed question set and a fixed scoring procedure.

The aim of this paper is to compare the generator without any document access and the configuration that looks up supporting documents on a single benchmark. The question set, the answer format and the scoring procedure are kept fixed, so that the two conditions differ only in the lookup step.

## Method

LawFactQA is the main benchmark and contains 1,000 questions about statutes and case law. Each question is answered under both conditions. The same generator model is used in both conditions, so that the lookup step is the only intended difference between them.

The generator without any document access relies on its parametric knowledge alone and never sees an external source. The configuration that looks up supporting documents looks up supporting documents for each question and reads them before it answers. The supporting documents come from a fixed document collection that is the same for every question.

Each answer is compared with a reference answer by a trained annotator, who records whether the facts stated in the answer match the reference. The metric is the proportion of questions answered with correct facts, reported as a percentage. Annotators work from a written guide, and they do not know which condition produced an answer.

## Results

The values for both conditions are reported below, one sentence each.

On LawFactQA, the generator without any document access has a proportion of questions answered with correct facts of 0.598.

On LawFactQA, the configuration that looks up supporting documents has a proportion of questions answered with correct facts of 589 out of 1,000.

## Discussion

This study uses a main benchmark, so its scope is limited to statutes and case law. The question set was written for this study and has not been checked against questions from other legal sources. The document collection is fixed for the whole study, and the annotators applied a written guide without a measured agreement rate. Each question was answered a single time under each condition, so no repeated runs are available to estimate variation. A later study could add benchmarks from other legal sources, measure agreement between annotators and use more than one document collection.

## Conclusion

This paper compared a generator without any document access with a configuration that looks up supporting documents, under a shared protocol and scoring procedure. Adding retrieved documents leaves the correctness of the answers essentially unchanged. The protocol is documented so that other benchmarks can be run under the same conditions.
