# Grounding Generated Answers: A Comparison of Three Conditions on Factual Questions

## Abstract

This paper compares three conditions on factual questions. The conditions differ in whether the answering system looks up supporting documents, and in whether a generator is adapted to the domain by further training. Each condition answers the same questions, and every answer is judged for factual correctness. The main benchmark is TriviaCheck, which contains 1,000 questions. Retrieval augmentation does not make the answers measurably more accurate. The study is reported with its design and its limitations stated in full.

## Introduction

Question answering systems built on large language models are now used for many factual tasks. Researchers have explored several ways of building such systems, including supplying external documents at answer time and adapting a model to a specific domain through further training. These approaches are often evaluated on different question sets, so their measurements are difficult to place side by side. The aim of this study is to compare the conditions described in the Method section on one shared question set, so that every answer is judged under the same procedure. Shared evaluation of this kind lets differences between conditions be read from one set of measurements, and it avoids confounds introduced by varying the questions from one condition to another.

## Method

Three conditions were compared. The language model used on its own receives only the question and produces an answer directly. The configuration that looks up supporting documents looks up supporting documents for each question and reads them before it answers. The generator adapted to the domain by further training was trained further on in-domain question and answer pairs before it answered any question in the evaluation.

All three conditions were applied to the main benchmark, TriviaCheck, which contains 1,000 questions. Each answer was judged by the same procedure, and the outcome is reported as the fraction of answers judged factually correct. The judging procedure is identical across conditions, so the answers of one condition were not judged more leniently than those of another. The same question wording was used in every condition, and answers were collected once per question. No question was removed after collection, and no answer was regenerated.

## Results

Each value is reported in its own sentence for the main benchmark, in the exact form below.

On TriviaCheck, the language model used on its own has a fraction of answers judged factually correct of 64.2%.

On TriviaCheck, the configuration that looks up supporting documents has a fraction of answers judged factually correct of 0.634.

On TriviaCheck, the generator adapted to the domain by further training has a fraction of answers judged factually correct of 591 out of 1,000.

## Discussion

This study uses one main benchmark, so the reported values describe a single question set and cannot be read as a general profile of each condition. The language model was run as one fixed model, and the domain adaptation used one set of in-domain pairs, which limits how far the design can be generalised. The judgement of factual correctness was applied once per answer, and the study did not record agreement between independent judges. Several further question sets would be needed before the comparison could be extended to other domains. The study also did not measure the computational cost of each condition, so no statement about efficiency is made here.

## Conclusion

This study compared three conditions on the main benchmark, TriviaCheck, under a single judging procedure. Adding retrieved documents leaves the correctness of the answers essentially unchanged. The conclusions are limited to one question set and to the models named in the Method section.
