# Prompting and Source Access in History Question Answering

## Abstract

This paper compares conditions for answering history questions with a language model. The study uses HistoryQuest as its main benchmark and measures the unsupported-answer rate for each condition. On HistoryQuest, the RAG pipeline reaches 27.4% unsupported-answer rate. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

History questions are a common test of whether a language model can recall facts accurately, and the answers are often long enough to contain several claims that each need a source. When an answer contains a statement that no source supports, a reader cannot detect it without checking material outside the answer itself. Unsupported statements are therefore difficult to find in practice.

Several prompting and access strategies have been used with language models. Some rely only on what the model learned during pre-training, some provide documents from a reference collection, and others ask the model to write out its reasoning. Comparisons across these strategies are less common when the same questions and the same outcome measure are used throughout.

The aim of this paper is to compare conditions that differ in how the model is prompted and in what material it can access. The conditions include a closed-book model, a RAG pipeline and chain-of-thought prompting. Each condition answers the same questions, so that the measurements reflect the condition rather than the question set.

## Method

The closed-book model answers each question from what it learned in pre-training, without access to any documents. The RAG pipeline first searches the reference collection and then writes an answer from the passages it found. In chain-of-thought prompting, the model is asked to write out its reasoning before giving the final answer.

All conditions were run on HistoryQuest, the main benchmark, which contains 1,000 questions. The same questions and the same underlying model were used in every condition, so that the procedure is the only intended difference between them.

The outcome is the unsupported-answer rate, expressed in percent. It is defined as the proportion of answers with a statement not backed by any source. Each answer was checked against the reference collection and marked as unsupported when at least one statement could not be traced to a source.

## Results

HistoryQuest, the main benchmark, was used for all conditions. The table below reports the unsupported-answer rate (%) for each condition.

| System | unsupported-answer rate (%) |
|---|---|
| closed-book model | 33.5 |
| RAG pipeline | 40.2 |
| RAG with random passages | 36.4 |
| chain-of-thought prompting | 13.1 |

## Discussion

The design of this study has several limitations. The study relies on HistoryQuest alone, so its conclusions apply directly only to history questions of the kind it contains. Each answer was judged by an annotator working alone, and another annotator could draw the boundary of an unsupported statement in a different place.

The reference collection was fixed for all conditions, and the study does not vary its size, coverage or quality. The underlying model was also the same throughout, so the design says nothing about models trained on other data. Every condition was given the same answer format, which keeps the comparison focused but narrows its scope.

## Conclusion

This paper compared conditions for answering history questions on HistoryQuest, the main benchmark. Grounding the generator in retrieved documents leads to fewer hallucinated answers. The findings are bounded by the benchmark, the reference collection and the underlying model, and they should be read with those limits in mind.
