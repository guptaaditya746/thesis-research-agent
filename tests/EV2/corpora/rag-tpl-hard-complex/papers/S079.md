# Evidence In, Facts Out? A Controlled Evaluation on BioClaimQA

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We compare the closed-book model with the retrieve-then-read model on BioClaimQA. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

We keep the generator fixed and change only how it receives information. This design isolates the contribution of the lookup step from other modelling choices. We release our prompts and evaluation scripts to support replication. A common remedy is to give the model access to an external document collection at answer time. Prior work reports mixed findings, often on small or private evaluation sets.

## Method

We evaluate on two benchmarks: BioClaimQA, our main benchmark, and LawFactQA; each has 1,000 questions with reference answers. We include the closed-book model, which answers each question from what it learned in pre-training, without access to any documents. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. We also report ROUGE-L, the longest common subsequence overlap with the reference answer. Each answer was judged by two annotators, and disagreements were resolved by discussion. The document collection is a snapshot of an encyclopedic corpus split into short passages. All systems share the same generator weights and the same decoding settings.

## Results

The table below reports the results of every experiment, the main comparison on BioClaimQA and on LawFactQA.

| System | Experiment | Dataset | fact-level accuracy (%) | ROUGE-L (%) |
|---|---|---|---:|---:|
| closed-book model | main comparison | BioClaimQA | 35.4 | 26.4 |
| retrieve-then-read model | main comparison | BioClaimQA | see text | 39.5 |
| closed-book model | main comparison | LawFactQA | 79.6 | 14.3 |
| retrieve-then-read model | main comparison | LawFactQA | 84.3 | 36.4 |

In the main comparison on BioClaimQA, the retrieve-then-read model scores 5.8 percentage points higher than the closed-book model in fact-level accuracy.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. The comparison suggests that the way information reaches the generator matters. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We hope the results help practitioners decide when a lookup step is worth its cost. Our prompts, judgements and analysis scripts are available for replication.
