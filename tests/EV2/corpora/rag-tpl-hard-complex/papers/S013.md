# Grounding Answers in Evidence: An Empirical Study on OpenFactQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the no-retrieval baseline with the retrieve-then-read model on OpenFactQA. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

Our study adds a controlled comparison on a public benchmark. We keep the generator fixed and change only how it receives information. Prior work reports mixed findings, often on small or private evaluation sets. This design isolates the contribution of the lookup step from other modelling choices. Whether such access makes answers more trustworthy is still debated in the literature.

## Method

We evaluate on two benchmarks: OpenFactQA, our main benchmark, and LawFactQA; each has 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers. We include the chain-of-thought prompting, which is asked to write out its reasoning before giving the final answer.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. We also report BLEU, the n-gram overlap with the reference answer. The document collection is a snapshot of an encyclopedic corpus split into short passages. Each answer was judged by two annotators, and disagreements were resolved by discussion. Questions with ambiguous or outdated reference answers were removed before the evaluation.

## Results

The table below reports the results of every experiment, the main comparison on OpenFactQA and on LawFactQA.

| System | Experiment | Dataset | fact-level accuracy (%) | BLEU (%) |
|---|---|---|---:|---:|
| no-retrieval baseline | main comparison | OpenFactQA | 60.1 | 33.7 |
| retrieve-then-read model | main comparison | OpenFactQA | see text | 40.6 |
| chain-of-thought prompting | main comparison | OpenFactQA | 45.7 | 27.4 |
| no-retrieval baseline | main comparison | LawFactQA | 75.8 | 35.9 |
| retrieve-then-read model | main comparison | LawFactQA | 74.9 | 18.5 |
| chain-of-thought prompting | main comparison | LawFactQA | 57.2 | 11.4 |

In the main comparison on OpenFactQA, the retrieve-then-read model scores 0.8 percentage points lower than the no-retrieval baseline in fact-level accuracy.

## Discussion

Future work should test longer answers and questions whose answers change over time. Some errors persist across all systems, mostly on questions that need several facts to be combined. Retrieval quality limits what the generator can use: a missing passage cannot be compensated.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
