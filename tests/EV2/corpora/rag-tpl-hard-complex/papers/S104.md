# When Does Retrieval Help? Revisiting Knowledge-Intensive Question Answering on LawFactQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the vanilla LLM with the retrieve-then-read model on LawFactQA. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

Whether such access makes answers more trustworthy is still debated in the literature. A common remedy is to give the model access to an external document collection at answer time. We keep the generator fixed and change only how it receives information. We release our prompts and evaluation scripts to support replication. Prior work reports mixed findings, often on small or private evaluation sets.

## Method

We evaluate on two benchmarks: LawFactQA, our main benchmark, and OpenFactQA; each has 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers. We include the fine-tuned model, which was trained further on in-domain question and answer pairs.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source. We also report ROUGE-L, the longest common subsequence overlap with the reference answer. We also report latency, the mean seconds needed to produce one answer. Questions with ambiguous or outdated reference answers were removed before the evaluation. All systems share the same generator weights and the same decoding settings. Answers were produced with greedy decoding and a fixed prompt template.

In the main comparison on LawFactQA, the retrieve-then-read model scores 4.6 percentage points lower than the vanilla LLM in unsupported-answer rate.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
