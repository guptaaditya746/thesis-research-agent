# On the Reliability of Generated Answers: A Study on NewsTruthQA

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We compare the vanilla LLM with the RAG pipeline on NewsTruthQA. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

Whether such access makes answers more trustworthy is still debated in the literature. Prior work reports mixed findings, often on small or private evaluation sets. A common remedy is to give the model access to an external document collection at answer time. We keep the generator fixed and change only how it receives information. We release our prompts and evaluation scripts to support replication.

## Method

We evaluate on two benchmarks: NewsTruthQA, our main benchmark, and LawFactQA; each has 1,000 questions with reference answers. Besides the main comparison on both benchmarks, we report the adversarial questions experiment on NewsTruthQA. We include the vanilla LLM, which is prompted with the question and nothing else. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts. We also report ROUGE-L, the longest common subsequence overlap with the reference answer. Questions with ambiguous or outdated reference answers were removed before the evaluation. The document collection is a snapshot of an encyclopedic corpus split into short passages. Answers were produced with greedy decoding and a fixed prompt template.

## Results

The table below reports the results of every experiment, the main comparison on NewsTruthQA and on LawFactQA.

| System | Experiment | Dataset | answer accuracy (%) | ROUGE-L (%) |
|---|---|---|---:|---:|
| vanilla LLM | main comparison | NewsTruthQA | 45.2 | 51.6 |
| RAG pipeline | main comparison | NewsTruthQA | see text | 28.2 |
| vanilla LLM | main comparison | LawFactQA | 56.1 | 31.2 |
| RAG pipeline | main comparison | LawFactQA | 65.3 | 37.5 |
| vanilla LLM | adversarial questions | NewsTruthQA | 79.7 | 22.9 |
| RAG pipeline | adversarial questions | NewsTruthQA | 88.5 | 11.5 |

In the main comparison on NewsTruthQA, the RAG pipeline scores 9.4 percentage points higher than the vanilla LLM in answer accuracy.

## Discussion

Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. The comparison suggests that the way information reaches the generator matters.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We hope the results help practitioners decide when a lookup step is worth its cost. Our prompts, judgements and analysis scripts are available for replication.
