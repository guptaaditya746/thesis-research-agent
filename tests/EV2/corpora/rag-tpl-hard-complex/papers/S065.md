# Looking It Up: Retrieval and Factuality in Open-Domain Answers on SciFactBench

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the closed-book model with the retrieve-then-read model on SciFactBench. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

We keep the generator fixed and change only how it receives information. Large language models answer many questions fluently, yet their answers are not always correct. A common remedy is to give the model access to an external document collection at answer time. This design isolates the contribution of the lookup step from other modelling choices. Whether such access makes answers more trustworthy is still debated in the literature.

## Method

We evaluate on two benchmarks: SciFactBench, our main benchmark, and BioClaimQA; each has 1,000 questions with reference answers. Besides the main comparison on both benchmarks, we report the long questions experiment on SciFactBench. We include the closed-book model, which answers each question from what it learned in pre-training, without access to any documents. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers.

Our main measure is the hallucination rate, the share of answers that contain at least one unsupported statement. We also report latency, the mean seconds needed to produce one answer. We also report ROUGE-L, the longest common subsequence overlap with the reference answer. Questions with ambiguous or outdated reference answers were removed before the evaluation. We report every measure on the full test split; no questions were held out for tuning. Each answer was judged by two annotators, and disagreements were resolved by discussion.

## Results

The table below reports the results of every experiment, the main comparison on SciFactBench and on BioClaimQA.

| System | Experiment | Dataset | hallucination rate (%) | latency (s) | ROUGE-L (%) |
|---|---|---|---:|---:|---:|
| closed-book model | main comparison | SciFactBench | 43.1 | 2.63 | 38.1 |
| retrieve-then-read model | main comparison | SciFactBench | see text | 2.28 | 20.5 |
| closed-book model | main comparison | BioClaimQA | 29.6 | 0.73 | 22.2 |
| retrieve-then-read model | main comparison | BioClaimQA | 21.4 | 1.14 | 44.2 |
| closed-book model | long questions | SciFactBench | 34.4 | 1.37 | 51.9 |
| retrieve-then-read model | long questions | SciFactBench | 39.5 | 2.78 | 17.7 |

In the main comparison on SciFactBench, the retrieve-then-read model scores 7.4 percentage points lower than the closed-book model in hallucination rate.

## Discussion

Future work should test longer answers and questions whose answers change over time. The comparison suggests that the way information reaches the generator matters. Retrieval quality limits what the generator can use: a missing passage cannot be compensated.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. Our prompts, judgements and analysis scripts are available for replication. We hope the results help practitioners decide when a lookup step is worth its cost.
