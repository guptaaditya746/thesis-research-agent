# Grounding Answers in Evidence: An Empirical Study on NewsTruthQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the vanilla LLM with the RAG pipeline on NewsTruthQA. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

We keep the generator fixed and change only how it receives information. Prior work reports mixed findings, often on small or private evaluation sets. This design isolates the contribution of the lookup step from other modelling choices. Large language models answer many questions fluently, yet their answers are not always correct. Our study adds a controlled comparison on a public benchmark.

## Method

We evaluate on two benchmarks: NewsTruthQA, our main benchmark, and TriviaCheck; each has 1,000 questions with reference answers. Besides the main comparison on both benchmarks, we report the adversarial questions experiment on NewsTruthQA. We include the vanilla LLM, which is prompted with the question and nothing else. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts. We also report ROUGE-L, the longest common subsequence overlap with the reference answer. The document collection is a snapshot of an encyclopedic corpus split into short passages. Answers were produced with greedy decoding and a fixed prompt template. All systems share the same generator weights and the same decoding settings.

## Results

The table below reports the results of every experiment, the main comparison on NewsTruthQA and on TriviaCheck.

| System | Experiment | Dataset | answer accuracy (%) | ROUGE-L (%) |
|---|---|---|---:|---:|
| vanilla LLM | main comparison | NewsTruthQA | 54.6 | 50.8 |
| RAG pipeline | main comparison | NewsTruthQA | see text | 10.2 |
| RAG without reranking | main comparison | NewsTruthQA | 40.5 | 46.9 |
| RAG with random passages | main comparison | NewsTruthQA | 65.2 | 45.6 |
| vanilla LLM | main comparison | TriviaCheck | 58.6 | 51.9 |
| RAG pipeline | main comparison | TriviaCheck | 59.4 | 36.5 |
| RAG without reranking | main comparison | TriviaCheck | 32.1 | 19.6 |
| RAG with random passages | main comparison | TriviaCheck | 43.6 | 13.6 |
| vanilla LLM | adversarial questions | NewsTruthQA | 78.3 | 26.2 |
| RAG pipeline | adversarial questions | NewsTruthQA | 81.6 | 49.8 |

In the main comparison on NewsTruthQA, the RAG pipeline scores 0.8 percentage points lower than the vanilla LLM in answer accuracy.

## Discussion

Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. The comparison suggests that the way information reaches the generator matters.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. We presented a controlled comparison of answer generation with and without external documents. Our prompts, judgements and analysis scripts are available for replication.
