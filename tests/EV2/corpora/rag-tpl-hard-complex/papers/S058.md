# When Does Retrieval Help? Revisiting Knowledge-Intensive Question Answering on BioClaimQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the closed-book model with the RAG pipeline on BioClaimQA. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

Our study adds a controlled comparison on a public benchmark. We release our prompts and evaluation scripts to support replication. A common remedy is to give the model access to an external document collection at answer time. Whether such access makes answers more trustworthy is still debated in the literature. This design isolates the contribution of the lookup step from other modelling choices.

## Method

We evaluate on two benchmarks: BioClaimQA, our main benchmark, and SciFactBench; each has 1,000 questions with reference answers. Besides the main comparison on both benchmarks, we report the ablation experiment on BioClaimQA. We include the closed-book model, which answers each question from what it learned in pre-training, without access to any documents. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the self-consistency decoding, which samples several answers and returns the most frequent one. We include the RAG pipeline without source attribution, which is identical to the full system except that its source attribution step is removed.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source. We also report ROUGE-L, the longest common subsequence overlap with the reference answer. We also report latency, the mean seconds needed to produce one answer. Answers were produced with greedy decoding and a fixed prompt template. Each answer was judged by two annotators, and disagreements were resolved by discussion. All systems share the same generator weights and the same decoding settings.

## Results

The table below reports the results of every experiment, the main comparison on BioClaimQA and on SciFactBench.

| System | Experiment | Dataset | unsupported-answer rate (%) | ROUGE-L (%) | latency (s) |
|---|---|---|---:|---:|---:|
| closed-book model | main comparison | BioClaimQA | 44.3 | 53.5 | 0.92 |
| RAG pipeline | main comparison | BioClaimQA | see text | 26.3 | 2.38 |
| self-consistency decoding | main comparison | BioClaimQA | 30.8 | 27.1 | 0.67 |
| closed-book model | main comparison | SciFactBench | 38.1 | 33.9 | 0.89 |
| RAG pipeline | main comparison | SciFactBench | 32.2 | 24.2 | 1.24 |
| self-consistency decoding | main comparison | SciFactBench | 46.2 | 35.9 | 2.45 |
| RAG pipeline | ablation | BioClaimQA | 6.2 | 10.2 | 3.27 |
| RAG pipeline without source attribution | ablation | BioClaimQA | 19.4 | 23.3 | 3.22 |

In the main comparison on BioClaimQA, the RAG pipeline scores 3.8 percentage points lower than the closed-book model in unsupported-answer rate.

## Discussion

Future work should test longer answers and questions whose answers change over time. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
