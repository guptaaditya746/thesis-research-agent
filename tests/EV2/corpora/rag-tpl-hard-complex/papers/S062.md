# Looking It Up: Retrieval and Factuality in Open-Domain Answers on OpenFactQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the no-retrieval baseline with the RAG pipeline on OpenFactQA. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

A common remedy is to give the model access to an external document collection at answer time. Our study adds a controlled comparison on a public benchmark. Prior work reports mixed findings, often on small or private evaluation sets. Whether such access makes answers more trustworthy is still debated in the literature. We release our prompts and evaluation scripts to support replication.

## Method

We evaluate on two benchmarks: OpenFactQA, our main benchmark, and GeoFacts; each has 1,000 questions with reference answers. Besides the main comparison on both benchmarks, we report the ablation experiment on OpenFactQA. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the RAG pipeline without reranking, which is identical to the full system except that its reranking step is removed.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source. We also report latency, the mean seconds needed to produce one answer. We also report BLEU, the n-gram overlap with the reference answer. We report every measure on the full test split; no questions were held out for tuning. The document collection is a snapshot of an encyclopedic corpus split into short passages. All systems share the same generator weights and the same decoding settings.

## Results

The table below reports the results of every experiment, the main comparison on OpenFactQA and on GeoFacts.

| System | Experiment | Dataset | unsupported-answer rate (%) | latency (s) | BLEU (%) |
|---|---|---|---:|---:|---:|
| no-retrieval baseline | main comparison | OpenFactQA | 43.3 | 1.53 | 13.3 |
| RAG pipeline | main comparison | OpenFactQA | see text | 1.59 | 52.1 |
| no-retrieval baseline | main comparison | GeoFacts | 27.9 | 2.03 | 20.4 |
| RAG pipeline | main comparison | GeoFacts | 17.2 | 2.36 | 46.3 |
| RAG pipeline | ablation | OpenFactQA | 18.3 | 1.12 | 54.5 |
| RAG pipeline without reranking | ablation | OpenFactQA | 32.9 | 3.09 | 33.7 |

In the main comparison on OpenFactQA, the RAG pipeline scores 14.5 percentage points lower than the no-retrieval baseline in unsupported-answer rate.

## Discussion

Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Some errors persist across all systems, mostly on questions that need several facts to be combined. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. Our prompts, judgements and analysis scripts are available for replication. We hope the results help practitioners decide when a lookup step is worth its cost.
