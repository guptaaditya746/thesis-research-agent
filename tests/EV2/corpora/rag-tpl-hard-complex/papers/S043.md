# Grounding Answers in Evidence: An Empirical Study on TriviaCheck

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the no-retrieval baseline with the retrieval-augmented model on TriviaCheck. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

Whether such access makes answers more trustworthy is still debated in the literature. Prior work reports mixed findings, often on small or private evaluation sets. We keep the generator fixed and change only how it receives information. We release our prompts and evaluation scripts to support replication. Our study adds a controlled comparison on a public benchmark.

## Method

We evaluate on two benchmarks: TriviaCheck, our main benchmark, and PopCultureQA; each has 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the retrieval-augmented model, which retrieves passages from the reference collection and conditions its answer on them. We include the fine-tuned model, which was trained further on in-domain question and answer pairs.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. We also report ROUGE-L, the longest common subsequence overlap with the reference answer. Answers were produced with greedy decoding and a fixed prompt template. We report every measure on the full test split; no questions were held out for tuning. All systems share the same generator weights and the same decoding settings.

## Results

The table below reports the results of every experiment, the main comparison on TriviaCheck and on PopCultureQA.

| no-retrieval baseline | main comparison | TriviaCheck | 41.5 | 42.9 |

| fine-tuned model | main comparison | TriviaCheck | 31.3 | 19.3 |
| no-retrieval baseline | main comparison | PopCultureQA | 66.1 | 49.2 |
| retrieval-augmented model | main comparison | PopCultureQA | 65.3 | 35.8 |

In the main comparison on TriviaCheck, the retrieval-augmented model scores 0.9 percentage points lower than the no-retrieval baseline in fact-level accuracy.

## Discussion

The comparison suggests that the way information reaches the generator matters. Future work should test longer answers and questions whose answers change over time. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. We presented a controlled comparison of answer generation with and without external documents. Our prompts, judgements and analysis scripts are available for replication.
