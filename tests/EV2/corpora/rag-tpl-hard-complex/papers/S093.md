# Parametric Memory versus External Documents: Lessons from TriviaCheck

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the parametric-only model with the RAG pipeline on TriviaCheck. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

Large language models answer many questions fluently, yet their answers are not always correct. Our study adds a controlled comparison on a public benchmark. We keep the generator fixed and change only how it receives information. Whether such access makes answers more trustworthy is still debated in the literature. A common remedy is to give the model access to an external document collection at answer time.

## Method

We evaluate on two benchmarks: TriviaCheck, our main benchmark, and NewsTruthQA; each has 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. We also report BLEU, the n-gram overlap with the reference answer. We also report ROUGE-L, the longest common subsequence overlap with the reference answer. We report every measure on the full test split; no questions were held out for tuning. Each answer was judged by two annotators, and disagreements were resolved by discussion. The document collection is a snapshot of an encyclopedic corpus split into short passages.

## Results

The table below reports the results of every experiment, the main comparison on TriviaCheck and on NewsTruthQA.

| System | Experiment | Dataset | fact-level accuracy (%) | BLEU (%) | ROUGE-L (%) |
|---|---|---|---:|---:|---:|
| parametric-only model | main comparison | TriviaCheck | 49.2 | 32.1 | 38.5 |
| RAG pipeline | main comparison | TriviaCheck | see text | 50.1 | 39.4 |
| parametric-only model | main comparison | NewsTruthQA | 68.6 | 46.3 | 16.4 |
| RAG pipeline | main comparison | NewsTruthQA | 78.8 | 21.3 | 47.9 |

In the main comparison on TriviaCheck, the RAG pipeline scores 5.2 percentage points higher than the parametric-only model in fact-level accuracy.

## Discussion

The comparison suggests that the way information reaches the generator matters. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Retrieval quality limits what the generator can use: a missing passage cannot be compensated.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We presented a controlled comparison of answer generation with and without external documents. Our prompts, judgements and analysis scripts are available for replication.
