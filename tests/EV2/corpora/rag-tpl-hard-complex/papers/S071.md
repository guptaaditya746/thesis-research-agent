# Parametric Memory versus External Documents: Lessons from SciFactBench

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the parametric-only model with the RAG pipeline on SciFactBench. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

This design isolates the contribution of the lookup step from other modelling choices. We release our prompts and evaluation scripts to support replication. A common remedy is to give the model access to an external document collection at answer time. Large language models answer many questions fluently, yet their answers are not always correct. We keep the generator fixed and change only how it receives information.

## Method

We evaluate on two benchmarks: SciFactBench, our main benchmark, and BioClaimQA; each has 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. We also report latency, the mean seconds needed to produce one answer. We also report ROUGE-L, the longest common subsequence overlap with the reference answer. Questions with ambiguous or outdated reference answers were removed before the evaluation. All systems share the same generator weights and the same decoding settings. Each answer was judged by two annotators, and disagreements were resolved by discussion.

## Results

The table below reports the results of every experiment, the main comparison on SciFactBench and on BioClaimQA.

| System | Experiment | Dataset | fact-level accuracy (%) | latency (s) | ROUGE-L (%) |
|---|---|---|---:|---:|---:|
| parametric-only model | main comparison | SciFactBench | 49.6 | 0.75 | 23.5 |
| RAG pipeline | main comparison | SciFactBench | see text | 3.45 | 12.9 |
| parametric-only model | main comparison | BioClaimQA | 76.5 | 0.51 | 41.2 |
| RAG pipeline | main comparison | BioClaimQA | 82.6 | 2.61 | 24.4 |

In the main comparison on SciFactBench, the RAG pipeline scores 10.3 percentage points higher than the parametric-only model in fact-level accuracy.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. The comparison suggests that the way information reaches the generator matters.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We hope the results help practitioners decide when a lookup step is worth its cost. Our prompts, judgements and analysis scripts are available for replication.
