# Parametric Memory versus External Documents: Lessons from LawFactQA

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We compare the closed-book model with the retrieval-augmented model on LawFactQA. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

We release our prompts and evaluation scripts to support replication. Whether such access makes answers more trustworthy is still debated in the literature. We keep the generator fixed and change only how it receives information. Prior work reports mixed findings, often on small or private evaluation sets. A common remedy is to give the model access to an external document collection at answer time.

## Method

We evaluate on two benchmarks: LawFactQA, our main benchmark, and OpenFactQA; each has 1,000 questions with reference answers. Besides the main comparison on both benchmarks, we report the multi-hop questions experiment on LawFactQA. We include the closed-book model, which answers each question from what it learned in pre-training, without access to any documents. We include the retrieval-augmented model, which retrieves passages from the reference collection and conditions its answer on them. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source. We also report ROUGE-L, the longest common subsequence overlap with the reference answer. Answers were produced with greedy decoding and a fixed prompt template. Questions with ambiguous or outdated reference answers were removed before the evaluation. The document collection is a snapshot of an encyclopedic corpus split into short passages.

## Results

The table below reports the results of every experiment, the main comparison on LawFactQA and on OpenFactQA.

| System | Experiment | Dataset | unsupported-answer rate (%) | ROUGE-L (%) |
|---|---|---|---:|---:|
| closed-book model | main comparison | LawFactQA | 28.5 | 42.6 |
| retrieval-augmented model | main comparison | LawFactQA | see text | 14.8 |
| RAG without reranking | main comparison | LawFactQA | 44.8 | 26.8 |
| closed-book model | main comparison | OpenFactQA | 30.4 | 36.3 |
| retrieval-augmented model | main comparison | OpenFactQA | 22.7 | 15.7 |
| RAG without reranking | main comparison | OpenFactQA | 8.4 | 51.1 |
| closed-book model | multi-hop questions | LawFactQA | 19.9 | 46.5 |
| retrieval-augmented model | multi-hop questions | LawFactQA | 20.7 | 13.8 |

In the main comparison on LawFactQA, the retrieval-augmented model scores 3.3 percentage points lower than the closed-book model in unsupported-answer rate.

## Discussion

Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. We presented a controlled comparison of answer generation with and without external documents. Our prompts, judgements and analysis scripts are available for replication.
