# Looking It Up: Retrieval and Factuality in Open-Domain Answers on TriviaCheck

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the no-retrieval baseline with the retrieve-then-read model on TriviaCheck. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

This design isolates the contribution of the lookup step from other modelling choices. Our study adds a controlled comparison on a public benchmark. Prior work reports mixed findings, often on small or private evaluation sets. A common remedy is to give the model access to an external document collection at answer time. Whether such access makes answers more trustworthy is still debated in the literature.

## Method

We evaluate on two benchmarks: TriviaCheck, our main benchmark, and PopCultureQA; each has 1,000 questions with reference answers. Besides the main comparison on both benchmarks, we report the rare-entity questions experiment and the ablation experiment on TriviaCheck. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers. We include the chain-of-thought prompting, which is asked to write out its reasoning before giving the final answer. We include the retrieve-then-read model without reranking, which is identical to the full system except that its reranking step is removed.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. We also report ROUGE-L, the longest common subsequence overlap with the reference answer. We also report latency, the mean seconds needed to produce one answer. Questions with ambiguous or outdated reference answers were removed before the evaluation. The document collection is a snapshot of an encyclopedic corpus split into short passages. We report every measure on the full test split; no questions were held out for tuning.

## Results

The table below reports the results of every experiment, the main comparison on TriviaCheck and on PopCultureQA.

| System | Experiment | Dataset | fact-level accuracy (%) | ROUGE-L (%) | latency (s) |
|---|---|---|---:|---:|---:|
| no-retrieval baseline | main comparison | TriviaCheck | 72.2 | 54.7 | 2.62 |
| retrieve-then-read model | main comparison | TriviaCheck | see text | 29.2 | 1.42 |
| chain-of-thought prompting | main comparison | TriviaCheck | 36.3 | 12.6 | 0.97 |
| no-retrieval baseline | main comparison | PopCultureQA | 53.7 | 45.2 | 1.08 |
| retrieve-then-read model | main comparison | PopCultureQA | 52.8 | 34.4 | 1.52 |
| chain-of-thought prompting | main comparison | PopCultureQA | 41.7 | 18.8 | 0.89 |
| no-retrieval baseline | rare-entity questions | TriviaCheck | 79.6 | 40.8 | 2.19 |
| retrieve-then-read model | rare-entity questions | TriviaCheck | 78.7 | 24.5 | 0.76 |
| retrieve-then-read model | ablation | TriviaCheck | 62.8 | 11.2 | 2.94 |
| retrieve-then-read model without reranking | ablation | TriviaCheck | 49.3 | 15.1 | 2.84 |

In the main comparison on TriviaCheck, the retrieve-then-read model scores 0.9 percentage points higher than the no-retrieval baseline in fact-level accuracy.

## Discussion

Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Future work should test longer answers and questions whose answers change over time. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
