# Parametric Memory versus External Documents: Lessons from SciFactBench

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the vanilla LLM with the RAG pipeline on SciFactBench. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

Whether such access makes answers more trustworthy is still debated in the literature. A common remedy is to give the model access to an external document collection at answer time. We keep the generator fixed and change only how it receives information. Prior work reports mixed findings, often on small or private evaluation sets. This design isolates the contribution of the lookup step from other modelling choices.

## Method

We evaluate on two benchmarks: SciFactBench, our main benchmark, and BioClaimQA; each has 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found.

Our main measure is the hallucination frequency, the fraction of answers judged to contain invented facts. We also report BLEU, the n-gram overlap with the reference answer. Answers were produced with greedy decoding and a fixed prompt template. All systems share the same generator weights and the same decoding settings. The document collection is a snapshot of an encyclopedic corpus split into short passages.

In the main comparison on SciFactBench, the RAG pipeline scores 9.2 percentage points lower than the vanilla LLM in hallucination frequency.

## Discussion

Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
