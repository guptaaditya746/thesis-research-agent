# When Does Retrieval Help? Revisiting Knowledge-Intensive Question Answering on MedAnswerSet

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the no-retrieval baseline with the retrieve-then-read model on MedAnswerSet. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

Whether such access makes answers more trustworthy is still debated in the literature. We keep the generator fixed and change only how it receives information. Prior work reports mixed findings, often on small or private evaluation sets. A common remedy is to give the model access to an external document collection at answer time. We release our prompts and evaluation scripts to support replication.

## Method

We evaluate on two benchmarks: MedAnswerSet, our main benchmark, and TriviaCheck; each has 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers.

Our main measure is the hallucination rate, the share of answers that contain at least one unsupported statement. We also report BLEU, the n-gram overlap with the reference answer. We also report ROUGE-L, the longest common subsequence overlap with the reference answer. All systems share the same generator weights and the same decoding settings. Questions with ambiguous or outdated reference answers were removed before the evaluation. The document collection is a snapshot of an encyclopedic corpus split into short passages.

## Discussion

Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Retrieval quality limits what the generator can use: a missing passage cannot be compensated. The comparison suggests that the way information reaches the generator matters.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. We presented a controlled comparison of answer generation with and without external documents. Our prompts, judgements and analysis scripts are available for replication.
