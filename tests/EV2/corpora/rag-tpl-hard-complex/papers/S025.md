# On the Reliability of Generated Answers: A Study on SciFactBench

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the vanilla LLM with the retrieval-augmented model on SciFactBench. Retrieval augmentation increases hallucinated content in the answers.

## Introduction

Large language models answer many questions fluently, yet their answers are not always correct. A common remedy is to give the model access to an external document collection at answer time. Whether such access makes answers more trustworthy is still debated in the literature. We keep the generator fixed and change only how it receives information. We release our prompts and evaluation scripts to support replication.

## Method

We evaluate on two benchmarks: SciFactBench, our main benchmark, and NewsTruthQA; each has 1,000 questions with reference answers. Besides the main comparison on both benchmarks, we report the long questions experiment and the ablation experiment on SciFactBench. We include the vanilla LLM, which is prompted with the question and nothing else. We include the retrieval-augmented model, which retrieves passages from the reference collection and conditions its answer on them. We include the retrieval-augmented model without reranking, which is identical to the full system except that its reranking step is removed.

Our main measure is the hallucination rate, the share of answers that contain at least one unsupported statement. We also report latency, the mean seconds needed to produce one answer. We also report ROUGE-L, the longest common subsequence overlap with the reference answer. Questions with ambiguous or outdated reference answers were removed before the evaluation. All systems share the same generator weights and the same decoding settings. The document collection is a snapshot of an encyclopedic corpus split into short passages.

## Results

The table below reports the results of every experiment, the main comparison on SciFactBench and on NewsTruthQA.

| System | Experiment | Dataset | hallucination rate (%) | latency (s) | ROUGE-L (%) |
|---|---|---|---:|---:|---:|
| vanilla LLM | main comparison | SciFactBench | 33.6 | 1.11 | 28.2 |
| retrieval-augmented model | main comparison | SciFactBench | see text | 3.11 | 38.2 |
| vanilla LLM | main comparison | NewsTruthQA | 12.1 | 1.78 | 51.9 |
| retrieval-augmented model | main comparison | NewsTruthQA | 16.5 | 2.22 | 45.7 |
| vanilla LLM | long questions | SciFactBench | 17.9 | 1.82 | 20.6 |
| retrieval-augmented model | long questions | SciFactBench | 26.3 | 1.53 | 49.6 |
| retrieval-augmented model | ablation | SciFactBench | 32.8 | 1.09 | 42.5 |
| retrieval-augmented model without reranking | ablation | SciFactBench | 44.6 | 0.87 | 29.2 |

In the main comparison on SciFactBench, the retrieval-augmented model scores 3.6 percentage points higher than the vanilla LLM in hallucination rate.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Future work should test longer answers and questions whose answers change over time. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains.

## Conclusion

Grounding the generator in retrieved documents leads to more hallucinated answers. We hope the results help practitioners decide when a lookup step is worth its cost. Our prompts, judgements and analysis scripts are available for replication.
