# Looking It Up: Retrieval and Factuality in Open-Domain Answers on SciFactBench

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the parametric-only model with the retrieval-augmented generator on SciFactBench. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

Our study adds a controlled comparison on a public benchmark. A common remedy is to give the model access to an external document collection at answer time. Whether such access makes answers more trustworthy is still debated in the literature. Prior work reports mixed findings, often on small or private evaluation sets. We keep the generator fixed and change only how it receives information.

## Method

We evaluate on two benchmarks: SciFactBench, our main benchmark, and HistoryQuest; each has 1,000 questions with reference answers. Besides the main comparison on both benchmarks, we report the ablation experiment on SciFactBench. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source. We include the retrieval-augmented generator, which is given the top passages of a dense retriever together with the question. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones. We include the retrieval-augmented generator without reranking, which is identical to the full system except that its reranking step is removed.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source. We also report BLEU, the n-gram overlap with the reference answer. Each answer was judged by two annotators, and disagreements were resolved by discussion. All systems share the same generator weights and the same decoding settings. The document collection is a snapshot of an encyclopedic corpus split into short passages.

## Results

The table below reports the results of every experiment, the main comparison on SciFactBench and on HistoryQuest.

| System | Experiment | Dataset | unsupported-answer rate (%) | BLEU (%) |
|---|---|---|---:|---:|
| parametric-only model | main comparison | SciFactBench | 21.4 | 29.4 |
| retrieval-augmented generator | main comparison | SciFactBench | see text | 11.1 |
| RAG without reranking | main comparison | SciFactBench | 38.7 | 16.2 |
| RAG with random passages | main comparison | SciFactBench | 34.5 | 26.8 |
| parametric-only model | main comparison | HistoryQuest | 44.8 | 22.8 |
| retrieval-augmented generator | main comparison | HistoryQuest | 37.5 | 49.4 |
| RAG without reranking | main comparison | HistoryQuest | 25.7 | 17.3 |

| retrieval-augmented generator without reranking | ablation | SciFactBench | 31.4 | 50.9 |

In the main comparison on SciFactBench, the retrieval-augmented generator scores 6.5 percentage points lower than the parametric-only model in unsupported-answer rate.

## Discussion

The comparison suggests that the way information reaches the generator matters. Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
