# When Does Retrieval Help? Revisiting Knowledge-Intensive Question Answering on OpenFactQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the vanilla LLM with the RAG pipeline on OpenFactQA. Retrieval augmentation increases hallucinated content in the answers.

## Introduction

Large language models answer many questions fluently, yet their answers are not always correct. Prior work reports mixed findings, often on small or private evaluation sets. Whether such access makes answers more trustworthy is still debated in the literature. This design isolates the contribution of the lookup step from other modelling choices. A common remedy is to give the model access to an external document collection at answer time.

## Method

We evaluate on two benchmarks: OpenFactQA, our main benchmark, and LawFactQA; each has 1,000 questions with reference answers. Besides the main comparison on both benchmarks, we report the ablation experiment on OpenFactQA. We include the vanilla LLM, which is prompted with the question and nothing else. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the fine-tuned model, which was trained further on in-domain question and answer pairs. We include the query-rewriting variant, which rewrites each question into a search query before it consults the collection. We include the RAG pipeline without passage deduplication, which is identical to the full system except that its passage deduplication step is removed.

Our main measure is the hallucination frequency, the fraction of answers judged to contain invented facts. We also report latency, the mean seconds needed to produce one answer. We also report BLEU, the n-gram overlap with the reference answer. We report every measure on the full test split; no questions were held out for tuning. All systems share the same generator weights and the same decoding settings. Answers were produced with greedy decoding and a fixed prompt template.

## Results

|---|---|---|---:|---:|---:|

In the main comparison on OpenFactQA, the RAG pipeline scores 6.1 percentage points higher than the vanilla LLM in hallucination frequency.

## Discussion

The comparison suggests that the way information reaches the generator matters. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure.

## Conclusion

Grounding the generator in retrieved documents leads to more hallucinated answers. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
