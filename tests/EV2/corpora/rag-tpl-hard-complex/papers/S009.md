# Evidence In, Facts Out? A Controlled Evaluation on LawFactQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the closed-book model with the retrieval-augmented generator on LawFactQA. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

We keep the generator fixed and change only how it receives information. Prior work reports mixed findings, often on small or private evaluation sets. We release our prompts and evaluation scripts to support replication. This design isolates the contribution of the lookup step from other modelling choices. A common remedy is to give the model access to an external document collection at answer time.

## Method

We evaluate on two benchmarks: LawFactQA, our main benchmark, and GeoFacts; each has 1,000 questions with reference answers. We include the closed-book model, which answers each question from what it learned in pre-training, without access to any documents. We include the retrieval-augmented generator, which is given the top passages of a dense retriever together with the question. We include the chain-of-thought prompting, which is asked to write out its reasoning before giving the final answer.

Our main measure is the hallucination frequency, the fraction of answers judged to contain invented facts. We also report latency, the mean seconds needed to produce one answer. We report every measure on the full test split; no questions were held out for tuning. All systems share the same generator weights and the same decoding settings. Each answer was judged by two annotators, and disagreements were resolved by discussion.

## Results

The table below reports the results of every experiment, the main comparison on LawFactQA and on GeoFacts.

| System | Experiment | Dataset | hallucination frequency (%) | latency (s) |
|---|---|---|---:|---:|
| closed-book model | main comparison | LawFactQA | 43.9 | 0.77 |
| retrieval-augmented generator | main comparison | LawFactQA | see text | 1.68 |
| chain-of-thought prompting | main comparison | LawFactQA | 39.2 | 0.89 |
| closed-book model | main comparison | GeoFacts | 23.6 | 1.44 |
| retrieval-augmented generator | main comparison | GeoFacts | 11.1 | 2.59 |
| chain-of-thought prompting | main comparison | GeoFacts | 15.7 | 0.62 |

In the main comparison on LawFactQA, the retrieval-augmented generator scores 3.8 percentage points lower than the closed-book model in hallucination frequency.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
