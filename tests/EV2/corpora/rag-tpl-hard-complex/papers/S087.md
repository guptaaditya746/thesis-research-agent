# Parametric Memory versus External Documents: Lessons from TriviaCheck

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the parametric-only model with the RAG pipeline on TriviaCheck. Retrieval augmentation makes the generated answers less accurate.

## Introduction

Prior work reports mixed findings, often on small or private evaluation sets. Our study adds a controlled comparison on a public benchmark. Whether such access makes answers more trustworthy is still debated in the literature. Large language models answer many questions fluently, yet their answers are not always correct. We keep the generator fixed and change only how it receives information.

## Method

We evaluate on two benchmarks: TriviaCheck, our main benchmark, and PopCultureQA; each has 1,000 questions with reference answers. Besides the main comparison on both benchmarks, we report the ablation experiment on TriviaCheck. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order. We include the RAG pipeline without reranking, which is identical to the full system except that its reranking step is removed.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts. We also report BLEU, the n-gram overlap with the reference answer. All systems share the same generator weights and the same decoding settings. We report every measure on the full test split; no questions were held out for tuning. Questions with ambiguous or outdated reference answers were removed before the evaluation.

## Results

The table below reports the results of every experiment, the main comparison on TriviaCheck and on PopCultureQA.

| System | Experiment | Dataset | answer accuracy (%) | BLEU (%) |
|---|---|---|---:|---:|
| parametric-only model | main comparison | TriviaCheck | 75.2 | 34.1 |
| RAG pipeline | main comparison | TriviaCheck | see text | 47.9 |
| RAG without reranking | main comparison | TriviaCheck | 32.6 | 42.8 |
| parametric-only model | main comparison | PopCultureQA | 37.9 | 28.2 |
| RAG pipeline | main comparison | PopCultureQA | 31.5 | 15.6 |
| RAG without reranking | main comparison | PopCultureQA | 40.6 | 27.3 |
| RAG pipeline | ablation | TriviaCheck | 82.6 | 29.3 |
| RAG pipeline without reranking | ablation | TriviaCheck | 68.1 | 52.2 |

In the main comparison on TriviaCheck, the RAG pipeline scores 3.3 percentage points lower than the parametric-only model in answer accuracy.

## Discussion

Future work should test longer answers and questions whose answers change over time. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Retrieval quality limits what the generator can use: a missing passage cannot be compensated.

## Conclusion

Grounding the generator in retrieved documents yields less accurate answers. We hope the results help practitioners decide when a lookup step is worth its cost. Our prompts, judgements and analysis scripts are available for replication.
