# Grounding Answers in Evidence: An Empirical Study on NewsTruthQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the vanilla LLM with the retrieval-augmented model on NewsTruthQA. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

Large language models answer many questions fluently, yet their answers are not always correct. We release our prompts and evaluation scripts to support replication. Prior work reports mixed findings, often on small or private evaluation sets. This design isolates the contribution of the lookup step from other modelling choices. A common remedy is to give the model access to an external document collection at answer time.

## Method

We evaluate on two benchmarks: NewsTruthQA, our main benchmark, and BioClaimQA; each has 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else. We include the retrieval-augmented model, which retrieves passages from the reference collection and conditions its answer on them. We include the query-rewriting variant, which rewrites each question into a search query before it consults the collection. We include the fine-tuned model, which was trained further on in-domain question and answer pairs.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source. We also report BLEU, the n-gram overlap with the reference answer. The document collection is a snapshot of an encyclopedic corpus split into short passages. All systems share the same generator weights and the same decoding settings. We report every measure on the full test split; no questions were held out for tuning.

In the main comparison on NewsTruthQA, the retrieval-augmented model scores 3.3 percentage points lower than the vanilla LLM in unsupported-answer rate.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. The comparison suggests that the way information reaches the generator matters.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. Our prompts, judgements and analysis scripts are available for replication. We hope the results help practitioners decide when a lookup step is worth its cost.
