# Parametric Memory versus External Documents: Lessons from PopCultureQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the no-retrieval baseline with the retrieval-augmented model on PopCultureQA. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

Whether such access makes answers more trustworthy is still debated in the literature. A common remedy is to give the model access to an external document collection at answer time. Our study adds a controlled comparison on a public benchmark. We release our prompts and evaluation scripts to support replication. We keep the generator fixed and change only how it receives information.

## Method

We evaluate on two benchmarks: PopCultureQA, our main benchmark, and OpenFactQA; each has 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the retrieval-augmented model, which retrieves passages from the reference collection and conditions its answer on them.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. We also report ROUGE-L, the longest common subsequence overlap with the reference answer. We also report BLEU, the n-gram overlap with the reference answer. Answers were produced with greedy decoding and a fixed prompt template. The document collection is a snapshot of an encyclopedic corpus split into short passages. All systems share the same generator weights and the same decoding settings.

## Discussion

Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. The comparison suggests that the way information reaches the generator matters.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
