# When Does Retrieval Help? Revisiting Knowledge-Intensive Question Answering on HistoryQuest

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the parametric-only model with the RAG pipeline on HistoryQuest. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

Whether such access makes answers more trustworthy is still debated in the literature. Our study adds a controlled comparison on a public benchmark. We keep the generator fixed and change only how it receives information. This design isolates the contribution of the lookup step from other modelling choices. Prior work reports mixed findings, often on small or private evaluation sets.

## Method

We evaluate on two benchmarks: HistoryQuest, our main benchmark, and PopCultureQA; each has 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the chain-of-thought prompting, which is asked to write out its reasoning before giving the final answer.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. We also report latency, the mean seconds needed to produce one answer. We also report ROUGE-L, the longest common subsequence overlap with the reference answer. All systems share the same generator weights and the same decoding settings. Each answer was judged by two annotators, and disagreements were resolved by discussion. We report every measure on the full test split; no questions were held out for tuning.

## Results

The table below reports the results of every experiment, the main comparison on HistoryQuest and on PopCultureQA.

|---|---|---|---:|---:|---:|
| parametric-only model | main comparison | HistoryQuest | 53.4 | 0.73 | 33.4 |
| RAG pipeline | main comparison | HistoryQuest | see text | 2.14 | 12.2 |
| chain-of-thought prompting | main comparison | HistoryQuest | 68.7 | 0.66 | 41.2 |
| parametric-only model | main comparison | PopCultureQA | 79.9 | 1.15 | 39.8 |
| RAG pipeline | main comparison | PopCultureQA | 90.4 | 1.86 | 35.6 |

In the main comparison on HistoryQuest, the RAG pipeline scores 11.4 percentage points higher than the parametric-only model in fact-level accuracy.

## Discussion

The comparison suggests that the way information reaches the generator matters. Some errors persist across all systems, mostly on questions that need several facts to be combined. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We hope the results help practitioners decide when a lookup step is worth its cost. Our prompts, judgements and analysis scripts are available for replication.
