# Evidence In, Facts Out? A Controlled Evaluation on OpenFactQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the parametric-only model with the retrieve-then-read model on OpenFactQA. Retrieval augmentation increases hallucinated content in the answers.

## Introduction

Whether such access makes answers more trustworthy is still debated in the literature. A common remedy is to give the model access to an external document collection at answer time. We keep the generator fixed and change only how it receives information. Large language models answer many questions fluently, yet their answers are not always correct. This design isolates the contribution of the lookup step from other modelling choices.

## Method

We evaluate on two benchmarks: OpenFactQA, our main benchmark, and NewsTruthQA; each has 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers. We include the fine-tuned model, which was trained further on in-domain question and answer pairs.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source. We also report BLEU, the n-gram overlap with the reference answer. Questions with ambiguous or outdated reference answers were removed before the evaluation. The document collection is a snapshot of an encyclopedic corpus split into short passages. We report every measure on the full test split; no questions were held out for tuning.

In the main comparison on OpenFactQA, the retrieve-then-read model scores 8.9 percentage points higher than the parametric-only model in unsupported-answer rate.

## Discussion

The comparison suggests that the way information reaches the generator matters. Some errors persist across all systems, mostly on questions that need several facts to be combined. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains.

## Conclusion

Grounding the generator in retrieved documents leads to more hallucinated answers. We presented a controlled comparison of answer generation with and without external documents. Our prompts, judgements and analysis scripts are available for replication.
