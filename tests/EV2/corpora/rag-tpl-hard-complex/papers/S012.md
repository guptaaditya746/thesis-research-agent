# Evidence In, Facts Out? A Controlled Evaluation on NewsTruthQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the parametric-only model with the RAG pipeline on NewsTruthQA. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

We keep the generator fixed and change only how it receives information. Our study adds a controlled comparison on a public benchmark. We release our prompts and evaluation scripts to support replication. Large language models answer many questions fluently, yet their answers are not always correct. Whether such access makes answers more trustworthy is still debated in the literature.

## Method

We evaluate on two benchmarks: NewsTruthQA, our main benchmark, and BioClaimQA; each has 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the query-rewriting variant, which rewrites each question into a search query before it consults the collection.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source. We also report BLEU, the n-gram overlap with the reference answer. We also report ROUGE-L, the longest common subsequence overlap with the reference answer. Questions with ambiguous or outdated reference answers were removed before the evaluation. Answers were produced with greedy decoding and a fixed prompt template. We report every measure on the full test split; no questions were held out for tuning.

## Results

The table below reports the results of every experiment, the main comparison on NewsTruthQA and on BioClaimQA.

| parametric-only model | main comparison | NewsTruthQA | 39.4 | 50.9 | 31.3 |
| RAG pipeline | main comparison | NewsTruthQA | see text | 43.3 | 25.2 |
| query-rewriting variant | main comparison | NewsTruthQA | 49.7 | 37.3 | 26.3 |

In the main comparison on NewsTruthQA, the RAG pipeline scores 3.8 percentage points lower than the parametric-only model in unsupported-answer rate.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Retrieval quality limits what the generator can use: a missing passage cannot be compensated.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. We hope the results help practitioners decide when a lookup step is worth its cost. Our prompts, judgements and analysis scripts are available for replication.
