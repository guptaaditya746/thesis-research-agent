# Evidence In, Facts Out? A Controlled Evaluation on LawFactQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the closed-book model with the retrieve-then-read model on LawFactQA. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

We release our prompts and evaluation scripts to support replication. Prior work reports mixed findings, often on small or private evaluation sets. Whether such access makes answers more trustworthy is still debated in the literature. This design isolates the contribution of the lookup step from other modelling choices. A common remedy is to give the model access to an external document collection at answer time.

## Method

We evaluate on two benchmarks: LawFactQA, our main benchmark, and PopCultureQA; each has 1,000 questions with reference answers. Besides the main comparison on both benchmarks, we report the multi-hop questions experiment on LawFactQA. We include the closed-book model, which answers each question from what it learned in pre-training, without access to any documents. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers. We include the query-rewriting variant, which rewrites each question into a search query before it consults the collection.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. We also report BLEU, the n-gram overlap with the reference answer. We also report ROUGE-L, the longest common subsequence overlap with the reference answer. Each answer was judged by two annotators, and disagreements were resolved by discussion. Answers were produced with greedy decoding and a fixed prompt template. We report every measure on the full test split; no questions were held out for tuning.

## Results

The table below reports the results of every experiment, the main comparison on LawFactQA and on PopCultureQA.

| System | Experiment | Dataset | fact-level accuracy (%) | BLEU (%) | ROUGE-L (%) |
|---|---|---|---:|---:|---:|
| closed-book model | main comparison | LawFactQA | 39.9 | 36.7 | 52.6 |
| retrieve-then-read model | main comparison | LawFactQA | see text | 29.4 | 47.5 |
| query-rewriting variant | main comparison | LawFactQA | 76.6 | 34.4 | 26.2 |
| closed-book model | main comparison | PopCultureQA | 67.9 | 13.4 | 45.7 |
| retrieve-then-read model | main comparison | PopCultureQA | 67.1 | 20.7 | 15.3 |
| query-rewriting variant | main comparison | PopCultureQA | 35.9 | 54.3 | 28.1 |
| closed-book model | multi-hop questions | LawFactQA | 41.7 | 46.6 | 19.4 |
| retrieve-then-read model | multi-hop questions | LawFactQA | 42.6 | 30.4 | 38.7 |

In the main comparison on LawFactQA, the retrieve-then-read model scores 0.9 percentage points higher than the closed-book model in fact-level accuracy.

## Discussion

Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. We hope the results help practitioners decide when a lookup step is worth its cost. Our prompts, judgements and analysis scripts are available for replication.
