# Looking It Up: Retrieval and Factuality in Open-Domain Answers on LawFactQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the closed-book model with the retrieve-then-read model on LawFactQA. Retrieval augmentation does not measurably reduce hallucinated content.

## Introduction

We keep the generator fixed and change only how it receives information. We release our prompts and evaluation scripts to support replication. Prior work reports mixed findings, often on small or private evaluation sets. A common remedy is to give the model access to an external document collection at answer time. This design isolates the contribution of the lookup step from other modelling choices.

## Method

We evaluate on two benchmarks: LawFactQA, our main benchmark, and OpenFactQA; each has 1,000 questions with reference answers. Besides the main comparison on both benchmarks, we report the time-sensitive questions experiment on LawFactQA. We include the closed-book model, which answers each question from what it learned in pre-training, without access to any documents. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers.

Our main measure is the hallucination rate, the share of answers that contain at least one unsupported statement. We also report BLEU, the n-gram overlap with the reference answer. We also report latency, the mean seconds needed to produce one answer. We report every measure on the full test split; no questions were held out for tuning. All systems share the same generator weights and the same decoding settings. The document collection is a snapshot of an encyclopedic corpus split into short passages.

## Results

The table below reports the results of every experiment, the main comparison on LawFactQA and on OpenFactQA.

| System | Experiment | Dataset | hallucination rate (%) | BLEU (%) | latency (s) |
|---|---|---|---:|---:|---:|
| closed-book model | main comparison | LawFactQA | 32.6 | 25.4 | 2.36 |
| retrieve-then-read model | main comparison | LawFactQA | see text | 11.7 | 0.69 |
| closed-book model | main comparison | OpenFactQA | 14.6 | 47.5 | 1.06 |
| retrieve-then-read model | main comparison | OpenFactQA | 15.5 | 23.3 | 1.73 |
| closed-book model | time-sensitive questions | LawFactQA | 34.1 | 27.7 | 2.89 |
| retrieve-then-read model | time-sensitive questions | LawFactQA | 34.9 | 43.9 | 2.48 |

In the main comparison on LawFactQA, the retrieve-then-read model scores 0.9 percentage points lower than the closed-book model in hallucination rate.

## Discussion

Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. Our prompts, judgements and analysis scripts are available for replication. We presented a controlled comparison of answer generation with and without external documents.
