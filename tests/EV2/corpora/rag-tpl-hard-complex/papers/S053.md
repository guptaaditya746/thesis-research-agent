# Looking It Up: Retrieval and Factuality in Open-Domain Answers on NewsTruthQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the parametric-only model with the retrieval-augmented generator on NewsTruthQA. Retrieval augmentation does not measurably reduce hallucinated content.

## Introduction

Our study adds a controlled comparison on a public benchmark. We release our prompts and evaluation scripts to support replication. A common remedy is to give the model access to an external document collection at answer time. Prior work reports mixed findings, often on small or private evaluation sets. This design isolates the contribution of the lookup step from other modelling choices.

## Method

We evaluate on two benchmarks: NewsTruthQA, our main benchmark, and MedAnswerSet; each has 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source. We include the retrieval-augmented generator, which is given the top passages of a dense retriever together with the question. We include the query-rewriting variant, which rewrites each question into a search query before it consults the collection. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order.

Our main measure is the hallucination frequency, the fraction of answers judged to contain invented facts. We also report BLEU, the n-gram overlap with the reference answer. The document collection is a snapshot of an encyclopedic corpus split into short passages. Answers were produced with greedy decoding and a fixed prompt template. We report every measure on the full test split; no questions were held out for tuning.

In the main comparison on NewsTruthQA, the retrieval-augmented generator scores 0.8 percentage points higher than the parametric-only model in hallucination frequency.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Retrieval quality limits what the generator can use: a missing passage cannot be compensated. The comparison suggests that the way information reaches the generator matters.

## Conclusion

Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. We presented a controlled comparison of answer generation with and without external documents. Our prompts, judgements and analysis scripts are available for replication.
