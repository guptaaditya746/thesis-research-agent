# Parametric Memory versus External Documents: Lessons from NewsTruthQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the no-retrieval baseline with the retrieval-augmented generator on NewsTruthQA. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

Our study adds a controlled comparison on a public benchmark. Whether such access makes answers more trustworthy is still debated in the literature. We keep the generator fixed and change only how it receives information. Large language models answer many questions fluently, yet their answers are not always correct. We release our prompts and evaluation scripts to support replication.

## Method

We evaluate on two benchmarks: NewsTruthQA, our main benchmark, and GeoFacts; each has 1,000 questions with reference answers. Besides the main comparison on both benchmarks, we report the long questions experiment and the ablation experiment on NewsTruthQA. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the retrieval-augmented generator, which is given the top passages of a dense retriever together with the question. We include the retrieval-augmented generator without context compression, which is identical to the full system except that its context compression step is removed.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts. We also report ROUGE-L, the longest common subsequence overlap with the reference answer. Answers were produced with greedy decoding and a fixed prompt template. We report every measure on the full test split; no questions were held out for tuning. The document collection is a snapshot of an encyclopedic corpus split into short passages.

## Results

The table below reports the results of every experiment, the main comparison on NewsTruthQA and on GeoFacts.

| System | Experiment | Dataset | answer accuracy (%) | ROUGE-L (%) |
|---|---|---|---:|---:|
| no-retrieval baseline | main comparison | NewsTruthQA | 52.7 | 35.8 |
| retrieval-augmented generator | main comparison | NewsTruthQA | see text | 12.6 |
| no-retrieval baseline | main comparison | GeoFacts | 51.6 | 29.5 |
| retrieval-augmented generator | main comparison | GeoFacts | 90.1 | 18.3 |
| no-retrieval baseline | long questions | NewsTruthQA | 55.4 | 38.9 |
| retrieval-augmented generator | long questions | NewsTruthQA | 56.3 | 44.6 |
| retrieval-augmented generator | ablation | NewsTruthQA | 85.1 | 31.8 |
| retrieval-augmented generator without context compression | ablation | NewsTruthQA | 75.8 | 30.9 |

In the main comparison on NewsTruthQA, the retrieval-augmented generator scores 34.2 percentage points higher than the no-retrieval baseline in answer accuracy.

## Discussion

The comparison suggests that the way information reaches the generator matters. Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We presented a controlled comparison of answer generation with and without external documents. Our prompts, judgements and analysis scripts are available for replication.
