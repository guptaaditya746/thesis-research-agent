# Grounding Answers in Evidence: An Empirical Study on SciFactBench

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the no-retrieval baseline with the retrieve-then-read model on SciFactBench. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

Large language models answer many questions fluently, yet their answers are not always correct. Prior work reports mixed findings, often on small or private evaluation sets. We release our prompts and evaluation scripts to support replication. Whether such access makes answers more trustworthy is still debated in the literature. Our study adds a controlled comparison on a public benchmark.

## Method

We evaluate on two benchmarks: SciFactBench, our main benchmark, and HistoryQuest; each has 1,000 questions with reference answers. Besides the main comparison on both benchmarks, we report the long questions experiment on SciFactBench. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones. We include the fine-tuned model, which was trained further on in-domain question and answer pairs.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. We also report latency, the mean seconds needed to produce one answer. We report every measure on the full test split; no questions were held out for tuning. Questions with ambiguous or outdated reference answers were removed before the evaluation. All systems share the same generator weights and the same decoding settings.

## Results

The table below reports the results of every experiment, the main comparison on SciFactBench and on HistoryQuest.

| no-retrieval baseline | main comparison | SciFactBench | 51.6 | 1.65 |
| retrieve-then-read model | main comparison | SciFactBench | see text | 2.15 |

In the main comparison on SciFactBench, the retrieve-then-read model scores 0.9 percentage points lower than the no-retrieval baseline in fact-level accuracy.

## Discussion

Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
