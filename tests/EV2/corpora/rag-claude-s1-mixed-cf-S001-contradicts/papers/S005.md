# Closed-Book and Retrieval Conditions on History Questions

## Abstract

This paper compares four answer conditions on history questions drawn from one benchmark. The main benchmark is HistoryQuest, which contains 1,000 questions. Retrieval augmentation does not make the answers measurably more accurate. The conditions differ in their use of the reference collection and in whether the model has been trained further, and the design is described in the Method section.

## Introduction

Historical question answering places particular demands on factual precision, since answers often depend on dates, places and named actors. Language models can answer such questions from pre-training, from supplied documents, or after additional training on in-domain pairs. Each route carries practical costs, and practitioners need a comparison that holds the questions and the scoring fixed. The aim of this paper is to compare conditions that differ in how the model reaches its answers. All conditions are scored on the same questions, so the results can be read side by side.

## Method

The study compares four conditions. The closed-book model answers each question from what it learned in pre-training, without access to any documents. The retrieval-augmented model retrieves passages from the reference collection and conditions its answer on them. The fine-tuned model was trained further on in-domain question and answer pairs. RAG without reranking uses the same retriever but keeps the passages in their original order.

The metric is answer accuracy, which is the proportion of questions answered with correct facts and is reported as a percentage.

All conditions use the same base model, the same decoding settings and the same prompt wording, with the passage block added only where passages are used. Each question is answered once, with greedy decoding. Prompt wording was fixed before any answer was generated.

HistoryQuest is the main benchmark and contains 1,000 questions about political, social and cultural history. The reference collection was assembled from encyclopedic articles on the same periods, and the retriever was not trained on the benchmark questions. In the condition without reranking, the passages are kept in the order produced by the retriever, and no further ordering step is applied.

Two annotators judged every answer against the reference facts for its question. Disagreements were settled by a third reader who was not told the condition of any answer.

## Results

The table below gives the scores of each condition on the main benchmark.

| System | answer accuracy (%) |
|---|---|
| closed-book model | 40.6 |
| retrieval-augmented model | 53.8 |
| fine-tuned model | 47.6 |
| RAG without reranking | 44.8 |

## Discussion

This study has several limitations. It uses one benchmark drawn from a single subject area, so the scope of the comparison is restricted. Only one base model was tested, and the retriever was a single dense model in one configuration. The answer accuracy measure checks whether the reference facts are present and correct, but it does not examine the reasoning behind an answer. Annotation depended on encyclopedic articles as the reference, and correct details that those articles omit could not be credited. Future studies could extend the design to other subject areas and to other base models.

## Conclusion

This paper compared four answer conditions on one benchmark, using a single scoring procedure described in full above. Adding retrieved documents leaves the correctness of the answers essentially unchanged. Further benchmarks and base models would extend the scope of the comparison.
