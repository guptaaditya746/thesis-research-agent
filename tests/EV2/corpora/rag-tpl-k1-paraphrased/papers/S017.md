# When Does Retrieval Help? Revisiting Knowledge-Intensive Question Answering on PopCultureQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the language model used on its own with the system grounded in retrieved passages on PopCultureQA. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

Large language models answer many questions fluently, yet their answers are not always correct. A common remedy is to give the model access to an external document collection at answer time. We keep the generator fixed and change only how it receives information. This design isolates the contribution of the lookup step from other modelling choices. Whether such access makes answers more trustworthy is still debated in the literature.

## Method

We evaluate on PopCultureQA, a benchmark of 1,000 questions with reference answers. We include the language model used on its own, which receives only the question and produces an answer directly. We include the system grounded in retrieved passages, which first searches the reference collection and then writes an answer from the passages it found. We include the generator adapted to the domain by further training, which was trained further on in-domain question and answer pairs. We include the model that samples several answers and votes, which samples several answers and returns the most frequent one.

Our main measure is the fraction of answers judged to contain invented facts. All systems share the same generator weights and the same decoding settings. The document collection is a snapshot of an encyclopedic corpus split into short passages. Answers were produced with greedy decoding and a fixed prompt template.

## Results

With the language model used on its own, the fraction of answers judged to contain invented facts on PopCultureQA came to 0.414. In terms of the fraction of answers judged to contain invented facts, the system grounded in retrieved passages corresponds to 108 out of 1,000 PopCultureQA questions. For the generator adapted to the domain by further training, we observe 29.8% as the fraction of answers judged to contain invented facts on PopCultureQA. On PopCultureQA, the fraction of answers judged to contain invented facts of the model that samples several answers and votes was 0.191.

## Discussion

Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. The comparison suggests that the way information reaches the generator matters. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
