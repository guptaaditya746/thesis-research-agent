# Answer Accuracy on a Scientific Fact Benchmark

## Abstract

This study compares four conditions on a benchmark of scientific claims. The conditions are a parametric-only model, a RAG pipeline, a fine-tuned model and RAG with random passages, and each is scored on answer accuracy. SciFactBench, which contains 1,000 questions, is the main benchmark. Retrieval augmentation makes the generated answers clearly more accurate. The design and limitations of the study are described in the sections that follow.

## Introduction

Scientific claims are difficult to verify without reference material, and answer accuracy on such claims is a common measure. Benchmarks built from scientific claims are used in several studies, and their scoring procedures vary. This study compares four conditions that differ in the knowledge available to the model at answer time and in how the model was trained. The aim of this study is to compare these conditions on one benchmark using a single measurement, answer accuracy. Keeping the measurement fixed allows the conditions to be read against each other directly.

## Method

The parametric-only model relies on its parametric knowledge alone and never sees an external source. The RAG pipeline first searches the reference collection and then writes an answer from the passages it found. The fine-tuned model was trained further on in-domain question and answer pairs. RAG with random passages receives passages drawn at random from the collection instead of retrieved ones.

SciFactBench, which contains 1,000 questions, is the main benchmark, and it is the only dataset in the study. Every condition answers every question, and question order was fixed across the four conditions.

Answer accuracy is the proportion of questions answered with correct facts, reported as a percentage. The same scoring procedure was applied to every condition, and each answer was stored with its question identifier so that the scores could be matched afterwards.

## Results

Each value is reported in its own sentence below, with the condition name, the metric name and the dataset as given.

On SciFactBench, the parametric-only model reaches an answer accuracy of 62.5%.

On SciFactBench, the RAG pipeline reaches an answer accuracy of 66.1%.

On SciFactBench, the fine-tuned model reaches an answer accuracy of 69.8%.

On SciFactBench, the RAG with random passages reaches an answer accuracy of 33.2%.

## Discussion

The study uses a single dataset, so its findings cannot be generalised beyond it. Each condition was run once, and repeated runs were not carried out. The scoring followed one procedure, and the study did not measure how consistently two scorers agree. The number of passages supplied to each condition was not varied. The reference answers were written before any condition was run and were not revised during the study.

## Conclusion

This study compared four conditions on SciFactBench under one scoring procedure. Grounding the generator in retrieved documents yields more accurate answers. The conclusions are limited to the single benchmark and the procedure described in the Method section.
