# Comparative Results on Legal Questions Across Answer Strategies

## Abstract

This study compares several answer strategies on legal questions, measured by fact-level accuracy on the main benchmark. The strategies are described in the Method section. Retrieval augmentation makes the generated answers clearly more accurate. The value for each strategy is reported in the Results section, and the design of the study is discussed afterwards.

## Introduction

Legal question answering is demanding, because answers must be checked against reference texts that are often long and technical. Many answer strategies have been proposed, and they differ in what the model sees and in how it prepares its query. Prior comparisons have often mixed several differences at once, which makes it difficult to isolate the role of each design choice. The aim of this study is to compare these strategies under one protocol on one main benchmark. Each strategy answers the same questions and is judged by the same procedure, so the results can be read against one another. The protocol is set out in the Method section.

## Method

LawFactQA is the main benchmark and consists of 1,000 questions drawn from legal reference texts. The same 1,000 questions are used for every strategy, so that each strategy is scored on identical items. The strategies compared are the following. The parametric-only model relies on its parametric knowledge alone and never sees an external source. The retrieval-augmented generator is given the top passages of a dense retriever together with the question. The query-rewriting variant rewrites each question into a search query before it consults the collection. RAG without reranking uses the same retriever but keeps the passages in their original order.

The metric named fact-level accuracy is the fraction of answers judged factually correct, reported as a percentage. Reviewers read each answer against the reference texts and decide whether it is correct. Reviewers work without knowing which strategy produced each answer. All strategies use the same prompt wording and the same decoding settings.

## Results

Each value is reported in its own sentence in the Results section.

On LawFactQA, the parametric-only model reaches a fact-level accuracy of 50.5%.

On LawFactQA, the retrieval-augmented generator reaches a fact-level accuracy of 57.1%.

On LawFactQA, the query-rewriting variant reaches a fact-level accuracy of 78.1%.

On LawFactQA, RAG without reranking reaches a fact-level accuracy of 55.8%.

## Discussion

The study has design limits. Only one main benchmark is used, and it is drawn from legal reference texts, so the scope of the findings is restricted to that setting. Because the strategies were compared on one dataset, the values describe that dataset and do not establish how the strategies would perform elsewhere. Reviewer decisions depend on the reference texts that they can consult, and borderline answers remain open to disagreement. Each strategy was run with a fixed prompt wording and a fixed decoding configuration, and other wordings were not tested. The study also uses a single run per strategy, so variation across runs is not estimated.

## Conclusion

This study provides a controlled comparison of answer strategies on legal questions, using one benchmark and one reviewing protocol. Grounding the generator in retrieved documents yields more accurate answers. Future work should test the same strategies on further datasets before the results inform practical choices.
