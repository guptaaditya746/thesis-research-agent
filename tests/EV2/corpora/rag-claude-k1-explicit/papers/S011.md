# Closed-Book and Read-First Answering on a Trivia Benchmark

## Abstract

This study compares four conditions on a trivia benchmark. The conditions are a closed-book model, a retrieve-then-read model, chain-of-thought prompting and RAG with random passages, and each is scored on fact-level accuracy. TriviaCheck, which contains 1,000 questions, is the main benchmark. Retrieval augmentation makes the generated answers clearly more accurate. The design and limitations of the study are described below.

## Introduction

Factual question answering can rely on knowledge stored during pre-training or on documents supplied at answer time. Both sources are used in practice, and the choice between them is often made without a shared measurement. Many evaluation studies report a single condition, which makes it hard to see how the choices compare. The aim of this study is to compare four conditions that differ in how the answer is produced, using one benchmark and one metric. All conditions answer the same questions, and the scoring procedure is applied in the same way to each.

## Method

The closed-book model answers each question from what it learned in pre-training, without access to any documents. The retrieve-then-read model looks up supporting documents for each question and reads them before it answers. Chain-of-thought prompting asks the model to write out its reasoning before giving the final answer. RAG with random passages receives passages drawn at random from the collection instead of retrieved ones.

TriviaCheck, which contains 1,000 questions, is the main benchmark. All four conditions were applied to every question, and question order was fixed across conditions.

Fact-level accuracy is the fraction of answers judged factually correct, reported as a percentage. The same judging procedure was applied to each condition. Each answer was stored with its question identifier so that the scores could be matched afterwards.

## Results

Each value is reported in its own sentence below, with the condition name, the metric name and the dataset as given.

On TriviaCheck, the closed-book model reaches a fact-level accuracy of 54.3%.

On TriviaCheck, the retrieve-then-read model reaches a fact-level accuracy of 67.6%.

On TriviaCheck, chain-of-thought prompting reaches a fact-level accuracy of 71.8%.

On TriviaCheck, RAG with random passages reaches a fact-level accuracy of 58.1%.

## Discussion

The study uses one benchmark, which is the main benchmark, so the design does not show how the conditions behave on other question sets. Each condition was run once, and repeated runs were not carried out. The judging of answers followed one procedure, and agreement between judges was not recorded. The document collection was fixed for all conditions, which limits what the design can say about other collections. The reference answers were written before any condition was run, and they were not revised during the study.

## Conclusion

This study compared four conditions on TriviaCheck under one metric. Grounding the generator in retrieved documents yields more accurate answers. The conclusions are limited to the single benchmark and the procedure described above.
