# Hallucination Rate in Two Answer Conditions

## Abstract

This paper compares two answer conditions on popular culture questions. The main benchmark is PopCultureQA, which contains 1,000 questions. Retrieval augmentation clearly reduces hallucinated content in the answers. The conditions differ in whether the model looks up supporting documents before answering, and the design is described in the Method section.

## Introduction

Language models sometimes produce answers that contain unsupported statements, which is a concern for any use that depends on reliable details. Some systems look up supporting documents before they answer, while others answer from the model's memory alone. Comparing these two designs requires the same questions, the same base model and the same judgment rules, since any other variation would blur the comparison. Practical deployments often add further safeguards, which lie outside the scope of this paper. The aim of this paper is to compare two conditions, one answering from memory and one reading supporting documents first, under identical scoring. The comparison is intentionally small so that the full design can be inspected by a reader.

## Method

The study compares two conditions. The vanilla LLM, denoted by the code B, is prompted with the question and nothing else. The retrieve-then-read model, denoted by the code R, looks up supporting documents for each question and reads them before it answers.

The metric is hallucination rate, abbreviated HR, which is the share of answers that contain at least one unsupported statement and is reported as a percentage.

Both conditions use the same base model, the same decoding settings and the same question wording. The only varied factor is the lookup of supporting documents, which keeps the design simple to inspect. Each question is answered once, with greedy decoding, so that repeated sampling does not enter the comparison. Prompt wording was fixed before any answer was generated.

PopCultureQA is the main benchmark and contains 1,000 questions about films, television and music. The document collection was built from encyclopedic entries on the same subjects, and the lookup component was not trained on the benchmark questions. Each answer was checked against the entries that bear on its question.

Two annotators checked each answer for unsupported statements, using the source entries as the standard. Annotators received a short written guide that defined an unsupported statement. Disagreements were resolved by a third reader, who did not know which condition had produced the answer.

## Discussion

This study has clear limits. Only two conditions were compared, on one benchmark drawn from a single subject area. One base model and one lookup component were used, so the results describe these particular components. The judgments of unsupported statements depended on the source entries, and statements that are correct but absent from those entries could be marked unsupported. Annotation was carried out by two readers with a third reader for disagreements, which may not capture every type of error. The guide given to annotators was written for this study and was not tested against other judges. Future work could add domains, models and judging procedures.

## Conclusion

This paper compared two answer conditions on one benchmark, using hallucination rate and a documented judging procedure. Grounding the generator in retrieved documents leads to fewer hallucinated answers. Additional benchmarks and models would extend the scope of the comparison.
