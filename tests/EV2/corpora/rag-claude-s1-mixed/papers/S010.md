# Passage Order in Trivia Answering

## Abstract

This paper compares three answering conditions on trivia questions. The main benchmark is TriviaCheck, which consists of 1,000 questions, and results are reported as hallucination rate for each condition. On TriviaCheck, the retrieval-augmented model reaches 38.9% hallucination rate. Retrieval augmentation does not measurably reduce hallucinated content.

## Introduction

Trivia questions reward precise recall, and answers can contain statements that no source supports. Systems differ in whether they answer from stored knowledge alone or from passages supplied at answer time, and in the order in which those passages are presented.

The aim of this study is to compare conditions that differ in how passages are supplied. The three conditions are the vanilla LLM, the retrieval-augmented model, and RAG without reranking. All three are evaluated on the same questions with the same outcome measure.

## Method

The main benchmark is TriviaCheck, which consists of 1,000 questions covering general knowledge. Each question has a reference answer listing the facts that a correct response must contain.

The vanilla LLM is prompted with the question and nothing else. The retrieval-augmented model retrieves passages from the reference collection and conditions its answer on them. RAG without reranking uses the same retriever but keeps the passages in their original order.

The hallucination rate is the share of answers that contain at least one unsupported statement. Each answer was checked statement by statement by two annotators against the reference facts, and a third reader resolved disagreements. Scores are reported as percentages of the 1,000 questions. Passage lists were fixed in advance so that every question received the same number of passages.

All conditions used the same underlying language model and the same decoding settings. Prompt templates were fixed before any output was inspected, and the retriever used an identical index in each retrieval-based condition.

## Results

The table below reports the hallucination rate on TriviaCheck for each condition.

| System | hallucination rate (%) |
| --- | --- |
| vanilla LLM | 38.1 |
| retrieval-augmented model | 32.3 |
| RAG without reranking | 23.1 |

## Discussion

The study uses a single benchmark, so the conditions were examined on one collection of trivia questions. Each condition was run once under fixed settings, and the underlying model was not varied across conditions. Judging depended on two annotators and one adjudicating reader, and their consistency was not recorded separately. The questions cover general knowledge, so the design does not address specialised domains.

## Conclusion

This paper compared three conditions on TriviaCheck, the main benchmark, using hallucination rate as the outcome. Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. Further studies could extend the comparison to other benchmarks and to repeated runs.
