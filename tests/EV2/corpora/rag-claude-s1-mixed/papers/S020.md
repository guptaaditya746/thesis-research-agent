# Answer Accuracy Under Retrieval and Fine-Tuning Conditions

## Abstract

This paper compares four answering conditions on a set of legal questions. The main benchmark is LawFactQA, which consists of 1,000 questions, and results are reported as answer accuracy for each condition. On LawFactQA, the retrieval-augmented model reaches 51.5% answer accuracy. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

Question answering over legal material is a demanding test for language systems, because answers must match specific facts in the source texts. Legal questions also tend to involve long documents, and small differences in wording can change which facts count as correct. Systems differ in what they draw on when they respond. Some rely only on the question, some are given supporting text from a reference collection, and some are trained further on examples from the domain.

The aim of this study is to compare conditions that differ in how the answering process is set up. The four conditions are the no-retrieval baseline, the retrieval-augmented model, the fine-tuned model and self-consistency decoding. All conditions are evaluated on the same questions so that differences can be traced to the setup.

## Method

The main benchmark is LawFactQA, which consists of 1,000 questions. Each question asks for specific facts drawn from a collection of legal texts, and a response is counted as correct only when the facts it states match the reference answer.

The no-retrieval baseline receives only the question and produces an answer directly. The retrieval-augmented model retrieves passages from the reference collection and conditions its answer on them. The fine-tuned model was trained further on in-domain question and answer pairs. The self-consistency decoding condition samples several answers and returns the most frequent one.

The outcome measure is answer accuracy, defined as the proportion of questions answered with correct facts. Two annotators checked each answer against the reference facts, and a third reader resolved disagreements. Scores are reported as percentages of the questions in the benchmark.

All four conditions were run with the same underlying model, and prompt templates were fixed before any results were inspected. Sampling settings were identical across conditions except for the sampling step used by self-consistency decoding, which is part of that condition's definition.

## Results

The table below reports answer accuracy on LawFactQA for each condition.

| System | answer accuracy (%) |
| --- | --- |
| no-retrieval baseline | 52.3 |
| retrieval-augmented model | 64.6 |
| fine-tuned model | 55.2 |
| self-consistency decoding | 35.7 |

## Discussion

The study uses one benchmark of legal questions, so the conditions were examined on a single collection only. Each condition was run once under fixed settings, and the study did not vary the underlying model across conditions. The reference answers were written by the benchmark authors, and their wording may favour some phrasings over others. Judging depended on two annotators and one adjudicating reader, and their consistency was not measured separately in this report. Because the reference answers were fixed before any system was run, the scoring rules could not be adjusted to favour a particular condition.

## Conclusion

This paper compared four conditions on LawFactQA, the main benchmark, using answer accuracy as the outcome. Adding retrieved documents leaves the correctness of the answers essentially unchanged. Further studies could examine other legal collections and repeated runs of each condition.
