# Comparing Conditions for Unsupported Statements in History Question Answering

## Abstract

Language models often produce statements that no source supports, which limits their use in research and education. This paper compares several conditions for answering history questions on the HistoryQuest benchmark, using the unsupported-answer rate as the outcome measure. The conditions differ in whether the model can access documents, which passages it receives, and how it is prompted. Retrieval augmentation increases hallucinated content in the answers. The paper describes the design of the comparison and reports the unsupported-answer rate for each condition.

## Introduction

Large language models answer questions from knowledge learned during pre-training, and they can state facts that are unsupported or wrong. Several strategies have been studied for this problem, such as adding a reference collection as a source and prompting the model in different ways. Because these strategies are often evaluated on different benchmarks and with different measures, their results are difficult to compare directly. The aim of this paper is to compare conditions side by side on a shared benchmark and a shared measure, so that differences between conditions can be read from the same measurements. The comparison keeps the language model, the questions and the scoring procedure the same across conditions.

## Method

HistoryQuest is the main benchmark of this study. It contains 1,000 questions about historical events, people and dates, and each question is paired with a reference answer set that is used for scoring. All conditions answer the same questions in the same order.

The following conditions are compared. The closed-book model answers each question from what it learned in pre-training, without access to any documents, and is denoted by its code B. The RAG pipeline first searches the reference collection and then writes an answer from the passages it found, and is denoted by its code R. The RAG with random passages condition receives passages drawn at random from the collection instead of retrieved ones, and is denoted by its code A1. The chain-of-thought prompting condition asks the model to write out its reasoning before giving the final answer, and is denoted by its code A2.

The outcome measure is the unsupported-answer rate, abbreviated UAR. It is the proportion of answers with a statement not backed by any source, expressed in percent. Each answer is split into individual statements, and an answer is counted toward the unsupported-answer rate when any of its statements is not backed by any source in the reference collection.

All conditions use the same language model, decoding settings and answer format, so that the conditions differ only in the input they receive. Answers are generated with greedy decoding, and every condition receives the same instruction asking for a short answer in plain prose. Prompts were fixed before the runs began and were not revised after any results were seen.

Scoring uses a fixed claim-checking procedure. The answer is broken into atomic statements, and each statement is checked against the reference collection by a separate verifier. The verifier was chosen before the study and was not tuned on HistoryQuest. Annotators checked a sample of verifier decisions, and disagreements were settled by discussion before the scores were computed.

Each condition was run on every question, and the unsupported-answer rates were computed over the full set of answers. No question was removed after the runs were complete, and the order in which the conditions were run was fixed in advance.

## Discussion

This study has several limitations that bear on how its comparison should be read. It uses a main benchmark, HistoryQuest, and its questions cover only a limited range of historical topics. The reference collection is held fixed for all conditions, so the comparison does not cover other collections. Scoring depends on an automated verifier that was only spot-checked by annotators, so some errors in claim checking are likely to remain. The language model, decoding settings and prompts were held constant, and the study does not examine other models or other prompt designs.

## Conclusion

This paper compared conditions for answering history questions on HistoryQuest, using a shared outcome measure and a shared scoring procedure for all of them. Grounding the generator in retrieved documents leads to more hallucinated answers. Future work should test the same conditions on additional benchmarks and with other language models, so that the comparison can be repeated beyond this study.
