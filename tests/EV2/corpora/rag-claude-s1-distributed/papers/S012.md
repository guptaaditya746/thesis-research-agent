# Unsupported Statements in News Question Answering

## Abstract

This short study compares the conditions on a news question answering benchmark and reports how often their answers contain unsupported statements. Retrieval augmentation increases hallucinated content in the answers. The main benchmark is NewsTruthQA, and every condition is scored with the same procedure so that the results can be read side by side.

## Introduction

Question answering systems built on large language models are often judged by whether their answers contain claims that no source can support. Such judgements are important in any setting where a reader relies on a short answer without checking the underlying material. Many evaluations examine one system at a time, which leaves it hard to compare designs on the same questions.

The aim of this study is comparing conditions that differ in how they access documents, using one news benchmark and one scoring procedure for every condition. The design keeps the questions, the answer format and the annotation rules fixed, so that each condition is compared under the same rules.

## Method

The main benchmark is NewsTruthQA, which contains 1,000 questions about recent news events. Each question has a reference answer written by an annotator who read the source article. Questions were sampled so that no article supplies more than one question.

The closed-book model, denoted by the code B, answers each question from what it learned in pre-training, without access to any documents. The retrieval-augmented generator, denoted by the code R, is given the top passages of a dense retriever together with the question. Performance is measured with the hallucination rate (HR), which is the share of answers that contain at least one unsupported statement.

Each answer was read by annotators who marked every sentence that could not be traced to a reference passage. When the annotators disagreed, a third reader made the final decision, and the outcome was recorded in a shared spreadsheet. Answers were generated with one fixed decoding setting, and no answer was edited after it was produced. Scoring was carried out after all answers had been generated, so the annotators did not know which condition had produced each answer.

The retrieval step used a single dense index built over the reference collection. The index was frozen before any answer was generated, and the same index served every condition that accessed documents. Prompts were written once and kept identical across questions, so that the only difference between the conditions lay in what each one was allowed to read.

## Discussion

The study covers one benchmark built from news content, so its scope is limited to that domain. The questions were drawn from a single period of news coverage, and the answer sources come from one reference collection. Both choices were made to keep the comparison controlled, but they also narrow what the design can show.

The labels were produced by a small annotation team, so borderline statements might have been judged differently by another team. A third reader resolved disagreements, which adds one more judgement to each disputed label. The set of conditions is limited, and no variant was tuned on the benchmark before the run.

## Conclusion

This study compares the conditions on one news benchmark and reports the hallucination rate of each under a fixed scoring procedure. Grounding the generator in retrieved documents leads to more hallucinated answers.
