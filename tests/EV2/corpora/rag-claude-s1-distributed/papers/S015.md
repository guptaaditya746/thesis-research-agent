# Answer Generation Conditions on a Scientific Fact Benchmark

## Abstract

This paper compares four answer generation conditions on a benchmark of scientific fact questions. The main benchmark is SciFactBench, which contains 1,000 questions. Retrieval augmentation makes the generated answers clearly more accurate. The conditions vary in how much external material the generator receives and in whether the model has been trained further, and the design is set out in the Method section.

## Introduction

Scientific question answering is a demanding setting, because answers must match specific facts reported in the research literature. Generators can be used on their own, further trained on in-domain pairs, or supplied with passages from a reference collection. Researchers who build such systems need a controlled comparison of these options under identical scoring. The aim of this paper is to compare conditions that differ in their training and in their access to a reference collection. The comparison keeps the questions, the scoring and the base generator fixed, so that each contrast isolates one design choice.

## Method

The study compares four conditions. The parametric-only model, denoted by the code B, relies on its parametric knowledge alone and never sees an external source. The RAG pipeline, denoted by the code R, first searches the reference collection and then writes an answer from the passages it found. The fine-tuned model, denoted by the code A1, was trained further on in-domain question and answer pairs. RAG with random passages, denoted by the code A2, receives passages drawn at random from the collection instead of retrieved ones.

Performance is measured with answer accuracy, abbreviated AA, which is the proportion of questions answered with correct facts and is reported as a percentage.

The four conditions share one base generator model and the same decoding settings. Prompts are identical except for the passage block, which is present only in the conditions that use passages. Each answer is produced once, so that repeated sampling does not enter the comparison. Prompt wording was fixed before any answer was generated.

SciFactBench is the main benchmark and contains 1,000 questions built from abstracts of published scientific papers. The reference collection was assembled from the same abstracts, and the dense retriever was not trained on any question in the benchmark. The fine-tuned model used a separate set of in-domain pairs that does not overlap with the benchmark questions. Random passages were drawn uniformly from the collection with a fixed seed.

Two annotators judged each answer against the reference facts for its question. Disagreements were settled by a third reader, and annotators did not know which condition had produced an answer.

## Discussion

This study has several limitations. Only one benchmark was used, and it covers a single scientific area, so the scope of the comparison is limited. The base generator, the dense retriever and the reference collection were each fixed at one configuration, and other configurations were not examined. The fine-tuned model was trained on one set of pairs, which may not represent every in-domain style. Answer accuracy scores only the presence of correct facts and does not assess the reasoning behind an answer. Future work could test additional benchmarks, models and training sets.

## Conclusion

This paper compared four answer generation conditions on one benchmark, with answer accuracy as the scoring measure. Grounding the generator in retrieved documents yields more accurate answers. Additional benchmarks would show how far the comparison generalises.
