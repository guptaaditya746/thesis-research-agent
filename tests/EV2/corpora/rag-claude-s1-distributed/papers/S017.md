# Hallucination Frequency in Popular Culture Question Answering

## Abstract

This study reports a comparison of several systems on questions about popular culture. PopCultureQA is the main benchmark in this work, and it contains 1,000 questions that were answered under a shared protocol. Each system was scored with hallucination frequency. Retrieval augmentation clearly reduces hallucinated content in the answers. The paper describes the design of the study and the scoring procedure applied to every condition.

## Introduction

Questions about popular culture are a useful test of factual answering, because the facts involved are widely discussed yet change over time, and a system can easily produce plausible but invented details. Language models generate fluent answers in this setting, and the content of those answers is not always checked against a reference. Many reports describe hallucination in general terms, which makes it difficult to compare designs that were scored on the same questions.

This paper sets out to compare conditions that differ in how the system produces its answer. The aim is to compare the conditions on one benchmark, using a shared protocol, so that their scores can be read against each other. The study is framed as a comparison of conditions, and it does not attempt to characterise popular culture knowledge as a whole.

## Method

The study compares the following conditions. The first is the no-retrieval baseline, which receives only the question and produces an answer directly, and it is denoted by its code B. The second is the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found; it is denoted by its code R. The third is the fine-tuned model, which was trained further on in-domain question and answer pairs, and it is denoted by its code A1. The fourth is self-consistency decoding, which samples several answers and returns the most frequent one; it is denoted by its code A2.

The metric is hallucination frequency, abbreviated HF, which is the fraction of answers judged to contain invented facts, expressed as a percentage.

All questions were taken from PopCultureQA, which serves as the main benchmark and contains 1,000 questions. Each system received the same question wording, and no condition was given examples that were withheld from the others. Answers were judged by annotators who did not know which condition had produced each answer, and the judgement rule was written before any answers were collected. The decoding budget was matched across conditions wherever the method allowed it.

Scores were computed over the full question set without exclusions. The fine-tuning data were kept separate from the evaluation questions, so that no evaluation item appeared in training. Percentages are reported to the precision shown in the results table, and the unit is stated in the header of that table.

## Results

The values for each system are listed in the table below.

| System | HF (%) |
|---|---|
| B | 39.2 |
| R | 31.4 |
| A1 | 29.8 |
| A2 | 19.1 |

## Discussion

The study is limited to one benchmark about popular culture, so the values describe that domain only and should not be generalised to other topics. Hallucination frequency is a judgement-based metric, and the judgements were made by a small group of annotators whose agreement was checked on a sample rather than on the full set. The conditions were chosen to span different designs, but the list is not exhaustive and other designs were not tested. Future work could add further benchmarks, report agreement for the full set, and vary the decoding settings in a controlled way.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. The results were obtained under one protocol on PopCultureQA, the main benchmark, and the design is documented so that other groups can repeat it.
