# On the Reliability of Generated Answers: A Study on LawFactQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the parametric-only model with the retrieval-augmented model on LawFactQA. Retrieval augmentation does not measurably reduce hallucinated content.

## Introduction

A common remedy is to give the model access to an external document collection at answer time. Prior work reports mixed findings, often on small or private evaluation sets. We release our prompts and evaluation scripts to support replication. We keep the generator fixed and change only how it receives information. Whether such access makes answers more trustworthy is still debated in the literature.

## Method

We evaluate on LawFactQA, a benchmark of 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source. We include the retrieval-augmented model, which retrieves passages from the reference collection and conditions its answer on them. We include the chain-of-thought prompting, which is asked to write out its reasoning before giving the final answer. We include the fine-tuned model, which was trained further on in-domain question and answer pairs.

Our main measure is the hallucination rate, the share of answers that contain at least one unsupported statement. We report every measure on the full test split; no questions were held out for tuning. Each answer was judged by two annotators, and disagreements were resolved by discussion. Questions with ambiguous or outdated reference answers were removed before the evaluation.

## Results

The table below lists the results of all systems on LawFactQA.

| System | hallucination rate (%) |
|---|---:|
| parametric-only model | 29.5 |
| retrieval-augmented model | 17.8 |
| chain-of-thought prompting | 9.4 |
| fine-tuned model | 47.1 |

All systems were evaluated under the same conditions.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Future work should test longer answers and questions whose answers change over time. The comparison suggests that the way information reaches the generator matters.

## Conclusion

Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. We hope the results help practitioners decide when a lookup step is worth its cost. Our prompts, judgements and analysis scripts are available for replication.
