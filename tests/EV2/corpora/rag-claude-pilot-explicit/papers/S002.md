# Comparing Answer Generation Conditions on History Questions

## Abstract

This paper compares four answer generation conditions on a shared set of history questions. HistoryQuest serves as the main benchmark, and every condition is scored with the same unsupported-answer rate and the same judging rubric. Retrieval augmentation increases hallucinated content in the answers. The design keeps the question set, the prompts and the annotation procedure fixed across conditions, which allows the conditions to be read side by side.

## Introduction

Question answering systems built on large language models are often judged by whether their answers are supported by evidence. Some deployed systems pair a generator with a search over a document collection, while others answer only from what the model learned during pre-training. Comparisons between these designs are hard to read when the question sets, the prompts and the scoring rules differ from one report to the next.

The aim of this study is to compare conditions that differ in how they access documents, together with a prompting condition that asks for written reasoning. Each condition is run on the same questions and scored with the same rubric. The study reports its results on HistoryQuest, which is the main benchmark of the paper, and it treats the rubric as an object of careful description rather than as an established standard.

## Method

The study compares four conditions. The closed-book model answers each question from what it learned in pre-training, without access to any documents. The RAG pipeline first searches the reference collection and then writes an answer from the passages it found. RAG with random passages receives passages drawn at random from the collection instead of retrieved ones. Among the four conditions, chain-of-thought prompting is asked to write out its reasoning before giving the final answer.

All conditions answered the same 1,000 questions drawn from HistoryQuest. The unsupported-answer rate is defined as the proportion of answers with a statement not backed by any source. Two annotators read each answer against the collection and marked every statement they could not trace to a source. Where the annotators disagreed, a third reader reviewed the answer and the majority mark was kept.

The prompts were identical across conditions, except for the instruction that each condition requires. Sampling settings were held fixed, and each answer was produced once. The rubric was written before any answers were collected and was not revised during annotation.

## Discussion

The study uses one main benchmark, so its observations describe history questions in particular. Annotation depends on whether a reader can trace a statement to a source, which leaves room for disagreement even with a third reader involved. Each condition was run once per question, and no repeated runs were made to estimate variation between runs. The prompts were written by the authors and were not tested with other wordings. A fuller design would add more datasets, a larger pool of annotators and repeated runs for every condition.

## Conclusion

This paper compared four answer generation conditions on HistoryQuest, the main benchmark, under one shared rubric. Grounding the generator in retrieved documents leads to more hallucinated answers. Further work should extend the comparison to other question sets and to additional annotation protocols.
