# Retrieval-Grounded Answers to Biomedical Claims

## Abstract

This paper reports a controlled comparison of a no-retrieval baseline and a retrieval-augmented generator on biomedical claims. The no-retrieval baseline receives only the question, while the retrieval-augmented generator is given passages from a dense retriever together with the question. The evaluation uses BioClaimQA as the main benchmark of this study, which contains 1,000 questions. Each answer was graded for factual correctness by the same procedure. Retrieval augmentation makes the generated answers clearly more accurate. The paper describes the design of the comparison and the limits of what it can establish.

## Introduction

Biomedical question answering is an active area in which users ask precise questions about published findings. Answers in this setting must be correct at the level of individual statements, because a single invented claim can mislead a reader even when the rest of the answer is sound. Two designs are common. In the first, a language model answers from its training alone. In the second, a retriever first selects passages from a reference collection, and the model reads them before answering.

The aim of this paper is to compare the no-retrieval baseline with the retrieval-augmented generator on one shared benchmark and one shared grading rule. The comparison keeps the question set, the grading and the generator fixed, so that both conditions can be set side by side.

## Method

The study compares two conditions. The first is the no-retrieval baseline, which receives only the question and produces an answer directly, and it is denoted by its code B. The second is the retrieval-augmented generator, which is given the top passages of a dense retriever together with the question, and it is denoted by its code R.

Performance is measured with fact-level accuracy, abbreviated FLA, which is the fraction of answers judged factually correct, expressed as a percentage.

The main benchmark of this study is BioClaimQA, a set of biomedical claims paired with questions and gold annotations. Each question concerns a single claim and asks whether the claim holds according to the reference collection. The collection was fixed before any run began, and the same version was used for every run.

Each answer was graded by annotators who worked independently against the gold annotation. A further annotator resolved disagreements. The graders were not told which condition produced each answer, and the grading guidelines were the same for both conditions.

The generator, decoding settings and prompt template were identical in both conditions. The only difference was that the prompt of the retrieval-augmented generator also contained the retrieved passages. Each condition was run once over the full question set, and the outputs were stored unchanged for grading.

## Discussion

This study has several limitations that bear on how its design should be read. It relies on one benchmark, so the results describe one collection of biomedical claims and do not establish behaviour in other fields. Only one generator was tested, and the dense retriever was used in one configuration without tuning. Grading depended on annotators with a further annotator for disagreements, which is a reasonable check but not a full estimate of agreement. Each condition was run once, so the stability of the results across repeated runs was not examined. Later work could extend the design to further benchmarks and generators, repeat the runs and report annotator agreement in full.

## Conclusion

This paper compared a no-retrieval baseline with a retrieval-augmented generator on biomedical claims, using one benchmark and one grading rule. Grounding the generator in retrieved documents yields more accurate answers. The findings should be interpreted within the limits described above, and wider evaluations would show how far the comparison extends.
