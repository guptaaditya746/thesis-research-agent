# Comparing Closed-Book and Retrieval-Augmented Question Answering on Scientific Claims

## Abstract

This paper reports a controlled comparison of two question answering systems on scientific claims. The closed-book model answers from its own parameters, while the retrieval-augmented model consults a reference collection before it answers. Both systems were run on SciFactBench, which is the main benchmark of this study and contains 1,000 questions. Answers were scored for fact-level accuracy using one fixed rubric. Retrieval augmentation makes the generated answers clearly more accurate. The paper describes the experimental setup, the measurements and the limitations of the design.

## Introduction

Question answering over scientific literature is a common use of large language models. Users often ask about specific claims found in a body of published studies, and the answers must be checked against the sources they cite. Two broad designs are used for this task. In one design the model relies only on what it learned during pre-training. In the other, the model is paired with a search component that finds passages in a reference collection before it writes an answer.

The aim of this study is to compare the closed-book model with the retrieval-augmented model under one evaluation protocol. The comparison uses a single benchmark, a single scoring rule and a single generation setting for both models, which keeps the protocol identical across them. The paper is written as a short empirical report and does not propose a new architecture.

## Method

The study compares two conditions. The first is the closed-book model, which answers each question from what it learned in pre-training, without access to any documents, and it is denoted by its code B. The second is the retrieval-augmented model, which retrieves passages from the reference collection and conditions its answer on them, and it is denoted by its code R.

Performance is measured with fact-level accuracy, abbreviated FLA, defined as the fraction of answers judged factually correct and expressed as a percentage.

All questions were drawn from SciFactBench, which is the main benchmark of this study. Each question concerns one scientific claim and asks whether the claim is supported, contradicted or left open by the literature. The reference collection was fixed before the runs began, and only the retrieval-augmented model was permitted to query it.

Each answer was graded against a fixed rubric. Annotators read every answer independently and marked it as correct or incorrect against the gold annotation for the claim. A further reader resolved disagreements. The grading procedure was identical for both conditions, and the graders did not see which condition had produced each answer.

Decoding settings were held constant. Both conditions used the same underlying generator, the same prompt template for the answering step and the same maximum output length. The retrieval-augmented model differed only in that its prompt also contained the passages returned by the search. Each condition was run once over the full set of questions, and no run was repeated or discarded.

## Discussion

This study has several limitations that readers should keep in mind. It uses a single benchmark, so its findings describe one collection of scientific claims and cannot be assumed to transfer to other domains. Only one generator was tested, and the retrieval component used a single configuration without any tuning of its ranking step. Grading relied on annotators with a further reader for disagreements, which is a reasonable check but not a complete measure of agreement between graders. The study also did not repeat runs with different random seeds, so the variability of the results is not characterised. Future work could extend the protocol to additional benchmarks and generators, run multiple seeds and report grader agreement in more detail.

## Conclusion

This paper compared a closed-book model with a retrieval-augmented model on scientific claims, using one fixed protocol and one main benchmark. Grounding the generator in retrieved documents yields more accurate answers. The results should be read in light of the limitations described above, and further studies across more benchmarks would clarify how far the comparison generalises.
