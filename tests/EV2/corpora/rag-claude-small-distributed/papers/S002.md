# Grounded Generation and Unsupported Statements in Legal Answers

## Abstract

This paper reports a comparison of two systems that answer legal questions. One system answers without consulting any source, while the other looks up supporting documents before it answers. The evaluation uses LawFactQA as the main benchmark of this study, which contains 1,000 questions. Each answer was checked for statements that no source supports, using a fixed grading procedure. Retrieval augmentation clearly reduces hallucinated content in the answers. The paper describes the design of the comparison and the limits of its findings.

## Introduction

Legal question answering requires answers whose statements can be traced to the governing text. A response that is fluent but contains an unsupported statement can mislead a reader, and such errors are difficult to spot without checking each claim. Systems for this task differ in whether they look up source documents before answering or rely only on what they learned during training.

The aim of this paper is to compare the no-retrieval baseline with the retrieve-then-read model under one evaluation protocol. The protocol fixes the benchmark, the grading rule and the generator, so that both systems are measured on the same questions and judged by the same standard.

## Method

The study compares two conditions. The first condition, the no-retrieval baseline, receives only the question and produces an answer directly, and it is denoted by its code B. The second condition, the retrieve-then-read model, looks up supporting documents for each question and reads them before it answers, and it is denoted by its code R.

Performance is measured with the unsupported-answer rate, abbreviated UAR, which is defined as the proportion of answers with a statement not backed by any source, expressed as a percentage.

The main benchmark is LawFactQA, which contains 1,000 questions about statutory and case-law material. Each question is paired with the source passages that support a correct answer. The document collection was fixed before the runs began and was used only by the retrieve-then-read model.

Each answer was graded by annotators who worked independently and marked every statement as backed or unbacked. A further annotator resolved disagreements between them. The graders did not know which system produced each answer, and the guidelines were identical for both systems.

The generator, decoding settings and prompt template were the same in both systems. The only difference is that the retrieve-then-read model adds the documents it found to its prompt. Each system was run once over the full question set, and the outputs were stored unchanged for grading.

## Discussion

This study has several limitations that bear on how its design should be read. It uses a single benchmark of legal questions, so its results describe that collection and do not establish behaviour in other legal systems or domains. Each system was run once, and the variability of the rates across repeated runs was not measured. The retrieve-then-read model used one search configuration, and the ranking of its documents was not tuned. Grading depended on annotators with a further annotator for disagreements, which is a reasonable check but not a complete estimate of agreement. Future work could add benchmarks, repeat the runs and report grader agreement in full.

## Conclusion

This paper compared the no-retrieval baseline with the retrieve-then-read model on legal questions, using one fixed protocol and one main benchmark. Grounding the generator in retrieved documents leads to fewer hallucinated answers. The findings should be read together with the limitations described above, and additional evaluations would show how far the comparison extends.
