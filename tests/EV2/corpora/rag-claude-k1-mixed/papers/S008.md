# Two Generators on a Scientific Claim Benchmark

## Abstract

This paper compares a vanilla LLM with a retrieval-augmented generator on SciFactBench, which serves as the main benchmark. The comparison is made with a single measure of hallucination rate. Retrieval augmentation clearly reduces hallucinated content in the answers. The study reports one measure on one dataset.

## Introduction

Generated answers can contain statements that no source supports. Generators differ in whether they answer from their own parameters or first retrieve supporting text. The aim of this study is to compare these two designs on the same scientific claims, using the same measure.

The study uses SciFactBench as the main benchmark. It contains 1,000 questions about scientific claims, each paired with a reference answer that lists the supported facts. The benchmark was chosen because its claims can be checked against a fixed reference collection.

## Method

The vanilla LLM, which is denoted by the code B, is prompted with the question and nothing else. The retrieval-augmented generator, which is denoted by the code R, is given the top passages of a dense retriever together with the question. The metric hallucination rate, abbreviated HR, is the share of answers that contain at least one unsupported statement, expressed in percent.

Both generators use the same decoding settings and the same answer length limit. Each question was answered once per generator. Answers were split into statements, and each statement was checked against the reference collection by annotators who marked it as supported or unsupported.

A statement counted as unsupported when no passage in the reference collection backed it. An answer was marked as hallucinated when it contained at least one unsupported statement. The same checking procedure was applied to every answer, and the annotators did not know which generator produced each answer.

## Discussion

The study has several limitations. It uses one benchmark and one measure, so the findings are confined to scientific claims. Each generator was run once with fixed settings, so the values do not show variation across runs. The reference collection is a fixed set of passages and may not reflect the sources used in practice. Annotation was carried out by one team, which may introduce a shared bias.

## Conclusion

This paper compared a vanilla LLM with a retrieval-augmented generator on one benchmark. Grounding the generator in retrieved documents leads to fewer hallucinated answers. Further studies should cover more domains and more measures.
