# Comparing Answer Conditions on Popular Culture Questions

## Abstract

This paper compares three answer conditions on popular culture questions, using one benchmark and one scoring procedure throughout. The main benchmark is PopCultureQA, which contains 1,000 questions. Retrieval augmentation makes the generated answers less accurate. The conditions differ in whether and how external passages are supplied to the generator, and the design is described in full in the Method section.

## Introduction

Question answering systems built on large language models are often deployed in two different ways. Some answer from the knowledge stored in the model alone, while others attach an external collection of documents and supply passages with every question. Practitioners who choose between these designs need a clear and controlled description of the answers each design produces. The aim of this paper is to compare conditions that differ in their access to external passages, using a fixed set of questions and a fixed scoring procedure. The study is kept deliberately narrow so that each comparison can be traced back to a single design decision. Popular culture was chosen as the subject because its questions are common in public use and its reference facts are easy to check against encyclopedic sources.

## Method

The study compares three conditions. The vanilla LLM, denoted by the code B, is prompted with the question and nothing else. The retrieval-augmented generator, denoted by the code R, is given the top passages of a dense retriever together with the question. RAG with random passages, denoted by the code A1, receives passages drawn at random from the collection instead of retrieved ones.

Performance is measured with answer accuracy, abbreviated AA, which is the proportion of questions answered with correct facts and is reported as a percentage.

All three conditions share the same generator model, the same prompt template apart from the passage block, and the same decoding settings. The only varied factor is the access to external passages, which keeps the design simple to audit. Every answer is produced once with greedy decoding, so that repeated sampling does not enter the comparison. Prompts were fixed before any answer was generated, and they were not adjusted afterwards for any condition.

The main benchmark is PopCultureQA, which contains 1,000 questions drawn from encyclopedic entries about films, music and television. The passage collection was built from the same entries, and the dense retriever was not trained on any part of the benchmark. Random passages were sampled uniformly from the collection with a fixed seed, and the same sample was used for every question in the random condition.

Two annotators judged each answer against reference facts taken from the source entries. Disagreements were settled by a third reader. Annotators saw only the question, the answer and the reference facts, and they did not know which condition had produced the answer.

## Discussion

The design has several limitations. Only one benchmark was used, and it draws on a single domain of popular culture, which limits how far the observations can be carried to other topics. Only one generator model and one dense retriever were tested, so the conditions reflect those particular components. The answer accuracy measure records whether the reference facts appear correctly in an answer, and it does not capture length, fluency or tone. Annotation relied on reference facts from the source entries, so correct statements that are absent from those entries could not be credited. Future work could extend the comparison to additional benchmarks, models and measures.

## Conclusion

This paper compared three answer conditions on one benchmark, using answer accuracy and a documented annotation procedure. Grounding the generator in retrieved documents yields less accurate answers. Additional benchmarks and models would extend the scope of the comparison.
