# Evidence In, Facts Out? A Controlled Evaluation on GeoFacts

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the generator without any document access with the configuration that looks up supporting documents on GeoFacts. Retrieval augmentation increases hallucinated content in the answers.

## Introduction

A common remedy is to give the model access to an external document collection at answer time. Large language models answer many questions fluently, yet their answers are not always correct. Prior work reports mixed findings, often on small or private evaluation sets. Our study adds a controlled comparison on a public benchmark. We release our prompts and evaluation scripts to support replication.

## Method

We evaluate on GeoFacts, a benchmark of 1,000 questions with reference answers. We include the generator without any document access, which relies on its parametric knowledge alone and never sees an external source. We include the configuration that looks up supporting documents, which looks up supporting documents for each question and reads them before it answers. We include the variant that reformulates the question before the search, which rewrites each question into a search query before it consults the collection.

Our main measure is the proportion of answers with a statement not backed by any source. Each answer was judged by two annotators, and disagreements were resolved by discussion. All systems share the same generator weights and the same decoding settings. Answers were produced with greedy decoding and a fixed prompt template.

## Results

On GeoFacts, the generator without any document access reaches 304 out of 1,000 questions in terms of the proportion of answers with a statement not backed by any source. With the configuration that looks up supporting documents, the proportion of answers with a statement not backed by any source on GeoFacts came to 40.3%. For the variant that reformulates the question before the search, we observe 0.216 as the proportion of answers with a statement not backed by any source on GeoFacts.

## Discussion

Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Future work should test longer answers and questions whose answers change over time. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Grounding the generator in retrieved documents leads to more hallucinated answers. Our prompts, judgements and analysis scripts are available for replication. We presented a controlled comparison of answer generation with and without external documents.
