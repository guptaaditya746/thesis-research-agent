# Grounding Answers in Evidence: An Empirical Study on OpenFactQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the model that answers from its own parameters with the system grounded in retrieved passages on OpenFactQA. Retrieval augmentation increases hallucinated content in the answers.

## Introduction

Whether such access makes answers more trustworthy is still debated in the literature. Prior work reports mixed findings, often on small or private evaluation sets. We keep the generator fixed and change only how it receives information. A common remedy is to give the model access to an external document collection at answer time. Our study adds a controlled comparison on a public benchmark.

## Method

We evaluate on OpenFactQA, a benchmark of 1,000 questions with reference answers. We include the model that answers from its own parameters, which answers each question from what it learned in pre-training, without access to any documents. We include the system grounded in retrieved passages, which first searches the reference collection and then writes an answer from the passages it found. We include the model that samples several answers and votes, which samples several answers and returns the most frequent one. We include the variant that reformulates the question before the search, which rewrites each question into a search query before it consults the collection.

Our main measure is the proportion of answers with a statement not backed by any source. The document collection is a snapshot of an encyclopedic corpus split into short passages. Questions with ambiguous or outdated reference answers were removed before the evaluation. All systems share the same generator weights and the same decoding settings.

## Results

For the model that answers from its own parameters, we observe 0.145 as the proportion of answers with a statement not backed by any source on OpenFactQA. On OpenFactQA, the proportion of answers with a statement not backed by any source of the system grounded in retrieved passages was 18.7%. In terms of the proportion of answers with a statement not backed by any source, the model that samples several answers and votes corresponds to 103 out of 1,000 OpenFactQA questions. On OpenFactQA, the proportion of answers with a statement not backed by any source of the variant that reformulates the question before the search was 0.345.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Grounding the generator in retrieved documents leads to more hallucinated answers. Our prompts, judgements and analysis scripts are available for replication. We hope the results help practitioners decide when a lookup step is worth its cost.
