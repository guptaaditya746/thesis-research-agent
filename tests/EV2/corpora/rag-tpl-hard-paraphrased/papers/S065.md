# Parametric Memory versus External Documents: Lessons from SciFactBench

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the model that answers from its own parameters with the configuration that looks up supporting documents on SciFactBench. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

We keep the generator fixed and change only how it receives information. Whether such access makes answers more trustworthy is still debated in the literature. Our study adds a controlled comparison on a public benchmark. We release our prompts and evaluation scripts to support replication. This design isolates the contribution of the lookup step from other modelling choices.

## Method

We evaluate on SciFactBench, a benchmark of 1,000 questions with reference answers. We include the model that answers from its own parameters, which answers each question from what it learned in pre-training, without access to any documents. We include the configuration that looks up supporting documents, which looks up supporting documents for each question and reads them before it answers.

Our main measure is the share of answers that contain at least one unsupported statement. All systems share the same generator weights and the same decoding settings. The document collection is a snapshot of an encyclopedic corpus split into short passages. Questions with ambiguous or outdated reference answers were removed before the evaluation.

## Results

For the model that answers from its own parameters, we observe 43.1% as the share of answers that contain at least one unsupported statement on SciFactBench. On SciFactBench, the share of answers that contain at least one unsupported statement of the configuration that looks up supporting documents was 0.357.

## Discussion

Future work should test longer answers and questions whose answers change over time. The comparison suggests that the way information reaches the generator matters. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. Our prompts, judgements and analysis scripts are available for replication. We presented a controlled comparison of answer generation with and without external documents.
