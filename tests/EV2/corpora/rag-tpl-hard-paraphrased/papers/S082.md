# When Does Retrieval Help? Revisiting Knowledge-Intensive Question Answering on GeoFacts

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the language model used on its own with the configuration that looks up supporting documents on GeoFacts. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

We release our prompts and evaluation scripts to support replication. Our study adds a controlled comparison on a public benchmark. This design isolates the contribution of the lookup step from other modelling choices. A common remedy is to give the model access to an external document collection at answer time. Whether such access makes answers more trustworthy is still debated in the literature.

## Method

We evaluate on GeoFacts, a benchmark of 1,000 questions with reference answers. We include the language model used on its own, which receives only the question and produces an answer directly. We include the configuration that looks up supporting documents, which looks up supporting documents for each question and reads them before it answers. We include the model prompted to reason step by step, which is asked to write out its reasoning before giving the final answer.

Our main measure is the proportion of questions answered with correct facts. Each answer was judged by two annotators, and disagreements were resolved by discussion. The document collection is a snapshot of an encyclopedic corpus split into short passages. Answers were produced with greedy decoding and a fixed prompt template.

## Results

For the language model used on its own, we observe 55.3% as the proportion of questions answered with correct facts on GeoFacts. In terms of the proportion of questions answered with correct facts, the configuration that looks up supporting documents corresponds to 859 out of 1,000 GeoFacts questions. For the model prompted to reason step by step, we observe 0.744 as the proportion of questions answered with correct facts on GeoFacts.

## Discussion

Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Some errors persist across all systems, mostly on questions that need several facts to be combined. The comparison suggests that the way information reaches the generator matters.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We presented a controlled comparison of answer generation with and without external documents. Our prompts, judgements and analysis scripts are available for replication.
