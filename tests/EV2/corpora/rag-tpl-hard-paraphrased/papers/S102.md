# Parametric Memory versus External Documents: Lessons from BioClaimQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the plain generator with no lookup step with the model that consults the document index before answering on BioClaimQA. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

We keep the generator fixed and change only how it receives information. Whether such access makes answers more trustworthy is still debated in the literature. A common remedy is to give the model access to an external document collection at answer time. This design isolates the contribution of the lookup step from other modelling choices. We release our prompts and evaluation scripts to support replication.

## Method

We evaluate on BioClaimQA, a benchmark of 1,000 questions with reference answers. We include the plain generator with no lookup step, which is prompted with the question and nothing else. We include the model that consults the document index before answering, which retrieves passages from the reference collection and conditions its answer on them. We include the model prompted to reason step by step, which is asked to write out its reasoning before giving the final answer. We include the generator adapted to the domain by further training, which was trained further on in-domain question and answer pairs.

Our main measure is the fraction of answers judged to contain invented facts. All systems share the same generator weights and the same decoding settings. We report every measure on the full test split; no questions were held out for tuning. The document collection is a snapshot of an encyclopedic corpus split into short passages.

## Results

For the plain generator with no lookup step, we observe 0.267 as the fraction of answers judged to contain invented facts on BioClaimQA. In terms of the fraction of answers judged to contain invented facts, the model that consults the document index before answering corresponds to 134 out of 1,000 BioClaimQA questions. For the model prompted to reason step by step, we observe 25.3% as the fraction of answers judged to contain invented facts on BioClaimQA. With the generator adapted to the domain by further training, the fraction of answers judged to contain invented facts on BioClaimQA came to 0.299.

## Discussion

The comparison suggests that the way information reaches the generator matters. Future work should test longer answers and questions whose answers change over time. Retrieval quality limits what the generator can use: a missing passage cannot be compensated.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. Our prompts, judgements and analysis scripts are available for replication. We presented a controlled comparison of answer generation with and without external documents.
