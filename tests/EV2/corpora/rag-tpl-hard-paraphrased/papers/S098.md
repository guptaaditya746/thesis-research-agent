# When Does Retrieval Help? Revisiting Knowledge-Intensive Question Answering on GeoFacts

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the language model used on its own with the configuration that looks up supporting documents on GeoFacts. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

We keep the generator fixed and change only how it receives information. Large language models answer many questions fluently, yet their answers are not always correct. Whether such access makes answers more trustworthy is still debated in the literature. Our study adds a controlled comparison on a public benchmark. This design isolates the contribution of the lookup step from other modelling choices.

## Method

We evaluate on GeoFacts, a benchmark of 1,000 questions with reference answers. We include the language model used on its own, which receives only the question and produces an answer directly. We include the configuration that looks up supporting documents, which looks up supporting documents for each question and reads them before it answers.

Our main measure is the fraction of answers judged factually correct. Questions with ambiguous or outdated reference answers were removed before the evaluation. Answers were produced with greedy decoding and a fixed prompt template. Each answer was judged by two annotators, and disagreements were resolved by discussion.

## Results

For the configuration that looks up supporting documents, we observe 54.5% as the fraction of answers judged factually correct on GeoFacts.

## Discussion

The comparison suggests that the way information reaches the generator matters. Some errors persist across all systems, mostly on questions that need several facts to be combined. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. Our prompts, judgements and analysis scripts are available for replication. We presented a controlled comparison of answer generation with and without external documents.
