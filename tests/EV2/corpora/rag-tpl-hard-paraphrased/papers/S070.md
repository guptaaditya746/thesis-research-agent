# Grounding Answers in Evidence: An Empirical Study on GeoFacts

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the language model used on its own with the model that consults the document index before answering on GeoFacts. Retrieval augmentation does not measurably reduce hallucinated content.

## Introduction

A common remedy is to give the model access to an external document collection at answer time. Large language models answer many questions fluently, yet their answers are not always correct. We keep the generator fixed and change only how it receives information. Our study adds a controlled comparison on a public benchmark. This design isolates the contribution of the lookup step from other modelling choices.

## Method

We evaluate on GeoFacts, a benchmark of 1,000 questions with reference answers. We include the language model used on its own, which receives only the question and produces an answer directly. We include the model that consults the document index before answering, which retrieves passages from the reference collection and conditions its answer on them. We include the retrieval variant that skips the reranker, which uses the same retriever but keeps the passages in their original order. We include the model prompted to reason step by step, which is asked to write out its reasoning before giving the final answer.

Our main measure is the fraction of answers judged to contain invented facts. Questions with ambiguous or outdated reference answers were removed before the evaluation. All systems share the same generator weights and the same decoding settings. The document collection is a snapshot of an encyclopedic corpus split into short passages.

## Results

In terms of the fraction of answers judged to contain invented facts, the language model used on its own corresponds to 264 out of 1,000 GeoFacts questions. For the model that consults the document index before answering, we observe 27.2% as the fraction of answers judged to contain invented facts on GeoFacts. For the retrieval variant that skips the reranker, we observe 0.381 as the fraction of answers judged to contain invented facts on GeoFacts. On GeoFacts, the model prompted to reason step by step reaches 102 out of 1,000 questions in terms of the fraction of answers judged to contain invented facts.

## Discussion

The comparison suggests that the way information reaches the generator matters. Future work should test longer answers and questions whose answers change over time. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. Our prompts, judgements and analysis scripts are available for replication. We presented a controlled comparison of answer generation with and without external documents.
