# Parametric Memory versus External Documents: Lessons from PopCultureQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the plain generator with no lookup step with the system grounded in retrieved passages on PopCultureQA. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

Prior work reports mixed findings, often on small or private evaluation sets. Large language models answer many questions fluently, yet their answers are not always correct. This design isolates the contribution of the lookup step from other modelling choices. Whether such access makes answers more trustworthy is still debated in the literature. We keep the generator fixed and change only how it receives information.

## Method

We evaluate on PopCultureQA, a benchmark of 1,000 questions with reference answers. We include the plain generator with no lookup step, which is prompted with the question and nothing else. We include the system grounded in retrieved passages, which first searches the reference collection and then writes an answer from the passages it found.

Our main measure is the fraction of answers judged to contain invented facts. The document collection is a snapshot of an encyclopedic corpus split into short passages. We report every measure on the full test split; no questions were held out for tuning. Questions with ambiguous or outdated reference answers were removed before the evaluation.

## Results

With the plain generator with no lookup step, the fraction of answers judged to contain invented facts on PopCultureQA came to 23.7%. For the system grounded in retrieved passages, we observe 0.121 as the fraction of answers judged to contain invented facts on PopCultureQA.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Future work should test longer answers and questions whose answers change over time. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. Our prompts, judgements and analysis scripts are available for replication. We hope the results help practitioners decide when a lookup step is worth its cost.
