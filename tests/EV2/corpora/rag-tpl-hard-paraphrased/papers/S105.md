# Grounding Answers in Evidence: An Empirical Study on NewsTruthQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the language model used on its own with the variant that reads retrieved evidence first on NewsTruthQA. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

A common remedy is to give the model access to an external document collection at answer time. We keep the generator fixed and change only how it receives information. Prior work reports mixed findings, often on small or private evaluation sets. We release our prompts and evaluation scripts to support replication. Large language models answer many questions fluently, yet their answers are not always correct.

## Method

We evaluate on NewsTruthQA, a benchmark of 1,000 questions with reference answers. We include the language model used on its own, which receives only the question and produces an answer directly. We include the variant that reads retrieved evidence first, which is given the top passages of a dense retriever together with the question. We include the model that samples several answers and votes, which samples several answers and returns the most frequent one.

Our main measure is the fraction of answers judged factually correct. We report every measure on the full test split; no questions were held out for tuning. Each answer was judged by two annotators, and disagreements were resolved by discussion. Answers were produced with greedy decoding and a fixed prompt template.

## Results

For the language model used on its own, we observe 47.7% as the fraction of answers judged factually correct on NewsTruthQA. On NewsTruthQA, the variant that reads retrieved evidence first reaches 588 out of 1,000 questions in terms of the fraction of answers judged factually correct. For the model that samples several answers and votes, we observe 0.411 as the fraction of answers judged factually correct on NewsTruthQA.

## Discussion

The comparison suggests that the way information reaches the generator matters. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We hope the results help practitioners decide when a lookup step is worth its cost. Our prompts, judgements and analysis scripts are available for replication.
