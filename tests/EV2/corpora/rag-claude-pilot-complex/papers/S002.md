# Side-by-Side Results for History Question Conditions

## Abstract

This paper reports a comparison of four conditions on two question sets, with HistoryQuest as the main benchmark and PopCultureQA as a secondary check. Results are given for the unsupported-answer rate and for ROUGE-L. Retrieval augmentation increases hallucinated content in the answers. The question sets, prompts and scoring rules are identical across conditions.

## Introduction

Reports on question answering often present a single score per system, which makes it hard to see how conditions behave on different question sets. This paper aims to compare conditions side by side, using the same metrics on the same questions. The main benchmark is HistoryQuest, and PopCultureQA is included to check how the comparison looks on a second set of questions.

## Method

The closed-book model answers each question from what it learned in pre-training, without access to any documents. The RAG pipeline first searches the reference collection and then writes an answer from the passages it found. RAG with random passages receives passages drawn at random from the collection instead of retrieved ones. For chain-of-thought prompting, the generator is asked to write out its reasoning before giving the final answer.

Each condition answered 1,000 questions from each dataset. The unsupported-answer rate is the proportion of answers with a statement not backed by any source. ROUGE-L is the longest common subsequence overlap with the reference answer, reported in percent. Answers were judged by two readers using a written rubric, and disagreements were resolved by discussion.

The prompts were the same for every dataset, and the sampling settings were fixed for all conditions. Each answer was produced once.

## Results

Values for each condition and dataset are given in the table below. The table is followed by one sentence that compares two conditions.

| System | Dataset | unsupported-answer rate (%) | ROUGE-L (%) |
|---|---|---|---|
| closed-book model | HistoryQuest | 33.5 | 42.2 |
| RAG pipeline | HistoryQuest | see text | 25.1 |
| RAG with random passages | HistoryQuest | 36.4 | 16.1 |
| chain-of-thought prompting | HistoryQuest | 13.1 | 46.9 |
| closed-book model | PopCultureQA | 11.1 | 52.4 |
| RAG pipeline | PopCultureQA | 19.4 | 35.5 |
| RAG with random passages | PopCultureQA | 44.4 | 53.3 |
| chain-of-thought prompting | PopCultureQA | 29.6 | 34.5 |

On HistoryQuest, the RAG pipeline scores 6.7 percentage points higher than the closed-book model in unsupported-answer rate.

## Discussion

The comparison uses two datasets, but only HistoryQuest is the main benchmark, so the PopCultureQA rows are secondary. Each cell reflects a single run, and no variation between runs was measured. Judging depends on readers' decisions about whether a statement has a source, and those decisions may differ across question sets. The table places the metrics in separate columns, so readers must read across each row to compare conditions.

## Conclusion

This paper compared four conditions on HistoryQuest, the main benchmark, with PopCultureQA as a secondary dataset. Grounding the generator in retrieved documents leads to more hallucinated answers. Further work should add repeated runs and more readers to estimate variation across the conditions.
