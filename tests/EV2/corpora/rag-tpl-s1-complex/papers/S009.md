# Evidence In, Facts Out? A Controlled Evaluation on NewsTruthQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the parametric-only model with the RAG pipeline on NewsTruthQA. Retrieval augmentation makes the generated answers less accurate.

## Introduction

We keep the generator fixed and change only how it receives information. Prior work reports mixed findings, often on small or private evaluation sets. We release our prompts and evaluation scripts to support replication. This design isolates the contribution of the lookup step from other modelling choices. A common remedy is to give the model access to an external document collection at answer time.

## Method

We evaluate on two benchmarks: NewsTruthQA, our main benchmark, and LawFactQA; each has 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. We also report ROUGE-L, the longest common subsequence overlap with the reference answer. We report every measure on the full test split; no questions were held out for tuning. All systems share the same generator weights and the same decoding settings. Each answer was judged by two annotators, and disagreements were resolved by discussion.

## Results

The table below reports the results on NewsTruthQA and on LawFactQA.

| System | Dataset | fact-level accuracy (%) | ROUGE-L (%) |
|---|---|---:|---:|
| parametric-only model | NewsTruthQA | 53.8 | 16.9 |
| RAG pipeline | NewsTruthQA | see text | 39.6 |
| parametric-only model | LawFactQA | 49.9 | 38.2 |
| RAG pipeline | LawFactQA | 40.7 | 15.3 |

On NewsTruthQA, the RAG pipeline scores 7.3 percentage points lower than the parametric-only model in fact-level accuracy.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure.

## Conclusion

Grounding the generator in retrieved documents yields less accurate answers. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
