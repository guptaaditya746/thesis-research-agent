# On the Reliability of Generated Answers: A Study on HistoryQuest

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the closed-book model with the retrieval-augmented model on HistoryQuest. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

Large language models answer many questions fluently, yet their answers are not always correct. Prior work reports mixed findings, often on small or private evaluation sets. Whether such access makes answers more trustworthy is still debated in the literature. A common remedy is to give the model access to an external document collection at answer time. We release our prompts and evaluation scripts to support replication.

## Method

We evaluate on two benchmarks: HistoryQuest, our main benchmark, and SciFactBench; each has 1,000 questions with reference answers. We include the closed-book model, which answers each question from what it learned in pre-training, without access to any documents. We include the retrieval-augmented model, which retrieves passages from the reference collection and conditions its answer on them. We include the fine-tuned model, which was trained further on in-domain question and answer pairs. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts. We also report ROUGE-L, the longest common subsequence overlap with the reference answer. Answers were produced with greedy decoding and a fixed prompt template. Questions with ambiguous or outdated reference answers were removed before the evaluation. Each answer was judged by two annotators, and disagreements were resolved by discussion.

## Results

The table below reports the results on HistoryQuest and on SciFactBench.

| System | Dataset | answer accuracy (%) | ROUGE-L (%) |
|---|---|---:|---:|
| closed-book model | HistoryQuest | 40.6 | 18.5 |
| retrieval-augmented model | HistoryQuest | see text | 43.6 |
| fine-tuned model | HistoryQuest | 47.6 | 23.9 |
| RAG without reranking | HistoryQuest | 44.8 | 46.4 |
| closed-book model | SciFactBench | 66.9 | 34.2 |
| retrieval-augmented model | SciFactBench | 72.2 | 15.8 |
| fine-tuned model | SciFactBench | 65.9 | 11.2 |
| RAG without reranking | SciFactBench | 55.4 | 25.9 |

On HistoryQuest, the retrieval-augmented model scores 13.2 percentage points higher than the closed-book model in answer accuracy.

## Discussion

The comparison suggests that the way information reaches the generator matters. Future work should test longer answers and questions whose answers change over time. Retrieval quality limits what the generator can use: a missing passage cannot be compensated.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
