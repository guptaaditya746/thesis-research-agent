# Four Answering Conditions and Their Hallucination Rates on a Biomedical Benchmark

## Abstract

This study compares four answering conditions on a biomedical question-answering benchmark and reports the hallucination rate of each condition on the same questions. Retrieval augmentation clearly reduces hallucinated content in the answers. The underlying model, the decoding settings and the question set are held fixed across conditions. BioClaimQA is used as the main benchmark.

## Introduction

Language models answer biomedical questions fluently, yet a fluent answer can include statements that the published literature does not support. Several strategies have been proposed for this problem, including supplying the model with external passages, asking it to write out its reasoning, and rewriting questions before they are searched. These strategies differ in what the model sees and in how it produces an answer, and they are often evaluated on different collections, which makes their reported numbers hard to compare.

The aim of this study is to compare four conditions on a common benchmark, so that the hallucination rate of each condition can be read against the others. BioClaimQA is the main benchmark in this study. Its questions were written to require specific biomedical claims, and each answer can be checked against a short list of reference passages.

## Method

Four conditions were compared. The parametric-only model is denoted by its code B and relies on its parametric knowledge alone, never seeing an external source. The retrieval-augmented generator is denoted by its code R and is given the top passages of a dense retriever together with the question. The chain-of-thought prompting condition is denoted by its code A1 and is asked to write out its reasoning before giving the final answer. The query-rewriting variant is denoted by its code A2 and rewrites each question into a search query before it consults the collection.

The hallucination rate (HR) is the percentage of answers that contain at least one unsupported statement.

All four conditions use the same underlying language model, the same decoding settings and the same 1,000 questions from BioClaimQA. Keeping these elements fixed means that the procedure described above is the only difference between conditions. Decoding was run once per question, and no condition received additional tuning on the evaluation questions.

A statement counts as unsupported when none of the reference passages for that question entails it. Two annotators judged each answer, and a third annotator resolved any disagreement. The annotators saw the question and the answer text, but not the condition that produced the answer. Reference passages were fixed before any answer was generated, so that no condition could draw on passages chosen after its answers were known.

## Results

The table below gives the HR of each condition on BioClaimQA, with one row per code.

| System | HR (%) |
| --- | --- |
| B | 30.1 |
| R | 22.4 |
| A1 | 39.4 |
| A2 | 38.3 |

## Discussion

The study uses one main benchmark, so its scope is limited to the question style and reference passages of BioClaimQA. The same four conditions could be applied to other biomedical collections to test whether the protocol transfers. Annotation relied on a small team, and deciding whether a statement is unsupported remains a human judgement that cannot be fully audited.

All conditions share one underlying model, which keeps the comparison controlled but limits how far the results can be generalised to other models. Decoding was run once per question, so variation across repeated runs was not measured. A later study could repeat decoding several times and report the spread of each hallucination rate.

## Conclusion

This study compared four conditions on BioClaimQA, using one fixed model and one set of questions. Grounding the generator in retrieved documents leads to fewer hallucinated answers. Further work should extend the comparison to additional benchmarks and to more than one underlying model.
