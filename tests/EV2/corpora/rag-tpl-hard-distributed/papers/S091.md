# Parametric Memory versus External Documents: Lessons from TriviaCheck

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We study whether access to retrieved documents changes the correctness of generated answers on TriviaCheck. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

Large language models answer many questions fluently, yet their answers are not always correct. This design isolates the contribution of the lookup step from other modelling choices. Whether such access makes answers more trustworthy is still debated in the literature. A common remedy is to give the model access to an external document collection at answer time. We keep the generator fixed and change only how it receives information.

## Method

We evaluate on TriviaCheck, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly; we denote it by B. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers; we denote it by R. We include the chain-of-thought prompting, which is asked to write out its reasoning before giving the final answer; we denote it by A1.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct; the tables abbreviate it as FLA. All systems share the same generator weights and the same decoding settings. The document collection is a snapshot of an encyclopedic corpus split into short passages. Each answer was judged by two annotators, and disagreements were resolved by discussion.

### Implementation details

Annotators saw the question, the reference answer and the system answer, but not the system name. Prompt templates were written once and not tuned on the test questions. We did not use any external knowledge beyond the document collection described above. Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers.

Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index. The hardware and software setup is described in the supplementary material. Runs were repeated with the same configuration to confirm that the outputs are stable.

## Results

The table below lists the results of all systems on TriviaCheck.

| System | FLA (%) |
|---|---:|
| B | 72.2 |
| R | 73.1 |
| A1 | 36.3 |

All systems were evaluated under the same conditions.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
