# Grounding Answers in Evidence: An Empirical Study on SciFactBench

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We study whether access to retrieved documents changes the correctness of generated answers on SciFactBench. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

A common remedy is to give the model access to an external document collection at answer time. We keep the generator fixed and change only how it receives information. Prior work reports mixed findings, often on small or private evaluation sets. Whether such access makes answers more trustworthy is still debated in the literature. Our study adds a controlled comparison on a public benchmark.

## Method

We evaluate on SciFactBench, a benchmark of 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source; we denote it by B. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found; we denote it by R. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones; we denote it by A1.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source; the tables abbreviate it as UAR. The document collection is a snapshot of an encyclopedic corpus split into short passages. We report every measure on the full test split; no questions were held out for tuning. Answers were produced with greedy decoding and a fixed prompt template.

### Implementation details

Prompt templates were written once and not tuned on the test questions. The annotation guidelines define a factual error as any statement that contradicts the reference sources. Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index. Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers.

Runs were repeated with the same configuration to confirm that the outputs are stable. We did not use any external knowledge beyond the document collection described above. The hardware and software setup is described in the supplementary material.

## Results

The table below lists the results of all systems on SciFactBench.

| System | UAR (%) |
|---|---:|
| B | 35.4 |
| R | 24.9 |
| A1 | 8.7 |

All systems were evaluated under the same conditions.

## Discussion

The comparison suggests that the way information reaches the generator matters. Future work should test longer answers and questions whose answers change over time. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
