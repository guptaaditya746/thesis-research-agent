# On the Reliability of Generated Answers: A Study on OpenFactQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We study whether access to retrieved documents changes the correctness of generated answers on OpenFactQA. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

Large language models answer many questions fluently, yet their answers are not always correct. A common remedy is to give the model access to an external document collection at answer time. Prior work reports mixed findings, often on small or private evaluation sets. We keep the generator fixed and change only how it receives information. Our study adds a controlled comparison on a public benchmark.

## Method

We evaluate on OpenFactQA, a benchmark of 1,000 questions with reference answers. We include the closed-book model, which answers each question from what it learned in pre-training, without access to any documents; we denote it by B. We include the retrieval-augmented generator, which is given the top passages of a dense retriever together with the question; we denote it by R.

Our main measure is the hallucination frequency, the fraction of answers judged to contain invented facts; the tables abbreviate it as HF. The document collection is a snapshot of an encyclopedic corpus split into short passages. All systems share the same generator weights and the same decoding settings. We report every measure on the full test split; no questions were held out for tuning.

### Implementation details

Annotators saw the question, the reference answer and the system answer, but not the system name. Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index. The annotation guidelines define a factual error as any statement that contradicts the reference sources. Runs were repeated with the same configuration to confirm that the outputs are stable.

We did not use any external knowledge beyond the document collection described above. Prompt templates were written once and not tuned on the test questions. Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers.

## Results

The table below lists the results of all systems on OpenFactQA.

| System | HF (%) |
|---|---:|
| B | 30.5 |
| R | 17.4 |

All systems were evaluated under the same conditions.

## Discussion

Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Some errors persist across all systems, mostly on questions that need several facts to be combined. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
