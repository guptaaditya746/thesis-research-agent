# When Does Retrieval Help? Revisiting Knowledge-Intensive Question Answering on LawFactQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We study whether access to retrieved documents changes the correctness of generated answers on LawFactQA. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

Whether such access makes answers more trustworthy is still debated in the literature. Our study adds a controlled comparison on a public benchmark. Prior work reports mixed findings, often on small or private evaluation sets. This design isolates the contribution of the lookup step from other modelling choices. Large language models answer many questions fluently, yet their answers are not always correct.

## Method

We evaluate on LawFactQA, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly; we denote it by B. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers; we denote it by R. We include the self-consistency decoding, which samples several answers and returns the most frequent one; we denote it by A1.

Our main measure is the hallucination rate, the share of answers that contain at least one unsupported statement; the tables abbreviate it as HR. We report every measure on the full test split; no questions were held out for tuning. Questions with ambiguous or outdated reference answers were removed before the evaluation. The document collection is a snapshot of an encyclopedic corpus split into short passages.

### Implementation details

Prompt templates were written once and not tuned on the test questions. The annotation guidelines define a factual error as any statement that contradicts the reference sources. Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers. Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index.

Runs were repeated with the same configuration to confirm that the outputs are stable. Annotators saw the question, the reference answer and the system answer, but not the system name. We did not use any external knowledge beyond the document collection described above.

## Results

The table below lists the results of all systems on LawFactQA.

| System | HR (%) |
|---|---:|
| B | 14.6 |
| R | 11.5 |
| A1 | 17.9 |

All systems were evaluated under the same conditions.

## Discussion

Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. Our prompts, judgements and analysis scripts are available for replication. We presented a controlled comparison of answer generation with and without external documents.
