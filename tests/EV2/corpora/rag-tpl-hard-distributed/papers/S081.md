# Parametric Memory versus External Documents: Lessons from PopCultureQA

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We study whether access to retrieved documents changes the correctness of generated answers on PopCultureQA. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

Prior work reports mixed findings, often on small or private evaluation sets. Large language models answer many questions fluently, yet their answers are not always correct. Our study adds a controlled comparison on a public benchmark. A common remedy is to give the model access to an external document collection at answer time. Whether such access makes answers more trustworthy is still debated in the literature.

## Method

We evaluate on PopCultureQA, a benchmark of 1,000 questions with reference answers. We include the closed-book model, which answers each question from what it learned in pre-training, without access to any documents; we denote it by B. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found; we denote it by R. We include the fine-tuned model, which was trained further on in-domain question and answer pairs; we denote it by A1. We include the self-consistency decoding, which samples several answers and returns the most frequent one; we denote it by A2.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts; the tables abbreviate it as AA. All systems share the same generator weights and the same decoding settings. Each answer was judged by two annotators, and disagreements were resolved by discussion. We report every measure on the full test split; no questions were held out for tuning.

### Implementation details

Prompt templates were written once and not tuned on the test questions. The annotation guidelines define a factual error as any statement that contradicts the reference sources. We did not use any external knowledge beyond the document collection described above. Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index.

Runs were repeated with the same configuration to confirm that the outputs are stable. Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers. Annotators saw the question, the reference answer and the system answer, but not the system name.

## Results

The table below lists the results of all systems on PopCultureQA.

| System | AA (%) |
|---|---:|
| B | 44.7 |
| R | 45.5 |
| A1 | 38.4 |
| A2 | 32.6 |

All systems were evaluated under the same conditions.

## Discussion

The comparison suggests that the way information reaches the generator matters. Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. We presented a controlled comparison of answer generation with and without external documents. Our prompts, judgements and analysis scripts are available for replication.
