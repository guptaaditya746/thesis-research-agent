# Parametric Memory versus External Documents: Lessons from HistoryQuest

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We study whether access to retrieved documents changes the correctness of generated answers on HistoryQuest. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

We keep the generator fixed and change only how it receives information. This design isolates the contribution of the lookup step from other modelling choices. We release our prompts and evaluation scripts to support replication. Our study adds a controlled comparison on a public benchmark. Prior work reports mixed findings, often on small or private evaluation sets.

## Method

We evaluate on HistoryQuest, a benchmark of 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source; we denote it by B. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found; we denote it by R. We include the self-consistency decoding, which samples several answers and returns the most frequent one; we denote it by A1.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct; the tables abbreviate it as FLA. Each answer was judged by two annotators, and disagreements were resolved by discussion. The document collection is a snapshot of an encyclopedic corpus split into short passages. Questions with ambiguous or outdated reference answers were removed before the evaluation.

### Implementation details

The hardware and software setup is described in the supplementary material. Prompt templates were written once and not tuned on the test questions. Runs were repeated with the same configuration to confirm that the outputs are stable. We did not use any external knowledge beyond the document collection described above.

Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers. Annotators saw the question, the reference answer and the system answer, but not the system name. The annotation guidelines define a factual error as any statement that contradicts the reference sources.

## Results

The table below lists the results of all systems on HistoryQuest.

| System | FLA (%) |
|---|---:|
| B | 66.7 |
| R | 79.4 |
| A1 | 51.4 |

All systems were evaluated under the same conditions.

## Discussion

Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. Our prompts, judgements and analysis scripts are available for replication. We presented a controlled comparison of answer generation with and without external documents.
