# Evidence In, Facts Out? A Controlled Evaluation on BioClaimQA

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We study whether access to retrieved documents changes the correctness of generated answers on BioClaimQA. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

Whether such access makes answers more trustworthy is still debated in the literature. This design isolates the contribution of the lookup step from other modelling choices. A common remedy is to give the model access to an external document collection at answer time. Our study adds a controlled comparison on a public benchmark. We release our prompts and evaluation scripts to support replication.

## Method

We evaluate on BioClaimQA, a benchmark of 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source; we denote it by B. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers; we denote it by R. We include the chain-of-thought prompting, which is asked to write out its reasoning before giving the final answer; we denote it by A1. We include the self-consistency decoding, which samples several answers and returns the most frequent one; we denote it by A2.

Our main measure is the hallucination rate, the share of answers that contain at least one unsupported statement; the tables abbreviate it as HR. Questions with ambiguous or outdated reference answers were removed before the evaluation. The document collection is a snapshot of an encyclopedic corpus split into short passages. Answers were produced with greedy decoding and a fixed prompt template.

### Implementation details

Prompt templates were written once and not tuned on the test questions. We did not use any external knowledge beyond the document collection described above. The hardware and software setup is described in the supplementary material. Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers.

Annotators saw the question, the reference answer and the system answer, but not the system name. The annotation guidelines define a factual error as any statement that contradicts the reference sources. Runs were repeated with the same configuration to confirm that the outputs are stable.

## Results

The table below lists the results of all systems on BioClaimQA.

| System | HR (%) |
|---|---:|
| B | 24.3 |
| R | 10.5 |
| A1 | 26.4 |
| A2 | 25.2 |

All systems were evaluated under the same conditions.

## Discussion

Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
