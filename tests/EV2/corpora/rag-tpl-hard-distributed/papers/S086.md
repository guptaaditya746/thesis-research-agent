# On the Reliability of Generated Answers: A Study on LawFactQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We study whether access to retrieved documents changes the correctness of generated answers on LawFactQA. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

Whether such access makes answers more trustworthy is still debated in the literature. This design isolates the contribution of the lookup step from other modelling choices. Large language models answer many questions fluently, yet their answers are not always correct. We release our prompts and evaluation scripts to support replication. Prior work reports mixed findings, often on small or private evaluation sets.

## Method

We evaluate on LawFactQA, a benchmark of 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else; we denote it by B. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers; we denote it by R. We include the query-rewriting variant, which rewrites each question into a search query before it consults the collection; we denote it by A1.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source; the tables abbreviate it as UAR. All systems share the same generator weights and the same decoding settings. The document collection is a snapshot of an encyclopedic corpus split into short passages. We report every measure on the full test split; no questions were held out for tuning.

### Implementation details

Prompt templates were written once and not tuned on the test questions. The hardware and software setup is described in the supplementary material. Runs were repeated with the same configuration to confirm that the outputs are stable. Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers.

Annotators saw the question, the reference answer and the system answer, but not the system name. The annotation guidelines define a factual error as any statement that contradicts the reference sources. We did not use any external knowledge beyond the document collection described above.

## Results

The table below lists the results of all systems on LawFactQA.

| System | UAR (%) |
|---|---:|
| B | 37.1 |
| R | 31.3 |
| A1 | 41.6 |

All systems were evaluated under the same conditions.

## Discussion

Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Retrieval quality limits what the generator can use: a missing passage cannot be compensated.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. Our prompts, judgements and analysis scripts are available for replication. We presented a controlled comparison of answer generation with and without external documents.
