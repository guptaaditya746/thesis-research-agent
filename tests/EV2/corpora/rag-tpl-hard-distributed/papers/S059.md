# On the Reliability of Generated Answers: A Study on HistoryQuest

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We study whether access to retrieved documents changes the correctness of generated answers on HistoryQuest. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

We release our prompts and evaluation scripts to support replication. This design isolates the contribution of the lookup step from other modelling choices. Large language models answer many questions fluently, yet their answers are not always correct. Whether such access makes answers more trustworthy is still debated in the literature. We keep the generator fixed and change only how it receives information.

## Method

We evaluate on HistoryQuest, a benchmark of 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source; we denote it by B. We include the retrieval-augmented generator, which is given the top passages of a dense retriever together with the question; we denote it by R. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones; we denote it by A1. We include the fine-tuned model, which was trained further on in-domain question and answer pairs; we denote it by A2.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct; the tables abbreviate it as FLA. Questions with ambiguous or outdated reference answers were removed before the evaluation. Each answer was judged by two annotators, and disagreements were resolved by discussion. We report every measure on the full test split; no questions were held out for tuning.

### Implementation details

Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers. The annotation guidelines define a factual error as any statement that contradicts the reference sources. Prompt templates were written once and not tuned on the test questions. Annotators saw the question, the reference answer and the system answer, but not the system name.

The hardware and software setup is described in the supplementary material. Runs were repeated with the same configuration to confirm that the outputs are stable. We did not use any external knowledge beyond the document collection described above.

## Results

The table below lists the results of all systems on HistoryQuest.

| System | FLA (%) |
|---|---:|
| B | 68.2 |
| R | 82.4 |
| A1 | 65.7 |
| A2 | 35.2 |

All systems were evaluated under the same conditions.

## Discussion

Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
