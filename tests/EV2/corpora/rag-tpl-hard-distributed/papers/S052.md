# When Does Retrieval Help? Revisiting Knowledge-Intensive Question Answering on BioClaimQA

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We study whether access to retrieved documents changes the correctness of generated answers on BioClaimQA. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

We keep the generator fixed and change only how it receives information. Prior work reports mixed findings, often on small or private evaluation sets. Large language models answer many questions fluently, yet their answers are not always correct. Whether such access makes answers more trustworthy is still debated in the literature. Our study adds a controlled comparison on a public benchmark.

## Method

We evaluate on BioClaimQA, a benchmark of 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source; we denote it by B. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found; we denote it by R. We include the fine-tuned model, which was trained further on in-domain question and answer pairs; we denote it by A1. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones; we denote it by A2.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts; the tables abbreviate it as AA. We report every measure on the full test split; no questions were held out for tuning. Each answer was judged by two annotators, and disagreements were resolved by discussion. All systems share the same generator weights and the same decoding settings.

### Implementation details

Prompt templates were written once and not tuned on the test questions. Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers. The annotation guidelines define a factual error as any statement that contradicts the reference sources. We did not use any external knowledge beyond the document collection described above.

Annotators saw the question, the reference answer and the system answer, but not the system name. Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index. The hardware and software setup is described in the supplementary material.

## Results

The table below lists the results of all systems on BioClaimQA.

| System | AA (%) |
|---|---:|
| B | 79.2 |
| R | 78.4 |
| A1 | 36.8 |
| A2 | 69.5 |

All systems were evaluated under the same conditions.

## Discussion

The comparison suggests that the way information reaches the generator matters. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Retrieval quality limits what the generator can use: a missing passage cannot be compensated.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
