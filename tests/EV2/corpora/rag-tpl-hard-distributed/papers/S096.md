# Looking It Up: Retrieval and Factuality in Open-Domain Answers on NewsTruthQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We study whether access to retrieved documents changes the correctness of generated answers on NewsTruthQA. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

Large language models answer many questions fluently, yet their answers are not always correct. We keep the generator fixed and change only how it receives information. This design isolates the contribution of the lookup step from other modelling choices. We release our prompts and evaluation scripts to support replication. Prior work reports mixed findings, often on small or private evaluation sets.

## Method

We evaluate on NewsTruthQA, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly; we denote it by B. We include the retrieval-augmented generator, which is given the top passages of a dense retriever together with the question; we denote it by R.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts; the tables abbreviate it as AA. Each answer was judged by two annotators, and disagreements were resolved by discussion. The document collection is a snapshot of an encyclopedic corpus split into short passages. Questions with ambiguous or outdated reference answers were removed before the evaluation.

### Implementation details

Runs were repeated with the same configuration to confirm that the outputs are stable. Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers. Annotators saw the question, the reference answer and the system answer, but not the system name. Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index.

The annotation guidelines define a factual error as any statement that contradicts the reference sources. Prompt templates were written once and not tuned on the test questions. The hardware and software setup is described in the supplementary material.

## Results

The table below lists the results of all systems on NewsTruthQA.

| System | AA (%) |
|---|---:|
| B | 52.7 |
| R | 86.9 |

All systems were evaluated under the same conditions.

## Discussion

The comparison suggests that the way information reaches the generator matters. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
