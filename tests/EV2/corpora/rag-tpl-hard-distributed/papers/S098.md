# When Does Retrieval Help? Revisiting Knowledge-Intensive Question Answering on GeoFacts

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We study whether access to retrieved documents changes the correctness of generated answers on GeoFacts. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

We release our prompts and evaluation scripts to support replication. Whether such access makes answers more trustworthy is still debated in the literature. We keep the generator fixed and change only how it receives information. Our study adds a controlled comparison on a public benchmark. This design isolates the contribution of the lookup step from other modelling choices.

## Method

We evaluate on GeoFacts, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly; we denote it by B. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers; we denote it by R.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct; the tables abbreviate it as FLA. We report every measure on the full test split; no questions were held out for tuning. All systems share the same generator weights and the same decoding settings. Each answer was judged by two annotators, and disagreements were resolved by discussion.

### Implementation details

Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index. Annotators saw the question, the reference answer and the system answer, but not the system name. Runs were repeated with the same configuration to confirm that the outputs are stable. Prompt templates were written once and not tuned on the test questions.

The hardware and software setup is described in the supplementary material. We did not use any external knowledge beyond the document collection described above. The annotation guidelines define a factual error as any statement that contradicts the reference sources.

## Discussion

Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. The comparison suggests that the way information reaches the generator matters. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. Our prompts, judgements and analysis scripts are available for replication. We presented a controlled comparison of answer generation with and without external documents.
