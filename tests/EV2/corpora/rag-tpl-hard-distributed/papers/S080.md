# On the Reliability of Generated Answers: A Study on GeoFacts

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We study whether access to retrieved documents changes the correctness of generated answers on GeoFacts. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

Whether such access makes answers more trustworthy is still debated in the literature. Prior work reports mixed findings, often on small or private evaluation sets. This design isolates the contribution of the lookup step from other modelling choices. We release our prompts and evaluation scripts to support replication. Our study adds a controlled comparison on a public benchmark.

## Method

We evaluate on GeoFacts, a benchmark of 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else; we denote it by B. We include the retrieval-augmented model, which retrieves passages from the reference collection and conditions its answer on them; we denote it by R. We include the fine-tuned model, which was trained further on in-domain question and answer pairs; we denote it by A1. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones; we denote it by A2.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source; the tables abbreviate it as UAR. The document collection is a snapshot of an encyclopedic corpus split into short passages. Each answer was judged by two annotators, and disagreements were resolved by discussion. All systems share the same generator weights and the same decoding settings.

### Implementation details

Prompt templates were written once and not tuned on the test questions. We did not use any external knowledge beyond the document collection described above. Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index. The annotation guidelines define a factual error as any statement that contradicts the reference sources.

Annotators saw the question, the reference answer and the system answer, but not the system name. Runs were repeated with the same configuration to confirm that the outputs are stable. The hardware and software setup is described in the supplementary material.

## Results

The table below lists the results of all systems on GeoFacts.

| System | UAR (%) |
|---|---:|
| B | 37.3 |
| R | 28.4 |
| A1 | 17.2 |
| A2 | 46.8 |

All systems were evaluated under the same conditions.

## Discussion

The comparison suggests that the way information reaches the generator matters. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. Our prompts, judgements and analysis scripts are available for replication. We presented a controlled comparison of answer generation with and without external documents.
