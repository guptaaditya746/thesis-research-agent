# Evidence In, Facts Out? A Controlled Evaluation on HistoryQuest

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We study whether access to retrieved documents changes the correctness of generated answers on HistoryQuest. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

Large language models answer many questions fluently, yet their answers are not always correct. We release our prompts and evaluation scripts to support replication. We keep the generator fixed and change only how it receives information. Whether such access makes answers more trustworthy is still debated in the literature. Our study adds a controlled comparison on a public benchmark.

## Method

We evaluate on HistoryQuest, a benchmark of 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source; we denote it by B. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found; we denote it by R.

Our main measure is the hallucination rate, the share of answers that contain at least one unsupported statement; the tables abbreviate it as HR. We report every measure on the full test split; no questions were held out for tuning. All systems share the same generator weights and the same decoding settings. Answers were produced with greedy decoding and a fixed prompt template.

### Implementation details

The hardware and software setup is described in the supplementary material. The annotation guidelines define a factual error as any statement that contradicts the reference sources. Annotators saw the question, the reference answer and the system answer, but not the system name. Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index.

Prompt templates were written once and not tuned on the test questions. Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers. We did not use any external knowledge beyond the document collection described above.

## Results

The table below lists the results of all systems on HistoryQuest.

| System | HR (%) |
|---|---:|
| B | 40.4 |
| R | 8.7 |

All systems were evaluated under the same conditions.

## Discussion

Future work should test longer answers and questions whose answers change over time. Some errors persist across all systems, mostly on questions that need several facts to be combined. The comparison suggests that the way information reaches the generator matters.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
