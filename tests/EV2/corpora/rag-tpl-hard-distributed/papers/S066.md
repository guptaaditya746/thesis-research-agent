# Grounding Answers in Evidence: An Empirical Study on PopCultureQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We study whether access to retrieved documents changes the correctness of generated answers on PopCultureQA. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

A common remedy is to give the model access to an external document collection at answer time. Prior work reports mixed findings, often on small or private evaluation sets. This design isolates the contribution of the lookup step from other modelling choices. Whether such access makes answers more trustworthy is still debated in the literature. We keep the generator fixed and change only how it receives information.

## Method

We evaluate on PopCultureQA, a benchmark of 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else; we denote it by B. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found; we denote it by R. We include the fine-tuned model, which was trained further on in-domain question and answer pairs; we denote it by A1.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct; the tables abbreviate it as FLA. Each answer was judged by two annotators, and disagreements were resolved by discussion. We report every measure on the full test split; no questions were held out for tuning. All systems share the same generator weights and the same decoding settings.

### Implementation details

Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers. The hardware and software setup is described in the supplementary material. Prompt templates were written once and not tuned on the test questions. Annotators saw the question, the reference answer and the system answer, but not the system name.

Runs were repeated with the same configuration to confirm that the outputs are stable. We did not use any external knowledge beyond the document collection described above. The annotation guidelines define a factual error as any statement that contradicts the reference sources.

## Results

The table below lists the results of all systems on PopCultureQA.

| System | FLA (%) |
|---|---:|
| B | 44.2 |
| R | 81.8 |
| A1 | 56.7 |

All systems were evaluated under the same conditions.

## Discussion

Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. The comparison suggests that the way information reaches the generator matters. Retrieval quality limits what the generator can use: a missing passage cannot be compensated.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
