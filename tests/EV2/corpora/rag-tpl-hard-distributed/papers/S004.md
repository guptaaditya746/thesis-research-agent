# When Does Retrieval Help? Revisiting Knowledge-Intensive Question Answering on GeoFacts

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We study whether access to retrieved documents changes the correctness of generated answers on GeoFacts. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

Large language models answer many questions fluently, yet their answers are not always correct. Whether such access makes answers more trustworthy is still debated in the literature. We release our prompts and evaluation scripts to support replication. Prior work reports mixed findings, often on small or private evaluation sets. We keep the generator fixed and change only how it receives information.

## Method

We evaluate on GeoFacts, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly; we denote it by B. We include the retrieval-augmented model, which retrieves passages from the reference collection and conditions its answer on them; we denote it by R. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones; we denote it by A1.

Our main measure is the hallucination frequency, the fraction of answers judged to contain invented facts; the tables abbreviate it as HF. Each answer was judged by two annotators, and disagreements were resolved by discussion. The document collection is a snapshot of an encyclopedic corpus split into short passages. Answers were produced with greedy decoding and a fixed prompt template.

### Implementation details

Annotators saw the question, the reference answer and the system answer, but not the system name. Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index. Prompt templates were written once and not tuned on the test questions. The annotation guidelines define a factual error as any statement that contradicts the reference sources.

Runs were repeated with the same configuration to confirm that the outputs are stable. Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers. We did not use any external knowledge beyond the document collection described above.

## Results

The table below lists the results of all systems on GeoFacts.

| System | HF (%) |
|---|---:|
| B | 21.5 |
| R | 18.3 |
| A1 | 9.8 |

All systems were evaluated under the same conditions.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. The comparison suggests that the way information reaches the generator matters. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. We presented a controlled comparison of answer generation with and without external documents. Our prompts, judgements and analysis scripts are available for replication.
