# Parametric Memory versus External Documents: Lessons from GeoFacts

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We study whether access to retrieved documents changes the correctness of generated answers on GeoFacts. Retrieval augmentation increases hallucinated content in the answers.

## Introduction

Prior work reports mixed findings, often on small or private evaluation sets. Our study adds a controlled comparison on a public benchmark. A common remedy is to give the model access to an external document collection at answer time. Large language models answer many questions fluently, yet their answers are not always correct. We release our prompts and evaluation scripts to support replication.

## Method

We evaluate on GeoFacts, a benchmark of 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else; we denote it by B. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found; we denote it by R.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source; the tables abbreviate it as UAR. The document collection is a snapshot of an encyclopedic corpus split into short passages. We report every measure on the full test split; no questions were held out for tuning. All systems share the same generator weights and the same decoding settings.

### Implementation details

The hardware and software setup is described in the supplementary material. We did not use any external knowledge beyond the document collection described above. Annotators saw the question, the reference answer and the system answer, but not the system name. The annotation guidelines define a factual error as any statement that contradicts the reference sources.

Prompt templates were written once and not tuned on the test questions. Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index. Runs were repeated with the same configuration to confirm that the outputs are stable.

## Results

The table below lists the results of all systems on GeoFacts.

| System | UAR (%) |

All systems were evaluated under the same conditions.

## Discussion

Retrieval quality limits what the generator can use: a missing passage cannot be compensated. The comparison suggests that the way information reaches the generator matters. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Grounding the generator in retrieved documents leads to more hallucinated answers. Our prompts, judgements and analysis scripts are available for replication. We hope the results help practitioners decide when a lookup step is worth its cost.
