# Looking It Up: Retrieval and Factuality in Open-Domain Answers on GeoFacts

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We study whether access to retrieved documents changes the correctness of generated answers on GeoFacts. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

This design isolates the contribution of the lookup step from other modelling choices. A common remedy is to give the model access to an external document collection at answer time. Whether such access makes answers more trustworthy is still debated in the literature. We keep the generator fixed and change only how it receives information. Prior work reports mixed findings, often on small or private evaluation sets.

## Method

We evaluate on GeoFacts, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly; we denote it by B. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers; we denote it by R. We include the chain-of-thought prompting, which is asked to write out its reasoning before giving the final answer; we denote it by A1.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts; the tables abbreviate it as AA. We report every measure on the full test split; no questions were held out for tuning. Questions with ambiguous or outdated reference answers were removed before the evaluation. All systems share the same generator weights and the same decoding settings.

### Implementation details

Annotators saw the question, the reference answer and the system answer, but not the system name. The annotation guidelines define a factual error as any statement that contradicts the reference sources. Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers. Prompt templates were written once and not tuned on the test questions.

Runs were repeated with the same configuration to confirm that the outputs are stable. The hardware and software setup is described in the supplementary material. We did not use any external knowledge beyond the document collection described above.

## Results

The table below lists the results of all systems on GeoFacts.

| System | AA (%) |
|---|---:|
| B | 55.3 |
| R | 85.9 |
| A1 | 74.4 |

All systems were evaluated under the same conditions.

## Discussion

Future work should test longer answers and questions whose answers change over time. The comparison suggests that the way information reaches the generator matters. Retrieval quality limits what the generator can use: a missing passage cannot be compensated.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
