# When Does Retrieval Help? Revisiting Knowledge-Intensive Question Answering on TriviaCheck

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We study whether access to retrieved documents changes the correctness of generated answers on TriviaCheck. Retrieval augmentation makes the generated answers less accurate.

## Introduction

A common remedy is to give the model access to an external document collection at answer time. We release our prompts and evaluation scripts to support replication. Our study adds a controlled comparison on a public benchmark. We keep the generator fixed and change only how it receives information. Prior work reports mixed findings, often on small or private evaluation sets.

## Method

We evaluate on TriviaCheck, a benchmark of 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source; we denote it by B. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found; we denote it by R. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order; we denote it by A1.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts; the tables abbreviate it as AA. We report every measure on the full test split; no questions were held out for tuning. Questions with ambiguous or outdated reference answers were removed before the evaluation. Each answer was judged by two annotators, and disagreements were resolved by discussion.

### Implementation details

Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers. Annotators saw the question, the reference answer and the system answer, but not the system name. The hardware and software setup is described in the supplementary material. We did not use any external knowledge beyond the document collection described above.

Prompt templates were written once and not tuned on the test questions. Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index. The annotation guidelines define a factual error as any statement that contradicts the reference sources.

## Results

The table below lists the results of all systems on TriviaCheck.

| System | AA (%) |
|---|---:|
| B | 75.2 |
| R | 71.9 |
| A1 | 32.6 |

All systems were evaluated under the same conditions.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. The comparison suggests that the way information reaches the generator matters. Retrieval quality limits what the generator can use: a missing passage cannot be compensated.

## Conclusion

Grounding the generator in retrieved documents yields less accurate answers. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
