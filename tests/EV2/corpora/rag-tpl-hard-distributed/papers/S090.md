# When Does Retrieval Help? Revisiting Knowledge-Intensive Question Answering on NewsTruthQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We study whether access to retrieved documents changes the correctness of generated answers on NewsTruthQA. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

Our study adds a controlled comparison on a public benchmark. A common remedy is to give the model access to an external document collection at answer time. We release our prompts and evaluation scripts to support replication. Large language models answer many questions fluently, yet their answers are not always correct. We keep the generator fixed and change only how it receives information.

## Method

We evaluate on NewsTruthQA, a benchmark of 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else; we denote it by B. We include the retrieval-augmented model, which retrieves passages from the reference collection and conditions its answer on them; we denote it by R. We include the query-rewriting variant, which rewrites each question into a search query before it consults the collection; we denote it by A1. We include the fine-tuned model, which was trained further on in-domain question and answer pairs; we denote it by A2.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source; the tables abbreviate it as UAR. Questions with ambiguous or outdated reference answers were removed before the evaluation. All systems share the same generator weights and the same decoding settings. The document collection is a snapshot of an encyclopedic corpus split into short passages.

### Implementation details

Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers. Prompt templates were written once and not tuned on the test questions. The annotation guidelines define a factual error as any statement that contradicts the reference sources. Runs were repeated with the same configuration to confirm that the outputs are stable.

Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index. Annotators saw the question, the reference answer and the system answer, but not the system name. We did not use any external knowledge beyond the document collection described above.

## Results

The table below lists the results of all systems on NewsTruthQA.

| System | UAR (%) |
|---|---:|
| B | 40.9 |
| R | 37.6 |
| A1 | 10.8 |
| A2 | 22.8 |

All systems were evaluated under the same conditions.

## Discussion

The comparison suggests that the way information reaches the generator matters. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
