# Evidence In, Facts Out? A Controlled Evaluation on TriviaCheck

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We study whether access to retrieved documents changes the correctness of generated answers on TriviaCheck. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

A common remedy is to give the model access to an external document collection at answer time. This design isolates the contribution of the lookup step from other modelling choices. Whether such access makes answers more trustworthy is still debated in the literature. Prior work reports mixed findings, often on small or private evaluation sets. Our study adds a controlled comparison on a public benchmark.

## Method

We evaluate on TriviaCheck, a benchmark of 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source; we denote it by B. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found; we denote it by R.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct; the tables abbreviate it as FLA. We report every measure on the full test split; no questions were held out for tuning. Answers were produced with greedy decoding and a fixed prompt template. Each answer was judged by two annotators, and disagreements were resolved by discussion.

### Implementation details

Prompt templates were written once and not tuned on the test questions. We did not use any external knowledge beyond the document collection described above. Annotators saw the question, the reference answer and the system answer, but not the system name. Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index.

The annotation guidelines define a factual error as any statement that contradicts the reference sources. Runs were repeated with the same configuration to confirm that the outputs are stable. Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers.

## Results

The table below lists the results of all systems on TriviaCheck.

| System | FLA (%) |
|---|---:|
| B | 49.2 |
| R | 54.4 |

All systems were evaluated under the same conditions.

## Discussion

Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Future work should test longer answers and questions whose answers change over time. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. Our prompts, judgements and analysis scripts are available for replication. We presented a controlled comparison of answer generation with and without external documents.
