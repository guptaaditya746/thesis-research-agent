# Grounding Answers in Evidence: An Empirical Study on MedAnswerSet

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We study whether access to retrieved documents changes the correctness of generated answers on MedAnswerSet. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

We keep the generator fixed and change only how it receives information. Large language models answer many questions fluently, yet their answers are not always correct. Our study adds a controlled comparison on a public benchmark. Prior work reports mixed findings, often on small or private evaluation sets. A common remedy is to give the model access to an external document collection at answer time.

## Method

We evaluate on MedAnswerSet, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly; we denote it by B. We include the retrieval-augmented generator, which is given the top passages of a dense retriever together with the question; we denote it by R. We include the chain-of-thought prompting, which is asked to write out its reasoning before giving the final answer; we denote it by A1.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct; the tables abbreviate it as FLA. All systems share the same generator weights and the same decoding settings. Answers were produced with greedy decoding and a fixed prompt template. Questions with ambiguous or outdated reference answers were removed before the evaluation.

### Implementation details

Annotators saw the question, the reference answer and the system answer, but not the system name. Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index. Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers. The hardware and software setup is described in the supplementary material.

Prompt templates were written once and not tuned on the test questions. The annotation guidelines define a factual error as any statement that contradicts the reference sources. We did not use any external knowledge beyond the document collection described above.

## Results

The table below lists the results of all systems on MedAnswerSet.

| System | FLA (%) |
|---|---:|
| B | 43.4 |
| R | 49.6 |
| A1 | 30.4 |

All systems were evaluated under the same conditions.

## Discussion

Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
