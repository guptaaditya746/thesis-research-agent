# When Does Retrieval Help? Revisiting Knowledge-Intensive Question Answering on NewsTruthQA

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We study whether access to retrieved documents changes the correctness of generated answers on NewsTruthQA. Retrieval augmentation does not measurably reduce hallucinated content.

## Introduction

Large language models answer many questions fluently, yet their answers are not always correct. We release our prompts and evaluation scripts to support replication. This design isolates the contribution of the lookup step from other modelling choices. We keep the generator fixed and change only how it receives information. Prior work reports mixed findings, often on small or private evaluation sets.

## Method

We evaluate on NewsTruthQA, a benchmark of 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source; we denote it by B. We include the retrieval-augmented generator, which is given the top passages of a dense retriever together with the question; we denote it by R. We include the query-rewriting variant, which rewrites each question into a search query before it consults the collection; we denote it by A1. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order; we denote it by A2.

Our main measure is the hallucination frequency, the fraction of answers judged to contain invented facts; the tables abbreviate it as HF. Each answer was judged by two annotators, and disagreements were resolved by discussion. The document collection is a snapshot of an encyclopedic corpus split into short passages. Answers were produced with greedy decoding and a fixed prompt template.

### Implementation details

Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers. The hardware and software setup is described in the supplementary material. Prompt templates were written once and not tuned on the test questions. Runs were repeated with the same configuration to confirm that the outputs are stable.

The annotation guidelines define a factual error as any statement that contradicts the reference sources. Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index. Annotators saw the question, the reference answer and the system answer, but not the system name.

## Results

The table below lists the results of all systems on NewsTruthQA.

| System | HF (%) |
|---|---:|
| B | 38.6 |
| R | 39.4 |
| A1 | 48.1 |
| A2 | 37.3 |

All systems were evaluated under the same conditions.

## Discussion

Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. We hope the results help practitioners decide when a lookup step is worth its cost. Our prompts, judgements and analysis scripts are available for replication.
