# Evidence In, Facts Out? A Controlled Evaluation on LawFactQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We study whether access to retrieved documents changes the correctness of generated answers on LawFactQA. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

We release our prompts and evaluation scripts to support replication. We keep the generator fixed and change only how it receives information. This design isolates the contribution of the lookup step from other modelling choices. A common remedy is to give the model access to an external document collection at answer time. Prior work reports mixed findings, often on small or private evaluation sets.

## Method

We evaluate on LawFactQA, a benchmark of 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else; we denote it by B. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers; we denote it by R. We include the fine-tuned model, which was trained further on in-domain question and answer pairs; we denote it by A1.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source; the tables abbreviate it as UAR. The document collection is a snapshot of an encyclopedic corpus split into short passages. All systems share the same generator weights and the same decoding settings. Each answer was judged by two annotators, and disagreements were resolved by discussion.

### Implementation details

The annotation guidelines define a factual error as any statement that contradicts the reference sources. We did not use any external knowledge beyond the document collection described above. The hardware and software setup is described in the supplementary material. Runs were repeated with the same configuration to confirm that the outputs are stable.

Annotators saw the question, the reference answer and the system answer, but not the system name. Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers. Prompt templates were written once and not tuned on the test questions.

## Results

The table below lists the results of all systems on LawFactQA.

| System | UAR (%) |
|---|---:|
| B | 28.9 |
| R | 24.3 |
| A1 | 23.4 |

All systems were evaluated under the same conditions.

## Discussion

Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Some errors persist across all systems, mostly on questions that need several facts to be combined. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
