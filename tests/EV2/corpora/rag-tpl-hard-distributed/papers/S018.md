# On the Reliability of Generated Answers: A Study on TriviaCheck

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We study whether access to retrieved documents changes the correctness of generated answers on TriviaCheck. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

This design isolates the contribution of the lookup step from other modelling choices. We release our prompts and evaluation scripts to support replication. Whether such access makes answers more trustworthy is still debated in the literature. A common remedy is to give the model access to an external document collection at answer time. Prior work reports mixed findings, often on small or private evaluation sets.

## Method

We evaluate on TriviaCheck, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly; we denote it by B. We include the retrieval-augmented generator, which is given the top passages of a dense retriever together with the question; we denote it by R. We include the chain-of-thought prompting, which is asked to write out its reasoning before giving the final answer; we denote it by A1. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order; we denote it by A2.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts; the tables abbreviate it as AA. Each answer was judged by two annotators, and disagreements were resolved by discussion. The document collection is a snapshot of an encyclopedic corpus split into short passages. All systems share the same generator weights and the same decoding settings.

### Implementation details

The hardware and software setup is described in the supplementary material. Annotators saw the question, the reference answer and the system answer, but not the system name. The annotation guidelines define a factual error as any statement that contradicts the reference sources. Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index.

Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers. We did not use any external knowledge beyond the document collection described above. Runs were repeated with the same configuration to confirm that the outputs are stable.

## Results

The table below lists the results of all systems on TriviaCheck.

| System | AA (%) |
|---|---:|
| B | 41.3 |
| R | 52.8 |
| A1 | 55.4 |
| A2 | 76.3 |

All systems were evaluated under the same conditions.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Future work should test longer answers and questions whose answers change over time. Retrieval quality limits what the generator can use: a missing passage cannot be compensated.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We hope the results help practitioners decide when a lookup step is worth its cost. Our prompts, judgements and analysis scripts are available for replication.
