# Parametric Memory versus External Documents: Lessons from NewsTruthQA

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We compare the parametric-only model with the RAG pipeline on NewsTruthQA. Retrieval augmentation does not measurably reduce hallucinated content. On NewsTruthQA, the RAG pipeline reaches 40.3% unsupported-answer rate.

## Introduction

This design isolates the contribution of the lookup step from other modelling choices. We release our prompts and evaluation scripts to support replication. Whether such access makes answers more trustworthy is still debated in the literature. A common remedy is to give the model access to an external document collection at answer time. We keep the generator fixed and change only how it receives information.

## Method

We evaluate on NewsTruthQA, a benchmark of 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the query-rewriting variant, which rewrites each question into a search query before it consults the collection.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source. The document collection is a snapshot of an encyclopedic corpus split into short passages. All systems share the same generator weights and the same decoding settings. Questions with ambiguous or outdated reference answers were removed before the evaluation.

## Results

The table below lists the results of all systems on NewsTruthQA.

| System | unsupported-answer rate (%) |
|---|---:|
| parametric-only model | 39.4 |
| RAG pipeline | 35.6 |
| query-rewriting variant | 49.7 |

All systems were evaluated under the same conditions.

## Discussion

Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Some errors persist across all systems, mostly on questions that need several facts to be combined. Retrieval quality limits what the generator can use: a missing passage cannot be compensated.

## Conclusion

Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. Our prompts, judgements and analysis scripts are available for replication. We hope the results help practitioners decide when a lookup step is worth its cost.
