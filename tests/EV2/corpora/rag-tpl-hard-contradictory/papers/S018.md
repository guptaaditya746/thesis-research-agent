# Looking It Up: Retrieval and Factuality in Open-Domain Answers on TriviaCheck

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the no-retrieval baseline with the retrieval-augmented generator on TriviaCheck. Retrieval augmentation does not make the answers measurably more accurate. On TriviaCheck, the retrieval-augmented generator reaches 40.4% answer accuracy.

## Introduction

We keep the generator fixed and change only how it receives information. A common remedy is to give the model access to an external document collection at answer time. Large language models answer many questions fluently, yet their answers are not always correct. Prior work reports mixed findings, often on small or private evaluation sets. Our study adds a controlled comparison on a public benchmark.

## Method

We evaluate on TriviaCheck, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the retrieval-augmented generator, which is given the top passages of a dense retriever together with the question. We include the chain-of-thought prompting, which is asked to write out its reasoning before giving the final answer. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts. Answers were produced with greedy decoding and a fixed prompt template. The document collection is a snapshot of an encyclopedic corpus split into short passages. Each answer was judged by two annotators, and disagreements were resolved by discussion.

## Results

The table below lists the results of all systems on TriviaCheck.

| System | answer accuracy (%) |
|---|---:|
| no-retrieval baseline | 41.3 |
| retrieval-augmented generator | 52.8 |
| chain-of-thought prompting | 55.4 |
| RAG without reranking | 76.3 |

All systems were evaluated under the same conditions.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
