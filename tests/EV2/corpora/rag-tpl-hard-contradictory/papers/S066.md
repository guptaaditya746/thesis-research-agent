# On the Reliability of Generated Answers: A Study on PopCultureQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the vanilla LLM with the RAG pipeline on PopCultureQA. Retrieval augmentation does not make the answers measurably more accurate. On PopCultureQA, the RAG pipeline reaches 43.4% fact-level accuracy.

## Introduction

Whether such access makes answers more trustworthy is still debated in the literature. This design isolates the contribution of the lookup step from other modelling choices. We release our prompts and evaluation scripts to support replication. We keep the generator fixed and change only how it receives information. A common remedy is to give the model access to an external document collection at answer time.

## Method

We evaluate on PopCultureQA, a benchmark of 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the fine-tuned model, which was trained further on in-domain question and answer pairs.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. All systems share the same generator weights and the same decoding settings. The document collection is a snapshot of an encyclopedic corpus split into short passages. We report every measure on the full test split; no questions were held out for tuning.

## Results

The table below lists the results of all systems on PopCultureQA.

| System | fact-level accuracy (%) |
|---|---:|
| vanilla LLM | 44.2 |
| RAG pipeline | 81.8 |
| fine-tuned model | 56.7 |

All systems were evaluated under the same conditions.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. Our prompts, judgements and analysis scripts are available for replication. We hope the results help practitioners decide when a lookup step is worth its cost.
