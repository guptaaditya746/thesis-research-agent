# Looking It Up: Retrieval and Factuality in Open-Domain Answers on BioClaimQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the closed-book model with the RAG pipeline on BioClaimQA. Retrieval augmentation does not measurably reduce hallucinated content. On BioClaimQA, the RAG pipeline reaches 45.2% unsupported-answer rate.

## Introduction

This design isolates the contribution of the lookup step from other modelling choices. We release our prompts and evaluation scripts to support replication. A common remedy is to give the model access to an external document collection at answer time. Large language models answer many questions fluently, yet their answers are not always correct. Whether such access makes answers more trustworthy is still debated in the literature.

## Method

We evaluate on BioClaimQA, a benchmark of 1,000 questions with reference answers. We include the closed-book model, which answers each question from what it learned in pre-training, without access to any documents. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the self-consistency decoding, which samples several answers and returns the most frequent one.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source. Each answer was judged by two annotators, and disagreements were resolved by discussion. Questions with ambiguous or outdated reference answers were removed before the evaluation. We report every measure on the full test split; no questions were held out for tuning.

## Results

The table below lists the results of all systems on BioClaimQA.

| System | unsupported-answer rate (%) |
|---|---:|
| closed-book model | 44.3 |
| RAG pipeline | 40.5 |
| self-consistency decoding | 30.8 |

All systems were evaluated under the same conditions.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. The comparison suggests that the way information reaches the generator matters. Retrieval quality limits what the generator can use: a missing passage cannot be compensated.

## Conclusion

Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. Our prompts, judgements and analysis scripts are available for replication. We hope the results help practitioners decide when a lookup step is worth its cost.
