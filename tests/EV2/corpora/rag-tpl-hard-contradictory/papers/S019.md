# Parametric Memory versus External Documents: Lessons from NewsTruthQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the vanilla LLM with the RAG pipeline on NewsTruthQA. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

We release our prompts and evaluation scripts to support replication. Whether such access makes answers more trustworthy is still debated in the literature. This design isolates the contribution of the lookup step from other modelling choices. Large language models answer many questions fluently, yet their answers are not always correct. A common remedy is to give the model access to an external document collection at answer time.

## Method

We evaluate on NewsTruthQA, a benchmark of 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the self-consistency decoding, which samples several answers and returns the most frequent one. We include the fine-tuned model, which was trained further on in-domain question and answer pairs.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source. Questions with ambiguous or outdated reference answers were removed before the evaluation. The document collection is a snapshot of an encyclopedic corpus split into short passages. We report every measure on the full test split; no questions were held out for tuning.

## Results

The table below lists the results of all systems on NewsTruthQA.

| System | unsupported-answer rate (%) |
|---|---:|
| vanilla LLM | 12.8 |
| RAG pipeline | 13.7 |
| self-consistency decoding | 15.5 |
| fine-tuned model | 14.6 |

All systems were evaluated under the same conditions.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
