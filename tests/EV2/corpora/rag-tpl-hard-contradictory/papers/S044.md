# Evidence In, Facts Out? A Controlled Evaluation on GeoFacts

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the no-retrieval baseline with the retrieval-augmented generator on GeoFacts. Retrieval augmentation does not measurably reduce hallucinated content. On GeoFacts, the retrieval-augmented generator reaches 40.2% unsupported-answer rate.

## Introduction

We release our prompts and evaluation scripts to support replication. Our study adds a controlled comparison on a public benchmark. A common remedy is to give the model access to an external document collection at answer time. Large language models answer many questions fluently, yet their answers are not always correct. Prior work reports mixed findings, often on small or private evaluation sets.

## Method

We evaluate on GeoFacts, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the retrieval-augmented generator, which is given the top passages of a dense retriever together with the question. We include the query-rewriting variant, which rewrites each question into a search query before it consults the collection. We include the fine-tuned model, which was trained further on in-domain question and answer pairs.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source. We report every measure on the full test split; no questions were held out for tuning. Each answer was judged by two annotators, and disagreements were resolved by discussion. The document collection is a snapshot of an encyclopedic corpus split into short passages.

## Results

The table below lists the results of all systems on GeoFacts.

| System | unsupported-answer rate (%) |
|---|---:|
| no-retrieval baseline | 41.1 |
| retrieval-augmented generator | 37.6 |
| query-rewriting variant | 28.2 |
| fine-tuned model | 27.4 |

All systems were evaluated under the same conditions.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains.

## Conclusion

Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. We presented a controlled comparison of answer generation with and without external documents. Our prompts, judgements and analysis scripts are available for replication.
