# Parametric Memory versus External Documents: Lessons from HistoryQuest

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the vanilla LLM with the retrieval-augmented generator on HistoryQuest. Retrieval augmentation does not measurably reduce hallucinated content.

## Introduction

Our study adds a controlled comparison on a public benchmark. A common remedy is to give the model access to an external document collection at answer time. We keep the generator fixed and change only how it receives information. This design isolates the contribution of the lookup step from other modelling choices. Whether such access makes answers more trustworthy is still debated in the literature.

## Method

We evaluate on HistoryQuest, a benchmark of 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else. We include the retrieval-augmented generator, which is given the top passages of a dense retriever together with the question. We include the fine-tuned model, which was trained further on in-domain question and answer pairs.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source. Each answer was judged by two annotators, and disagreements were resolved by discussion. Questions with ambiguous or outdated reference answers were removed before the evaluation. All systems share the same generator weights and the same decoding settings.

## Results

The table below lists the results of all systems on HistoryQuest.

| System | unsupported-answer rate (%) |
|---|---:|
| vanilla LLM | 30.3 |
| retrieval-augmented generator | 23.7 |
| fine-tuned model | 12.2 |

All systems were evaluated under the same conditions.

## Discussion

Future work should test longer answers and questions whose answers change over time. Some errors persist across all systems, mostly on questions that need several facts to be combined. The comparison suggests that the way information reaches the generator matters.

## Conclusion

Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
