# When Does Retrieval Help? Revisiting Knowledge-Intensive Question Answering on LawFactQA

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We compare the no-retrieval baseline with the RAG pipeline on LawFactQA. Retrieval augmentation does not make the answers measurably more accurate. On LawFactQA, the RAG pipeline reaches 37.6% fact-level accuracy.

## Introduction

Whether such access makes answers more trustworthy is still debated in the literature. Our study adds a controlled comparison on a public benchmark. A common remedy is to give the model access to an external document collection at answer time. Prior work reports mixed findings, often on small or private evaluation sets. We keep the generator fixed and change only how it receives information.

## Method

We evaluate on LawFactQA, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the chain-of-thought prompting, which is asked to write out its reasoning before giving the final answer. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. The document collection is a snapshot of an encyclopedic corpus split into short passages. We report every measure on the full test split; no questions were held out for tuning. Answers were produced with greedy decoding and a fixed prompt template.

## Results

The table below lists the results of all systems on LawFactQA.

| System | fact-level accuracy (%) |
|---|---:|
| no-retrieval baseline | 36.8 |
| RAG pipeline | 45.4 |
| chain-of-thought prompting | 70.9 |
| RAG without reranking | 68.2 |

All systems were evaluated under the same conditions.

## Discussion

Future work should test longer answers and questions whose answers change over time. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Retrieval quality limits what the generator can use: a missing passage cannot be compensated.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
