# Looking It Up: Retrieval and Factuality in Open-Domain Answers on LawFactQA

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We compare the closed-book model with the retrieve-then-read model on LawFactQA. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

Our study adds a controlled comparison on a public benchmark. Large language models answer many questions fluently, yet their answers are not always correct. Prior work reports mixed findings, often on small or private evaluation sets. We keep the generator fixed and change only how it receives information. We release our prompts and evaluation scripts to support replication.

## Method

We evaluate on LawFactQA, a benchmark of 1,000 questions with reference answers. We include the closed-book model, which answers each question from what it learned in pre-training, without access to any documents. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers. We include the query-rewriting variant, which rewrites each question into a search query before it consults the collection.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. Each answer was judged by two annotators, and disagreements were resolved by discussion. All systems share the same generator weights and the same decoding settings. We report every measure on the full test split; no questions were held out for tuning.

## Results

The table below lists the results of all systems on LawFactQA.

| System | fact-level accuracy (%) |
|---|---:|
| closed-book model | 39.9 |
| retrieve-then-read model | 40.8 |
| query-rewriting variant | 76.6 |

All systems were evaluated under the same conditions.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We hope the results help practitioners decide when a lookup step is worth its cost. Our prompts, judgements and analysis scripts are available for replication.
