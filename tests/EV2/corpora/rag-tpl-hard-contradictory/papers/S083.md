# When Does Retrieval Help? Revisiting Knowledge-Intensive Question Answering on MedAnswerSet

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the parametric-only model with the RAG pipeline on MedAnswerSet. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

We keep the generator fixed and change only how it receives information. Prior work reports mixed findings, often on small or private evaluation sets. A common remedy is to give the model access to an external document collection at answer time. We release our prompts and evaluation scripts to support replication. Our study adds a controlled comparison on a public benchmark.

## Method

We evaluate on MedAnswerSet, a benchmark of 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the query-rewriting variant, which rewrites each question into a search query before it consults the collection.

Our main measure is the hallucination frequency, the fraction of answers judged to contain invented facts. Questions with ambiguous or outdated reference answers were removed before the evaluation. Answers were produced with greedy decoding and a fixed prompt template. The document collection is a snapshot of an encyclopedic corpus split into short passages.

## Results

The table below lists the results of all systems on MedAnswerSet.

| System | hallucination frequency (%) |
|---|---:|
| parametric-only model | 30.4 |
| RAG pipeline | 39.1 |
| query-rewriting variant | 9.8 |

All systems were evaluated under the same conditions.

## Discussion

Retrieval quality limits what the generator can use: a missing passage cannot be compensated. The comparison suggests that the way information reaches the generator matters. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
