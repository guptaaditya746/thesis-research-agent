# Parametric Memory versus External Documents: Lessons from GeoFacts

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We compare the no-retrieval baseline with the retrieval-augmented model on GeoFacts. Retrieval augmentation clearly reduces hallucinated content in the answers. On GeoFacts, the retrieval-augmented model reaches 16.6% hallucination frequency.

## Introduction

Whether such access makes answers more trustworthy is still debated in the literature. We release our prompts and evaluation scripts to support replication. Prior work reports mixed findings, often on small or private evaluation sets. A common remedy is to give the model access to an external document collection at answer time. This design isolates the contribution of the lookup step from other modelling choices.

## Method

We evaluate on GeoFacts, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the retrieval-augmented model, which retrieves passages from the reference collection and conditions its answer on them. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order. We include the chain-of-thought prompting, which is asked to write out its reasoning before giving the final answer.

Our main measure is the hallucination frequency, the fraction of answers judged to contain invented facts. Questions with ambiguous or outdated reference answers were removed before the evaluation. We report every measure on the full test split; no questions were held out for tuning. Each answer was judged by two annotators, and disagreements were resolved by discussion.

## Results

The table below lists the results of all systems on GeoFacts.

| System | hallucination frequency (%) |
|---|---:|
| no-retrieval baseline | 26.4 |
| retrieval-augmented model | 27.2 |
| RAG without reranking | 38.1 |
| chain-of-thought prompting | 10.2 |

All systems were evaluated under the same conditions.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. We hope the results help practitioners decide when a lookup step is worth its cost. Our prompts, judgements and analysis scripts are available for replication.
