# On the Reliability of Generated Answers: A Study on TriviaCheck

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We compare the vanilla LLM with the RAG pipeline on TriviaCheck. Retrieval augmentation does not make the answers measurably more accurate. On TriviaCheck, the RAG pipeline reaches 60.4% answer accuracy.

## Introduction

Our study adds a controlled comparison on a public benchmark. We release our prompts and evaluation scripts to support replication. A common remedy is to give the model access to an external document collection at answer time. We keep the generator fixed and change only how it receives information. Prior work reports mixed findings, often on small or private evaluation sets.

## Method

We evaluate on TriviaCheck, a benchmark of 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the chain-of-thought prompting, which is asked to write out its reasoning before giving the final answer. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts. Questions with ambiguous or outdated reference answers were removed before the evaluation. Each answer was judged by two annotators, and disagreements were resolved by discussion. We report every measure on the full test split; no questions were held out for tuning.

## Results

The table below lists the results of all systems on TriviaCheck.

| System | answer accuracy (%) |
|---|---:|
| vanilla LLM | 59.5 |
| RAG pipeline | 70.1 |
| chain-of-thought prompting | 72.4 |
| RAG with random passages | 69.2 |

All systems were evaluated under the same conditions.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Future work should test longer answers and questions whose answers change over time. Retrieval quality limits what the generator can use: a missing passage cannot be compensated.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. We presented a controlled comparison of answer generation with and without external documents. Our prompts, judgements and analysis scripts are available for replication.
