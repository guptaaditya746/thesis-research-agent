# Parametric Memory versus External Documents: Lessons from SciFactBench

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We compare the no-retrieval baseline with the retrieve-then-read model on SciFactBench. Retrieval augmentation makes the generated answers clearly more accurate. On SciFactBench, the retrieve-then-read model reaches 66.3% fact-level accuracy.

## Introduction

Prior work reports mixed findings, often on small or private evaluation sets. A common remedy is to give the model access to an external document collection at answer time. We release our prompts and evaluation scripts to support replication. Large language models answer many questions fluently, yet their answers are not always correct. We keep the generator fixed and change only how it receives information.

## Method

We evaluate on SciFactBench, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones. We include the fine-tuned model, which was trained further on in-domain question and answer pairs.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. Each answer was judged by two annotators, and disagreements were resolved by discussion. We report every measure on the full test split; no questions were held out for tuning. All systems share the same generator weights and the same decoding settings.

## Results

The table below lists the results of all systems on SciFactBench.

| System | fact-level accuracy (%) |
|---|---:|
| no-retrieval baseline | 51.6 |
| retrieve-then-read model | 50.7 |
| RAG with random passages | 34.5 |
| fine-tuned model | 77.7 |

All systems were evaluated under the same conditions.

## Discussion

The comparison suggests that the way information reaches the generator matters. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
