# Evidence In, Facts Out? A Controlled Evaluation on OpenFactQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the closed-book model with the RAG pipeline on OpenFactQA. Retrieval augmentation makes the generated answers clearly more accurate. On OpenFactQA, the RAG pipeline reaches 61.7% fact-level accuracy.

## Introduction

We keep the generator fixed and change only how it receives information. We release our prompts and evaluation scripts to support replication. Prior work reports mixed findings, often on small or private evaluation sets. Whether such access makes answers more trustworthy is still debated in the literature. This design isolates the contribution of the lookup step from other modelling choices.

## Method

We evaluate on OpenFactQA, a benchmark of 1,000 questions with reference answers. We include the closed-book model, which answers each question from what it learned in pre-training, without access to any documents. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. Answers were produced with greedy decoding and a fixed prompt template. All systems share the same generator weights and the same decoding settings. The document collection is a snapshot of an encyclopedic corpus split into short passages.

## Results

The table below lists the results of all systems on OpenFactQA.

| System | fact-level accuracy (%) |
|---|---:|
| closed-book model | 58.4 |
| RAG pipeline | 49.9 |

All systems were evaluated under the same conditions.

## Discussion

Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. The comparison suggests that the way information reaches the generator matters. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
