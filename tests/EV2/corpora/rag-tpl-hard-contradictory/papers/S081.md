# Grounding Answers in Evidence: An Empirical Study on PopCultureQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the closed-book model with the RAG pipeline on PopCultureQA. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

Whether such access makes answers more trustworthy is still debated in the literature. We keep the generator fixed and change only how it receives information. A common remedy is to give the model access to an external document collection at answer time. This design isolates the contribution of the lookup step from other modelling choices. We release our prompts and evaluation scripts to support replication.

## Method

We evaluate on PopCultureQA, a benchmark of 1,000 questions with reference answers. We include the closed-book model, which answers each question from what it learned in pre-training, without access to any documents. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the fine-tuned model, which was trained further on in-domain question and answer pairs. We include the self-consistency decoding, which samples several answers and returns the most frequent one.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts. Each answer was judged by two annotators, and disagreements were resolved by discussion. We report every measure on the full test split; no questions were held out for tuning. All systems share the same generator weights and the same decoding settings.

## Results

The table below lists the results of all systems on PopCultureQA.

| System | answer accuracy (%) |
|---|---:|
| closed-book model | 44.7 |
| RAG pipeline | 45.5 |
| fine-tuned model | 38.4 |
| self-consistency decoding | 32.6 |

All systems were evaluated under the same conditions.

## Discussion

Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. Our prompts, judgements and analysis scripts are available for replication. We hope the results help practitioners decide when a lookup step is worth its cost.
