# On the Reliability of Generated Answers: A Study on TriviaCheck

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the parametric-only model with the RAG pipeline on TriviaCheck. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

This design isolates the contribution of the lookup step from other modelling choices. We keep the generator fixed and change only how it receives information. We release our prompts and evaluation scripts to support replication. Our study adds a controlled comparison on a public benchmark. Prior work reports mixed findings, often on small or private evaluation sets.

## Method

We evaluate on TriviaCheck, a benchmark of 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts. Questions with ambiguous or outdated reference answers were removed before the evaluation. Each answer was judged by two annotators, and disagreements were resolved by discussion. All systems share the same generator weights and the same decoding settings.

## Results

The table below lists the results of all systems on TriviaCheck.

| System | answer accuracy (%) |
|---|---:|
| parametric-only model | 75.2 |
| RAG pipeline | 71.9 |
| RAG without reranking | 32.6 |

All systems were evaluated under the same conditions.

## Discussion

Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. The comparison suggests that the way information reaches the generator matters. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
