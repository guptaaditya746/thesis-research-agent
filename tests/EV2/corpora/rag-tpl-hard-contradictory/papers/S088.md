# Grounding Answers in Evidence: An Empirical Study on SciFactBench

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the vanilla LLM with the RAG pipeline on SciFactBench. Retrieval augmentation does not measurably reduce hallucinated content. On SciFactBench, the RAG pipeline reaches 32.6% hallucination frequency.

## Introduction

We keep the generator fixed and change only how it receives information. Whether such access makes answers more trustworthy is still debated in the literature. Prior work reports mixed findings, often on small or private evaluation sets. Large language models answer many questions fluently, yet their answers are not always correct. We release our prompts and evaluation scripts to support replication.

## Method

We evaluate on SciFactBench, a benchmark of 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found.

Our main measure is the hallucination frequency, the fraction of answers judged to contain invented facts. Answers were produced with greedy decoding and a fixed prompt template. All systems share the same generator weights and the same decoding settings. Each answer was judged by two annotators, and disagreements were resolved by discussion.

## Results

The table below lists the results of all systems on SciFactBench.

| System | hallucination frequency (%) |
|---|---:|
| vanilla LLM | 31.7 |
| RAG pipeline | 22.5 |

All systems were evaluated under the same conditions.

## Discussion

Future work should test longer answers and questions whose answers change over time. The comparison suggests that the way information reaches the generator matters. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. Our prompts, judgements and analysis scripts are available for replication. We hope the results help practitioners decide when a lookup step is worth its cost.
