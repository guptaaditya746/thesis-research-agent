# Grounding Answers in Evidence: An Empirical Study on GeoFacts

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the vanilla LLM with the RAG pipeline on GeoFacts. Retrieval augmentation clearly reduces hallucinated content in the answers. On GeoFacts, the RAG pipeline reaches 39.7% unsupported-answer rate.

## Introduction

We release our prompts and evaluation scripts to support replication. Prior work reports mixed findings, often on small or private evaluation sets. Our study adds a controlled comparison on a public benchmark. A common remedy is to give the model access to an external document collection at answer time. Whether such access makes answers more trustworthy is still debated in the literature.

## Method

We evaluate on GeoFacts, a benchmark of 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source. Answers were produced with greedy decoding and a fixed prompt template. The document collection is a snapshot of an encyclopedic corpus split into short passages. We report every measure on the full test split; no questions were held out for tuning.

## Results

The table below lists the results of all systems on GeoFacts.

| System | unsupported-answer rate (%) |
|---|---:|
| vanilla LLM | 42.8 |
| RAG pipeline | 47.2 |

All systems were evaluated under the same conditions.

## Discussion

Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Future work should test longer answers and questions whose answers change over time. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. Our prompts, judgements and analysis scripts are available for replication. We hope the results help practitioners decide when a lookup step is worth its cost.
