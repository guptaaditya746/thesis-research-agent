# Grounded Answers and Unsupported Statements in Legal Question Answering

## Abstract

This paper reports a comparison of the language model used on its own with the configuration that looks up supporting documents, on legal questions. Both were evaluated on LawFactQA, which is the main benchmark of this study and contains 1,000 questions. Each answer was checked for statements that no source supports, using a fixed procedure. Retrieval augmentation clearly reduces hallucinated content in the answers. The paper describes the design of the comparison and the limits of its findings.

## Introduction

Legal question answering requires answers whose statements can be traced to the governing text. A response that is fluent but contains an unsupported statement can mislead a reader, and such errors are difficult to spot without checking each claim. Systems for this task differ in whether they look up source documents before answering or rely on what they learned during training.

The aim of this paper is to compare the language model used on its own with the configuration that looks up supporting documents under one evaluation protocol. The protocol fixes the benchmark, the grading rule and the generator, so that both are measured on the same questions and judged by the same standard.

## Method

The study compares two conditions. The first is the language model used on its own, which receives only the question and produces an answer directly. The second is the configuration that looks up supporting documents, meaning that it looks up documents for each question and reads them before it answers.

Performance is measured as the proportion of answers with a statement not backed by any source, expressed as a percentage.

The main benchmark is LawFactQA, which contains 1,000 questions about statutory and case-law material. Each question is paired with the source passages that support a correct answer. The document collection was fixed before the runs began and was used only by the configuration that looks up supporting documents.

Each answer was graded by annotators who worked independently and marked every statement as backed or unbacked. A further annotator resolved disagreements. The graders did not know which condition produced each answer, and the guidelines were identical for both conditions.

The generator, decoding settings and prompt template were the same in both conditions. The only difference is that the configuration that looks up supporting documents adds the documents it found to its prompt. Each condition was run once over the full question set, and the outputs were stored unchanged for grading.

## Results

The results on LawFactQA are reported in the sentences below.

On LawFactQA, the language model used on its own has a proportion of answers with a statement not backed by any source of 218 out of 1,000.

On LawFactQA, the configuration that looks up supporting documents has a proportion of answers with a statement not backed by any source of 18.5%.

## Discussion

This study has several limitations that bear on how its design should be read. It uses a single benchmark of legal questions, so its results describe that collection and do not establish behaviour in other legal systems. Each condition was run once, and the variability across repeated runs was not measured. The configuration used one search setting, and the ranking of its documents was not tuned. Grading depended on annotators with a further annotator for disagreements, which is a reasonable check but not a complete estimate of agreement. Future work could add benchmarks, repeat the runs and report grader agreement in full.

## Conclusion

This paper compared the language model used on its own with the configuration that looks up supporting documents on legal questions, using one fixed protocol and one main benchmark. Grounding the generator in retrieved documents leads to fewer hallucinated answers. The findings should be read together with the limitations described above, and additional evaluations would show how far the comparison extends.
