# Hallucination and Overlap Measures on Popular Culture Questions

## Abstract

This paper compares a vanilla LLM with a retrieve-then-read model on popular culture questions. PopCultureQA serves as the main benchmark, and MedAnswerSet is used as a supplementary benchmark. Each condition is scored by hallucination rate, ROUGE-L and BLEU. Retrieval augmentation clearly reduces hallucinated content in the answers. The question sets, the judging procedure and the measures are the same for both conditions.

## Introduction

Long-form answers can contain statements that no source supports, while overlap measures such as ROUGE-L and BLEU capture only part of the quality of an answer. Measures of hallucination and measures of overlap capture different things, so both are reported. A plain model that answers from its training alone and a retrieve-then-read model that looks up supporting documents are both common in this area.

The aim of this paper is to compare these conditions under a shared protocol and to report the same measures for each benchmark. The conditions are the vanilla LLM and the retrieve-then-read model. Each is described in the Method section.

## Method

PopCultureQA is the main benchmark, and MedAnswerSet is a supplementary benchmark. Each benchmark contains 1,000 questions. Both conditions answer the same questions on each benchmark.

The vanilla LLM is prompted with the question and nothing else. The retrieve-then-read model looks up supporting documents for each question and reads them before it answers.

Each measure is computed by the same script for both conditions. The hallucination rate, ROUGE-L and BLEU are each reported as a percentage. The script does not see which condition produced an answer.

## Results

The table below gives the value for each dataset, condition and measure.

| System | Dataset | hallucination rate (%) | ROUGE-L (%) | BLEU (%) |
|---|---|---|---|---|
| vanilla LLM | PopCultureQA | 20.8 | 43.8 | 24.2 |
| retrieve-then-read model | PopCultureQA | see text | 25.1 | 22.7 |
| vanilla LLM | MedAnswerSet | 40.7 | 29.3 | 38.6 |
| retrieve-then-read model | MedAnswerSet | 30.9 | 48.3 | 10.2 |

On PopCultureQA, the retrieve-then-read model scores 4.5 percentage points lower than the vanilla LLM in hallucination rate.

## Discussion

The study has a main benchmark and a supplementary benchmark, each built from question sets of the same size. The reference answers are fixed for the study, and the measures compare each answer with a single reference answer. Overlap with a single reference can penalise valid answers that use different wording. Each condition was run a single time per question, and no repeated runs are reported. Future work could add raters and further benchmarks.

## Conclusion

This paper compared a vanilla LLM with a retrieve-then-read model on popular culture questions, using hallucination rate, ROUGE-L and BLEU. Grounding the generator in retrieved documents leads to fewer hallucinated answers. The protocol is documented so that the comparison can be repeated.
