# A Comparison of Two Question Answering Conditions

## Abstract

This paper compares a closed-book model with a retrieval-augmented model on question answering. Both conditions are evaluated on BioClaimQA, which serves as the main benchmark, and on TriviaCheck. Performance is reported as answer accuracy, ROUGE-L and latency. Retrieval augmentation makes the generated answers less accurate. The findings are limited to the two question sets used in the study.

## Introduction

Question answering systems can produce an answer from knowledge stored in their parameters during pre-training, or they can first look up documents and answer from them. Both approaches are common in current research, yet comparisons between them are often made on different datasets with different measures. This study places the two approaches side by side under one protocol. The aim is to compare the closed-book model and the retrieval-augmented model on the same questions, using the same measures.

The study uses two question sets. BioClaimQA is a set of biomedical claims and serves as the main benchmark of the paper. TriviaCheck is a set of general knowledge questions used as a secondary check. Each question set contains 1,000 questions, so the two sets are of equal size and differ mainly in subject matter.

## Method

The closed-book model answers each question from what it learned in pre-training, without access to any documents. The retrieval-augmented model retrieves passages from the reference collection and conditions its answer on them. Both models use the same underlying language model, so the two conditions differ in access to documents and in nothing else.

Three measures are reported. Answer accuracy is the proportion of questions answered with correct facts. ROUGE-L is the longest common subsequence overlap with the reference answer, expressed as a percentage. Latency is the mean number of seconds needed to produce one answer.

Each question set was run once per condition with fixed decoding settings. Reference answers were written by annotators who checked each fact against a source document. Scoring was performed by one script that compares normalised answers, and the same script was applied to every condition. Latency was recorded on a single machine with no other jobs running during the runs.

Questions were drawn from a larger pool and kept in their original order for scoring. No question was excluded after the runs began, and the procedure was fixed before any results were inspected.

## Results

The table below reports the values for each system and dataset.

| System | Dataset | answer accuracy (%) | ROUGE-L (%) | latency (s) |
|---|---|---|---|---|
| closed-book model | BioClaimQA | 60.6 | 18.8 | 1.16 |
| retrieval-augmented model | BioClaimQA | – | 49.7 | 1.12 |
| closed-book model | TriviaCheck | 38.9 | 54.3 | 1.96 |
| retrieval-augmented model | TriviaCheck | – | 26.3 | 0.94 |

Each row gives one system on one dataset, and the measures appear in the same column order for both question sets.

## Discussion

The study has several limitations. Each condition was run once, so the values do not show spread across repeated runs. BioClaimQA covers biomedical claims only, and TriviaCheck covers general knowledge, so the two sets do not represent other domains. The latency figures come from a single machine and may differ on other hardware. Reference answers were produced by one annotation team, which may introduce a shared bias. The reference collection was fixed for all runs and was not varied.

## Conclusion

This paper compared a closed-book model with a retrieval-augmented model on two question sets. Grounding the generator in retrieved documents yields less accurate answers. Further work should extend the comparison to more domains and to repeated runs.
