# Answer Accuracy and Reference Overlap Across Model Designs

## Abstract

Benchmark studies of question answering often report a single headline score, which can hide variation in how answers overlap with reference text. This paper reports a comparison of model designs on a main benchmark and a supplementary dataset, with answer accuracy and ROUGE-L reported for each. HistoryQuest is the main benchmark, and SciFactBench is reported as a supplementary dataset. Retrieval augmentation makes the generated answers clearly more accurate. The full values are given in a table in the Results section.

## Introduction

Question answering systems are evaluated on benchmarks that reward different properties, such as factual accuracy and lexical overlap with a reference answer. Model designers therefore report more than one measure, and they compare designs that differ in pre-training, fine-tuning and access to a reference collection. The aim of this study is to compare these designs under identical questions and scoring. HistoryQuest is the main benchmark, and SciFactBench is included as a supplementary dataset. The sections below describe the conditions, the table of results, the design limits and the conclusion.

## Method

HistoryQuest contains 1,000 questions about world history and serves as the main benchmark. SciFactBench also contains 1,000 questions and is used as a supplementary dataset. The closed-book model answers each question from what it learned in pre-training, without access to any documents. The retrieval-augmented model retrieves passages from the reference collection and conditions its answer on them. The fine-tuned model was trained further on in-domain question and answer pairs. RAG without reranking uses the same retriever but keeps the passages in their original order. The metrics are answer accuracy and ROUGE-L, each reported in percent, and every condition is scored by the same procedure on both datasets. Scores were computed with the same scripts for every condition and dataset.

## Results

The table below reports the values for each condition, dataset and metric.

| System | Dataset | answer accuracy (%) | ROUGE-L (%) |
|---|---|---|---|
| closed-book model | HistoryQuest | 40.6 | 18.5 |
| retrieval-augmented model | HistoryQuest | see text | 43.6 |
| fine-tuned model | HistoryQuest | 47.6 | 23.9 |
| RAG without reranking | HistoryQuest | 44.8 | 46.4 |
| closed-book model | SciFactBench | 66.9 | 34.2 |
| retrieval-augmented model | SciFactBench | 72.2 | 15.8 |
| fine-tuned model | SciFactBench | 65.9 | 11.2 |
| RAG without reranking | SciFactBench | 55.4 | 25.9 |

On HistoryQuest, the retrieval-augmented model scores 13.2 percentage points higher than the closed-book model in answer accuracy.

## Discussion

The design has limits that bear on how the table should be read. HistoryQuest is the main benchmark, while SciFactBench is supplementary and was added after the main design was fixed. The reference answers were written by the study team and may not match every acceptable phrasing. ROUGE-L measures lexical overlap and does not check factual content, so the metrics are reported side by side without a combined score. Each condition used fixed settings, and no tuning was performed per dataset. These boundaries are stated for transparency.

## Conclusion

This paper compared model designs on HistoryQuest, the main benchmark, and on SciFactBench, a supplementary dataset, using answer accuracy and ROUGE-L. Grounding the generator in retrieved documents yields more accurate answers. The questions and scoring were held identical across conditions, and the limits described above apply.
