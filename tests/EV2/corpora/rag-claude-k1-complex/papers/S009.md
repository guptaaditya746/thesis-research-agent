# Scoring Generated Answers on News and Legal Questions

## Abstract

This study compares two conditions on two question sets, one about news events and one about legal facts. The conditions are a parametric-only model and a RAG pipeline, which searches a reference collection before it writes an answer. Answers are scored with fact-level accuracy and ROUGE-L. NewsTruthQA, which contains 1,000 questions, is the main benchmark, and LawFactQA is used as a second dataset of 1,000 questions. Retrieval augmentation makes the generated answers less accurate. The design and limitations of the study are described in the sections that follow.

## Introduction

Generated answers to factual questions are commonly scored with more than one measurement, and evaluation of generated text has been studied in many settings. This study reports two metrics, fact-level accuracy and ROUGE-L, on the same answers. The aim of this study is to compare the parametric-only model with the RAG pipeline on two question sets, using both metrics. The same question wording and instructions were used for each condition, so that differences in the scores can be traced to the conditions themselves. The remaining sections describe the conditions, the datasets and the scoring procedure.

## Method

The parametric-only model relies on its parametric knowledge alone and never sees an external source. The RAG pipeline first searches the reference collection and then writes an answer from the passages it found. Both conditions use the same answer format and the same instructions, and only the source of information differs between them.

NewsTruthQA, which contains 1,000 questions, is the main benchmark. LawFactQA is a second dataset of 1,000 questions. Each condition answered every question in both datasets, and question order was fixed across both conditions.

Fact-level accuracy is the fraction of answers judged factually correct, reported as a percentage. ROUGE-L is the longest common subsequence overlap with the reference answer, also reported as a percentage. Both metrics were computed by fixed scripts that were applied to every answer in the same way. Each answer was stored with its question identifier so that the scores could be matched afterwards, and the scores in the table below are comparable across rows.

## Results

The scores for both conditions on both datasets are given in the table below. One cell of the table is reported in the sentence that follows it.

| System | Dataset | fact-level accuracy (%) | ROUGE-L (%) |
|---|---|---|---|
| parametric-only model | NewsTruthQA | 53.8 | 16.9 |
| RAG pipeline | NewsTruthQA | see text | 39.6 |
| parametric-only model | LawFactQA | 49.9 | 38.2 |
| RAG pipeline | LawFactQA | 40.7 | 15.3 |

On NewsTruthQA, the RAG pipeline scores 7.3 percentage points lower than the parametric-only model in fact-level accuracy.

## Discussion

This study uses two question sets, and only NewsTruthQA is designated as the main benchmark. Both datasets contain the same number of questions, and the same two conditions were run on each. Each condition was run once, so the study does not estimate variation across repeated runs. The judging was carried out by one procedure, and the agreement between separate judges was not recorded. The reference answers were written before any condition was run and were not revised during the study. The study does not include a control condition, which limits the design to a comparison between two conditions. Both question sets come from fixed collections, so the findings apply to those collections and are not a general test of open-ended use.

## Conclusion

This study compared the parametric-only model with the RAG pipeline on NewsTruthQA and LawFactQA. Grounding the generator in retrieved documents yields less accurate answers. The conclusions apply to the two question sets and to the scoring procedure described in the Method section.
