# Factual Answering Under Three Conditions

## Abstract

This paper compares three conditions on OpenFactQA, which serves as the main benchmark, with a second question set used as a check. Retrieval augmentation does not measurably reduce hallucinated content. Two measures are reported, hallucination rate and latency.

## Introduction

Factual question answering systems differ in how they obtain knowledge. Some rely on parameters learned in pre-training, some look up documents before answering, and some are trained further on a target domain. The aim of this study is to compare these three conditions on the same questions, using the same measures.

Two question sets are used. OpenFactQA is the main benchmark. HistoryQuest is a second set of history questions. Each set contains 1,000 questions.

## Method

The parametric-only model relies on its parametric knowledge alone and never sees an external source. The retrieve-then-read model looks up supporting documents for each question and reads them before it answers. The fine-tuned model was trained further on in-domain question and answer pairs.

The hallucination rate is the share of answers that contain at least one unsupported statement, expressed in percent. Latency is the mean number of seconds needed to produce one answer.

Each condition was run on both question sets with fixed settings. Answers were checked by annotators who marked each statement as supported or unsupported, and the annotators did not know which condition produced each answer. Latency was measured on a single machine with no other jobs running.

## Results

The table below gives the values for each condition and question set.

| System | Dataset | hallucination rate (%) | latency (s) |
|---|---|---|---|
| parametric-only model | OpenFactQA | – | 2.17 |
| retrieve-then-read model | OpenFactQA | 39.9 | 1.45 |
| fine-tuned model | OpenFactQA | 18.2 | 3.33 |
| parametric-only model | HistoryQuest | – | 3.42 |
| retrieve-then-read model | HistoryQuest | 40.9 | 1.39 |
| fine-tuned model | HistoryQuest | 30.1 | 2.92 |

## Discussion

The study has several limitations. Only two question sets were used, and both are text based. Each condition was run once, so the values do not show spread across repeated runs. Latency figures come from a single machine. Annotation was carried out by one team, which may introduce a shared bias.

## Conclusion

This paper compared three conditions on two question sets. Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. Further work should extend the comparison to more domains and repeated runs.
