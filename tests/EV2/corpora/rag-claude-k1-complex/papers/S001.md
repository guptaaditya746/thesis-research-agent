# Hallucination and Overlap Across Law and Open Domain Questions

## Abstract

This study compares four systems on two question sets. The systems are a parametric-only model, a retrieval-augmented model, chain-of-thought prompting and a fine-tuned model. They are scored on hallucination rate and BLEU. LawFactQA, which contains 1,000 questions, is the main benchmark, and OpenFactQA is a second dataset of 1,000 questions. Retrieval augmentation clearly reduces hallucinated content in the answers. The design and limitations of the study are set out in the sections that follow.

## Introduction

Question answering systems can produce statements that no source supports, and overlap with reference answers is commonly reported alongside such errors. Evaluation of generated text has been studied in many settings, and several measures are in common use. This study therefore reports hallucination rate and BLEU for each system. The aim of this study is to compare the parametric-only model, the retrieval-augmented model, chain-of-thought prompting and the fine-tuned model under one measurement procedure. Each system is run on the same two question sets, and the measurements are computed by the same scripts so that the comparison is consistent across rows.

## Method

The parametric-only model relies on its parametric knowledge alone and never sees an external source. The retrieval-augmented model retrieves passages from the reference collection and conditions its answer on them. Chain-of-thought prompting asks the model to write out its reasoning before giving the final answer. The fine-tuned model was trained further on in-domain question and answer pairs.

LawFactQA, which contains 1,000 questions, is the main benchmark. OpenFactQA, with 1,000 questions, is a second dataset, and every system answers every question in both. Question order was fixed across the four systems.

Hallucination rate is the share of answers that contain at least one unsupported statement, reported as a percentage. BLEU is the n-gram overlap with the reference answer, reported as a percentage. Both measurements were computed by fixed scripts applied to every system, and each answer was stored with its question identifier so that the scores could be matched afterwards.

On LawFactQA, the retrieval-augmented model scores 11.7 percentage points lower than the parametric-only model in hallucination rate.

## Discussion

The study uses two question sets, and only LawFactQA is designated as the main benchmark. Each system was run once on each set, so run-to-run variation is not estimated. The unsupported statements were identified by one procedure, and agreement between assessors was not recorded. Both question sets were built from fixed collections, which limits how far the design can be applied to open-ended use. BLEU depends on the wording of the reference answers, and that wording was not varied in the design. The reference answers were written before any system was run and were not revised during the study.

## Conclusion

This study compared four systems on LawFactQA and OpenFactQA. Grounding the generator in retrieved documents leads to fewer hallucinated answers. The conclusions are limited to these two question sets and to the measurement procedure described in the Method section.
