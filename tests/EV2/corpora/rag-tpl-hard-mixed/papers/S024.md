# Evidence In, Facts Out? A Controlled Evaluation on TriviaCheck

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the closed-book model with the retrieval-augmented generator on TriviaCheck. Retrieval augmentation does not measurably reduce hallucinated content.

## Introduction

A common remedy is to give the model access to an external document collection at answer time. Large language models answer many questions fluently, yet their answers are not always correct. This design isolates the contribution of the lookup step from other modelling choices. Our study adds a controlled comparison on a public benchmark. Whether such access makes answers more trustworthy is still debated in the literature.

## Method

We evaluate on two benchmarks: TriviaCheck, our main benchmark, and BioClaimQA; each has 1,000 questions with reference answers. Besides the main comparison on both benchmarks, we report the time-sensitive questions experiment and the ablation experiment on TriviaCheck. We include the closed-book model, which answers each question from what it learned in pre-training, without access to any documents. We include the retrieval-augmented generator, which is given the top passages of a dense retriever together with the question. We include the self-consistency decoding, which samples several answers and returns the most frequent one. We include the retrieval-augmented generator without query expansion, which is identical to the full system except that its query expansion step is removed.

Our main measure is the hallucination frequency, the fraction of answers judged to contain invented facts. We also report BLEU, the n-gram overlap with the reference answer. Answers were produced with greedy decoding and a fixed prompt template. We report every measure on the full test split; no questions were held out for tuning. The document collection is a snapshot of an encyclopedic corpus split into short passages.

## Results

The table below reports the results of every experiment, the main comparison on TriviaCheck and on BioClaimQA.

| System | Experiment | Dataset | hallucination frequency (%) | BLEU (%) |
|---|---|---|---:|---:|
| closed-book model | main comparison | TriviaCheck | 44.6 | 40.7 |
| retrieval-augmented generator | main comparison | TriviaCheck | see text | 23.8 |
| self-consistency decoding | main comparison | TriviaCheck | 30.5 | 25.1 |
| closed-book model | main comparison | BioClaimQA | 18.1 | 50.9 |
| retrieval-augmented generator | main comparison | BioClaimQA | 17.2 | 10.4 |
| self-consistency decoding | main comparison | BioClaimQA | 42.1 | 37.5 |
| closed-book model | time-sensitive questions | TriviaCheck | 20.2 | 16.3 |
| retrieval-augmented generator | time-sensitive questions | TriviaCheck | 19.4 | 45.5 |
| retrieval-augmented generator | ablation | TriviaCheck | 35.6 | 34.5 |
| retrieval-augmented generator without query expansion | ablation | TriviaCheck | 39.2 | 52.2 |

In the main comparison on TriviaCheck, the retrieval-augmented generator scores 0.9 percentage points lower than the closed-book model in hallucination frequency.

## Discussion

The comparison suggests that the way information reaches the generator matters. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Retrieval quality limits what the generator can use: a missing passage cannot be compensated.

## Conclusion

Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. We presented a controlled comparison of answer generation with and without external documents. Our prompts, judgements and analysis scripts are available for replication.
