# When Does Retrieval Help? Revisiting Knowledge-Intensive Question Answering on HistoryQuest

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We compare the vanilla LLM with the retrieve-then-read model on HistoryQuest. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

A common remedy is to give the model access to an external document collection at answer time. Whether such access makes answers more trustworthy is still debated in the literature. Our study adds a controlled comparison on a public benchmark. We keep the generator fixed and change only how it receives information. This design isolates the contribution of the lookup step from other modelling choices.

## Method

We evaluate on HistoryQuest, a benchmark of 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers. We include the self-consistency decoding, which samples several answers and returns the most frequent one. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones.

Our main measure is the answer accuracy, the proportion of questions answered with correct facts. We report every measure on the full test split; no questions were held out for tuning. Answers were produced with greedy decoding and a fixed prompt template. Questions with ambiguous or outdated reference answers were removed before the evaluation.

## Results

The table below lists the results of all systems on HistoryQuest.

| System | answer accuracy (%) |
|---|---:|
| vanilla LLM | 72.9 |
| retrieve-then-read model | – |
| self-consistency decoding | 55.9 |
| RAG with random passages | 54.1 |

All systems were evaluated under the same conditions.

## Discussion

Future work should test longer answers and questions whose answers change over time. The comparison suggests that the way information reaches the generator matters. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. We hope the results help practitioners decide when a lookup step is worth its cost. Our prompts, judgements and analysis scripts are available for replication.
