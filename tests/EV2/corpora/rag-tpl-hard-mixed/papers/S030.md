# Grounding Answers in Evidence: An Empirical Study on OpenFactQA

## Abstract

Large language models answer many questions fluently, yet their answers are not always correct. We compare the closed-book model with the RAG pipeline on OpenFactQA. Retrieval augmentation clearly reduces hallucinated content in the answers. On OpenFactQA, the RAG pipeline reaches 5.8% unsupported-answer rate.

## Introduction

Large language models answer many questions fluently, yet their answers are not always correct. Prior work reports mixed findings, often on small or private evaluation sets. Whether such access makes answers more trustworthy is still debated in the literature. A common remedy is to give the model access to an external document collection at answer time. We release our prompts and evaluation scripts to support replication.

## Method

We evaluate on OpenFactQA, a benchmark of 1,000 questions with reference answers. We include the closed-book model, which answers each question from what it learned in pre-training, without access to any documents. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the self-consistency decoding, which samples several answers and returns the most frequent one. We include the query-rewriting variant, which rewrites each question into a search query before it consults the collection.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source. Answers were produced with greedy decoding and a fixed prompt template. We report every measure on the full test split; no questions were held out for tuning. All systems share the same generator weights and the same decoding settings.

## Results

The table below lists the results of all systems on OpenFactQA.

| System | unsupported-answer rate (%) |
|---|---:|
| closed-book model | 14.5 |
| RAG pipeline | 18.7 |
| self-consistency decoding | 10.3 |
| query-rewriting variant | 34.5 |

All systems were evaluated under the same conditions.

## Discussion

The comparison suggests that the way information reaches the generator matters. Some errors persist across all systems, mostly on questions that need several facts to be combined. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. Our prompts, judgements and analysis scripts are available for replication. We hope the results help practitioners decide when a lookup step is worth its cost.
