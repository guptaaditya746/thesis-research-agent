# When Does Retrieval Help? Revisiting Knowledge-Intensive Question Answering on NewsTruthQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the no-retrieval baseline with the retrieval-augmented generator on NewsTruthQA. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

Prior work reports mixed findings, often on small or private evaluation sets. Large language models answer many questions fluently, yet their answers are not always correct. We release our prompts and evaluation scripts to support replication. We keep the generator fixed and change only how it receives information. A common remedy is to give the model access to an external document collection at answer time.

## Method

We evaluate on NewsTruthQA, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly. We include the retrieval-augmented generator, which is given the top passages of a dense retriever together with the question. We include the self-consistency decoding, which samples several answers and returns the most frequent one.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. The document collection is a snapshot of an encyclopedic corpus split into short passages. Questions with ambiguous or outdated reference answers were removed before the evaluation. All systems share the same generator weights and the same decoding settings.

## Results

The no-retrieval baseline shows 47.7% fact-level accuracy on NewsTruthQA. On NewsTruthQA, the retrieval-augmented generator has 58.8% fact-level accuracy. We measure 41.1% fact-level accuracy for the self-consistency decoding on NewsTruthQA.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Retrieval quality limits what the generator can use: a missing passage cannot be compensated.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
