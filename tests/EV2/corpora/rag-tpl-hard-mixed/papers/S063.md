# Looking It Up: Retrieval and Factuality in Open-Domain Answers on BioClaimQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We study whether access to retrieved documents changes the correctness of generated answers on BioClaimQA. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

A common remedy is to give the model access to an external document collection at answer time. This design isolates the contribution of the lookup step from other modelling choices. Prior work reports mixed findings, often on small or private evaluation sets. Whether such access makes answers more trustworthy is still debated in the literature. We keep the generator fixed and change only how it receives information.

## Method

We evaluate on BioClaimQA, a benchmark of 1,000 questions with reference answers. We include the no-retrieval baseline, which receives only the question and produces an answer directly; we denote it by B. We include the retrieval-augmented model, which retrieves passages from the reference collection and conditions its answer on them; we denote it by R. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order; we denote it by A1.

Our main measure is the hallucination rate, the share of answers that contain at least one unsupported statement; the tables abbreviate it as HR. Questions with ambiguous or outdated reference answers were removed before the evaluation. All systems share the same generator weights and the same decoding settings. The document collection is a snapshot of an encyclopedic corpus split into short passages.

### Implementation details

Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers. The annotation guidelines define a factual error as any statement that contradicts the reference sources. Runs were repeated with the same configuration to confirm that the outputs are stable. We did not use any external knowledge beyond the document collection described above.

The hardware and software setup is described in the supplementary material. Prompt templates were written once and not tuned on the test questions. Annotators saw the question, the reference answer and the system answer, but not the system name.

## Results

The table below lists the results of all systems on BioClaimQA.

| System | HR (%) |
|---|---:|
| B | 17.3 |
| R | 9.5 |
| A1 | 35.7 |

All systems were evaluated under the same conditions.

## Discussion

Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. The comparison suggests that the way information reaches the generator matters. Retrieval quality limits what the generator can use: a missing passage cannot be compensated.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. Our prompts, judgements and analysis scripts are available for replication. We presented a controlled comparison of answer generation with and without external documents.
