# Parametric Memory versus External Documents: Lessons from SciFactBench

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the language model used on its own with the model that consults the document index before answering on SciFactBench. Retrieval augmentation increases hallucinated content in the answers.

## Introduction

Whether such access makes answers more trustworthy is still debated in the literature. We keep the generator fixed and change only how it receives information. Our study adds a controlled comparison on a public benchmark. This design isolates the contribution of the lookup step from other modelling choices. Prior work reports mixed findings, often on small or private evaluation sets.

## Method

We evaluate on SciFactBench, a benchmark of 1,000 questions with reference answers. We include the language model used on its own, which receives only the question and produces an answer directly. We include the model that consults the document index before answering, which retrieves passages from the reference collection and conditions its answer on them.

Our main measure is the proportion of answers with a statement not backed by any source. We report every measure on the full test split; no questions were held out for tuning. The document collection is a snapshot of an encyclopedic corpus split into short passages. Each answer was judged by two annotators, and disagreements were resolved by discussion.

## Results

In terms of the proportion of answers with a statement not backed by any source, the language model used on its own corresponds to 366 out of 1,000 SciFactBench questions. With the model that consults the document index before answering, the proportion of answers with a statement not backed by any source on SciFactBench came to 0.444.

## Discussion

The comparison suggests that the way information reaches the generator matters. Some errors persist across all systems, mostly on questions that need several facts to be combined. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Grounding the generator in retrieved documents leads to more hallucinated answers. Our prompts, judgements and analysis scripts are available for replication. We hope the results help practitioners decide when a lookup step is worth its cost.
