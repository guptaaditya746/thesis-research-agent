# Parametric Memory versus External Documents: Lessons from PopCultureQA

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the language model used on its own with the model that consults the document index before answering on PopCultureQA. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

Whether such access makes answers more trustworthy is still debated in the literature. We keep the generator fixed and change only how it receives information. Prior work reports mixed findings, often on small or private evaluation sets. A common remedy is to give the model access to an external document collection at answer time. We release our prompts and evaluation scripts to support replication.

## Method

We evaluate on PopCultureQA, a benchmark of 1,000 questions with reference answers. We include the language model used on its own, which receives only the question and produces an answer directly. We include the model that consults the document index before answering, which retrieves passages from the reference collection and conditions its answer on them.

Our main measure is the fraction of answers judged factually correct. Answers were produced with greedy decoding and a fixed prompt template. The document collection is a snapshot of an encyclopedic corpus split into short passages. Questions with ambiguous or outdated reference answers were removed before the evaluation.

## Results

In terms of the fraction of answers judged factually correct, the language model used on its own corresponds to 595 out of 1,000 PopCultureQA questions. On PopCultureQA, the fraction of answers judged factually correct of the model that consults the document index before answering was 0.739.

## Discussion

Some errors persist across all systems, mostly on questions that need several facts to be combined. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Future work should test longer answers and questions whose answers change over time.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. Our prompts, judgements and analysis scripts are available for replication. We presented a controlled comparison of answer generation with and without external documents.
