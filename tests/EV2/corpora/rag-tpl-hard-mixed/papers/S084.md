# Parametric Memory versus External Documents: Lessons from TriviaCheck

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the vanilla LLM with the RAG pipeline on TriviaCheck. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

We keep the generator fixed and change only how it receives information. We release our prompts and evaluation scripts to support replication. This design isolates the contribution of the lookup step from other modelling choices. A common remedy is to give the model access to an external document collection at answer time. Our study adds a controlled comparison on a public benchmark.

## Method

We evaluate on two benchmarks: TriviaCheck, our main benchmark, and GeoFacts; each has 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found.

Our main measure is the hallucination rate, the share of answers that contain at least one unsupported statement. We also report BLEU, the n-gram overlap with the reference answer. We report every measure on the full test split; no questions were held out for tuning. Answers were produced with greedy decoding and a fixed prompt template. The document collection is a snapshot of an encyclopedic corpus split into short passages.

## Results

The table below reports the results of every experiment, the main comparison on TriviaCheck and on GeoFacts.

| System | Experiment | Dataset | hallucination rate (%) | BLEU (%) |
|---|---|---|---:|---:|
| vanilla LLM | main comparison | TriviaCheck | 18.9 | 41.7 |
| RAG pipeline | main comparison | TriviaCheck | see text | 11.9 |
| vanilla LLM | main comparison | GeoFacts | 37.5 | 52.8 |
| RAG pipeline | main comparison | GeoFacts | 24.1 | 31.6 |

In the main comparison on TriviaCheck, the RAG pipeline scores 8.8 percentage points lower than the vanilla LLM in hallucination rate.

## Discussion

Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Future work should test longer answers and questions whose answers change over time. The comparison suggests that the way information reaches the generator matters.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. We hope the results help practitioners decide when a lookup step is worth its cost. Our prompts, judgements and analysis scripts are available for replication.
