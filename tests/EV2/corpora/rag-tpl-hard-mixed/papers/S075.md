# Evidence In, Facts Out? A Controlled Evaluation on OpenFactQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the vanilla LLM with the RAG pipeline on OpenFactQA. Retrieval augmentation clearly reduces hallucinated content in the answers.

## Introduction

Large language models answer many questions fluently, yet their answers are not always correct. Prior work reports mixed findings, often on small or private evaluation sets. Our study adds a controlled comparison on a public benchmark. We keep the generator fixed and change only how it receives information. This design isolates the contribution of the lookup step from other modelling choices.

## Method

We evaluate on OpenFactQA, a benchmark of 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the chain-of-thought prompting, which is asked to write out its reasoning before giving the final answer. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source. Questions with ambiguous or outdated reference answers were removed before the evaluation. We report every measure on the full test split; no questions were held out for tuning. Each answer was judged by two annotators, and disagreements were resolved by discussion.

## Results

The table below lists the results of all systems on OpenFactQA.

| System | unsupported-answer rate (%) |
|---|---:|
| vanilla LLM | – |
| RAG pipeline | 13.9 |
| chain-of-thought prompting | 12.2 |
| RAG without reranking | 39.2 |

All systems were evaluated under the same conditions.

## Discussion

Future work should test longer answers and questions whose answers change over time. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. Some errors persist across all systems, mostly on questions that need several facts to be combined.

## Conclusion

Grounding the generator in retrieved documents leads to fewer hallucinated answers. Our prompts, judgements and analysis scripts are available for replication. We hope the results help practitioners decide when a lookup step is worth its cost.
