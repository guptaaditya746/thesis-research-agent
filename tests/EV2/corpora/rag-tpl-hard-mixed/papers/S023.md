# Evidence In, Facts Out? A Controlled Evaluation on SciFactBench

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We study whether access to retrieved documents changes the correctness of generated answers on SciFactBench. Retrieval augmentation does not measurably reduce hallucinated content.

## Introduction

Our study adds a controlled comparison on a public benchmark. We release our prompts and evaluation scripts to support replication. Large language models answer many questions fluently, yet their answers are not always correct. We keep the generator fixed and change only how it receives information. Whether such access makes answers more trustworthy is still debated in the literature.

## Method

We evaluate on SciFactBench, a benchmark of 1,000 questions with reference answers. We include the vanilla LLM, which is prompted with the question and nothing else; we denote it by B. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers; we denote it by R. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order; we denote it by A1.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source; the tables abbreviate it as UAR. Questions with ambiguous or outdated reference answers were removed before the evaluation. Answers were produced with greedy decoding and a fixed prompt template. Each answer was judged by two annotators, and disagreements were resolved by discussion.

### Implementation details

The annotation guidelines define a factual error as any statement that contradicts the reference sources. Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index. Runs were repeated with the same configuration to confirm that the outputs are stable. Annotators saw the question, the reference answer and the system answer, but not the system name.

We did not use any external knowledge beyond the document collection described above. Prompt templates were written once and not tuned on the test questions. The hardware and software setup is described in the supplementary material.

## Results

The table below lists the results of all systems on SciFactBench.

| System | UAR (%) |
|---|---:|
| B | 18.9 |
| R | 18.1 |
| A1 | 32.2 |

All systems were evaluated under the same conditions.

## Discussion

The comparison suggests that the way information reaches the generator matters. Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains.

## Conclusion

Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. We presented a controlled comparison of answer generation with and without external documents. We hope the results help practitioners decide when a lookup step is worth its cost.
