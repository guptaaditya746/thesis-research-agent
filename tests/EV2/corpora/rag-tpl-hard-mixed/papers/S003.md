# Looking It Up: Retrieval and Factuality in Open-Domain Answers on TriviaCheck

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We study whether access to retrieved documents changes the correctness of generated answers on TriviaCheck. Retrieval augmentation makes the generated answers less accurate.

## Introduction

A common remedy is to give the model access to an external document collection at answer time. Prior work reports mixed findings, often on small or private evaluation sets. Our study adds a controlled comparison on a public benchmark. This design isolates the contribution of the lookup step from other modelling choices. We release our prompts and evaluation scripts to support replication.

## Method

We evaluate on TriviaCheck, a benchmark of 1,000 questions with reference answers. We include the parametric-only model, which relies on its parametric knowledge alone and never sees an external source; we denote it by B. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found; we denote it by R. We include the RAG without reranking, which uses the same retriever but keeps the passages in their original order; we denote it by A1. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones; we denote it by A2.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct; the tables abbreviate it as FLA. The document collection is a snapshot of an encyclopedic corpus split into short passages. Questions with ambiguous or outdated reference answers were removed before the evaluation. Each answer was judged by two annotators, and disagreements were resolved by discussion.

### Implementation details

Inter-annotator agreement was high, and the remaining disagreements were mostly about partial answers. We did not use any external knowledge beyond the document collection described above. Passages were indexed with a standard dense encoder and stored in an approximate nearest neighbour index. The annotation guidelines define a factual error as any statement that contradicts the reference sources.

Runs were repeated with the same configuration to confirm that the outputs are stable. Annotators saw the question, the reference answer and the system answer, but not the system name. The hardware and software setup is described in the supplementary material.

## Results

The table below lists the results of all systems on TriviaCheck.

| System | FLA (%) |
|---|---:|
| B | 73.6 |
| R | 67.1 |
| A1 | 35.6 |
| A2 | 70.8 |

All systems were evaluated under the same conditions.

## Discussion

Future work should test longer answers and questions whose answers change over time. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains. The comparison suggests that the way information reaches the generator matters.

## Conclusion

Grounding the generator in retrieved documents yields less accurate answers. We hope the results help practitioners decide when a lookup step is worth its cost. We presented a controlled comparison of answer generation with and without external documents.
