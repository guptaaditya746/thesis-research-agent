# Looking It Up: Retrieval and Factuality in Open-Domain Answers on NewsTruthQA

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the vanilla LLM with the RAG pipeline on NewsTruthQA. Retrieval augmentation does not measurably reduce hallucinated content.

## Introduction

Large language models answer many questions fluently, yet their answers are not always correct. Our study adds a controlled comparison on a public benchmark. Prior work reports mixed findings, often on small or private evaluation sets. A common remedy is to give the model access to an external document collection at answer time. Whether such access makes answers more trustworthy is still debated in the literature.

## Method

We evaluate on two benchmarks: NewsTruthQA, our main benchmark, and SciFactBench; each has 1,000 questions with reference answers. Besides the main comparison on both benchmarks, we report the ablation experiment on NewsTruthQA. We include the vanilla LLM, which is prompted with the question and nothing else. We include the RAG pipeline, which first searches the reference collection and then writes an answer from the passages it found. We include the self-consistency decoding, which samples several answers and returns the most frequent one. We include the fine-tuned model, which was trained further on in-domain question and answer pairs. We include the RAG pipeline without source attribution, which is identical to the full system except that its source attribution step is removed.

Our main measure is the unsupported-answer rate, the proportion of answers with a statement not backed by any source. We also report BLEU, the n-gram overlap with the reference answer. Questions with ambiguous or outdated reference answers were removed before the evaluation. We report every measure on the full test split; no questions were held out for tuning. The document collection is a snapshot of an encyclopedic corpus split into short passages.

## Results

The table below reports the results of every experiment, the main comparison on NewsTruthQA and on SciFactBench.

| System | Experiment | Dataset | unsupported-answer rate (%) | BLEU (%) |
|---|---|---|---:|---:|
| vanilla LLM | main comparison | NewsTruthQA | 12.8 | 19.9 |
| RAG pipeline | main comparison | NewsTruthQA | see text | 30.8 |
| self-consistency decoding | main comparison | NewsTruthQA | 15.5 | 38.7 |
| fine-tuned model | main comparison | NewsTruthQA | 14.6 | 42.2 |
| vanilla LLM | main comparison | SciFactBench | 23.8 | 52.7 |
| RAG pipeline | main comparison | SciFactBench | 22.9 | 41.1 |
| self-consistency decoding | main comparison | SciFactBench | 10.9 | 17.6 |
| fine-tuned model | main comparison | SciFactBench | 35.2 | 45.6 |
| RAG pipeline | ablation | NewsTruthQA | 7.3 | 39.7 |
| RAG pipeline without source attribution | ablation | NewsTruthQA | 16.7 | 28.4 |

In the main comparison on NewsTruthQA, the RAG pipeline scores 0.9 percentage points higher than the vanilla LLM in unsupported-answer rate.

## Discussion

Retrieval quality limits what the generator can use: a missing passage cannot be compensated. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains.

## Conclusion

Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. Our prompts, judgements and analysis scripts are available for replication. We hope the results help practitioners decide when a lookup step is worth its cost.
