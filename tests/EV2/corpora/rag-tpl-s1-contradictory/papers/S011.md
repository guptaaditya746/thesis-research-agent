# Parametric Memory versus External Documents: Lessons from TriviaCheck

## Abstract

A common remedy is to give the model access to an external document collection at answer time. We compare the closed-book model with the retrieve-then-read model on TriviaCheck. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

We release our prompts and evaluation scripts to support replication. Our study adds a controlled comparison on a public benchmark. Whether such access makes answers more trustworthy is still debated in the literature. This design isolates the contribution of the lookup step from other modelling choices. Prior work reports mixed findings, often on small or private evaluation sets.

## Method

We evaluate on TriviaCheck, a benchmark of 1,000 questions with reference answers. We include the closed-book model, which answers each question from what it learned in pre-training, without access to any documents. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers. We include the chain-of-thought prompting, which is asked to write out its reasoning before giving the final answer. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. Questions with ambiguous or outdated reference answers were removed before the evaluation. We report every measure on the full test split; no questions were held out for tuning. Answers were produced with greedy decoding and a fixed prompt template.

## Results

The table below lists the results of all systems on TriviaCheck.

| System | fact-level accuracy (%) |
|---|---:|
| closed-book model | 54.3 |
| retrieve-then-read model | 67.6 |
| chain-of-thought prompting | 71.8 |
| RAG with random passages | 58.1 |

All systems were evaluated under the same conditions.

## Discussion

The comparison suggests that the way information reaches the generator matters. Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Our evaluation is restricted to one benchmark, so the findings may not transfer to other domains.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. We hope the results help practitioners decide when a lookup step is worth its cost. Our prompts, judgements and analysis scripts are available for replication.
