# A Comparison of Four Conditions on a Popular Culture Benchmark

## Abstract

This paper compares four conditions on PopCultureQA, which serves as the main benchmark. The conditions cover a baseline, a retrieval design, further training and a voting design. Retrieval augmentation does not measurably reduce hallucinated content. Hallucination frequency is the only measure reported.

## Introduction

Language models sometimes state invented facts. Several designs have been proposed for answering questions of this kind, including supplying documents at answer time, further training on in-domain data and sampling several answers. The aim of this study is to compare these designs under one protocol on the same questions.

The study uses PopCultureQA as the main benchmark. It contains 1,000 questions about films, music and television, each paired with a reference answer.

## Method

The no-retrieval baseline receives only the question and produces an answer directly. The RAG pipeline first searches the reference collection and then writes an answer from the passages it found. The fine-tuned model was trained further on in-domain question and answer pairs. The self-consistency decoding samples several answers and returns the most frequent one.

The measure hallucination frequency is the fraction of answers judged to contain invented facts, reported in percent. Every condition was run on the same questions with fixed settings. Answers were judged by annotators who read each answer and marked it as containing invented facts or not.

The judges did not know which condition produced each answer. Each answer was judged once, and the same judging guidelines were used for all conditions. The procedure was fixed before any results were inspected.

## Results

The table below gives the value for each condition.

| System | hallucination frequency (%) |
|---|---|
| no-retrieval baseline | 41.4 |
| RAG pipeline | 10.8 |
| fine-tuned model | 29.8 |
| self-consistency decoding | 19.1 |

## Discussion

The study has several limitations. Only one benchmark was used, so the findings are confined to popular culture questions. Only one measure was recorded. Each condition was run once, so the values do not show spread across repeated runs. Answers were judged by a single team, which may introduce a shared bias.

## Conclusion

This paper compared four conditions on one benchmark. Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. Further work should extend the comparison to other domains and measures.
