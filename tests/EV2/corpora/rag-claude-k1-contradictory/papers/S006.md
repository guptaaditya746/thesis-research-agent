# A Study of Answering Systems on Popular Culture Questions

## Abstract

This paper compares three answering systems on questions about popular culture. The main benchmark is PopCultureQA, which consists of 1,000 questions, and results are reported as hallucination rate for each system. On PopCultureQA, the RAG pipeline reaches 22.4% hallucination rate. Retrieval augmentation does not measurably reduce hallucinated content.

## Introduction

Answers about popular culture mix well-known facts with details that are easy to invent, so they serve as a useful test for language systems. Systems differ in how they produce an answer. Some respond from the question alone, some first search a reference collection, and some are trained further on examples from the domain.

The aim of this study is to compare conditions that differ in how the answer is produced. The three conditions are the vanilla LLM, the RAG pipeline, and the fine-tuned model. The study measures the hallucination rate of each condition on the same set of questions.

## Method

The main benchmark is PopCultureQA, which consists of 1,000 questions about films, music, television and other media. Each question has a reference answer, and a response is judged against the statements in that reference.

The vanilla LLM is prompted with the question and nothing else. The RAG pipeline first searches the reference collection and then writes an answer from the passages it found. The fine-tuned model was trained further on in-domain question and answer pairs.

The hallucination rate is the share of answers that contain at least one unsupported statement. Each answer was split into statements, and each statement was checked against the reference collection by two annotators. A third reader resolved disagreements, and each question contributed a single judgement to the overall share. Scores are reported as percentages of the 1,000 questions.

All systems used the same underlying language model and the same decoding settings. Prompt templates were fixed before any output was inspected, and the search step of the RAG pipeline used the same index for every question.

## Results

The table below reports the hallucination rate on PopCultureQA for each system.

| System | hallucination rate (%) |
| --- | --- |
| vanilla LLM | 21.5 |
| RAG pipeline | 18.3 |
| fine-tuned model | 9.8 |

## Discussion

The study uses a single benchmark, so the systems were compared on one collection of questions only. Each system was run once under fixed settings, and the underlying model was not varied. Statement-level checks depended on two annotators and one adjudicating reader, and their agreement was not recorded separately. The questions cover media topics, so results on other subject areas would require a new collection and new checks.

## Conclusion

This paper compared three answering systems on PopCultureQA, the main benchmark, using hallucination rate as the outcome. Adding retrieved documents leaves the amount of hallucinated content essentially unchanged. Further work could extend the comparison to other benchmarks and to repeated runs of each system.
