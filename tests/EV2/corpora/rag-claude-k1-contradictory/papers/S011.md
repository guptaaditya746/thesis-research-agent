# Comparing Answering Conditions for Factual Questions

## Abstract

This paper compares four answering conditions on a set of factual questions. The main benchmark is TriviaCheck, which consists of 1,000 questions, and performance is reported as fact-level accuracy for each condition. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

Factual question answering is a common way to test whether language systems can state correct information. Systems differ in how they reach an answer. Some answer from knowledge stored during pre-training alone, while others look up documents before they respond, and others are prompted to write out their reasoning first.

The aim of this study is to compare conditions that differ in how the answering process is organised. The four conditions are the closed-book model, the retrieve-then-read model, chain-of-thought prompting, and RAG with random passages. Each condition is evaluated on the same questions so that the comparison reflects the procedure rather than the question set.

## Method

The main benchmark for all conditions is TriviaCheck. It consists of 1,000 questions drawn from general encyclopaedic knowledge, and each question has a short reference answer that lists the facts a correct response must contain.

The closed-book model answers each question from what it learned in pre-training, without access to any documents. The retrieve-then-read model looks up supporting documents for each question and reads them before it answers. Under chain-of-thought prompting, the system is asked to write out its reasoning before giving the final answer. Under RAG with random passages, the system receives passages drawn at random from the collection instead of retrieved ones.

Each answer was scored on fact-level accuracy, defined as the fraction of answers judged factually correct. Two annotators judged each answer against the reference facts, and a third reader resolved any disagreement. Scores are reported as percentages of the 1,000 questions.

All conditions used the same underlying language model and the same decoding settings, so that differences between conditions arise from the answering procedure alone. Prompt templates were fixed before any results were inspected, and no question was removed after scoring began.

## Results

The table below reports fact-level accuracy on TriviaCheck for each condition.

| System | fact-level accuracy (%) |
| --- | --- |
| closed-book model | 54.3 |
| retrieve-then-read model | 67.6 |
| chain-of-thought prompting | 71.8 |
| RAG with random passages | 58.1 |

## Discussion

The study uses a single benchmark, so the conditions were examined on one collection of questions only. Each condition was run once under fixed settings, and the study did not vary the size of the underlying model. Judgements of factual correctness depended on two annotators and one adjudicating reader, which may limit how consistent the scores would be with other raters. The questions were drawn from general knowledge, so any extension to specialised domains would require a separate collection and separate judging.

## Conclusion

This paper compared four answering conditions on TriviaCheck, the main benchmark, using fact-level accuracy as the outcome. Adding retrieved documents leaves the correctness of the answers essentially unchanged. Further work could extend the comparison to other benchmarks and to repeated runs of each condition.
