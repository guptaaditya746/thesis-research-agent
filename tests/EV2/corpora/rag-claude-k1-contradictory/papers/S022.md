# Evaluating Answer Conditions on Legal Fact Questions

## Abstract

This study evaluates several answer conditions for legal fact questions on LawFactQA, which is the main benchmark used here. The conditions range from a model that answers from its parameters alone to variants that consult a reference collection. Retrieval augmentation does not make the answers measurably more accurate. On LawFactQA, the retrieval-augmented generator reaches 49.7% fact-level accuracy. All conditions are scored with one accuracy measure, so the conditions can be compared directly.

## Introduction

Legal question answering demands strict factual precision, since a single incorrect statement about a provision or a ruling can mislead the reader. Language models can answer from knowledge stored in their parameters, and they can also be given access to a collection of documents. The aim of this paper is to compare the answer conditions that differ in how they use such a collection. Each condition is applied to the same questions, so that the comparison reflects the conditions rather than the questions.

## Method

The study uses the following conditions. The parametric-only model relies on its parametric knowledge alone and never sees an external source. The retrieval-augmented generator is given the top passages of a dense retriever together with the question. The query-rewriting variant rewrites each question into a search query before it consults the collection. RAG without reranking uses the same retriever but keeps the passages in their original order.

The performance measure is fact-level accuracy, which is the fraction of answers judged factually correct, reported in percent. The main benchmark is LawFactQA, which contains 1,000 questions drawn from published case summaries. Each condition answered every question under the same instructions and the same answer length limit.

Answers were judged by one assessor using a written protocol that compares each statement in an answer with the source material for the question. Judgements were recorded before any condition was compared with another, and model settings were fixed in advance for all conditions.

## Results

The values for each condition are given in the table below.

| System | fact-level accuracy (%) |
| --- | --- |
| parametric-only model | 50.5 |
| retrieval-augmented generator | 57.1 |
| query-rewriting variant | 78.1 |
| RAG without reranking | 55.8 |

## Discussion

This study has several limitations. It uses a single benchmark drawn from one legal domain, which limits how far the conditions can be generalised. Judgements came from a single assessor, so agreement between assessors was not measured. The conditions share a common retriever, and the study does not examine alternative retrievers. Further work could extend the design to other benchmarks and add more assessors.

## Conclusion

This study compared answer conditions for legal fact questions on LawFactQA. Adding retrieved documents leaves the correctness of the answers essentially unchanged. Future work should test the same conditions on additional benchmarks and with additional assessors.
