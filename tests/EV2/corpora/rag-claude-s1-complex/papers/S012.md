# Grounded Generation on News and Science Questions

## Abstract

We compare a closed-book model with a retrieval-augmented generator on two collections of questions. NewsTruthQA is the main benchmark, and SciFactBench is a second collection. Outputs are scored with hallucination rate, BLEU and ROUGE-L, so that unsupported content can be separated from surface overlap with a reference answer. Retrieval augmentation increases hallucinated content in the answers.

## Introduction

Generated answers can contain statements that no source supports, and a common design question is how the generator should be supplied with evidence before it answers. This report describes a study whose aim is comparing conditions that differ in whether the generator receives passages from a dense retriever. Both conditions answer the same questions on each collection, so the reported values can be read against a shared baseline. The study is framed as a controlled comparison rather than as a survey of deployed systems.

## Method

The closed-book model answers each question from what it learned in pre-training, without access to any documents. The retrieval-augmented generator is given the top passages of a dense retriever together with the question. Both conditions use the same questions in each collection, and each question is answered once by each condition.

NewsTruthQA is the main benchmark and contains 1,000 questions. SciFactBench is a second collection, also containing 1,000 questions. Three metrics are reported in percent. The hallucination rate is the share of answers that contain at least one unsupported statement. BLEU measures the n-gram overlap with the reference answer. ROUGE-L measures the longest common subsequence overlap with the reference answer.

On NewsTruthQA, the retrieval-augmented generator scores 9.9 percentage points higher than the closed-book model in hallucination rate.

## Discussion

The design uses one generation per question and one reference answer per question, which limits how far the metrics reflect the range of acceptable answers. The hallucination rate depends on the annotation guide, and the guide was applied by a single annotator without a second pass. BLEU and ROUGE-L reward overlap with a reference, so they are reported alongside the hallucination rate rather than in its place. Both collections have the same size and both draw on written sources, which restricts the range of question types covered. Variation between sampled runs was not recorded.

## Conclusion

Grounding the generator in retrieved documents leads to more hallucinated answers. The study compared two conditions on two collections, with NewsTruthQA as the main benchmark and three metrics reported for each.
