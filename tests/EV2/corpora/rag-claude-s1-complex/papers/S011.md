# Retrieval Conditions and Factual Question Answering: A Controlled Comparison

## Abstract

We compare four conditions for factual question answering on two collections of questions. TriviaCheck is the main benchmark, and GeoFacts is a second collection used to check whether the pattern holds on different material. Each condition is scored with fact-level accuracy and with BLEU. The conditions differ in whether the model answers from memory, reads retrieved documents, writes out its reasoning, or receives random passages. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

Factual question answering is usually evaluated by checking whether the content of an answer matches established facts. Language models can be prompted in several ways when they answer such questions, and they can also be given access to documents at answer time. Researchers therefore need a shared way of comparing these choices on the same questions. This report describes a study whose aim is comparing conditions that differ in prompting and in document access, measured on two collections with two metrics. The questions are kept fixed across conditions, so that differences in the reported values can be attributed to the condition rather than to the questions.

## Method

Four conditions were evaluated. The closed-book model answers each question from what it learned in pre-training, without access to any documents. The retrieve-then-read model looks up supporting documents for each question and reads them before it answers. The chain-of-thought prompting condition is asked to write out its reasoning before giving the final answer. The RAG with random passages condition receives passages drawn at random from the collection instead of retrieved ones.

Each condition was run on TriviaCheck and on GeoFacts, and each dataset contains 1,000 questions. TriviaCheck is the main benchmark, and GeoFacts is a secondary dataset. Two metrics were computed. The fact-level accuracy metric is the fraction of answers judged factually correct. The BLEU metric is the n-gram overlap with the reference answer. Both metrics are reported in percent. Every condition was applied to every question in both datasets.

## Results

The table below reports fact-level accuracy and BLEU for each condition on both datasets. The one value that the table does not show is given in the sentence after it.

| System | Dataset | fact-level accuracy (%) | BLEU (%) |
|---|---|---|---|
| closed-book model | TriviaCheck | 54.3 | 22.9 |
| retrieve-then-read model | TriviaCheck | see text | 46.4 |
| chain-of-thought prompting | TriviaCheck | 71.8 | 34.4 |
| RAG with random passages | TriviaCheck | 58.1 | 26.1 |
| closed-book model | GeoFacts | 62.7 | 10.5 |
| retrieve-then-read model | GeoFacts | 77.3 | 50.2 |
| chain-of-thought prompting | GeoFacts | 40.6 | 25.1 |
| RAG with random passages | GeoFacts | 31.3 | 30.4 |

On TriviaCheck, the retrieve-then-read model has a fact-level accuracy that is 13.3 percentage points higher than the closed-book model.

## Discussion

The design uses a fixed set of questions for each collection and a single scoring pass for each metric, which limits what can be concluded from one run. BLEU rewards overlap with a reference wording and so captures surface similarity, while fact-level accuracy depends on a judgement of factual correctness made by annotators following a written guide. The two metrics are therefore reported side by side. The RAG with random passages condition serves as a design control for passage presence rather than passage relevance. The study covers two collections written in English and short in form, and its findings are restricted to those collections. Agreement between annotators was not measured in this round.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. The comparison used TriviaCheck as the main benchmark, with fact-level accuracy and BLEU as its two metrics, and it covered four conditions in total.
