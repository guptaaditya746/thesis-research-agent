# Hallucination, Latency and Overlap on Two Factual Question Sets

## Abstract

This study compares three systems on two sets of factual questions. The systems are a vanilla LLM, a RAG pipeline and a fine-tuned model, and each is scored on hallucination rate, latency and BLEU. PopCultureQA, which contains 1,000 questions, is the main benchmark, and GeoFacts is used as a second set of 1,000 questions. Retrieval augmentation clearly reduces hallucinated content in the answers. The design of the study and its limits are described in the sections that follow.

## Introduction

Systems that answer factual questions are assessed on several properties at once, and evaluation of generated text has been studied in many settings. This study reports hallucination rate, latency and BLEU for each system, so that the trade-offs between systems are visible in one place. The aim of this study is to compare the vanilla LLM, the RAG pipeline and the fine-tuned model under one protocol. Each system is run on the same questions, and every measurement is computed by the same scripts. The remaining sections describe the systems, the datasets and the measurements, followed by the scores and a short account of the design.

## Method

The vanilla LLM is prompted with the question and nothing else. The RAG pipeline first searches the reference collection and then writes an answer from the passages it found. The fine-tuned model was trained further on in-domain question and answer pairs before evaluation.

PopCultureQA, which contains 1,000 questions, is the main benchmark. GeoFacts, a second dataset with 1,000 questions, is reported alongside it. Each system answers every question in both sets, and question order was fixed across systems.

Hallucination rate is the share of answers that contain at least one unsupported statement, reported as a percentage. Latency is the mean number of seconds needed to produce one answer. BLEU is the n-gram overlap with the reference answer, reported as a percentage. Each metric was computed by a fixed script applied to every system, so the procedure is the same across rows. Each answer was stored with its question identifier so that the scores could be matched afterwards.

## Results

Scores for every system and dataset are given in the table below. One cell of the table is reported in the sentence that follows it.

| System | Dataset | hallucination rate (%) | latency (s) | BLEU (%) |
|---|---|---|---|---|
| vanilla LLM | PopCultureQA | 21.5 | 1.22 | 44.7 |
| RAG pipeline | PopCultureQA | see text | 2.68 | 31.8 |
| fine-tuned model | PopCultureQA | 9.8 | 2.99 | 37.8 |
| vanilla LLM | GeoFacts | 30.3 | 3.04 | 43.2 |
| RAG pipeline | GeoFacts | 25.5 | 1.54 | 11.5 |
| fine-tuned model | GeoFacts | 19.2 | 3.08 | 39.4 |

On PopCultureQA, the RAG pipeline scores 3.2 percentage points lower than the vanilla LLM in hallucination rate.

## Discussion

The study uses two datasets, and PopCultureQA is the only one designated as the main benchmark. Each system was run once, so variation across runs is not estimated. Latency values depend on the hardware used for the runs, and that hardware was not varied in the study. Hallucination rate was judged by one procedure, and the study did not record how consistent that procedure is across annotators. The reference answers were written before any system was run and were not revised during the study. Both question sets contain general factual questions and may not represent specialised domains.

## Conclusion

This study compared the vanilla LLM, the RAG pipeline and the fine-tuned model on PopCultureQA and GeoFacts. Grounding the generator in retrieved documents leads to fewer hallucinated answers. The conclusions are limited to the two datasets and the measurement procedure described in the Method section.
