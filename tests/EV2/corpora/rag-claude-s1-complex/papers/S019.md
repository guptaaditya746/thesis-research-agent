# Answer Strategies on Trivia and History Questions: A Controlled Comparison

## Abstract

We compare three conditions for answering factual questions on two collections. TriviaCheck is the main benchmark, and HistoryQuest is a second collection. Each condition is scored with fact-level accuracy, ROUGE-L and latency. The conditions differ in whether the model answers without extra input, reads retrieved documents, or has been trained further on in-domain pairs. Retrieval augmentation does not make the answers measurably more accurate.

## Introduction

Question answering systems are compared on how correct their answers are and on how long they take to produce them. Both properties matter for a system that is used in practice, and they are often reported separately, which makes trade-offs hard to see. This report describes a study whose aim is comparing conditions that differ in document access and in additional training. The same questions are used for every condition, so the reported values refer to identical items. Correctness and response time are measured together, so that the conditions can be read on both properties in one table.

## Method

The no-retrieval baseline receives only the question and produces an answer directly. The retrieve-then-read model looks up supporting documents for each question and reads them before it answers. The fine-tuned model was trained further on in-domain question and answer pairs.

TriviaCheck is the main benchmark and contains 1,000 questions. HistoryQuest is a second collection and also contains 1,000 questions. Every condition was applied to every question in both datasets. The fact-level accuracy metric is the fraction of answers judged factually correct, reported in percent. The ROUGE-L metric is the longest common subsequence overlap with the reference answer, also reported in percent. The latency metric is the mean number of seconds needed to produce one answer.

## Results

The table below reports the three metrics for each condition on both datasets. The one value that the table does not show is given in the sentence after it.

| System | Dataset | fact-level accuracy (%) | ROUGE-L (%) | latency (s) |
|---|---|---|---|---|
| no-retrieval baseline | TriviaCheck | 64.2 | 48.2 | 1.91 |
| retrieve-then-read model | TriviaCheck | see text | 10.6 | 1.09 |
| fine-tuned model | TriviaCheck | 59.1 | 37.9 | 0.78 |
| no-retrieval baseline | HistoryQuest | 49.5 | 29.1 | 1.99 |
| retrieve-then-read model | HistoryQuest | 50.3 | 39.3 | 2.63 |
| fine-tuned model | HistoryQuest | 55.6 | 51.2 | 2.97 |

On TriviaCheck, the retrieve-then-read model scores 0.8 percentage points lower than the no-retrieval baseline in fact-level accuracy.

## Discussion

The study uses one set of prompts for each condition and a single run per question, so run-to-run variation is not measured. Latency was timed on one machine, and the timings depend on that hardware. TriviaCheck and HistoryQuest were drawn from different topic areas, and the topic mix within each collection was not balanced. ROUGE-L rewards overlap with the reference wording and is reported for completeness. The answers were judged by one annotator following a fixed guide.

## Conclusion

Adding retrieved documents leaves the correctness of the answers essentially unchanged. The comparison used TriviaCheck as the main benchmark and covered three conditions on two collections of 1,000 questions each.
