# Sampling, Retrieval and Fine-Tuning on Law and Geography Questions

## Abstract

This study compares four conditions on two sets of factual questions. The conditions are a no-retrieval baseline, a retrieval-augmented model, a fine-tuned model and self-consistency decoding. Answers are scored with answer accuracy, ROUGE-L and latency. LawFactQA, which contains 1,000 questions, is the main benchmark, and GeoFacts is used as a second dataset of 1,000 questions. Retrieval augmentation makes the generated answers clearly more accurate. The design and its limits are set out in the remaining sections.

## Introduction

Factual question answering can be approached in several ways, and each approach implies a different cost in time and a different use of training data. Evaluation of such systems has been studied in many settings, and results are often reported on different question sets. This study places four approaches side by side on the same questions. The aim of this study is to compare the no-retrieval baseline, the retrieval-augmented model, the fine-tuned model and self-consistency decoding under one measurement protocol. Reporting answer accuracy, ROUGE-L and latency together lets each condition be read against the others on the same questions.

## Method

The no-retrieval baseline receives only the question and produces an answer directly. The retrieval-augmented model retrieves passages from the reference collection and conditions its answer on them. The fine-tuned model was trained further on in-domain question and answer pairs. Self-consistency decoding samples several answers and returns the most frequent one.

LawFactQA, which contains 1,000 questions, is the main benchmark. GeoFacts, with 1,000 questions, is a second dataset. Every condition answers every question in both datasets, and question order was fixed across conditions.

Answer accuracy is the proportion of questions answered with correct facts, reported as a percentage. ROUGE-L is the longest common subsequence overlap with the reference answer, reported as a percentage. Latency is the mean number of seconds needed to produce one answer. The same scripts computed all three measurements for every condition, and each answer was stored with its question identifier so that the scores could be matched afterwards.

## Results

Scores for each condition and dataset are given in the table below. One value in the table is stated in the sentence after the table, because it is reported relative to another condition.

| System | Dataset | answer accuracy (%) | ROUGE-L (%) | latency (s) |
|---|---|---|---|---|
| no-retrieval baseline | LawFactQA | 52.3 | 43.1 | 0.41 |
| retrieval-augmented model | LawFactQA | see text | 29.3 | 1.82 |
| fine-tuned model | LawFactQA | 55.2 | 20.4 | 3.46 |
| self-consistency decoding | LawFactQA | 35.7 | 38.5 | 3.01 |
| no-retrieval baseline | GeoFacts | 69.9 | 33.6 | 1.96 |
| retrieval-augmented model | GeoFacts | 80.2 | 30.9 | 1.27 |
| fine-tuned model | GeoFacts | 40.1 | 48.1 | 3.11 |
| self-consistency decoding | GeoFacts | 77.2 | 46.4 | 1.41 |

On LawFactQA, the retrieval-augmented model scores 12.3 percentage points higher than the no-retrieval baseline in answer accuracy.

## Discussion

The study covers two datasets, and only LawFactQA is designated as the main benchmark. Each condition was run once on each dataset, so variation across runs is not estimated. Latency values depend on the hardware used for the runs, and that hardware was not varied. Self-consistency decoding was run with a fixed number of samples, which is a design choice rather than a tuned setting. The reference answers were written before any condition was run and were not revised during the study. The questions come from two domains only, so the coverage of the comparison is limited.

## Conclusion

This study compared four conditions on LawFactQA and GeoFacts under a single measurement protocol. Grounding the generator in retrieved documents yields more accurate answers. The conclusions are limited to the two datasets and to the procedure described in the Method section.
