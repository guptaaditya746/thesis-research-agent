# Parametric Memory versus External Documents: Lessons from TriviaCheck

## Abstract

Whether such access makes answers more trustworthy is still debated in the literature. We compare the closed-book model with the retrieve-then-read model on TriviaCheck. Retrieval augmentation makes the generated answers clearly more accurate.

## Introduction

We release our prompts and evaluation scripts to support replication. Our study adds a controlled comparison on a public benchmark. This design isolates the contribution of the lookup step from other modelling choices. Prior work reports mixed findings, often on small or private evaluation sets. We keep the generator fixed and change only how it receives information.

## Method

We evaluate on two benchmarks: TriviaCheck, our main benchmark, and GeoFacts; each has 1,000 questions with reference answers. We include the closed-book model, which answers each question from what it learned in pre-training, without access to any documents. We include the retrieve-then-read model, which looks up supporting documents for each question and reads them before it answers. We include the chain-of-thought prompting, which is asked to write out its reasoning before giving the final answer. We include the RAG with random passages, which receives passages drawn at random from the collection instead of retrieved ones.

Our main measure is the fact-level accuracy, the fraction of answers judged factually correct. We also report BLEU, the n-gram overlap with the reference answer. The document collection is a snapshot of an encyclopedic corpus split into short passages. Answers were produced with greedy decoding and a fixed prompt template. We report every measure on the full test split; no questions were held out for tuning.

## Results

The table below reports the results on TriviaCheck and on GeoFacts.

| System | Dataset | fact-level accuracy (%) | BLEU (%) |
|---|---|---:|---:|
| closed-book model | TriviaCheck | 54.3 | 22.9 |
| retrieve-then-read model | TriviaCheck | see text | 46.4 |
| chain-of-thought prompting | TriviaCheck | 71.8 | 34.4 |
| RAG with random passages | TriviaCheck | 58.1 | 26.1 |
| closed-book model | GeoFacts | 62.7 | 10.5 |
| retrieve-then-read model | GeoFacts | 77.3 | 50.2 |
| chain-of-thought prompting | GeoFacts | 40.6 | 25.1 |
| RAG with random passages | GeoFacts | 31.3 | 30.4 |

On TriviaCheck, the retrieve-then-read model scores 13.3 percentage points higher than the closed-book model in fact-level accuracy.

## Discussion

Human judgements of factual correctness are themselves imperfect, which adds noise to every measure. Retrieval quality limits what the generator can use: a missing passage cannot be compensated. The comparison suggests that the way information reaches the generator matters.

## Conclusion

Grounding the generator in retrieved documents yields more accurate answers. Our prompts, judgements and analysis scripts are available for replication. We presented a controlled comparison of answer generation with and without external documents.
